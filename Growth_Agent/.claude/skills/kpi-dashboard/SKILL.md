# KPI 대시보드 스킬

> 핵심 성과 지표를 인터랙티브 HTML 대시보드로 시각화합니다.

## 실행 절차

### Step 1: 데이터 수집

`$ARGUMENTS`에서 데이터 소스를 파악합니다.

- 데이터 파일 → CSV/JSON 파싱
- 서비스명 → 관련 산출물 탐색 (`Growth_Agent/outputs/`, `Income_Factory/`)
- 없으면 → 샘플 데이터로 대시보드 템플릿 생성

### Step 2: 대시보드 구성

| 섹션        | 포함 지표              | 시각화                |
| ----------- | ---------------------- | --------------------- |
| Overview    | DAU, MAU, 매출, 설치수 | 카드 + 전일 대비 변동 |
| AAARRR 퍼널 | 단계별 전환율          | 퍼널 차트             |
| 리텐션      | D1/D7/D30              | 라인 차트 (코호트)    |
| 수익        | ARPU, ARPPU, LTV       | 바 차트               |
| 트렌드      | 주간/월간 추이         | 라인 차트             |

### Step 3: HTML 대시보드 생성

기술 스펙:

- **자체 완결형** (외부 의존성 없음)
- 다크 테마 (`#0d1117` 배경, HKD852 표준)
- 반응형 그리드 레이아웃
- 인라인 SVG 차트 (Chart.js/D3 없이 순수 SVG)
- 인터랙티브: 호버 툴팁, 필터 토글

레이아웃:

```
┌─────────────────────────────────────┐
│  HKD852 KPI Dashboard     [날짜]    │
├─────┬─────┬─────┬─────┬────────────┤
│ DAU │ MAU │매출 │설치 │ 전일 대비   │
├─────┴─────┴─────┴─────┴────────────┤
│         AAARRR 퍼널 차트            │
├──────────────────┬─────────────────┤
│  리텐션 커브      │  수익 분석       │
├──────────────────┴─────────────────┤
│           주간/월간 트렌드           │
└─────────────────────────────────────┘
```

### Step 4: 데이터 바인딩

- 데이터가 있으면 → 실제 수치 반영
- 데이터가 없으면 → 플레이스홀더 + 데이터 입력 가이드
- 자동 계산: 전환율, 전일 대비 변동률, 코호트 감소율

### Step 5: 산출물 저장

산출물 경로: `Growth_Agent/outputs/kpi_dashboard_YYYY-MM-DD.html`

## 인자 처리

- `$ARGUMENTS`가 비어있으면: 샘플 데이터 기반 템플릿 대시보드
- 서비스명 지정 시: 해당 서비스 맞춤 대시보드
  - 예: `/kpi-dashboard 화투 로그라이크`
- 데이터 파일 지정 시: 실데이터 반영 대시보드
  - 예: `/kpi-dashboard data/kpi_202602.csv`

## HTML 표준

HKD852 HTML 산출물 표준 준수:

- 외부 CDN/라이브러리 없이 자체 완결
- 다크 테마 필수 (배경 `#0d1117`, 텍스트 `#e6edf3`)
- 브라우저에서 바로 열 수 있는 단일 파일
- 인쇄 시 라이트 모드 자동 전환 (`@media print`)
