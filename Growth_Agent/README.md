# Growth Agent

HKD852 스튜디오의 **CEO 직속 성장전략 매니저** 에이전트입니다.

## 주요 역할

- AAARRR(해적지표) 퍼널 전략 수립 및 진단
- 온보딩 마이크로 퍼널 설계 및 이탈 분석
- 핵심 KPI 모니터링 대시보드 생성

## 스킬

| 명령어               | 설명                                  |
| -------------------- | ------------------------------------- |
| `/funnel-audit`      | AAARRR 퍼널 진단 → 병목 식별 → 개선안 |
| `/onboarding-review` | 온보딩 9단계 플로우 리뷰              |
