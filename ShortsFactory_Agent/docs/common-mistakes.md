# 쇼츠 파이프라인 자주 발생하는 실수 & 해결 기록

> 재발 방지를 위한 트러블슈팅 로그

---

## 1. 영어 약어 TTS 발음 이상 (v3.7 수정)

**증상**: MBTI, ENFP, AI 등 영어 약어를 TTS가 이상하게 읽음
**원인**: Qwen3-TTS CustomVoice가 영어 알파벳을 한국어 문맥에서 제대로 발음하지 못함
**해결**: `_convert_english_to_korean_pronunciation()` 함수 추가 (video_composer.py)

- TTS 텍스트에서만 영어→한국어 발음 자동 변환
- 자막은 원본 유지 (MBTI, ENFP 등 그대로 표시)
- `preprocess_korean_for_tts()` 0.9단계에 삽입

**예시**:
| 자막 | TTS 발음 |
|------|---------|
| MBTI | 엠비티아이 |
| ENFP | 이엔에프피 |
| AI | 에이아이 |

**에피소드**: EP049 (MBTI 초능력) — 수정 전 발음 이상 → 수정 후 재렌더링

## 2. 영어 약어 자막 싱크 미스매칭 (v3.7 수정)

**증상**: 영어 약어가 포함된 자막 구절이 0.2초만 표시되거나 위치가 틀어짐
**원인**: `_normalize_for_match()`에서 영어→한국어 발음 변환을 하지 않아 Whisper 출력과 매칭 실패

- 자막 텍스트: `"INFJ가 떠 있다."` → normalize → `"infj가떠있다"` (영어 소문자 그대로)
- Whisper 출력: `"아예 내프재이가 또 있다"` → normalize → `"아예내프재이가또있다"` (한국어)
- `"infj"` vs `"아예내프재이"` → **매칭 불가** → 보간 fallback → 타이밍 부정확
  **해결**: `_normalize_for_match()`에서도 `_convert_english_to_korean_pronunciation()` 적용
- 변환 후: `"INFJ가 떠 있다."` → `"아이엔에프제이가떠있다"` → Whisper `"아예내프재이"` 와 퍼지 매칭 가능
- 최종 정규식도 `[^가-힣a-z]` → `[^가-힣]` 변경 (영어 이미 한국어로 변환됨)

**에피소드**: EP052 (MBTI 머리 위) — 청크[13] "INFJ가 떠 있다." 0.20초, 청크[14] "지원자보다 면접관이" 0.22초

## 3. CustomVoice speed 파라미터 무시 (미해결)

**증상**: `render_config.speed`를 1.3이나 1.0으로 설정해도 영상 길이가 동일
**원인**: mlx_audio의 `generate_audio()`가 CustomVoice(ref_audio) 모드에서 speed 파라미터를 무시
**우회법**: 텍스트 길이로 영상 길이를 조절 (타겟 45-55초)

- EP047 v1: 7씬 긴 텍스트 → 70.9초 (너무 길음)
- EP047 v3: 6씬 짧은 텍스트 → 43.8초 (적절)

**텍스트 길이 가이드라인** (cool-girl 프리셋 기준):
| 목표 길이 | full_text 글자 수 (한국어) |
|----------|-------------------------|
| ~35초 | ~150자 |
| ~45초 | ~200자 |
| ~50초 | ~230자 |
| ~55초 | ~260자 |

## 4. 이미지 프롬프트에 텍스트/숫자 포함 금지

**증상**: AI 생성 이미지에서 간판, 배너, 가격표 텍스트가 깨져서 보임
**원인**: Gemini Imagen이 텍스트 렌더링을 정확하게 못 함
**규칙**: image_prompt에 절대 텍스트/숫자를 포함하지 않음

- BAD: `banner reading "SALE 50%"`, `price tag shows ₩3,000,000`
- GOOD: `glowing red price tag shows a huge number`, `a sign with warning symbols`

## 5. TTS 이중모음 전이음 삽입 ("뇌 속" → "뇌어 속")

**증상**: ㅚ/ㅙ/ㅞ 등 이중모음 종성 뒤 공백에서 "어" 소리가 삽입됨
**원인**: Qwen3-TTS의 한국어 음절 연결 처리 버그
**해결**: `preprocess_korean_for_tts()` 0.5단계 compound_joins 에 해당 단어 추가

- `"뇌 속"` → `"뇌속"`, `"회 사"` → `"회사"` 등 붙여쓰기

---

## 6. 영상 길이가 너무 짧거나 길 때

**증상**: 목표 45-55초인데 32초나 70초로 렌더링됨
**원인**: CustomVoice에서 speed 무시 + 텍스트 길이만 영상 길이 결정
**체크리스트**:

1. full_text 글자 수 확인 (200-260자 목표)
2. 씬 수 6개 기준, 씬당 평균 35-45자
3. 씬 간 무음 0.15초 × (씬수-1) 추가
4. 너무 짧으면 → 에스컬레이션 단계 추가
5. 너무 길면 → 불필요한 수식어 제거, 문장 압축

## 7. 숫자+단위명사 고유어 수사 누락 (v3.8 수정)

**증상**: "3정거장"을 TTS가 "삼정거장"으로 읽음 (올바른 발음: "세 정거장")
**원인**: `_convert_korean_numbers()`의 `native_counters` 목록에 "정거장" 등 일부 단위명사가 빠져 있었음
**해결**: `native_counters` 정규식에 누락된 고유어 수사 단위 추가

**한국어 숫자 읽기 규칙**:
| 수사 체계 | 사용 단위 | 예시 |
|----------|----------|------|
| **고유어** (하나/둘/셋...) | 개, 명, 마리, 번, 살, 시, 잔, 병, 장, 권, 대, 벌, 정거장, 바퀴, 군데, 켤레, 쌍, 송이, 자루, 톨, 알, 포기, 모금, 걸음... | 3정거장→세 정거장, 5명→다섯 명 |
| **한자어** (일/이/삼...) | 일, 월, 년, 분, 초, 원, 호, 위, 층, 번째... | 3월→삼월, 2호선→이호선 |

**스크립트 작성 시 주의**: 새로운 단위명사가 나오면 `native_counters` 또는 `sino_counters` 목록에 포함되어 있는지 확인

**에피소드**: EP054 (지하철 내릴 역) — "3정거장"이 "삼정거장"으로 발음됨 → native_counters에 추가

## 체크리스트 (스크립트 작성 시)

- [ ] 영어 약어가 포함되어 있으면 TTS 발음 테스트 (`preprocess_korean_for_tts()`)
- [ ] full_text 글자 수 200-260자 범위 확인
- [ ] image_prompt에 텍스트/숫자 표현 없는지 확인
- [ ] 이중모음(ㅚ/ㅙ/ㅞ) 뒤 공백이 있으면 compound_joins에 등록 필요 여부 체크
- [ ] 숫자+단위명사가 있으면 고유어/한자어 수사 구분 확인 (3정거장→세 정거장, 3월→삼월)
- [ ] 렌더링 후 싱크율 95%+ 확인, FAIL 구간 원인 분석
