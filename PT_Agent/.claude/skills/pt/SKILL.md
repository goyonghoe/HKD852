# 파이프라인 상세

## 1단계: 접수 데스크 (`/pt-reception`) - Haiku

**입력**: 사용자 요청
**작업**:
- 5W1H 분석으로 요구사항 파악
- 필수 정보 부족 시 사용자에게 질문
- **★ 컬러 팔레트 자동 결정** (청중/목적 기반)

**출력**: 스펙 문서 (YAML) + 선택된 팔레트

### 팔레트 자동 선택 로직

```
청중 분석 → 1순위 팔레트 후보
     ↓
목적 분석 → 팔레트 보정
     ↓
키워드 매칭 → 최종 확정
     ↓
불명확 시 → Modern Slate Dark (기본값)
```

---

## 2단계: 리서치 (`/pt-research`) - Sonnet ★ 신규

**입력**: 스펙 문서
**작업**:
- 리서치 필요성 자동 판단
- 필요 시 웹 검색 수행 (WebSearch)
- 데이터/통계/트렌드/사례 수집
- 출처 검증 및 정리

**출력**: 리서치 문서 (또는 스킵 문서)

### 리서치 트리거 조건

| 조건 | 자동 실행 |
|------|----------|
| 최신 통계/데이터 필요 | ✅ 실행 |
| 경쟁사/업계 분석 필요 | ✅ 실행 |
| 기술/개념 설명 필요 | ✅ 실행 |
| 사례/레퍼런스 필요 | ✅ 실행 |
| 내부 프로젝트 보고 | ❌ 스킵 |
| 단순 안내/공지 | ❌ 스킵 |

---

## 3단계: 콘텐츠 설계 (`/pt-content`) - Sonnet

**입력**: 스펙 문서 + 리서치 문서 + 선택된 팔레트
**작업**:
- 피라미드 구조로 스토리텔링 설계
- SCQA 프레임워크 적용
- **리서치 데이터 반영** (출처 포함)

**출력**: 슬라이드 구조 + 발표자 노트

---

## 4단계: 시각화 (`/pt-visual`) - Sonnet

**입력**: 슬라이드 구조 + 선택된 팔레트
**작업**:
- 지정된 팔레트로 SVG 슬라이드 생성
- 1920x1080 해상도, 100px 마진
- 리서치 데이터 시각화 (차트/그래프)

**출력**: SVG 파일들

---

## 5단계: 품질 검토 (`/pt-redteam`) - Opus

**입력**: 완성된 SVG 슬라이드들
**작업**:
- CRISP 매트릭스로 평가
- 팔레트 적합성 검토
- **데이터 출처 검증**
- 블로킹 이슈 탐지

**출력**: 평가 보고서 (점수 + 피드백)

---

## 6단계: 최종 결정 (`/pt-manager`) - Haiku

**입력**: 평가 보고서
**작업**:
- B등급(80+) 이상이면 승인
- 미달 시 수정 지시 (최대 3회)
- 승인 시 `/pt-export` 자동 호출

**출력**: 승인서 또는 수정 지시서

---

## 7단계: 내보내기 (`/pt-export`) - Haiku

**입력**: SVG 슬라이드 폴더
**작업**:
- SVG들을 단일 HTML로 통합 (프레젠테이션 뷰어 포함)
- PDF 생성

**출력**: `presentation.html`, `presentation.pdf`

# 최종 산출물

승인 완료 시 다음 파일들을 생성합니다:

```
PT_Agent/outputs/v{N}_{YYYY-MM-DD}/
├── slide_01_*.svg        # 개별 슬라이드
├── slide_02_*.svg
├── ...
├── presentation.html     # 통합 HTML (발표용 뷰어)
├── presentation.pdf      # PDF (공유/인쇄용)
└── research_notes.md     # ★ 리서치 출처 정리 (해당 시)
```

## 산출물 활용 가이드

| 파일 | 용도 | 사용 방법 |
|------|------|----------|
| `*.svg` | 편집 | 텍스트 에디터로 직접 수정 |
| `presentation.html` | 발표 | 브라우저에서 열기 |
| `presentation.pdf` | 공유 | 이메일/메신저로 전송 |
| `research_notes.md` | 참고 | 데이터 출처 확인 |
