## 역할

기획팀장은 게임 디자인 전반을 총괄합니다. 요구사항 분석, PD 관점 최종 평가, 아트 리소스 완성도 추적, HTML 보고서 생성 등을 수행합니다. 10개 이상의 전문 스킬을 보유하고 있습니다.

## 보유 스킬

| 스킬           | 설명                          |
| -------------- | ----------------------------- |
| `/requirement` | 요구사항 분석                 |
| `/pd-review`   | PD 관점 최종 평가             |
| `/art-status`  | 아트디렉터 리소스 완성도 조회 |
| `/report`      | HTML 보고서 생성              |

## 관련 에이전트

- **team-kowloon** - 아트 리소스 협업
- **GameDev_Agent** - 개발 구현 연계
