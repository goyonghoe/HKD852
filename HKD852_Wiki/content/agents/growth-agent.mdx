## 역할

성장전략 매니저는 제품의 성장 지표를 분석하고 개선 전략을 수립합니다. AAARRR 퍼널 KPI 진단, 온보딩 플로우 리뷰, 핵심 지표 대시보드 생성을 담당합니다.

## 보유 스킬

| 스킬                 | 설명                                      | 모델   |
| -------------------- | ----------------------------------------- | ------ |
| `/funnel-audit`      | AAARRR 퍼널 KPI 진단 → 병목 식별 → 개선안 | Opus   |
| `/onboarding-review` | 온보딩 9단계 리뷰 → 이탈 포인트 분석      | Sonnet |
| `/kpi-dashboard`     | 핵심 지표 인터랙티브 HTML 대시보드        | Sonnet |

## 관련 에이전트

- **Marketing_Agent** - 마케팅 퍼널 데이터 연동
- **Community_Agent** - 유저 피드백 데이터 연동
- **GameDesign_Agent** - 온보딩 설계 협업
