## 역할

투자 대시보드는 CEO의 투자 포트폴리오를 관리하는 Next.js 웹 애플리케이션입니다. 배당 투자 전략 기반 스크리닝, 시장 브리핑, 포트폴리오 추적 등을 제공합니다.

## 보유 스킬

| 스킬 | 설명 | 모델 |
|------|------|------|
| `/invest-analyze` | 종목 심층 분석 | Opus |
| `/invest-dashboard` | 대시보드 관리 | Sonnet |
| `/invest-journal` | 투자 일지 | Sonnet |
| `/invest-plan` | 투자 계획 수립 | Opus |
| `/invest-review` | 포트폴리오 리뷰 | Opus |
| `/invest-screen` | 종목 스크리닝 | Sonnet |
| `/market-brief` | 시장 브리핑 | Sonnet |

## 관련 에이전트

- **Secretary_Agent** - 투자 현황 브리핑 연동
