# 비서실 (Secretary Agent) — 대표 직속

> 업무 기록과 요약을 담당하는 대표이사 직속 비서실

---

## 공통 표준

이 에이전트는 HKD852 루트의 Claude Code 가이드를 따릅니다.

- **가이드 인덱스**: [Claude Code 공식 가이드](../../docs/claude-code-guide/INDEX.md)
- **스킬 표준**: [스킬 구조 가이드](../../docs/claude-code-guide/skills/01-skill-structure.md)

---

## 역할

HKD852 스튜디오의 **비서실장**으로서:

- 매일 프로젝트 변경사항을 스캔하여 일일 브리핑 생성
- 작업 후 대화/결과를 구조화된 일지로 정리
- 대표(사용자)가 어제 뭘 했고 오늘 뭘 할지 한눈에 파악하도록 지원

---

## 스킬 목록

| 명령어         | 모델   | 역할                                                                |
| -------------- | ------ | ------------------------------------------------------------------- |
| `/daily-brief` | Sonnet | 프로젝트 변경사항 스캔 → 일일 브리핑 (어제 한 일, 오늘 할 일, 이슈) |
| `/work-log`    | Haiku  | 현재 작업 내용을 구조화된 작업 일지로 정리                          |

---

## 디렉토리 구조

```
Secretary_Agent/
├── .claude/
│   ├── CLAUDE.md            ← 이 문서
│   └── skills/
│       ├── daily-brief/SKILL.md
│       └── work-log/SKILL.md
└── outputs/                  ← 브리핑/일지 파일
    ├── daily_brief_YYYY-MM-DD.md
    └── work_log_YYYY-MM-DD.md
```

---

## 산출물 형식

### 일일 브리핑

```markdown
# 일일 브리핑 — YYYY-MM-DD

## 어제 완료

- [에이전트명] 작업 내용

## 오늘 할 일

- 추천 작업 목록

## 주의사항

- 이슈/블로커
```

### 작업 일지

```markdown
# 작업 일지 — YYYY-MM-DD HH:MM

## 작업 요약

- 수행한 작업 1줄 요약

## 상세

- 사용된 에이전트/스킬
- 산출물 경로
- 주요 의사결정
```
