## 디자인 언어: Dark Glassmorphism

### 핵심 원칙

- **반투명 패널**: 배경이 비치는 글래스 효과 (깊이감 연출)
- **불투명도 범위**: 0.15 ~ 0.40
- **테두리**: 1px, alpha 0.3, `#4a6fa5`
- **코너 반경**: 12 ~ 24px (컴포넌트 크기에 비례)

### 패널 불투명도 가이드

| 용도                 | Alpha | 반경 |
| -------------------- | ----- | ---- |
| 배경 오버레이 (모달) | 0.40  | 24px |
| HUD 패널             | 0.25  | 16px |
| 카드/셀              | 0.20  | 12px |
| 힌트/툴팁            | 0.15  | 8px  |

## 버튼 스타일

### 주요 버튼 (Primary)

- 배경: `#e94560` (Accent)
- 텍스트: `#ffffff`, 22px Bold
- 최소 크기: 220 × 60 dp
- 눌림 효과: scale 0.95×, 밝기 -10%

### 보조 버튼 (Secondary)

- 배경: Glass panel (alpha 0.25)
- 텍스트: `#ecf0f1`, 22px Regular
- 눌림 효과: scale 0.95×

### 아이콘 버튼 (Icon)

- 크기: 48 × 48 dp (터치 타겟 최소)
- 눌림 효과: scale 0.90×, alpha 0.7

## 스크롤 가능 리스트 규칙 (M-016)

### 뷰포트 바운드 원칙

```
totalHeight = startY + ceil(itemCount / cols) * (cardH + gap) + footerH
totalHeight > 1280px → DragScroll 필수 적용
```

### 고정 네비게이션 버튼

- Back, Close 버튼은 **스크롤 컨테이너 외부에 고정**
- 권장 위치: Y = 1200 ~ 1240 (화면 하단 safe area)
- 네비게이션 버튼이 콘텐츠와 함께 스크롤되면 절대 안 됨

### 참조 구현

- `EnemyCodexScene.ts` — DragScroll 적용된 스크롤 리스트
- `WorldMapScene.ts` — DragScroll 적용된 맵 뷰

## 레벨업 선택 UI

- 카드 크기: 200 × 240px, 간격 16px
- 3장 가로 배치, 배경 Modal overlay (alpha 0.40)
- **5초 후 자동 선택** (`autoSelectDelayMs: 5000`)
- 카드 내용: 아이콘, 이름, 설명, 레벨, DPS 수치

### 튜토리얼 연동 주의사항 (TASK-131)

레벨업 UI(depth 2000)와 튜토리얼 오버레이(depth 5000)가 동시에 표시될 때 depth 충돌 발생. 튜토리얼의 `triggerSkillSelect` 단계에서는:

- **반드시** 튜토리얼 오버레이(backdrop + tapZone)를 숨겨야 함
- 카드 선택 완료 후 `notifyTutorialLevelUp()`으로 스텝 진행 시 오버레이 자동 복원

## 접근성

- 색상만으로 정보 구분하지 않음 (아이콘/심벌 병행)
- 텍스트 대비 비율 4.5:1 이상
- 적 유형은 도형으로 구분 (circle, triangle, rect, diamond, hexagon)
- 애니메이션 축소 옵션 지원 (prefers-reduced-motion)
