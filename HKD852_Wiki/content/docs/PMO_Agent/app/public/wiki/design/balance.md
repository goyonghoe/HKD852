# 밸런스 가이드

> 수치 설계 원칙, DPS 공식, 난이도 스케일링, 핵심 상수

관련 파일: `src/config/balance.ts`, `design/reference/numerical-bible.md`

---

## 설계 원칙

### 속성 계층

1. **1st 속성 (원초적)**: `baseDamage`, `cooldownMs`, `baseHp`, `baseSpeed`
2. **2nd 속성 (수정자)**: `critChance`, `piercing`
3. **3rd 속성 (배율)**: `damageMultiplier`, `attackSpeedMultiplier`

### 카운터 속성 쌍

모든 속성에는 대응 카운터가 존재합니다:

- DPS ↔ HP (공격력 vs 내구도)
- 이동속도 ↔ 넉백 (기동성 vs 제어)
- 사거리 ↔ 투사체 속도 (간접 견제)

### I/O 밸런스

- **입력**: 생존 시간, 처치 수
- **출력**: XP 획득, 골드, 레벨업 빈도
- 이 비율이 깨지면 게임이 너무 쉽거나 어려워짐

### S-커브 난이도

```
Stage 1-4:   학습 구간 (적은 적, 낮은 스케일)
Stage 5-10:  도전 구간
Stage 11-16: 숙련 구간 (전체 적 풀, 높은 스케일)
```

## DPS 공식

```
DPS = baseDamage × (1 + projectileCount - 1) × (1000 / cooldownMs) × damageMultiplier
    × (1 + critChance × (critMultiplier - 1))
```

### T1 무기 DPS 비교 (레벨 1, 배율 1.0)

| 무기          | 기본 DPS | 비고                          |

| 속사포        | 15.0     | 초당 5발, 누적 DPS 높음       |
| 레이저 빔     | 12.5     | 관통, 다중 타격 시 실질 DPS ↑ |

| 수리검        | 12.0     | 관통 3                        |

## 난이도 스케일링 상수

### 시간 기반 (분 단위)

```typescript
BALANCE.DIFFICULTY = {
  hpScalePerMin: 2.2, // 1분마다 적 HP × 2.2
  speedScalePerMin: 1.5, // 1분마다 적 속도 × 1.5 (최대 × 2.8)
  damageScalePerMin: 2.0, // 1분마다 적 데미지 × 2.0
  maxSpeedMultiplier: 2.8, // 속도 스케일 상한
  maxBossHp: 15000, // 보스 HP 절대 상한
};
```

### 스테이지 누적 배율

| 배율             | 값    |
| ---------------- | ----- |
| HP per stage     | ×1.35 |
| 속도 per stage   | ×1.10 |
| 데미지 per stage | ×1.15 |

스테이지 16에서 누적 HP 배율: `1.35^15 ≈ ×67`

## 스폰 밸런스

```typescript
BALANCE.SPAWN = {
  initialDelayMs: 600, // 첫 스폰 전 대기
  baseIntervalMs: 800, // 기본 스폰 간격
  minIntervalMs: 400, // 최소 간격 (하한선)
  intervalDecayPerMin: 0.45, // 분당 간격 ×0.45 감소
  maxEnemiesOnScreen: 45, // 화면 최대 적 수
  eliteChanceBase: 0.1, // 초기 엘리트 10%
  eliteChancePerMin: 0.25, // 분당 +25%
  eliteChanceMax: 0.5, // 엘리트 최대 50%
};
```

## 4대 KPI

게임 밸런스를 평가할 때 사용하는 핵심 지표:

1. **스테이지 클리어율**: 각 스테이지를 클리어한 유저 비율
2. **평균 생존 시간**: 런당 생존 시간 분포
3. **DPS 효율**: 획득 무기 vs 처치한 적 수
4. **레벨업 빈도**: 분당 레벨업 횟수 (이상적: 1.5~2.5회/분)
