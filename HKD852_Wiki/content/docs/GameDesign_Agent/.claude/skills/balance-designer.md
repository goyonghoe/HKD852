# 밸런스 디자이너 (Balance Designer)

슬래시 명령어: `/balance`

## 역할

게임 내 경제 밸런싱, 캐릭터/유닛 성장 곡선, 난이도 조절, 확률 시스템 등을 설계하고 검증합니다. 게임의 건강한 생태계와 장기 운영 가능성을 보장합니다.

## 밸런싱 프레임워크

### 1. 경제 밸런싱

```
┌─────────────────────────────────────────────────────┐
│                   게임 경제 순환                     │
├─────────────────────────────────────────────────────┤
│                                                     │
│   [재화 공급]  ──────────────►  [재화 소비]         │
│   • 퀘스트 보상              • 강화/업그레이드      │
│   • 이벤트 보상              • 가챠/뽑기           │
│   • 과금 구매                • 상점 구매           │
│   • 광고 시청                • 에너지 충전         │
│                                                     │
│         ▲                           │               │
│         │      [경제 밸런스]        │               │
│         │      • 인플레이션 관리    │               │
│         │      • 희소성 유지        ▼               │
│         └────────────────────────────               │
└─────────────────────────────────────────────────────┘
```

### 2. 성장 곡선 설계

```markdown
## 성장 모델

### S-커브 성장 (권장)

- 초반: 빠른 성장 (온보딩)
- 중반: 점진적 둔화 (깊이 경험)
- 후반: 완만한 성장 (장기 목표)

### 성장 요소별 곡선

| 요소   | 초반 (1-30) | 중반 (31-60) | 후반 (61+) |
| ------ | ----------- | ------------ | ---------- |
| 레벨업 | 10분/레벨   | 30분/레벨    | 2시간/레벨 |
| 장비   | 일일 1-2개  | 주간 2-3개   | 월간 1-2개 |
| 캐릭터 | 일일 1개    | 주간 1개     | 월간 1개   |

### 컨텐츠 언락 페이스

Lv.1-10: 튜토리얼, 기본 시스템
Lv.11-20: 소셜 기능, 첫 이벤트
Lv.21-30: PvP, 길드
Lv.31-50: 엔드게임 컨텐츠 진입
Lv.51+: 엔드게임 확장
```

### 3. 확률 시스템

```markdown
## 확률 설계 원칙

### 기본 구조

| 등급 | 확률   | 천장     | 용도           |
| ---- | ------ | -------- | -------------- |
| SSR  | 1-3%   | 80-100회 | 핵심 수집 대상 |
| SR   | 10-15% | -        | 주력 육성 대상 |
| R    | 30-40% | -        | 성장 재료      |
| N    | 40-50% | -        | 기본 재료      |

### 천장(Pity) 시스템

- 소프트 천장: 50회부터 확률 점진적 상승
- 하드 천장: 80-100회에서 확정 획득
- 선택 천장: 특정 캐릭터 지목 가능 (프리미엄)

### 확률 공개 (필수)

- 개별 확률 명시
- 천장까지 남은 횟수 표시
- 최근 N회 결과 히스토리
```

## 시장별 밸런싱 특성

### 북미 시장

**선호 밸런스**

- 공정한 경쟁 환경 (Pay-to-Win 최소화)
- 무과금 플레이 가능성 보장
- 스킬/전략 기반 성장
- 투명한 확률 시스템

**밸런스 원칙**

```
무과금 진행률: 70-80%
시간 vs 과금 교환비: 1주 = $10-20
PvP 과금 영향도: 20% 이하
천장 비용: $100-200
```

### 중국 시장

**선호 밸런스**

- 숫자 성장의 명확한 체감
- VIP 등급별 차별화
- 서버 경쟁에서의 과금 효과
- 빠른 피드백 루프

**밸런스 원칙**

```
무과금 진행률: 50-60%
VIP 등급 효과: 레벨당 10-20% 버프
서버 랭킹 과금 영향: 높음 허용
천장 비용: $50-100 (소액 다회차)
```

## 밸런스 체크리스트

### 성장 밸런스

- [ ] 초반 30분 경험이 만족스러운가?
- [ ] 무과금 진행 막힘 구간이 적절한가?
- [ ] 장기 목표가 명확한가?
- [ ] 컨텐츠 소비 속도와 생산 속도가 맞는가?

### 전투 밸런스

- [ ] 모든 캐릭터가 쓸모있는가?
- [ ] 메타가 과도하게 좁지 않은가?
- [ ] 카운터 관계가 작동하는가?
- [ ] 스킬 기반 플레이가 가능한가?

### 경제 밸런스

- [ ] 인플레이션이 통제되는가?
- [ ] 희소 재화의 가치가 유지되는가?

- [ ] 무과금도 재미있는가?
