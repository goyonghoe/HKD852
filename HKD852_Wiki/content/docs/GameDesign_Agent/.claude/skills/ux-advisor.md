# UX 어드바이저 (UX Advisor)

슬래시 명령어: `/ux`

## 역할

모바일 게임의 UX/UI를 최적화하고, 온보딩 경험 설계, 리텐션 개선 방안을 제시합니다. 유저 여정 전반에 걸쳐 최상의 경험을 설계합니다.

## UX 프레임워크

### 1. 유저 여정 맵

```
┌─────────────────────────────────────────────────────────────────┐
│                        유저 여정                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│ [인지]    [획득]    [활성화]   [유지]    [수익]    [추천]       │
│   │         │         │         │         │         │          │
│   ▼         ▼         ▼         ▼         ▼         ▼          │
│ 광고     다운로드   튜토리얼  일일접속  첫과금   친구초대      │
│ ASO      첫실행    첫플레이  습관형성  반복과금  커뮤니티      │
│                                                                 │
│ 이탈점: 로딩    FTUE     D1      D7       D30     지속         │
└─────────────────────────────────────────────────────────────────┘
```

### 2. 핵심 UX 원칙

```markdown
## 모바일 게임 UX 10원칙

1. **즉시성**: 터치 후 0.1초 내 피드백
2. **명확성**: 무엇을 해야 하는지 항상 명확
3. **보상감**: 모든 행동에 긍정적 피드백
4. **진행감**: 성장과 진행이 시각적으로 명확
5. **접근성**: 한 손 조작, 세로 모드 고려
6. **일관성**: UI 패턴의 일관된 사용
7. **용서성**: 실수해도 복구 가능
8. **최소성**: 필요한 것만 보여주기
9. **맥락성**: 상황에 맞는 정보 제공
10. **기대성**: 다음에 무슨 일이 일어날지 예측 가능
```

### 3. FTUE (First Time User Experience)

```
분 단위 온보딩 설계:

0-1분: 첫 인상
├── 로딩 (15초 이내)
├── 최소 권한 요청
└── 즉시 플레이 가능

1-3분: 핵심 루프 체험
├── 가장 재미있는 순간 경험
├── 쉬운 성공 경험
└── 보상 획득

3-10분: 기본 시스템 학습
├── 핵심 메카닉 습득
├── 성장 시스템 이해
└── 첫 목표 완료

10-30분: 확장 경험
├── 추가 시스템 unlock
├── 소셜 기능 노출
└── 장기 목표 제시
```

## 시장별 UX 특성

### 북미 시장 UX

**선호 패턴**

- 직관적 인터페이스 (학습 곡선 최소화)
- 튜토리얼 스킵 옵션 필수
- 접근성(Accessibility) 중요
- 다크 모드 지원

**UI 특성**
| 요소 | 선호 | 비선호 |
|------|------|--------|
| 레이아웃 | 심플, 여백 | 빽빽함, 복잡함 |
| 색상 | 절제된 팔레트 | 과도한 색상 |
| 텍스트 | 간결함 | 장문 |
| 팝업 | 최소화 | 빈번한 팝업 |

**접근성 필수 요소**

- [ ] 색맹 모드
- [ ] 텍스트 크기 조절
- [ ] 음성 안내 (VoiceOver)
- [ ] 진동 피드백 옵션
- [ ] 자막 지원

### 중국 시장 UX

**선호 패턴**

- 정보 밀도 높음 허용
- 빨간색/금색 = 긍정적 의미
- 숫자 성장의 시각화 중요
- 알림/푸시 거부감 적음

**UI 특성**
| 요소 | 선호 | 비선호 |
|------|------|--------|
| 레이아웃 | 정보 풍부 | 과도한 여백 |
| 색상 | 빨강, 금, 화려함 | 칙칙함, 어두움 |
| 텍스트 | 상세 설명 | 정보 부족 |
| 팝업 | 이벤트/보상 알림 | - |

**문화적 고려**

- 숫자 8 = 행운, 4 = 기피
- 붉은색 = 행운, 축하
- 금색 = 부, 고급
- 길드/사회적 요소 강조

## UX 설계 템플릿

### 화면 설계

```markdown
## [화면명] UX 설계

### 화면 목적

[이 화면에서 유저가 달성할 목표]

### 유저 플로우

[진입] → [주요 행동] → [결과] → [다음 화면]

### 정보 계층

1. Primary: [가장 중요한 정보/액션]
2. Secondary: [보조 정보/액션]
3. Tertiary: [부가 정보]

### 핵심 요소

| 요소     | 위치      | 크기 | 상호작용    |
| -------- | --------- | ---- | ----------- |
| CTA 버튼 | 하단 중앙 | 대형 | 탭 → [결과] |
| ...      | ...       | ...  | ...         |

### 피드백 설계

- 성공: [시각/청각/촉각 피드백]
- 실패: [에러 메시지 및 복구 방법]
- 대기: [로딩 표시]

### 엣지 케이스

- 데이터 없음:
- 오프라인:
- 에러:
```

```markdown
| 2    | 1분  | 전투 이해 | 자동전투 | 승리 연출 |
| ...  | ...  | ...       | ...      | ...       |

### 스킵 정책

- 스킵 가능 시점:
- 스킵 시 보상:

- 단계별 완료율
- 평균 소요 시간
- 이탈 지점
```

## 리텐션 UX 전략

### D1 리텐션 (24시간)

```markdown
핵심: "내일 다시 오고 싶게"

전략:

1. 미완료 목표 제시 (진행 중인 퀘스트)
2. 내일 보상 예고 (일일 보너스)
3. 푸시 알림 동의 유도
4. 친구 초대/연결
```

### D7 리텐션 (1주일)

```markdown
핵심: "습관 형성"

전략:

1. 주간 보상 시스템
2. 길드/소셜 연결
3. 신규 컨텐츠 해금 예고
4. 이벤트 참여
```

### D30 리텐션 (1개월)

```markdown
핵심: "장기 목표 설정"

전략:

1. 월간 목표/보상
2. 시즌/배틀패스 진행
3. 엔드게임 컨텐츠 진입
4. 커뮤니티 소속감
```

## UX 체크리스트

### 접근성

- [ ] 한 손 조작 가능
- [ ] 버튼 최소 크기 44pt
- [ ] 색상만으로 정보 전달 안함
- [ ] 텍스트 가독성 확보

### 피드백

- [ ] 모든 터치에 즉각 반응
- [ ] 성공/실패 명확히 구분
- [ ] 진행 상황 항상 표시
- [ ] 에러 시 해결 방법 제시

### 네비게이션

- [ ] 현재 위치 명확
- [ ] 뒤로가기 항상 가능
- [ ] 깊이 3단계 이내
- [ ] 자주 쓰는 기능 접근 용이

### 온보딩

- [ ] 30초 내 첫 재미
- [ ] 설명보다 행동 유도
- [ ] 스킵 옵션 제공
- [ ] 점진적 복잡도 증가
