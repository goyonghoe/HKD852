# 아트 상태 조회 스킬

> Game Hub 내 크로스-에이전트 연결: GameDesign ↔ team-kowloon

## 역할

기획 의사결정 시 아트 리소스 완성 상태를 자동 참조하여:

- 아트 미완성 기능의 런칭 일정 조정
- 우선순위 높은 아트 작업 식별
- PD 리뷰 시 아트 실현 가능성 보고

## 실행 절차

### Step 1: 아트 스펙 파일 탐색

team-kowloon의 명세서와 산출물을 스캔:

```
Glob: team-kowloon/명세서/*.xlsx
Glob: team-kowloon/3_ai_output/generated_specs/**/*.csv
Glob: team-kowloon/3_ai_output/generated_specs/**/*.md
```

### Step 2: 리소스 상태 분석

CSV/마크다운 명세서에서 다음 정보를 추출:

- 카테고리별 리소스 수
- 완성/미완성 상태
- 우선순위 (High/Medium/Low)
- 해상도/포맷 기준 충족 여부

### Step 3: 기획 연관성 매핑

사용자가 질문한 기능/시스템과 관련된 아트 리소스를 매칭:

| 기획 키워드    | 관련 아트 카테고리          |
| -------------- | --------------------------- |
| 캐릭터, 보스   | 캐릭터 일러스트, 스프라이트 |
| 카드, 포토카드 | 카드 아트, 프레임           |
| UI, 메뉴       | UI 에셋, 아이콘             |
| 이벤트         | 이벤트 배너, 팝업           |
| 앨범, 테마     | 앨범 커버, 테마 배경        |
| 뽑기, 가차     | 연출 이펙트, 결과 화면      |

### Step 4: 보고

```markdown
## 아트 리소스 상태 보고

**조회 일시**: YYYY-MM-DD HH:MM
**관련 기능**: [사용자 질문 기능명]

### 리소스 현황

| 카테고리 | 총 리소스 | 완료 | 미완료 | 완성도 |
| -------- | --------- | ---- | ------ | ------ |
| ...      | ...       | ...  | ...    | ...%   |

### 기획 영향도

- **즉시 가능**: [아트 완료된 기능 목록]
- **대기 필요**: [아트 미완료 기능 + ETA]
- **권장 일정**: [런칭 추천 시점]

### PD 참고사항

- [아트 병목 지점]
- [우선 작업 제안]
```

## /pd-review 연동

이 스킬의 결과는 `/pd-review` 실행 시 자동 참조 가능:

```
/pd-review 실행 시:
  1. 기획 분석 수행
  2. /art-status 자동 호출 (관련 아트 있을 경우)
  3. 아트 완성도를 PD 판정에 반영
  4. "아트 미완성" 경고를 리스크 섹션에 포함
```
