# How to Use This Prompt Pack

## Quick Start (2 Minutes)

1. **Pick a category** that matches your product (e.g., "Jewelry & Accessories")
2. **Copy any prompt** from that category
3. **Replace `[product]` or `[YOUR PRODUCT]`** with your actual product description
4. **Paste into your AI tool** (Midjourney, DALL-E 3, Stable Diffusion)
5. **Generate and download** your product photo

That's it. No photography skills needed.

## Customization Guide

### Replacing the Product Placeholder

**Bad**: `[product]` → "my item"
**Good**: `[product]` → "handmade silver ring with blue topaz gemstone, thin band"

The more specific you are, the better the result. Include:

- **Material** (leather, ceramic, stainless steel)
- **Color** (matte black, rose gold, forest green)
- **Size/Shape** (compact, oversized, rectangular)
- **Key Feature** (textured surface, transparent lid, embossed logo)

### Adjusting Aspect Ratios

| Platform              | Recommended Ratio        | Use                  |
| --------------------- | ------------------------ | -------------------- |
| Instagram Feed        | `--ar 1:1`               | Square product posts |
| Instagram Story/Reels | `--ar 9:16`              | Vertical stories     |
| Pinterest             | `--ar 2:3` or `--ar 4:5` | Tall pins            |
| Amazon/Shopify        | `--ar 1:1`               | Product listings     |
| Website Hero          | `--ar 16:9`              | Banner images        |
| Etsy Listing          | `--ar 4:3`               | Landscape thumbnails |

### Modifying Lighting

Add these modifiers to any prompt:

- **Brighter**: add "high key lighting, bright and airy"
- **Moodier**: add "low key lighting, dramatic shadows"
- **Warmer**: add "warm golden light, sunset tones"
- **Cooler**: add "cool blue tones, daylight balanced"
- **Studio**: add "professional studio strobe lighting, softbox"

### Changing Backgrounds

Replace background descriptions with:

- `pure white background` — Clean marketplace standard
- `light grey seamless background` — Professional catalog
- `black background` — Premium/luxury feel
- `natural lifestyle setting` — Contextual marketing
- `wooden table surface` — Rustic/artisanal
- `marble surface` — High-end aesthetic

## Platform-Specific Tips

### Midjourney

```
[prompt text] --ar 1:1 --v 6 --style raw --q 2
```

- `--v 6` — Use latest model version
- `--style raw` — More photographic, less artistic
- `--q 2` — Maximum quality
- `--no text, watermark, logo` — Remove unwanted elements
- `--s 100` — Lower stylization for realism

### DALL-E 3 (ChatGPT)

- Remove all `--ar`, `--style raw` parameters
- Add "photorealistic, professional product photography" at the end
- Specify "no text overlays on the image"
- Request specific dimensions: "Generate as a 1024x1024 image"

### Stable Diffusion

- Use realistic checkpoints: "Realistic Vision V5", "Dreamshaper XL"
- Add negative prompt: "blurry, low quality, distorted, amateur, cartoon, illustration, text, watermark"
- Settings: Steps 40-50, CFG 7-8, Sampler DPM++ 2M Karras
- Resolution: 768x768 minimum, upscale to 1024+

### Adobe Firefly

- Paste prompt text directly
- Select "Photo" as content type
- Adjust style/mood sliders after generation
- Use reference images for consistent style

## Pro Tips for E-Commerce

### Consistency Across Listings

Use the **same prompt style** for all products in a collection. Change only the `[product]` description. This creates a unified store aesthetic.

### Creating Variations

For each product, generate 5-7 images using different prompts from the same category:

1. **Hero shot** (main listing image)
2. **White background** (marketplace requirement)
3. **Lifestyle context** (shows product in use)
4. **Detail/macro** (shows quality)
5. **Scale reference** (shows size)
6. **Packaging shot** (if applicable)
7. **Collection/group** (for bundles)

### Batch Processing

Group similar products and use the same prompt template. Just swap the product description. This saves time when listing multiple items.

### A/B Testing

Generate 2-3 hero images per product. Upload different versions to your listing and track which gets more clicks. Most platforms (Etsy, Amazon) support this.
