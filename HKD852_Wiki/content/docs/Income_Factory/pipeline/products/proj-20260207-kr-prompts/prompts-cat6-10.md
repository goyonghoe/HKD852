# 마케팅 카피라이팅 AI 프롬프트 마스터팩 - 카테고리 6-10

## 카테고리 6: 광고 카피 (네이버/카카오/메타)

### 프롬프트 26: 네이버 검색광고 제목+설명 생성기

**용도**: 네이버 파워링크/브랜드검색 광고 제작 시

**프롬프트**:

```
당신은 네이버 검색광고 전문 카피라이터입니다. 다음 제품/서비스에 대해 클릭률을 극대화하는 광고 문구를 작성해주세요.

[제품/서비스 정보를 입력하세요]

**출력 형식**:
- 제목 (15자 이내): [핵심 키워드 + 강점]
- 설명 1 (45자 이내): [구체적 혜택]
- 설명 2 (45자 이내): [차별화 포인트 또는 프로모션]

**작성 규칙**:
1. 제목에 반드시 타겟 키워드 포함
2. 숫자/할인율은 구체적으로 명시
3. "지금", "오늘만", "한정" 등 긴급성 표현 활용
4. 네이버 광고 금지어 (최고급, 1위 등) 사용 금지
5. 3개 버전 제공 (A/B 테스트용)
```

**Before (입력 예시)**:

> 제품: 프리미엄 수제 강아지 간식 "멍멍베이커리"
> 특징: 무첨가, 국내산 재료, 수의사 추천
> 프로모션: 첫 구매 20% 할인

**After (출력 예시)**:

> **버전 A**
>
> - 제목: 수제 강아지간식 20%할인
> - 설명 1: 국내산 무첨가 재료만 사용, 수의사 추천 건강간식
> - 설명 2: 첫 구매 고객 20% 할인 + 무료배송 / 오늘만 특가
>
> **버전 B**
>
> - 제목: 강아지간식 무첨가 수제
> - 설명 1: 수의사가 추천하는 100% 국내산 프리미엄 간식
> - 설명 2: 신규회원 20% 즉시할인 / 2만원 이상 무료배송
>
> **버전 C**
>
> - 제목: 수의사추천 강아지간식
> - 설명 1: 화학첨가물 제로! 사람도 먹을 수 있는 안전한 간식
> - 설명 2: 지금 가입하면 20% 할인쿠폰 / 당일발송 가능

**활용 팁**: 3개 버전을 동시에 돌려보고 클릭률(CTR)을 비교하세요. 보통 숫자가 들어간 버전이 클릭률이 10-15% 높습니다.

### 프롬프트 27: 카카오모먼트 배너 카피 생성기

**용도**: 카카오톡 비즈보드/배너 광고 제작 시

**프롬프트**:

```
당신은 카카오모먼트 광고 전문 카피라이터입니다. 모바일 환경에서 3초 안에 시선을 사로잡는 배너 카피를 작성해주세요.

[제품/서비스 정보를 입력하세요]

**출력 형식**:
- 메인 카피 (10자 이내): [임팩트 있는 한 문장]
- 서브 카피 (20자 이내): [구체적 혜택/설득 포인트]
- CTA 버튼 문구 (6자 이내): [행동 유도]

**작성 규칙**:
1. 메인 카피는 의문문/명령문으로 강렬하게
2. 이모지 1-2개 활용 (과하지 않게)
3. 카카오톡 사용자 특성 고려 (2030 여성 중심)
4. 3개 버전 (감성/혜택/긴급 각 1개씩)
```

**Before (입력 예시)**:

> 제품: 출근길 간편식 "오피스런치박스"
> 타겟: 2030 직장인 여성
> 특징: 500kcal 이하, 영양 균형, 전자레인지 3분
> 프로모션: 5개 구매 시 1개 무료

**After (출력 예시)**:

> **버전 A (감성형)**
>
> - 메인 카피: 다이어트 중인데요? 🥗
> - 서브 카피: 500kcal 균형 도시락 3분이면 끝
> - CTA: 보러가기
>
> **버전 B (혜택형)**
>
> - 메인 카피: 5+1 런치박스 🎁
> - 서브 카피: 한 끼 5천원대 건강식 / 오늘만 특가
> - CTA: 특가확인
>
> **버전 C (긴급형)**
>
> - 메인 카피: 내일 점심 준비 완료? ⏰
> - 서브 카피: 저녁 9시 주문 → 내일 아침 도착
> - CTA: 주문하기

**활용 팁**: 카카오톡 배너는 체류시간이 짧으므로 메인 카피만 보고도 무슨 제품인지 알 수 있어야 합니다. 이모지는 필수!

### 프롬프트 28: 메타(인스타/페이스북) 광고 카피 생성기

**용도**: 인스타그램/페이스북 피드/스토리 광고 제작 시

**프롬프트**:

```
당신은 메타 광고 전문 카피라이터입니다. 스크롤을 멈추게 만드는 소셜 광고 카피를 작성해주세요.

[제품/서비스 정보를 입력하세요]

**출력 형식**:
- 훅(Hook) 문장 (15자 이내): [스크롤 멈추게 할 첫 문장]
- 본문 (80-100자): [공감 → 문제 제시 → 솔루션 제시]
- CTA (10자 이내): [행동 유도]
- 해시태그 5개: [검색 최적화용]

**작성 규칙**:
1. 첫 문장은 반드시 타겟의 고민/욕구 건드리기
2. "당신도", "혹시", "이런 경험" 등 공감 표현 활용
3. 친구가 추천하는 듯한 자연스러운 톤
4. 인스타는 감성, 페이스북은 실용성 강조
```

**Before (입력 예시)**:

> 제품: 숙면 베개 "클라우드필로우"
> 타겟: 30-40대 불면증 직장인
> 특징: 경추 교정, 메모리폼, 높이 조절 가능
> 프로모션: 100일 무료 체험

**After (출력 예시)**:

> **훅**: 아침에 일어나면 목이 뻐근하신가요?
>
> **본문**:
> 저도 베개만 10개를 바꿨어요. 그러다 정형외과 의사가 추천해준 이 베개를 쓰고 나서...
>
> 😴 경추 각도 자동 교정
> 😴 나만의 높이로 조절 가능
> 😴 100일 써보고 마음에 안 들면 전액 환불
>
> 지금은 새벽에 한 번도 안 깨고 푹 자요. 아침에 목 뻐근한 게 사라졌어요.
>
> **CTA**: 100일 체험하기
>
> **해시태그**: #불면증 #숙면베개 #경추베개 #목통증 #베개추천

**활용 팁**: 메타 광고는 "광고 같지 않은" 것이 핵심입니다. 친구의 솔직한 후기처럼 작성하되, 해시태그로 검색 유입을 노리세요.

### 프롬프트 29: 구글 쇼핑 광고 타이틀 생성기

**용도**: 구글 쇼핑(Google Shopping) 상품 광고 제목 작성 시

**프롬프트**:

```
당신은 구글 쇼핑 광고 최적화 전문가입니다. 검색 의도에 맞는 상품 타이틀을 작성해주세요.

[제품 정보를 입력하세요]

**출력 형식**:
- 타이틀 (70자 이내): [브랜드 + 핵심 키워드 + 스펙 + 차별점]

**작성 규칙**:
1. 구글 검색어 상위 키워드 반드시 포함
2. 브랜드명은 앞 또는 뒤에 배치
3. 숫자/스펙을 구체적으로 명시
4. "무료배송", "당일발송" 등 배송 정보 포함 시 클릭률 상승
5. 3개 버전 (키워드 순서 변경)
```

**Before (입력 예시)**:

> 제품: 블루투스 이어폰 "사운드프로 X10"
> 스펙: 노이즈캔슬링, 40시간 재생, IPX7 방수
> 가격: 89,000원
> 배송: 무료배송

**After (출력 예시)**:

> **버전 A (브랜드 앞)**
> 사운드프로 X10 블루투스 이어폰 노이즈캔슬링 40시간재생 IPX7방수 무료배송
>
> **버전 B (키워드 앞)**
> 노이즈캔슬링 블루투스 이어폰 40시간 재생 방수 사운드프로 X10 무료배송
>
> **버전 C (가격 강조)**
> 블루투스 이어폰 노캔 40시간 방수 IPX7 사운드프로 X10 89000원 무료배송

**활용 팁**: 구글 쇼핑은 검색어와의 정확한 매칭이 중요합니다. "블루투스이어폰"으로 검색하는 사람이 많다면 띄어쓰기 없이 붙여쓰는 것도 전략입니다.

### 프롬프트 30: 리타겟팅 광고 문구 생성기

**용도**: 장바구니 이탈/방문 후 미구매 고객 대상 재광고

**프롬프트**:

```
당신은 리타겟팅 광고 전문가입니다. 한 번 관심을 보인 고객을 다시 끌어들이는 카피를 작성해주세요.

[고객 행동 + 제품 정보를 입력하세요]

**출력 형식**:
- 메인 카피 (20자 이내): [고객 행동 상기 + 긴급성]
- 서브 카피 (40자 이내): [추가 혜택 또는 사회적 증거]
- 특별 오퍼: [리타겟팅 전용 인센티브]

**작성 규칙**:
1. "아직도 고민 중이세요?", "놓치신 상품" 등 행동 상기
2. 추가 할인/사은품으로 구매 동기 부여
3. 재고/시간 제한으로 긴급성 조성
4. 3단계 리타겟팅 (1일 후 / 3일 후 / 7일 후)
```

**Before (입력 예시)**:

> 고객 행동: 여성 크로스백 상품 페이지 3분 체류 후 이탈
> 제품: 이탈리아 가죽 크로스백 128,000원
> 재고: 5개 남음

**After (출력 예시)**:

> **1일 후 리타겟팅**
>
> - 메인 카피: 어제 보신 그 가방, 아직 있어요 👜
> - 서브 카피: 지금 구매하시면 5% 추가할인 / 5개 남음
> - 특별 오퍼: 24시간 한정 5% 쿠폰 자동 적용
>
> **3일 후 리타겟팅**
>
> - 메인 카피: 고민하는 사이 3개 팔렸어요 😢
> - 서브 카피: 마지막 2개 남음 / 이번 주 재입고 없음
> - 특별 오퍼: 10% 할인쿠폰 + 무료 각인 서비스
>
> **7일 후 리타겟팅 (최종)**
>
> - 메인 카피: 마지막 기회! 내일이면 품절됩니다
> - 서브 카피: 이미 324명이 구매한 베스트셀러 / 재입고 미정
> - 특별 오퍼: 15% 할인 + 무료배송 + 가죽 케어킷 증정

**활용 팁**: 리타겟팅은 시간이 지날수록 할인율을 높이되, 너무 자주 노출하면 역효과입니다. 1일 → 3일 → 7일 간격 추천.

## 카테고리 7: 이메일/CRM 마케팅

### 프롬프트 31: 환영 이메일 생성기 (첫 구매 후)

**용도**: 신규 고객 첫 구매 직후 발송하는 감사 이메일

**프롬프트**:

```
당신은 브랜드 CRM 전문가입니다. 첫 구매 고객에게 따뜻한 환영과 함께 재구매를 유도하는 이메일을 작성해주세요.

[브랜드 정보 + 첫 구매 상품을 입력하세요]

**출력 형식**:
- 제목: [개인화 + 감사]
- 본문 (200-300자):
  1. 진심 어린 환영 인사
  2. 제품 사용 팁 또는 관리법
  3. 다음 구매 혜택 안내
  4. 브랜드 커뮤니티 초대
- 추천 상품 3개: [첫 구매와 연관된 제품]

**작성 규칙**:
1. 고객 이름 개인화 ([고객명]님)
2. 판매가 아닌 '도움' 중심 톤
3. 브랜드 스토리 자연스럽게 녹이기
4. 다음 구매 쿠폰은 적당한 유효기간 (30일)
```

**Before (입력 예시)**:

> 브랜드: "순수공방" (천연 수제 비누)
> 첫 구매 상품: 라벤더 비누 3개입
> 고객명: 김민지
> 다음 구매 혜택: 15% 할인 쿠폰

**After (출력 예시)**:

> **제목**: 민지님, 순수공방 가족이 되어주셔서 감사합니다 💜
>
> **본문**:
> 안녕하세요, 민지님!
>
> 순수공방 대표 박지은입니다. 라벤더 비누를 선택해주셔서 진심으로 감사드려요.
>
> 저희 비누는 40일간 자연 숙성시켜 만듭니다. 처음엔 향이 약하게 느껴지실 수 있는데, 사용하실수록 은은한 라벤더 향이 피어나실 거예요. 샤워 후 통풍이 잘 되는 곳에 보관해주세요!
>
> 라벤더 비누를 좋아하시는 분들이 함께 구매한 제품:
> • 티트리 클렌징바 (민감성 피부 추천)
> • 쑥 샴푸바 (두피 케어)
> • 비누받침 세트 (보관 필수템)
>
> 다음 구매 시 사용하실 15% 할인쿠폰을 드렸어요. (유효기간 30일)
>
> 인스타그램 @soonsoogongbang을 팔로우하시면 매주 천연 비누 만드는 과정을 보실 수 있어요. 민지님도 참여해주세요!
>
> 오늘도 좋은 하루 되세요 :)
> 순수공방 박지은 드림

**활용 팁**: 환영 이메일은 오픈율이 50% 이상으로 매우 높습니다. 단순 할인 쿠폰보다는 브랜드 스토리와 사용 팁을 담아 신뢰를 쌓으세요.

### 프롬프트 32: 장바구니 이탈 리마인더 생성기

**용도**: 장바구니에 담고 1-3일 내 구매하지 않은 고객 대상

**프롬프트**:

```
당신은 이커머스 CRM 전문가입니다. 장바구니에 담아둔 고객을 부드럽게 넛지(nudge)하는 리마인더 이메일을 작성해주세요.

[장바구니 상품 정보를 입력하세요]
