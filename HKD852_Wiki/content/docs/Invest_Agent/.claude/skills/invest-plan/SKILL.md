# 투자 계획 수립

현재 투자 단계(§3.1~§3.4)를 판단하고 다음 실행 액션을 제안합니다.

## 참조 문서

- 투자 전략: `Invest_Agent/docs/strategy.md` (§3 단계별 포트폴리오 구축 전략)
- 규칙 엔진: `Invest_Agent/app/src/lib/strategy/rules.ts`

## 데이터 수집

### 포트폴리오 현황

```bash
cat Invest_Agent/data/portfolio.jsonl
```

### 시장 현황

```bash

```

```bash
tail -5 Invest_Agent/data/journal.jsonl
```

데이터가 없으면 사용자에게 현재 상황을 물어보세요.

## 단계 판단 (§3.1~§3.4)

### 1단계: 지수 추종 ETF 분할 매수 (§3.1)

**조건**: 투자 경험 초기, 개별 종목 선별 능력 미확보
**액션**:

- 코스피 200 ETF 매일 분할 매수
- 하락일(파란 불)에만 매수 (§2.3)
- 장 시작 후 1시간 매매 자제 (§2.4)

### 2단계: 배당주 투자 (§3.2)

**조건**: ETF 매수 습관 정착, 배당 기본 이해
**액션**:

- 배당수익률 3%+ 안정적 배당주 발굴
- 배당 기준일 영업일 기준 이틀 전 매수 완료
- 배당 성향 30% 수준 유지 기업 우선

### 3단계: 브릿지 → 주도주 (§3.3)

**조건**: 섹터 ETF 비교 분석 경험, 개별 종목 리서치 가능
**액션**:

- 섹터 ETF 바구니 비교 → 효자 종목 추출
- 미인 대회 원칙: 시장이 인정하는 주도주 선별
- 수출 증가 기업 (조선, 방산, 원자력, 반도체) 중점

### 4단계: 바벨 전략 (§3.4)

**조건**: 자산 규모 확대, 포트폴리오 분산 필요
**액션**:

- 80% ETF(안정) + 20% 개별 주식(공격) 분리
- 리밸런싱 주기 설정

## FOMO 방지 (§5.3)

- "지금 안 사면 늦는다" 등 조급함 유발 표현 금지
- 숫자 기반 객관적 판단만 제시
- 최종 투자 판단은 CEO(사용자)의 몫
