# 주간 포트폴리오 분석

보유 종목의 현재 상태를 전략 규칙 기반으로 점검하고 리밸런싱을 제안합니다.

## 참조 문서

- 투자 전략: `Invest_Agent/docs/strategy.md`
- 규칙 엔진: `Invest_Agent/app/src/lib/strategy/rules.ts`

## 데이터 수집

### 1단계: 포트폴리오 데이터

```bash
# 포트폴리오 데이터 (JSONL)
cat Invest_Agent/data/portfolio.jsonl
```

각 줄 = 한 보유 종목 JSON: `{ code, name, buyPrice, quantity, buyDate, stopLossPrice, type, buyReason }`

포트폴리오 파일이 없으면 사용자에게 보유 종목을 직접 물어보세요.

### 2단계: 현재가 조회

```bash
# 각 종목별 현재가
curl -s "https://invest-dashboard-azure.vercel.app/api/stock/[종목코드]"
```

## 분석 항목

### A. 손절 체크 (§2.1)

각 보유 종목에 대해:

- **수익률** = (현재가 - 매수가) / 매수가 × 100
- 수익률 ≤ -10%: **손절 경고** (빨간색)
- **ETF 예외**: type="etf"인 종목은 손절 기준 미적용

### B. 익절 체크 (§2.2)

- **최고가 대비 하락률** = (최고가 - 현재가) / 최고가 × 100
- 최고가 대비 10% 이상 하락: **익절 시그널**
- 아직 수익 중이면서 고점 대비 하락 시작: 매도 타이밍 검토

### C. 바벨 비율 (§3.4)

- ETF 비중 = ETF 평가액 합계 / 전체 평가액
- 목표: **80% ETF + 20% 개별 주식**
- 편차 10%p 이상: 리밸런싱 필요 표시

### D. 종합 평가

- 총 투자금 / 총 평가액 / 총 수익률
- 손절 알림 종목 수
- 익절 시그널 종목 수
- 바벨 비율 적정 여부

- 숫자와 규칙 기반 객관적 판정만 제시

- 최종 매매 판단은 CEO(사용자)의 몫
