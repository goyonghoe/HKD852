# 투자 일지

투자 매수/매도 결정을 기록하고 인과관계를 훈련합니다 (전략 §5.2).

## 참조 문서

- 투자 전략: `Invest_Agent/docs/strategy.md` (§5.2 투자 일지 작성)

## 데이터 파일

- 위치: `Invest_Agent/data/journal.jsonl`
- 형식: JSON Lines (한 줄 = 한 기록)

## 사용법

### 매수 기록: `/invest-journal buy [종목명]`

사용자에게 다음 정보를 순차적으로 확인:

1. **종목명** (인수로 전달되지 않은 경우)
2. **종목코드** (6자리)
3. **매수 날짜** (기본: 오늘)
4. **매수 가격** (원)
5. **매수 수량** (주)
6. **매수 이유** — 반드시 다음 중 하나: `성장성` 또는 `저평가` (§5.2)
7. **목표 손절가** (매수가 대비 10% 하락 기본 제안) (§2.1)
8. **유형**: `etf` 또는 `stock`
9. **메모** (선택)

```json
{
  "id": "j_20260228_001",
  "type": "buy",
  "date": "2026-02-28",
  "code": "005930",
  "name": "삼성전자",
  "price": 72000,
  "quantity": 10,
  "reason": "저평가",
  "stopLossPrice": 64800,
  "assetType": "stock",
  "memo": "PBR 0.9 저평가 구간"
}
```

### 매도 기록: `/invest-journal sell [종목명]`

사용자에게 다음 정보를 확인:

1. **종목명/코드**
2. **매도 날짜** (기본: 오늘)
3. **매도 가격**
4. **매도 수량**
5. **매도 사유**: `손절`, `익절`, `리밸런싱`, `기타`
6. **상승/하락의 원인** — 인과관계 기록 (§5.2 핵심)
7. **메모** (선택)

```json
{
  "id": "j_20260228_002",
  "type": "sell",
  "date": "2026-02-28",
  "code": "005930",
  "name": "삼성전자",
  "price": 78000,
  "quantity": 5,
  "sellReason": "익절",
  "causeAnalysis": "반도체 업황 회복 기대감 + 외국인 순매수 전환",
  "profitPercent": 8.33,
  "memo": ""
}
```

### 일지 조회: `/invest-journal list`

- `Invest_Agent/data/journal.jsonl` 읽기
- 최근 10건 역순 표시
- 매수/매도별 요약 통계

## 출력 형식

기록 완료 후 CLI에 요약 표시:

```
--- 투자 일지 기록 완료 ---
유형: 매수
종목: 삼성전자 (005930)
가격: 72,000원 × 10주 = 720,000원
사유: 저평가 (PBR 0.9)
손절가: 64,800원 (-10%)
기록: Invest_Agent/data/journal.jsonl
```

## 전략 검증 (자동)

- 매수 시: 장 시작 직후(9~10시) 매수인 경우 경고 (§2.4)
- 매수 시: 레버리지/인버스 ETF 경고 (§2.4)
- 매도 시: 손절 기준(10%) 미달인데 매도하는 경우 이유 확인 (§2.1)
- 매도 시: 수익 중인 종목 조기 매도 시 주의 (§2.2)
