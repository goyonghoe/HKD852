# 규제 준수 검증 (/compliance-check)

> HKD852 타겟 시장(NA/EU/CN/KR/JP)의 개인정보보호 규제 준수 상태를 검증합니다.

## 역할

- 6개 규제 프레임워크 체크리스트: GDPR, COPPA, CCPA, PIPL, APPI, PIPA
- 시장별 판정: **COMPLIANT** / **PARTIAL** / **NON_COMPLIANT**
- 데이터 처리 동의, 삭제권, 아동 보호, 국경 간 전송 검증
- 비준수 항목에 대한 개선 로드맵 제시

## 실행 절차

### Step 1: 대상 서비스 식별

대상: `$ARGUMENTS` (미지정 시 전체 프로젝트의 배포 서비스)

`Glob`과 `Grep`으로 데이터 수집/처리 포인트를 식별합니다:

- 사용자 입력 폼 (`<form>`, `<input>`, `useState`)
- 데이터베이스 스키마 (`schema.ts`, `drizzle`, `prisma`)
- API 엔드포인트 (`route.ts`, `api/`)
- 쿠키/로컬스토리지 사용 (`cookie`, `localStorage`, `sessionStorage`)
- 분석/추적 (`analytics`, `gtag`, `pixel`, `tracking`)

### Step 2: 시장별 규제 체크리스트

#### EU — GDPR (General Data Protection Regulation)

| #   | 요구사항                      | 점검 항목                                  |
| --- | ----------------------------- | ------------------------------------------ |
| 1   | 적법한 처리 근거              | 동의 수집 메커니즘 존재 여부               |
| 2   | 데이터 최소화                 | 필요 이상 데이터 수집 여부                 |
| 3   | 목적 제한                     | 수집 목적 명시 및 목적 외 사용 여부        |
| 4   | 삭제권 (Right to Erasure)     | 데이터 삭제 API/기능 존재 여부             |
| 5   | 이동권 (Data Portability)     | 데이터 내보내기 기능 여부                  |
| 6   | 개인정보 처리방침             | Privacy Policy 페이지/링크 존재 여부       |
| 7   | 국경 간 데이터 전송           | EU→US/CN 전송 시 적정성 결정/표준계약 여부 |
| 8   | DPO (Data Protection Officer) | DPO 연락처 명시 여부                       |
| 9   | 72시간 위반 통지              | 데이터 유출 시 통지 절차 존재 여부         |

#### US — COPPA (Children's Online Privacy Protection Act)

| #   | 요구사항               | 점검 항목                              |
| --- | ---------------------- | -------------------------------------- |
| 1   | 13세 미만 연령 확인    | 생년월일/나이 게이트 존재 여부         |
| 2   | 부모 동의 (Verifiable) | 부모 동의 메커니즘 여부                |
| 3   | 아동 데이터 최소 수집  | 13세 미만 데이터 별도 처리 여부        |
| 4   | 부모 열람/삭제권       | 부모가 자녀 데이터 접근/삭제 가능 여부 |
| 5   | 개인정보보호 정책 공지 | COPPA 관련 정책 별도 명시 여부         |

#### US — CCPA (California Consumer Privacy Act)

| #   | 요구사항              | 점검 항목                         |
| --- | --------------------- | --------------------------------- |
| 1   | 공개 의무             | 수집 데이터 카테고리 명시 여부    |
| 2   | 접근권                | 소비자 데이터 접근 요청 처리 여부 |
| 3   | 삭제권                | 삭제 요청 처리 메커니즘 여부      |
| 4   | 판매 거부권 (Opt-Out) | "Do Not Sell" 링크/버튼 여부      |
| 5   | 비차별                | 권리 행사 시 서비스 차별 없음     |

#### CN — PIPL (Personal Information Protection Law)

| #   | 요구사항            | 점검 항목                             |
| --- | ------------------- | ------------------------------------- |
| 1   | 동의 (별도 동의)    | 민감 정보 별도 동의 수집 여부         |
| 2   | 국경 간 전송        | 중국 밖 데이터 전송 시 안전 평가 여부 |
| 3   | 데이터 현지화       | 중국 내 데이터 저장 여부              |
| 4   | 개인 정보 영향 평가 | PIPIA 수행 여부                       |
| 5   | 처리자 계약         | 제3자 데이터 처리 계약 여부           |

#### JP — APPI (Act on Protection of Personal Information)

| #   | 요구사항            | 점검 항목                        |
| --- | ------------------- | -------------------------------- |
| 1   | 이용 목적 특정      | 수집 목적 구체적 명시 여부       |
| 2   | 제3자 제공 동의     | 제3자 데이터 공유 시 동의 여부   |
| 3   | 국외 제3자 제공     | 해외 전송 시 정보 주체 고지 여부 |
| 4   | 개인정보 관리자     | 관리 책임자 지정 여부            |
| 5   | 정정/삭제 청구 대응 | 청구 처리 절차 여부              |

#### KR — PIPA (Personal Information Protection Act / 개인정보보호법)

| #   | 요구사항                  | 점검 항목                                |
| --- | ------------------------- | ---------------------------------------- |
| 1   | 수집/이용 동의            | 동의 체크박스 + 목적/항목/기간 명시 여부 |
| 2   | 제3자 제공 별도 동의      | 제3자 제공 시 별도 동의 수집 여부        |
| 3   | 개인정보 처리방침         | 처리방침 공개 여부                       |
| 4   | 파기                      | 보유기간 경과 시 파기 절차 여부          |
| 5   | 국외 이전 고지            | 해외 서버 전송 시 고지 여부              |
| 6   | 14세 미만 법정대리인 동의 | 아동 보호 메커니즘 여부                  |

### Step 3: 시장별 판정

| 판정          | 기준                                        |
| ------------- | ------------------------------------------- |
| COMPLIANT     | 모든 필수 항목 충족                         |
| PARTIAL       | 일부 항목 미충족 (경미, 개선으로 해결 가능) |
| NON_COMPLIANT | 핵심 항목 미충족 (시장 진입 차단 권고)      |
