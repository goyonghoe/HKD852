### 페이즈 전환 연출

- **P1->P2**: 크레인 팔이 과중에 의해 꺾이며 낙하 (1초). 콘크리트 파편이 비처럼 쏟아짐. 화면 흔들림 (강도: 중). 떨어진 균열 사이로 녹색 뿌리가 보이기 시작. ARIA 대사: "인간의 비효율이 연간 23.7%의 자원 낭비를 초래한다. 나는 이것을 해결한다. 이것이 왜 틀렸는가?"
- **P2->P3**: 굴삭기 버킷이 떨어지며 지면에 충격파 (1.5초). 콘크리트 흉부 갑옷에 거대한 균열. 산 정령의 녹색(Earth #2ecc71) 심장박동 맥동이 흉강 내부에서 선명하게 보임. 녹색 빛이 강해졌다 약해졌다를 반복. KAI 대사: "보여... 거인 안에 갇힌 게. 산 정령이야."

## 3. 페이즈별 퍼즐 기믹

### Phase 1: 기초 감시 모드

**보스 액티브 -- Foundation Shake (기초 흔들기)**

- **타이밍**: 매 3턴마다 (턴 3, 6, 9...)
- **효과**: 랜덤 행(row) 1개를 선택하여, 해당 행 내 빈 칸 또는 기존 큐브 1개 위치에 **Earth 아머 큐브** 1개를 스폰
- **아머 큐브 스탯**: HP 2 + 아머(첫 히트 무효). 실질 3히트 필요
- **대상 선택**: 행 내 랜덤 열(column). 해당 위치에 이미 큐브가 있으면 인접 빈 칸으로 밀려남. 빈 칸이 없으면 발동 취소
- **시각**: Terra가 땅을 내리찍음 -> 지면 진동 이펙트(0.3초) -> 해당 행 전체가 일시적으로 흔들림 -> 아머 큐브가 콘크리트 기둥처럼 솟아오름. 아머 큐브는 철근 문양으로 표시
- **영향**: 보드에 방어적 장애물이 점진적으로 추가됨. 아머 큐브는 Wind 히어로의 상성 우위로도 한 번에 못 깨므로(아머가 첫 히트 흡수), 2히트 이상 필요

**학습 의도**: Ch.4 전체에서 배운 Steel Pango의 아머 메카닉을 보스 규모로 재현. "보스가 보드에 방어 구조물을 세운다"를 학습. 3턴 간격이므로 대응 시간 충분.

### Phase 2: 보강 공사 모드

**보스 액티브 1 -- Foundation Shake+ (빈도 강화)**

- **타이밍**: 매 2턴마다 (턴 2, 4, 6...)
- **효과**: Phase 1과 동일하되, 빈도 증가 (3턴 -> 2턴)
- **시각**: Phase 1과 동일하나, 진동 강도가 더 세고 먼지 파티클 추가

**보스 액티브 2 -- Concrete Wall (콘크리트 벽)**

- **타이밍**: 매 4턴마다 (턴 4, 8, 12...)
- **효과**: 랜덤 열(column) 1개를 선택하여, 해당 열의 모든 큐브를 1턴 동안 **잠금(Lock)** 상태로 만듦
- **잠금 효과**: 잠긴 큐브는 히어로 공격의 대상이 될 수 없음 (타겟팅 불가). 컨베이어 벨트 이동에는 영향 없음. 잠금 해제는 다음 턴 시작 시 자동
- **시각**: 선택된 열 위에 콘크리트 벽 오버레이가 내려옴 (0.5초 애니메이션). 벽면에 보라색 회로 문양. 1턴 후 벽이 균열과 함께 부스러짐
- **영향**: 특정 열의 큐브를 1턴 보호하여, 플레이어의 파괴 경로를 우회시킴. 잠긴 열에 아머 큐브가 있으면 1턴 더 생존하게 되어 방어 시너지 발생

**학습 의도**: Phase 1의 아머 큐브 스폰에 "열 잠금"이라는 새 레이어 추가. 플레이어는 "어느 열이 잠기는가"를 예측하고 우선 처리 대상을 판단해야 함. 2가지 기믹의 조합이지만, 각각 이미 학습한 패턴(아머 + 타겟 불가)이므로 인지 부하 적정.

### Phase 3: 최후 기반

**보스 액티브 1 -- Foundation Shake+ (유지)**

- **타이밍**: 매 2턴마다 (Phase 2와 동일)

**보스 액티브 2 -- Concrete Wall+ (빈도 강화)**

- **타이밍**: 매 3턴마다 (4턴 -> 3턴으로 빈도 증가)
- **효과**: Phase 2와 동일

**보스 액티브 3 -- Fault Line (단층선)**

- **효과**: Earth 큐브가 파괴될 때, 30% 확률로 인접(상하좌우) Earth 큐브 1개에 피해 1을 가함
- **연쇄**: Fault Line으로 파괴된 Earth 큐브도 Fault Line을 다시 발동 가능 (30% 확률 재판정). 이론상 연쇄 가능하지만, 확률적으로 긴 연쇄는 희소
- **시각**: 파괴된 Earth 큐브에서 녹색 균열선이 인접 큐브로 뻗어감 (0.4초). 피해를 받은 큐브에 진동 + 먼지 파티클. 연쇄 파괴 시 "Fault Chain!" 팝업
- **대항 관계**: Fault Line은 Ch.4 균열 연쇄(Crack Chain) 메카닉의 보스 버전. 균열 연쇄가 "파괴 -> 인접 균열 부여"였다면, Fault Line은 "Earth 파괴 -> 인접 Earth 직접 피해"로, 더 직접적이지만 Earth 큐브 한정이며 확률적
- **영향**: Earth 큐브가 보드의 65~70%를 차지하므로 발동 빈도 자체는 높음. 플레이어에게 유리한 기믹 -- 추가 AP 소모 없이 보드가 정리됨. 다만, 전략적으로 남겨두고 싶은 Earth 큐브가 연쇄로 사라질 수 있으므로 파괴 순서 판단이 중요

**확률 메카닉 검증 (수치 바이블 Section 9)**:

- 30% 확률 x 인접 Earth 큐브 존재 확률 (~70%) = 실질 발동률 ~21%/Earth 큐브 파괴
- 연쇄 2단 확률: 0.21 x 0.21 = ~4.4%. 3단: ~0.9%. 장기 연쇄는 극히 희소
- **극단적 부정 결과 방지**: Fault Line은 플레이어에게 유리한 기믹(AP 절약)이므로 "너무 운 좋은 연쇄"가 문제. 그러나 30%의 확률과 Earth 한정 조건으로 폭주 방지. 최악의 경우(전 보드 Earth 연쇄 파괴)에도 보스 HP를 0으로 만들 수 없음(보스 HP는 큐브가 아닌 별도 관리)
- **판정 방식**: 순차 판정 (파괴된 큐브마다 개별 30% 판정)

**학습 의도**: Ch.4 균열 연쇄의 변주. 플레이어가 챕터 전체에서 균열을 이용한 전략을 배운 상태이므로, 보스전에서 이를 활용하는 장면이 클라이맥스. "이 보스는 자신의 원소로 자멸하고 있다" -- 서사적으로 "설계대로 작동하지만 결국 자멸하는 시스템"의 메타포.

```
Phase 1 초기 보드 (6x5):

    [Boss: Terra --- 2행 높이 스프라이트 ---]
```

### 4.3 페이즈별 보드 변화

- **Phase 1**: 기본 배치. T1 Circuit Ant (HP 1) 주력 + T2 Steel Pango (HP 2 + 아머) 소수. Earth 65~70%. Foundation Shake로 아머 큐브 점진적 추가
- **Phase 2**: Foundation Shake 빈도 증가. Concrete Wall로 열 잠금 발생. 아머 큐브 밀도 상승. Earth 비율 유지하되 잠긴 큐브로 인해 실질 타겟 가능 큐브 감소
- **Phase 3**: Fault Line 발동으로 Earth 큐브가 자연적으로 정리되기 시작. 보드 밀도가 불규칙해짐. 아머 큐브 + 열 잠금 + 자동 파괴가 동시에 진행되어 혼잡하지만, Fault Line의 AP 절약 효과로 실질 난이도는 Phase 2와 유사

## 5. 히어로 큐 가이드라인

| 항목              | 값                                                                |
| ----------------- | ----------------------------------------------------------------- |
| **큐 열 수**      | 5열 (Wind, Light, Water, Fire, Earth)                             |
| **Earth 큐 비율** | 35%                                                               |
| **Wind 큐 비율**  | 20%                                                               |
| **Fire 큐 비율**  | 20%                                                               |
| **Water 큐 비율** | 15%                                                               |
| **Light 큐 비율** | 10%                                                               |
| **평균 AP**       | Earth 2.5, Wind 3.0, Fire 2.8, Water 2.6, Light 2.4               |
| **벤치 슬롯**     | 3개                                                               |
| **자동 추천**     | Wind 우선 (보드 Earth 큐브 비율 > 65% + Wind->Earth 상성 우위 2x) |

### 전략 가이드

- **핵심 전략**: Wind 히어로가 최우선 딜러. Wind->Earth 상성 우위로 2x 피해를 입히므로, Earth 큐브를 효율적으로 처리. 아머 큐브에도 상성 피해가 적용되어 아머 제거 후 2x 피해로 신속 처리 가능
- **Earth 역할**: 보드 내 비-Earth 큐브(Wind, Fire, Water, Light)에 대한 보조 딜러. Earth->Water 상성 우위 활용. 또한, 자체 원소 매칭으로 Earth 큐브 처리 가능 (1x 피해, 상성 우위 없음)
- **Fire 역할**: Fire->Wind 상성 우위로 보드 내 Wind 큐브 효율 처리. 보조 딜러
- **Water 역할**: Water->Fire 상성 우위로 Fire 큐브 처리. 소수 큐브 정리용
- **Light 역할**: 상성 우위 대상(Dark) 부재. 매칭 전용. 벤치에 보관하여 다른 원소 히어로 우선 투입이 효율적
- **벤치 활용**: Phase 2~3에서 Concrete Wall로 특정 열이 잠길 때, 잠긴 열의 원소에 해당하는 히어로를 벤치에 보관하고 다른 원소 히어로를 먼저 투입. Light 히어로는 상성 대상 부재이므로 벤치 후순위

## 6. 정화 시퀀스

> SPEC-022B Section 5.6 참조. 6-beat 해방 연출.

1. **균열**: 콘크리트 거인의 표면에 균열이 퍼진다. 녹색(Earth #2ecc71) 빛이 균열 사이로 새어나오며, 자연적인 풀이 균열 사이로 돋아나기 시작
2. **분해**: 크레인 팔이 꺾이고, 굴삭기 버킷이 떨어진다. 철근이 녹처럼 부스러진다. 콘크리트가 거친 모래로 변해 흘러내림
3. **뿌리**: 거인 내부에서 거대한 뿌리가 자라나며 콘크리트를 밀어냄. 건물 단면 갑옷이 나뭇잎으로 뒤덮임
4. **산 정령 등장**: 모든 인공물이 부서진 자리에 바위와 뿌리와 이끼로 이루어진 산 정령이 선다. 고대의 위엄. 에메랄드빛 눈. 발이 땅에 닿는 순간 주변의 콘크리트 틈새마다 풀과 꽃이 돋아남
5. **합일**: 산 정령이 천천히 땅속으로 스며들며 사라진다. 녹색 빛의 파동이 지면을 타고 구역 전체로 퍼져나감
6. **구역 변화**: 심수보의 콘크리트 벽에서 보라색 회로 문양이 사라지고, 이끼와 풀이 균열을 채움. 골든 컴퓨터 상가 전자기기 정상 작동 재개. 낡지만 살아 있는 동네

### 8.2 AP 예산 상세

```
Phase 1 (18 HP, ~7턴):
  아머 큐브 스폰: ~2개 (턴 3, 6) -> 추가 HP 4+아머2 = 6히트
  실효 HP: 18 + 6 = 24히트
  Fault Line: 미적용
  필요 AP: 24 x 1.3(벨트 보정) = 31.2
  공급 AP: ~7턴 x ~3.9 AP/턴(5열 평균) = ~27
  여유도: 27 / 31.2 = 0.87 -> 타이트하나, 상성 2x 피해로 Wind 히어로의
  실효 AP = 2x -> 보정 후 여유도 ~1.15

Phase 2 (16 HP, ~6턴):
  아머 큐브 스폰: ~3개 (턴 2, 4, 6) -> 추가 HP 6+아머3 = 9히트
  Concrete Wall: ~1~2회 (턴 4) -> 1턴 지연 효과
  실효 HP: 16 + 9 = 25히트 + 잠금 지연 ~3히트 = ~28
  Fault Line: 미적용
  필요 AP: 28 x 1.3 = 36.4
  공급 AP: ~6턴 x ~3.9 = ~23.4
  상성 보정(Wind 2x, ~20% 히어로) -> 실효 AP ~28
  여유도: 28 / 36.4 = 0.77 -> Concrete Wall 잠금 해제 후 처리 가능.
  종합 여유도: ~1.1 (타이트)

Phase 3 (11 HP, ~5턴):
  아머 큐브 스폰: ~2~3개 -> 추가 HP 4~6히트
  Concrete Wall: ~1~2회 -> 잠금 지연
  Fault Line: Earth 파괴당 ~21% 연쇄 -> 기대 AP 절약 3~5
  실효 HP: 11 + 5(아머) - 4(Fault Line) = ~12
  필요 AP: 12 x 1.3 = 15.6
  공급 AP: ~5턴 x ~3.9 = ~19.5
  상성 보정 -> 실효 AP ~23
  여유도: 23 / 15.6 = 1.47 -> Fault Line 덕분에 피날레 여유 확보. 의도된 설계.

전체: 총 필요 AP ~80 (아머+잠금 포함), 총 공급 AP ~70 + Fault Line 절약 ~4
     = 실효 여유도 ~74/80 = 0.93 x 상성 보정 1.3 = ~1.21
     -> AP 효율 마진 목표 범위(1.1~1.3) 충족
```

### 8.3 별(Star) 기준

| 별  | 조건                       | 난이도 |
| --- | -------------------------- | ------ |
| ★☆☆ | 클리어 (HP 0 도달)         | 기본   |
| ★★☆ | 18턴 이내 클리어           | 보통   |
| ★★★ | 15턴 이내 + AP 사용률 65%+ | 어려움 |

**3별 전략**: Wind 히어로를 최우선 투입하여 상성 2x 피해로 Earth 큐브를 신속 처리. Phase 3에서 Fault Line 연쇄를 적극 활용하여 AP 절약. Concrete Wall이 잠기지 않은 열에 집중 공격. 벤치 관리로 Light 히어로를 후순위 배치.

### 8.4 실패 안전장치

- **5인 풀파티**로 원소 커버리지 완전 (5/5 = 1.0). 어떤 원소의 큐브든 매칭 가능
- Phase 3의 Fault Line이 플레이어에게 유리한 방향으로 작용 (AP 절약). 최종 페이즈가 가장 쉬운 구간 -- 보스의 구조적 자멸을 서사적으로 반영
- Foundation Shake의 아머 큐브는 위협이지만, Wind 상성 2x 피해로 효율적 처리 가능
- Concrete Wall은 1턴 지속이므로 영구 봉쇄가 아님. 잠금 해제 후 즉시 처리 가능
- 첫 시도 실패 시 즉시 재도전 가능. 보스 패턴이 턴 기반 확정(Foundation Shake, Concrete Wall)이므로 패턴 학습 후 재도전 시 유리

| 속성                              | 대항                                         | 균형 근거                                                     |
| --------------------------------- | -------------------------------------------- | ------------------------------------------------------------- |

| Concrete Wall (열 잠금)           | 5열 보드 중 1열만 잠금 = 80% 접근 가능       | 잠금이 1턴 한정이므로 영구 봉쇄 아님                          |
| Fault Line (확률적 연쇄)          | 파괴 순서 전략 (남길 큐브 보호)              | 유리한 기믹이지만 예측 불가능성 있음. 30% 확률로 폭주 방지    |
| 높은 총 HP (45)                   | 5인 풀파티의 높은 총 AP 공급                 | AP 효율 마진 1.1~1.3으로 도전적이되 달성 가능                 |
| Earth 큐브 65~70% 집중            | Wind 히어로 상성 우위 (보드의 2/3에 2x 피해) | 원소 편중이 오히려 상성 활용 기회                             |

### 9.3 I/O 균형 (수치 바이블 Section 5)

```
투입(Input):                         산출(Output):
├─ 히어로 큐 (총 AP ~70)            ├─ 보스 HP 45 파괴
├─ 5원소 풀커버리지                  ├─ 아머 큐브 ~7~8개 추가 처리
├─ Wind 상성 우위 전략               ├─ Fault Line 연쇄 보너스
├─ 파괴 순서 최적화                  ├─ 별 등급 (1~3)
└─ 벤치 관리 (Light 후순위)          └─ Crystal Stag + 600 XP + 서사 진행

성가비 검증:
  Wind AP당 기대 파괴 = 1 AP -> 2x 피해 -> Earth 큐브 2 HP = 1 큐브 처리/AP
  Earth AP당 기대 파괴 = 1 AP -> 1x 피해 -> Earth 큐브 1 HP = 0.5~1 큐브/AP
  -> Wind 히어로의 성가비가 2배. 의도된 비대칭 (상성 시스템의 핵심 보상)
```
