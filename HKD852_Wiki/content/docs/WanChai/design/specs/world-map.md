## 요약

기존 worldbuilding.md(SPEC-010)의 판타지 구역명(용암 시장, 심해 부두 등)을 **실제 홍콩(香港) 행정 구역, MTR 노선, 랜드마크**로 전면 교체한다. 프로젝트명 자체가 "WanChai(灣仔)"인 만큼, 완차이를 홈 허브로 삼고 홍콩의 실제 지리를 게임 세계로 재구성한다. 6개 원소는 각각 실제 홍콩 구역에 매핑되며, MTR 지하철 노선도가 월드맵/이동 시스템 역할을 한다.

**핵심 변경 사항**:

- 6개 판타지 구역 -> 6개 실제 홍콩 구역
- 추상적 월드맵 -> MTR 노선도 기반 세계지도
- 허브 "완차이 항구" -> 실제 완차이(灣仔) 지역
- 최종 챕터 추가: 란타우섬(大嶼山)

## 2. 허브: 완차이 (灣仔 Wan Chai)

### 2.1 개요

완차이는 플레이어의 홈 베이스이자 튜토리얼 구역이다. 게임 시작 지점이며, 챕터 사이에 항상 돌아오는 거점이다. MTR 완차이역(灣仔站)이 중심이 되며, 역 주변의 실제 랜드마크가 기능 허브 역할을 한다.

### 2.2 허브 기능 매핑

| 실제 장소             | 繁體字           | 게임 기능                  | 설명                                                 |
| --------------------- | ---------------- | -------------------------- | ---------------------------------------------------- |
| **Blue House**        | 藍屋             | 크리터 수집소 (Collection) | 완차이의 상징적인 파란 건물. 크리터 도감/컬렉션 열람 |
| **Wan Chai Market**   | 灣仔街市         | 상점 (Shop)                | 실제 재래시장. 유물/아이템 영구 구매, 업그레이드     |
| **Star Ferry Pier**   | 天星碼頭         | 출격 (Departure)           | 스타 페리 선착장에서 각 챕터로 출발. MTR 월드맵 진입 |
| **Convention Centre** | 香港會議展覽中心 | 도감/기록 (Codex)          | 바다 위의 거대 건축물. 적 도감, 유물 도감, 전적 기록 |
| **Hopewell Centre**   | 合和中心         | 대장간 (Forge)             | 원형 마천루. 크리터 강화/진화 시설                   |
| **Wan Chai Station**  | 灣仔站           | MTR 월드맵 입구            | 지하철역에서 세계지도로 진입                         |

### 2.3 허브 픽셀아트 비주얼

```
시각 키워드:
- 파란색 건물 파사드 (Blue House 모티프)
- 재래시장 노란 차양 + 과일 상자
- 스타 페리의 녹백색 선체가 정박한 부두
- 컨벤션 센터의 유선형 지붕 실루엣
- 배경: 빅토리아 하버 + 구룡반도 스카이라인
- 조명: 따뜻한 석양 / 네온 간판의 옅은 빛
- 컬러 팔레트: 주황-노랑 따뜻한 톤 + 바다의 진청색
```

#### 3.6.5 역사 참고 -- 구룡성채

> 구룡성채(Kowloon Walled City)는 1898~1994년 존재했던 홍콩의 전설적 구역이다. 2.7헥타르(약 8,200평)에 최대 33,000명이 거주했으며, 무허가 건물이 층층이 쌓여 빛이 닿지 않는 미로를 형성했다. 1994년 철거되어 현재는 공원(九龍寨城公園)이 되었지만, 홍콩 문화에서 "도시 안의 도시"로 강렬한 상징성을 가진다. 게임에서는 역병이 사람들의 집단 기억을 이용해 이 도시를 그림자로 재건한 것으로 설정한다.

### 5.3 정화 (Purification) 재해석

| 기존 설정                  | 새 설정                                                                                      |
| -------------------------- | -------------------------------------------------------------------------------------------- |
| "역병에서 해방시키는 행위" | 각 구역의 **원래 정체성을 되찾는 행위**. 정화 완료 시 구역 비주얼이 밝아지고 사람들이 돌아옴 |
| 추상적 정화                | 각 랜드마크가 제 빛을 되찾는 구체적 연출 (예: 사원 지붕이 다시 금빛으로, 네온이 원래 색으로) |

### 5.4 컨베이어 벨트 재해석

| -------------- | ------------------- | ---------------------------------------------------------------------- |

interface ChapterData {
