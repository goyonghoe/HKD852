## 1. 크리터 컬렉션

### 1.1 개요

런에서 **보스를 격파**하면 런 중 영입한 크리터가 영구 컬렉션에 추가된다. 런 실패 시에는 추가되지 않는다 (재도전 동기).

### 1.2 컬렉션 규칙

| 항목             | 규칙                                          |
| ---------------- | --------------------------------------------- |
| 컬렉션 최대 크기 | 제한 없음 (18종 + 진화 18종 = 36종)           |
| 중복 보유        | 불허 — 이미 보유 종은 경험치로 전환 (300 exp) |
| 진화체 별도 등록 | 예 — 불여우와 화염여우는 별개 도감 항목       |
| 초기 보유        | 스타터 1 + 바람토끼 + 빛사자 = 3마리          |

### 1.3 컬렉션 데이터 구조

```typescript
interface CollectionData {
  critters: CritterInstance[]; // 보유 크리터 목록
  discoveredIds: string[]; // 도감에 발견한 크리터 ID 목록
  totalCrittersRecruited: number; // 누적 영입 수
}
```

### 1.4 크리터 경험치 영구 보존

런에서 획득한 **크리터 경험치는 영구 보존**된다.

| 상황    | 경험치 처리                     |
| ------- | ------------------------------- |
| 런 승리 | 전투/킬/클리어 경험치 100% 보존 |
| 런 패배 | 전투/킬 경험치 50% 보존         |
| 런 포기 | 경험치 0% (손실)                |

## 2. 도감 시스템

### 2.1 도감 구조

| 섹션            | 내용                                               | 해금 조건        |
| --------------- | -------------------------------------------------- | ---------------- |
| **크리터 도감** | 18종 기본 + 18종 진화 = 36종                       | 해당 크리터 획득 |
| **적 도감**     | 18종 일반 (6원소 x 3티어) + 4 특수 + 6 보스 = 28종 | 해당 적 처치     |
| **유물 도감**   | 15종                                               | 해당 유물 획득   |

### 2.2 도감 UI

```
┌─────────────────────────────┐
│ [뒤로]      도감      36/79  │
├─────────────────────────────┤
│ [크리터] [적] [유물]          │
├─────────────────────────────┤
│ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐  │
│ │🦊│ │🦎│ │🐉│ │? │ │? │  │
│ │Lv5│ │Lv3│ │Lv1│ │  │ │  │  │
│ └──┘ └──┘ └──┘ └──┘ └──┘  │
│                              │
│ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐  │
│ │🐻│ │🦔│ │🦌│ │? │ │? │  │
│ └──┘ └──┘ └──┘ └──┘ └──┘  │
│                              │
│ (스크롤)                     │
└─────────────────────────────┘
```

- 미발견 크리터: `?` 아이콘 + 실루엣 (원소 색상 힌트)
- 발견 크리터: 풀 아이콘 + 이름 + 레벨
- 탭 시 상세 팝업: 스탯, 패시브, 설명 텍스트, 진화 정보

### 2.3 도감 마일스톤 보상

| 달성률              | 보상                              |
| ------------------- | --------------------------------- |
| 25% (9/36 크리터)   | 그림자늑대(Dark Common) 무료 지급 |
| 50% (18/36 크리터)  | 유물 슬롯 +1 (5→6)                |
| 75% (27/36 크리터)  | 시작 유물 1개 선택 (런 시작 시)   |
| 100% (36/36 크리터) | 홈타운 특별 건물 "원소 신전" 해금 |

| 달성률       | 적 도감 보상                                 |
| ------------ | -------------------------------------------- |
| 50% (14/28)  | 적 정보 미리보기 (전투 진입 전 적 구성 확인) |
| 100% (28/28) | "역병 감정사" 칭호 + 특수 적 HP-1 영구       |

## 3. 홈타운 업그레이드

### 3.1 개요

홈타운은 런 시작 전의 허브 화면으로, **메타 통화(정화 결정)**를 소비하여 영구 강화 건물을 업그레이드한다.

### 3.2 메타 통화: 정화 결정 (Purification Crystal)

| 획득원           | 수량            | 조건         |
| ---------------- | --------------- | ------------ |
| 런 승리          | 정화 점수의 10% | 보스 격파    |
| 런 패배          | 정화 점수의 5%  | 전투 중 패배 |
| 도감 마일스톤    | 고정 보상       | 달성률별     |
| 월드 최초 클리어 | 500             | 1회성        |

> 예시: 런 승리, 정화 점수 15,000 → 정화 결정 1,500 획득

### 3.3 건물 목록

| 건물          | 영문           | 최대 레벨 | 효과 (레벨별)                     | 업그레이드 비용           |
| ------------- | -------------- | --------- | --------------------------------- | ------------------------- |
| **훈련소**    | Training Hall  | 5         | 크리터 경험치 획득 +10%/Lv        | 200, 400, 800, 1500, 3000 |
| **여관**      | Inn            | 3         | 벤치 슬롯 +1/Lv (기본 5 → 최대 8) | 300, 800, 2000            |
| **대장간**    | Forge          | 3         | 모든 크리터 시작 AP +1/Lv         | 500, 1500, 4000           |
| **정찰탑**    | Watchtower     | 3         | 분기 맵 노드 1/2/3개 미리 공개    | 200, 500, 1200            |
| **상인 길드** | Merchant Guild | 3         | 상점 가격 -10%/-15%/-20%          | 300, 700, 1500            |

### 3.4 건물 업그레이드 비용 설계

**가속 성장 곡선** 적용 (수치 바이블 Section 6):

```
비용(Lv) = 기본비용 × Lv^1.5

예시 (훈련소, 기본비용=200):
  Lv1: 200 × 1^1.5 = 200
  Lv2: 200 × 2^1.5 = 566 → 반올림 400
  Lv3: 200 × 3^1.5 = 1039 → 반올림 800
  Lv4: 200 × 4^1.5 = 1600 → 반올림 1500
  Lv5: 200 × 5^1.5 = 2236 → 반올림 3000
```

> 수동 조정으로 체감 적정 비용 유지. 정확한 공식보다 플레이어 경험 우선 (수치 바이블 Section 8 원칙 4).

### 3.5 건물 효과의 속성 계층

| 건물             | 속성 계층 | 대항 속성                                   |
| ---------------- | --------- | ------------------------------------------- |
| 훈련소 (경험치+) | 3차 보정  | 레벨업 경험치 요구량 증가 곡선              |
| 여관 (벤치+)     | 1차 직접  | Floor 난이도 증가 (적 HP+)                  |
| 대장간 (AP+)     | 1차 직접  | World 보정값 (적 HP 전체 상승)              |
| 정찰탑 (정보)    | 3차 보정  | 없음 (정보 = 전략적 이점, 직접 전투력 아님) |
| 상인 길드 (할인) | 3차 보정  | 상품 가격 스케일링                          |

### 3.6 건물 밸런스 시뮬레이션

| 홈타운 상태           | 런 전투력 변화                         | 소요 런 횟수 |
| --------------------- | -------------------------------------- | ------------ |
| 모두 Lv0 (초기)       | 기준 100%                              | 0            |
| 훈련소 Lv3 + 여관 Lv1 | +15% 경험치 + 벤치 1                   | ~5           |
| 대장간 Lv1 + 여관 Lv2 | AP+1 + 벤치 2                          | ~8           |
| 모두 Lv2              | +20% 경험치 + 벤치 2 + AP+2 + 할인 15% | ~15          |
| 모두 MAX              | +50% 경험치 + 벤치 3 + AP+3 + 할인 20% | ~40          |

> 목표: 모든 건물 MAX까지 약 **40런** (20~30시간). 이후에는 크리터 수집/도감이 주요 동기.

## 4. 월드 해금

### 4.1 해금 조건

| 월드                  | 해금 조건         | 권장 전투력  |
| --------------------- | ----------------- | ------------ |
| World 1 (용암 시장)   | 게임 시작 시 해금 | 기본         |
| World 2 (심해 부두)   | W1 보스 격파      | 홈타운 Lv1~2 |
| World 3 (뿌리 골목)   | W2 보스 격파      | 홈타운 Lv2~3 |
| World 4 (바람 탑)     | W3 보스 격파      | 홈타운 Lv3~4 |
| World 5 (등대 언덕)   | W4 보스 격파      | 홈타운 Lv4~5 |
| World 6 (그림자 지하) | W5 보스 격파      | 홈타운 MAX   |

### 4.2 월드별 난이도 스케일링

| 월드 | 적 HP 보정 | 특수 적 비율 보정 | 보스 HP | 신규 메카닉                 |
| ---- | ---------- | ----------------- | ------- | --------------------------- |
| W1   | +0         | 기본              | 5       | 튜토리얼 (기본 메카닉)      |
| W2   | +1 (전체)  | +5%               | 6       | 분열 적 등장                |
| W3   | +2         | +10%              | 7       | 흡수 적 등장                |
| W4   | +3         | +15%              | 8       | 보스 특수 능력 강화         |
| W5   | +4         | +20%              | 9       | 복합 특수 적 (아머+분열 등) |
| W6   | +5         | +25%              | 10      | 역병핵 2개, 최종 보스       |

### 4.3 패널 공식 적용

```
적 실제 HP = 기본 HP(티어별) × Floor 계수 + World 보정

예시 (W3, Floor 2, T2 적):
  실제 HP = 2 × 1.3 + 2 = 4.6 → 반올림 5

크리터 실제 AP = baseAP + levelBonus + evolutionBonus + forgeBonus

예시 (Common Lv5 + 대장간 Lv2, 진화 전):
  실제 AP = 2 + 2 + 0 + 2 = 6
```

### 4.4 난이도 곡선 검증 (수치 바이블 Section 6)

```
AP 여유도 = 파티 총 AP / Floor 총 적 HP

목표 곡선 (S자):
  W1: 여유도 1.5~1.8 (쉬움 — 학습 구간)
  W2: 여유도 1.3~1.5 (약간 어려움)
  W3: 여유도 1.1~1.3 (도전적)
  W4: 여유도 1.0~1.2 (타이트)
  W5: 여유도 0.9~1.1 (매우 어려움)
  W6: 여유도 0.8~1.0 (극한 — 홈타운 MAX 필요)

  여유도
  1.8 ┤●
  1.5 ┤  ●
  1.2 ┤    ● ●
  1.0 ┤        ● ●
  0.8 ┤            ●
  0.0 ┼────────────────
      W1 W2 W3 W4 W5 W6
```

## 6. 세이브 데이터 확장

### 6.1 기존 SaveData 확장

```typescript
interface SaveData {
  // ... 기존 필드 유지

  // 신규: 메타 진행
  meta: {
    collection: CollectionData;
    codex: CodexData;
    hometown: HometownData;
    worldProgress: WorldProgressData;
    currency: {
      purificationCrystals: number; // 정화 결정
    };
  };

  // 신규: 진행 중인 런 (있을 경우)
  activeRun?: RunSaveData;
}

interface HometownData {
  buildings: {
    trainingHall: number; // 0~5
    inn: number; // 0~3
    forge: number; // 0~3
    watchtower: number; // 0~3
    merchantGuild: number; // 0~3
  };
}

interface WorldProgressData {
  unlockedWorlds: number[]; // [1, 2, 3] etc.
  clearedWorlds: number[]; // 보스 격파 월드
  worldBestScores: Record<number, number>; // 월드별 최고 점수
}

interface CodexData {
  discoveredCritters: string[]; // 크리터 ID 목록
  discoveredBlights: string[]; // 적 ID 목록
  discoveredRelics: string[]; // 유물 ID 목록
}
```

## 7. I/O 프레임워크 (수치 바이블 Section 5)

### 7.1 메타 진행 I/O

```
투입(Input):                          산출(Output):
├─ 런 플레이 시간 (15~25분)          ├─ 크리터 경험치 (영구)
├─ 전략적 의사결정                   ├─ 정화 결정 (메타 통화)
├─ 런 반복 (재도전)                  ├─ 도감 달성률
└─ 정화 결정 소비                    ├─ 홈타운 업그레이드
                                     └─ 월드 해금
```

### 7.2 진행 속도 밸런스

| 마일스톤   | 예상 소요 시간 | 런 횟수 |
| ---------- | -------------- | ------- |
| W1 클리어  | 1~2시간        | 2~4     |
| W3 클리어  | 5~8시간        | 10~15   |
| W6 클리어  | 20~30시간      | 35~50   |
| 도감 100%  | 30~50시간      | 50~80   |
| 홈타운 MAX | 20~30시간      | 35~50   |

### 7.3 소비 모델 (수치 바이블 Section 5)

```
초반 (W1~W2): 적은 투자, 빠른 보상 → 성공 경험 쌓기
중반 (W3~W4): 홈타운 투자 시작, 전략적 선택 필요
후반 (W5~W6): 대량 투자, 최적화 필수 → 깊이 보장
```
