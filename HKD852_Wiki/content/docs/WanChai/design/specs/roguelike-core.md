## 요약

WanChai를 **런(Run) 기반 로그라이크**로 리디자인한다. 플레이어는 크리터 컬렉션에서 9명의 파티를 편성하고, 분기 맵을 따라 Floor를 진행하며, 스테이지 사이에 보상을 선택한다. 기존 원형 컨베이어 벨트 퍼즐 전투는 그대로 유지하되, 그 위에 런 구조, 분기 맵, 보상 시스템을 감싼다.

## 1. 런(Run) 구조

### 1.1 런 생명주기

```
[홈타운]
  │
  ├─ 파티 편성 (9명 선택 + 순서 배치)
  │
  ▼
[런 시작] ─── World X, Floor 1
  │
  ├─ Floor 1: 분기 맵 3스테이지 + 중간 보상
  ├─ Floor 2: 분기 맵 3스테이지 + 중간 보상
  ├─ Floor 3: 분기 맵 3스테이지 + 중간 보상
  ├─ Boss Floor: 보스 스테이지 1개
  │
  ▼
[런 종료]
  ├─ 승리: 보스 격파 → 영구 보상 + 다음 월드 해금
  └─ 패배: 런 중 게임 오버 → 일부 보상만 획득
```

### 1.2 Floor 구조

각 Floor는 분기 맵의 **3개 노드(스테이지)**로 구성된다. 플레이어는 한 줄씩 진행하며 좌/우 분기를 선택한다.

```
Floor 1 예시:
     [전투]
    /      \
 [상점]   [엘리트]
    \      /
     [보상 선택]
         |
    ─── Floor 2 ───
```

### 1.3 스테이지(노드) 유형

| 노드 타입          | 아이콘        | 설명                                     | 출현 빈도     |
| ------------------ | ------------- | ---------------------------------------- | ------------- |
| **전투 (Battle)**  | 검 아이콘     | 일반 역병 피조물과 컨베이어 벨트 전투    | 높음 (40%)    |
| **엘리트 (Elite)** | 해골 아이콘   | 강화된 적 (특수 타입 포함), 보상 상향    | 중간 (15%)    |
| **상점 (Shop)**    | 동전 아이콘   | 크리터 레벨업/유물 구매 (정화 점수 소비) | 중간 (15%)    |
| **휴식 (Rest)**    | 모닥불 아이콘 | 벤치 초기화 + 크리터 1명 레벨업          | 낮음 (10%)    |
| **이벤트 (Event)** | ? 아이콘      | 랜덤 이벤트 (보상/리스크 택1)            | 중간 (15%)    |
| **보스 (Boss)**    | 왕관 아이콘   | 월드 보스 (역병핵 포함)                  | 고정 (마지막) |

## 2. 분기 맵 시스템

### 2.1 맵 생성 규칙

Slay the Spire 스타일의 분기 맵을 **절차적으로 생성**한다.

**맵 파라미터**:

| 파라미터        | 값           | 근거                               |
| --------------- | ------------ | ---------------------------------- |
| 열 수 (노드 층) | 7~9          | 한 Floor당 충분한 선택지           |
| 행 수 (분기 폭) | 3~4          | 화면 너비 720px에서 탭 가능한 크기 |
| 시작 노드       | 1~2개        | 첫 선택부터 분기                   |
| 보스 노드       | 1개 (고정)   | 모든 경로가 수렴                   |
| 연결 밀도       | 2~3 per node | 너무 단선이면 선택감 저하          |

### 2.2 맵 생성 알고리즘

```
1. 시작 층(layer 0)에 1~2개 노드 배치
2. 각 층마다 3~4개 노드를 행 위치에 배치
3. 인접 층 노드 간 간선 연결 (최소 1개 입력, 최소 1개 출력 보장)
4. 노드 타입 배정:
   - 층 0~1: 전투 위주
   - 층 2~3: 상점/이벤트 혼합
   - 층 4~5: 엘리트/휴식
   - 층 6 (마지막 전 층): 휴식 보장
   - 층 7 (마지막): 보스 고정
5. 검증: 모든 경로에 최소 1개 상점 + 1개 휴식 접근 가능
```

### 2.3 맵 비주얼

```
720px 너비, 세로 스크롤 가능

[START]
  |    \
  O     O      ← 전투 / 전투
  |  X  |
  O     O      ← 이벤트 / 상점
  | / \ |
  O  O  O      ← 전투 / 엘리트 / 전투
     |  |
     O  O      ← 상점 / 휴식
     | /
     O         ← 전투
     |
    [BOSS]

O = 일반 노드
X = 교차 간선
```

## 3. 9인 파티 시스템

### 3.1 파티 편성

| 항목           | 값                   | 근거                                      |
| -------------- | -------------------- | ----------------------------------------- |
| 파티 최대 인원 | **9명**              | 기존 heroQueue 시스템과 호환, 충분한 조합 |
| 최소 인원      | **3명**              | 너무 적으면 전략 자유도 부족              |
| 출격 순서      | 드래그로 재배치 가능 | 순서 = 전략의 핵심 (컬러 레이어링)        |
| 중복 원소      | 허용                 | Fire 크리터 3명 등 가능                   |
| 중복 크리터    | 불허                 | 같은 개체 중복 편성 불가                  |

### 3.2 파티 ↔ 기존 heroQueue 매핑

```
파티 9명 = heroQueue[0..8]

HeroQueueEntry 확장:
{
  element: ElementColor,
  ap: number,
  critterId: string,      // 신규: 크리터 고유 ID
  level: number,           // 신규: 크리터 레벨 (AP에 반영)
  passive: PassiveSkill,   // 신규: 패시브 스킬 ID
}
```

기존 `heroQueue` 인터페이스를 확장하되, **하위 호환성을 유지**한다. `critterId`, `level`, `passive`가 없으면 기존 방식 그대로 동작.

### 3.3 런 내 파티 변동

| 이벤트             | 파티 영향                               |
| ------------------ | --------------------------------------- |
| 크리터 영입 (3택1) | 파티에 1명 추가 (9명 미만 시) 또는 교체 |
| 크리터 레벨업      | AP 증가, 패시브 강화                    |
| 크리터 손실        | 이벤트에서 발생 가능 (페널티)           |
| 유물 획득          | 파티 전체에 효과 적용                   |

## 4. 전투 스테이지 (Battle Node)

### 4.1 기존 메카닉 유지

전투 노드에 진입하면 **기존 PuzzleScene과 동일한 컨베이어 벨트 전투**를 수행한다.

- 보드 배치: 역병 피조물 (기존 큐브 → 몬스터 스프라이트)
- 히어로 큐: 파티의 크리터 9명
- 벨트, 벤치, 오비트, 매칭 파괴 → 모두 기존 로직 동일

### 4.2 전투 → 런 상태 전이

```
전투 시작:
  - 파티 9명 → heroQueue 로딩
  - 보드 = 스테이지 데이터 (적 배치)

전투 종료 (승리):
  - 벤치에 남은 크리터 → 다음 스테이지에 AP 감소 상태로 유지
  - 소진된 크리터(AP=0) → 다음 스테이지에서도 AP=0 (사용 불가)
  - 잔여 AP 크리터 → 그대로 다음 스테이지 투입

전투 종료 (패배 = 게임 오버):
  - 런 종료 → 부분 보상 → 홈타운 복귀
```

### 4.3 스테이지 간 크리터 상태 누적 (중요)

**벤치 = 런의 체력 시스템.**

| 상태                 | 다음 스테이지                                |
| -------------------- | -------------------------------------------- |
| 정상 출격 후 AP 소진 | heroQueue에서 제외 (이번 Floor 내 사용 불가) |
| 벤치행 (AP 잔여)     | heroQueue에 복귀 (잔여 AP 유지)              |
| 미출격 (큐에 남음)   | 그대로 유지 (AP 풀)                          |

**예시 시나리오**:

1. 파티: Fire3 Water3 Earth3 (각 AP=3)
2. 스테이지 1: Fire3명 출격 → 2명 소진, 1명 벤치행(AP=1)
3. 스테이지 2 시작 파티: Fire1(AP=1) + Water3(AP=3) + Earth3(AP=3) = 7명

### 4.4 난이도 지표 (수치 바이블 적용)

전투 노드 생성 시 다음 지표를 기반으로 적 배치를 결정한다.

| 지표             | Floor 1     | Floor 2          | Floor 3        | Boss           |
| ---------------- | ----------- | ---------------- | -------------- | -------------- |
| **총 적 HP**     | 12~16       | 18~24            | 24~32          | 35~45          |
| **원소 종류**    | 2~3         | 3~4              | 4~5            | 5~6            |
| **보드 크기**    | 4x4         | 4x5              | 5x5            | 5x6~6x6        |
| **특수 적 비율** | 0%          | 10~20%           | 20~30%         | 30~50%         |
| **AP 여유도**    | 1.5+ (easy) | 1.2~1.5 (normal) | 1.0~1.2 (hard) | 0.9~1.1 (boss) |

> 패널 공식 적용: `실제 난이도 = 기초 난이도 x Floor 계수 + World 보정`
>
> - Floor 계수: F1=1.0, F2=1.3, F3=1.6, Boss=2.0
> - World 보정: W1=0, W2=+3, W3=+6, W4=+9, W5=+12, W6=+15

## 5. 엘리트 노드

### 5.1 엘리트 규칙

- 일반 전투보다 **적 HP +50%, 특수 적 비율 +20%**
- 보상도 상향: **유물 1개 확정** + 정화 점수 2배

### 5.2 엘리트 난이도 지표

| 지표         | 값         | 근거                       |
| ------------ | ---------- | -------------------------- |
| 총 적 HP     | 일반 x 1.5 | 도전적이되 불가능하지 않음 |
| 특수 적 비율 | 일반 + 20% | 아머, 분열 등 복합 배치    |
| AP 여유도    | 0.9~1.1    | 최적 플레이 요구           |

## 6. 상점 노드

### 6.1 상점 구조

정화 점수(런 내 획득)를 소비하여 강화를 구매한다.

| 상품          | 가격 (정화 점수) | 효과                                      |
| ------------- | ---------------- | ----------------------------------------- |
| 크리터 레벨업 | 300~500          | 선택한 크리터 레벨 +1                     |
| 유물 구매     | 500~800          | 유물 3택1                                 |
| AP 회복       | 200              | 벤치 크리터 1명 AP 최대치 복원            |
| 크리터 교체   | 400              | 파티 크리터 1명을 새 크리터로 교체 (3택1) |

### 6.2 가격 스케일링

```
가격 = 기본 가격 x (1 + Floor번호 x 0.1)
```

| 상품   | Floor 1 | Floor 2 | Floor 3 |
| ------ | ------- | ------- | ------- |
| 레벨업 | 300~500 | 330~550 | 360~600 |
| 유물   | 500~800 | 550~880 | 600~960 |

## 7. 휴식 노드

### 7.1 휴식 효과 (택1)

| 선택지           | 효과                         | 디자인 의도                  |
| ---------------- | ---------------------------- | ---------------------------- |
| **야영 (Rest)**  | 모든 소진 크리터 AP 50% 회복 | 지구력 회복, 다음 Floor 대비 |
| **훈련 (Train)** | 크리터 1명 레벨업            | 장기 투자, 보스전 대비       |
| **정찰 (Scout)** | 다음 Floor 맵 전체 공개      | 정보 우위, 경로 최적화       |

### 7.2 벤치 초기화

휴식 노드 방문 시 **벤치가 초기화**된다 (벤치 슬롯 전부 비움). 이는 런의 "체크포인트" 역할을 한다.

## 9. 보상 시스템

### 9.1 전투 승리 보상

| 보상 유형       | 확률                       | 내용                   |
| --------------- | -------------------------- | ---------------------- |
| **정화 점수**   | 100%                       | 전투 스코어의 100%     |
| **크리터 영입** | 50%                        | 3택1 신규 크리터       |
| **유물**        | 15% (일반) / 100% (엘리트) | 3택1 유물              |
| **크리터 강화** | 35%                        | 파티 크리터 1명 레벨업 |

### 9.2 보상 선택 UI

전투 승리 후 보상 선택 화면:

```
┌─────────────────────────────┐
│     전투 승리!               │
│     정화 점수: +1,200       │
├─────────────────────────────┤
│                              │
│  [크리터 영입]  [강화]  [건너뛰기] │
│   불여우 Lv3   곰돌이    +200점  │
│   물수달 Lv2   레벨+1          │
│   바람토끼 Lv1                  │
│                              │
└─────────────────────────────┘
```

### 9.3 보상 가치 균형 (I/O 프레임워크)

| 투입                    | 산출                             | 성가비              |
| ----------------------- | -------------------------------- | ------------------- |
| 전투 1회 (파티 AP 소비) | 정화 점수 800~1500               | AP 1당 약 100~150점 |
| 엘리트 전투 1회         | 점수 1600~3000 + 유물            | AP 1당 약 200~300점 |
| 런 1회 (15~20분)        | 크리터 1~2명 + 유물 2~3개 + 점수 | 시간당 보상 적정    |

## 10. 런 종료 조건

### 10.1 승리

- 보스 Floor 클리어 → **월드 클리어**
- 영구 보상: 크리터 컬렉션에 런 중 영입 크리터 추가
- 다음 월드 해금

### 10.2 패배

- 전투 중 게임 오버 (벤치 풀, 큐 비어짐 등)
- 영구 보상: 정화 점수의 50%만 메타 통화로 전환
- 런 중 영입한 크리터는 **보유하지 못함** (재도전 동기)

### 10.3 포기

- 플레이어가 런을 도중 포기
- 패배와 동일 처리

## 속성 계층 분류 (수치 바이블 Section 2)

### 신규 1차 속성

| 속성                  | 분류                 | 대항 속성             |
| --------------------- | -------------------- | --------------------- |
| 파티 크기 (9)         | 1차 — 런 투입 자원   | 적 총 HP (Floor 합산) |
| 크리터 AP (누적 잔여) | 1차 — 전투 투입 자원 | 적 HP + 특수 적       |
| 정화 점수 (런 통화)   | 1차 — 경제 자원      | 상점 가격             |

### 신규 2차 속성

| 속성               | 분류                | 대항 속성        |
| ------------------ | ------------------- | ---------------- |
| 유물 효과          | 2차 — 보너스        | 엘리트/보스 강화 |
| 크리터 패시브      | 2차 — 조건부 보너스 | 적 특수 능력     |
| 이벤트 보상/리스크 | 2차 — 확률적 이득   | 이벤트 리스크    |

### 신규 3차 속성

| 속성              | 분류              | 역할               |
| ----------------- | ----------------- | ------------------ |
| Floor 난이도 계수 | 3차 — 스케일링    | 후반 밸런스 조정   |
| World 보정값      | 3차 — 글로벌 보정 | 월드별 전체 난이도 |

## 대항 속성 쌍 (수치 바이블 Section 8)

| 공격 측 (플레이어)  | 방어 측 (시스템)           | 균형 목표                     |
| ------------------- | -------------------------- | ----------------------------- |
| 파티 9명 총 AP      | Floor 총 적 HP             | AP 여유도 1.0~1.5             |
| 크리터 레벨업 (AP+) | Floor 난이도 계수 (적 HP+) | S자 곡선 유지                 |
| 유물 효과           | 특수 적 비율 증가          | 유물 2~3개 = 특수 적 30% 상쇄 |
| 정화 점수 축적      | 상점 가격 스케일링         | Floor당 1~2회 구매 가능       |
| 벤치 슬롯 (5개)     | 연속 전투 AP 소모          | 휴식 노드에서만 초기화        |
