# /kanban-status — 칸반 보드 현황 조회

## 목적

WanChai 칸반 보드의 전체 태스크 현황을 CLI 테이블로 출력합니다.
모든 팀원이 읽기 전용으로 사용할 수 있습니다.

## 인자

- `[필터]` (선택): `assignee:game-designer`, `priority:high`, `status:in_progress`, `sprint:sprint-003` 등
- 인자 없으면 전체 현황 요약

## 실행 절차

### 1. 데이터 로드

`WanChai/kanban.json` 파일을 Read 도구로 읽습니다.

### 2. 필터 적용

인자가 있으면 해당 필드로 필터링합니다.

### 3. 출력 형식

#### 요약 헤더

```
📋 WanChai 칸반 보드 — 2026-03-02 기준
총 태스크: 15 | 대기: 3 | 진행 중: 5 | 검토: 2 | QA 통과: 1 | 완료: 4
🔋 AI 토큰: 470.4K (Input: 278.0K / Output: 192.4K)
```

#### 상태별 테이블

```
🔲 대기 (3)
| ID       | 제목                    | 담당            | 우선순위 |
|----------|------------------------|----------------|---------|
| TASK-001 | 무기 코덱스 씬 UX 설계   | game-designer   | 🔴 high |
| TASK-002 | 메인 메뉴 레이아웃 구현   | ui-designer     | 🟡 mid  |

🔵 진행 중 (5)
| ID       | 제목                    | 담당            | 우선순위 | 시작일     |
|----------|------------------------|----------------|---------|-----------|
| TASK-003 | 패시브 시스템 구현       | programmer      | 🔴 high | 2026-03-01 |
...

...

🟢 QA 통과 (1)
...

...
```


## 우선순위 배지

- `critical`: 🔴🔴
- `high`: 🔴
- `mid`: 🟡
- `low`: 🟢

## 상태 매핑 (5컬럼)

- **대기**: `backlog`
- **진행 중**: `in_progress`
- **검토**: `done`, `qa_fail`, `redteam_reject`
- **QA 통과**: `qa_passed`
- **완료**: `final_done`
