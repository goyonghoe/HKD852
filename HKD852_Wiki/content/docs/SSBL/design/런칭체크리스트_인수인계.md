## 4. 알려진 기술 이슈

### LibreOffice 수식 재계산 폰트 오염 문제

**증상**: openpyxl로 폰트를 `Noto Sans KR`로 수정한 후 LibreOffice recalc 스크립트를 돌리면, 378셀이 다시 `Noto Sans CJK SC`로 복원됨.

**원인**: LibreOffice의 수식 재계산 프로세스가 셀 폰트 메타데이터를 부수효과로 변경함.

**해결 순서 (필수)**:

```
1. 용어/데이터 변경 (openpyxl)
2. 수식 재계산 (LibreOffice recalc)
3. 폰트 수정 (openpyxl) ← 반드시 recalc 이후에
4. 저장 (recalc 다시 돌리지 않음)
```

**잘못된 순서** (폰트가 다시 깨짐):

```
❌ 폰트 수정 → 수식 재계산 → 저장
```

### 폰트 수정 코드 (검증 완료)

```python
from openpyxl import load_workbook
from openpyxl.styles import Font

wb = load_workbook('파일경로.xlsx')
for ws in wb.worksheets:
    for row in ws.iter_rows():
        for cell in row:
            if cell.font:
                fn = cell.font.name or ''
                if 'CJK' in fn or fn == '' or fn == 'Calibri':
                    old = cell.font
                    cell.font = Font(
                        name='Noto Sans KR',
                        size=old.size if old.size else 11,
                        bold=old.bold,
                        italic=old.italic,
                        color=old.color,
                        underline=old.underline,
                        strikethrough=old.strikethrough
                    )
wb.save('출력경로.xlsx')
```

### 수식 재계산 (로컬)

```bash
libreoffice --headless --calc --convert-to xlsx 입력파일.xlsx --outdir 출력디렉토리/
```
