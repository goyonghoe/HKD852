## 1. 니치별 RPM 분석 (2025-2026 최신 데이터)

### 수익 구조 이해

YouTube Shorts는 **공유 수익 풀(Revenue Pool)** 모델을 사용합니다:

- Shorts 피드 광고 수익이 지역별 풀로 집계
- 음악 라이선싱 비용 차감 후 크리에이터 풀 배분
- 크리에이터는 자신의 풀 배분액의 **45%**를 수령 (롱폼 55% 대비 낮음)
- 음악 미사용 시 100% → 크리에이터 풀 / 1트랙 사용 시 50%만 크리에이터 풀
- **핵심**: 음악 없이 오리지널 보이스오버 사용 시 수익 극대화
