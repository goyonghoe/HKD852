# SNS 마케팅 카피 스킬

> 제품 홍보를 위한 플랫폼별 최적화된 마케팅 카피를 생성합니다.

## 실행 절차

### Step 1: 제품 분석

`$ARGUMENTS`에서 제품 정보를 파악합니다.

- 제품명 → `Income_Factory/pipeline/products/` 탐색
- 없으면 → 최신 런칭 제품 자동 선택

다음 정보를 정리:

- 제품의 핵심 가치 (어떤 문제를 해결하는가?)
- 타겟 고객 (누가 사용하는가?)
- 차별점 (경쟁 대비 장점)
- 가격 및 구매 링크

### Step 2: 플랫폼별 카피 생성

#### X (트위터)

- **런칭 트윗** (280자): 제품 소개 + CTA + 링크
- **쓰레드** (5~7개): 제작 과정, 기능 소개, 사용 사례
- **후속 트윗** (3개): 사용 팁, 할인, 고객 반응

규칙:

- 이모지 적절히 사용
- 해시태그 3~5개
- 링크는 마지막 트윗에

#### Instagram

- **피드 게시물 캡션**: 가치 제안 + 스토리 + CTA
- **릴스 스크립트** (30초): 훅 → 문제 → 솔루션 → CTA
- **해시태그**: 20~30개 (대형 5, 중형 10, 소형 15)

규칙:

- 첫 줄에 훅 (스크롤 멈추게)
- 줄바꿈으로 가독성 확보
- 프로필 링크 유도

#### YouTube

- **제목** (60자 이내): 키워드 + 호기심 유발
- **설명**: 요약 → 타임스탬프 → 링크 → 관련 영상
- **태그**: 15~20개
- **썸네일 텍스트**: 3~5단어 핵심 문구

규칙:

- 제목에 숫자/수치 포함
- 설명 첫 2줄에 핵심 키워드
- 챕터 타임스탬프 포함

#### Product Hunt (해당 시)

- **태그라인** (60자): 핵심 가치 한 줄
- **설명**: 제품 소개, 기능, 사용법
- **메이커 코멘트**: 제작 동기, 향후 계획

### Step 3: A/B 변형

각 플랫폼별 핵심 카피 2가지 변형 제시:

- **변형 A**: 감성적 접근 (스토리, 공감)
- **변형 B**: 실용적 접근 (수치, 기능)

### Step 4: 산출물 저장

산출물 경로: `Marketing_Agent/outputs/social_copy_YYYY-MM-DD.md`

## 인자 처리

- `$ARGUMENTS`가 비어있으면: Income_Factory 최신 제품 자동 탐색
- 제품명 지정 시: 해당 제품 중심 카피 생성
  - 예: `/social-copy AI 프롬프트팩`
- 플랫폼 지정 시: 해당 플랫폼만 집중
  - 예: `/social-copy 프롬프트팩 --platform youtube`
