# 온보딩 리뷰 스킬

> 설치→Aha Moment까지 9단계 온보딩 마이크로 퍼널을 리뷰합니다.

## 실행 절차

### Step 1: 온보딩 정보 수집

`$ARGUMENTS`에서 리뷰 대상을 파악합니다.

- 서비스명 → 관련 기획 문서 탐색
- 플로우 설명 → 텍스트 기반 플로우 파싱
- 없으면 → 가이드 기반 일반 리뷰 체크리스트 제공

수집 정보:

- 서비스 유형
- 현재 온보딩 단계 수
- 각 단계별 이탈률 데이터 (있으면)
- 타겟 사용자 특성

### Step 2: 9단계 플로우 분석

각 단계별 리뷰:

| #   | 단계                 | 핵심 체크 포인트                      |
| --- | -------------------- | ------------------------------------- |
| 1   | 설치 → 실행          | 앱 용량, 첫 실행 로딩 시간, 스플래시  |
| 2   | BI/CI 스플래시       | 노출 시간 3초 이내, 스킵 가능 여부    |
| 3   | 약관 동의            | 필수/선택 분리, 원터치 동의, 가독성   |
| 4   | 로그인/게스트        | 게스트 퍼스트, 소셜 로그인 순서, 스킵 |
| 5   | 추가 리소스 다운로드 | 프로그레스바, 용량 표시, 백그라운드   |
| 6   | 계정/프로필 생성     | 최소 입력, 랜덤 닉네임, 후속 설정     |
| 7   | 권한 요청            | Just-in-time, 설명 충분, 필수만       |
| 8   | 튜토리얼/FTUE        | 인터랙티브, 스킵 가능, 점진적 공개    |
| 9   | Aha Moment           | 목표 시간 내 도달, 보상 명확          |

### Step 3: 이탈 포인트 식별

각 단계에 대해:

- 예상/실제 이탈률 평가
- 이탈 원인 분류:
  - 기술적 (로딩, 크래시)
  - UX (혼란, 피로)
  - 동기 부족 (가치 불명확)
  - 마찰 (불필요한 입력, 대기)

### Step 4: 시장별 차이 분석

| 요소   | 한국          | 북미         | 중국      | 일본   |
| ------ | ------------- | ------------ | --------- | ------ |
| 약관   | 엄격 (KISA)   | CCPA/COPPA   | 실명인증  | APPI   |
| 로그인 | 카카오/네이버 | Google/Apple | WeChat/QQ | LINE/X |
| 결제   | 원스토어 고려 | -            | Alipay    | -      |

### Step 5: 개선 우선순위

매트릭스 기반 우선순위화:

| 우선순위  | 기준                    |
| --------- | ----------------------- |
| P0 (즉시) | 이탈률 높음 + 수정 쉬움 |
| P1 (1주)  | 이탈률 높음 + 수정 보통 |
| P2 (2주)  | 이탈률 보통 + 수정 쉬움 |
| P3 (분기) | 구조적 변경 필요        |

### Step 6: 가이드 참조

분석 시 다음 가이드를 참조합니다:

- `Growth_Agent/guides/onboarding-funnel-design-guide.html` — 9단계 상세 설계
- `Growth_Agent/guides/mobile-funnel-strategy-guide.html` — Activation 단계 전략

### Step 7: 산출물 저장

산출물 경로: `Growth_Agent/outputs/onboarding_review_YYYY-MM-DD.md`

## 인자 처리

- `$ARGUMENTS`가 비어있으면: 일반 온보딩 리뷰 체크리스트 제공
- 서비스명 지정 시: 해당 서비스 맞춤 리뷰
  - 예: `/onboarding-review 화투 로그라이크`
- 플로우 설명 시: 설명 기반 리뷰
  - 예: `/onboarding-review "설치→스플래시→약관→게스트→튜토리얼→메인"`
