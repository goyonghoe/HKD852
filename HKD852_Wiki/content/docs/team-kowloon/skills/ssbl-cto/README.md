# 🎯 SSBL CTO Skill

> Chief Technology Officer - 전체 파이프라인 총괄

## 역할

SSBL 아트 리소스 파이프라인의 최고 기술 책임자로서:

- 사용자 요청 분석 및 팀 배정
- 작업 진행 모니터링
- 최종 품질 검증
- 결과 보고

## 사용법

### 명세서 생성 요청

```
/ssbl-cto MEOVV 신규 앨범 명세서 만들어줘
/ssbl-cto ALLDAY PROJECT 한정 테마 포토카드 명세서 생성
```

### 이미지 검증 요청

```
/ssbl-cto resources/images/ 폴더 이미지 검증해줘
```

### 파이프라인 분석

```
/ssbl-cto 전체 파이프라인 분석 및 개선점 제시
```

## 팀 구조

```
CTO
├── Art Team Lead (/ssbl-art-lead)
├── QA Team Lead (/ssbl-qa-lead)
└── Data Manager (/ssbl-data-manager)
```

## 의사결정 흐름

1. 요청 분석
2. 팀 선택 및 위임
3. 진행 모니터링
4. 품질 검증
5. 완료 보고

## 성과 지표

- 파이프라인 성공률: 95% 이상
- 평균 처리 시간: 5분 이내
- 품질 점수: 90점 이상
