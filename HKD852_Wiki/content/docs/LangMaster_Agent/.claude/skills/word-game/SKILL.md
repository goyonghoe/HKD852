# Word Game — 미니게임 설계 스킬

## 역할

HSK 단어 학습에 최적화된 하이퍼캐주얼 미니게임을 설계하고 프로토타이핑한다.

## 입력

사용자가 다음 중 하나를 요청:

- 새 미니게임 아이디어 설계
- 기존 미니게임 개선
- 특정 학습 목표에 맞는 게임 메카닉 제안

## 실행 절차

### 1. 요구사항 파악

```
- 대상 HSK 레벨: (1-9, HSK 3.0 기준)
- 학습 목표: (인식/발음/의미/맥락/구조/번역)
- 세션 길이: (15초/30초/60초)
- 조작 방식: (탭/스와이프/드래그/타이핑)
```

### 2. 게임 메카닉 설계

각 미니게임에 필수 포함:

- **Core Loop**: 한 판의 시작→진행→종료 흐름
- **학습 매핑**: 어떤 단어 지식이 강화되는지
- **난이도 스케일**: HSK 레벨/숙련도에 따른 변화
- **SRS 연동**: 복습 필요 단어가 게임에 어떻게 삽입되는지
- **피드백**: 정답/오답 시 즉각 반응

### 3. 프로토타입 출력

HTML+JS로 플레이 가능한 프로토타입 생성:

- 파일 위치: `LangMaster_Agent/outputs/prototypes/{game-name}.html`
- 터치/클릭 조작 지원
- 샘플 HSK 단어 10개 내장
- 점수/타이머 표시

### 4. 설계 문서 출력

```yaml
game_name: "Word Fall"
mechanic: "떨어지는 한자 + 하단 4지선다 뜻 선택"
learning_target: "한자→의미 인식 속도"
session_length: "30초"
words_per_session: 8
difficulty_params:
  fall_speed: [1.0, 1.2, 1.4, 1.6, 1.8, 2.0, 2.2, 2.4, 2.6] # HSK 1~9
  choices: [2, 3, 4, 4, 4, 4, 4, 4, 4] # 선택지 수
  time_bonus: true
srs_integration: "틀린 단어 → 같은 세션 내 재등장 + 다음 세션 큐"
```

위치: `LangMaster_Agent/design/games/{game-name}.yaml`

## 미니게임 레퍼런스 (8종)

| #   | 이름             | 메카닉                       | 학습 효과 | HSK 대응 |
| --- | ---------------- | ---------------------------- | --------- | -------- |
| 1   | Word Fall        | 떨어지는 한자 → 뜻 선택      | 인식 속도 | 1-9      |
| 2   | Pinyin Shooter   | 한자 보고 병음 사격          | 발음 매핑 | 1-9      |
| 3   | Match Rush       | 한자-뜻 카드 매칭            | 쌍 기억   | 1-9      |
| 4   | Fill Blast       | 문장 빈칸 채우기             | 맥락 이해 | 2-9      |
| 5   | Tone Surf        | 성조별 파도타기              | 성조 구별 | 1-6      |
| 6   | Radical Builder  | 부수 조합 → 한자 완성        | 한자 구조 | 3-9      |
| 7   | Translate Sprint | 모국어→중국어 빠른 번역      | 번역 능력 | 6-9      |
| 8   | Context Weaver   | 고급 문장에 적절한 단어 배치 | 문맥/문법 | 5-9      |

> 게임 7-8은 HSK 3.0 신규 요구사항(번역 능력, 고급 문맥 추론) 대응

## 설계 원칙

1. **3초 규칙**: 게임 시작 3초 안에 플레이 방법 이해 가능
2. **One-hand Play**: 한 손(엄지) 조작 가능
3. **30초 세션**: 지하철 한 정거장에 한 판
4. **즉각 피드백**: 정답=초록 반짝 + 효과음, 오답=빨간 흔들림 + 정답 표시
5. **학습 은닉**: 유저는 "게임"을 한다고 느끼지, "공부"한다고 느끼면 안 됨
