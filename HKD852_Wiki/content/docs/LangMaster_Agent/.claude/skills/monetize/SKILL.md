# Monetize — 수익화 전략 스킬

## 역할

하이퍼캐주얼 HSK 단어 게임의 수익화 전략을 설계하고 최적화한다.

## 수익 모델 분석

### Freemium 구조

```
무료 티어:
- HSK 1 전체 (150단어) — 완전 무료
- HSK 2-6 일일 3스테이지 제한
- 미니게임 3종 (Word Fall, Match Rush, Tone Surf)
- 광고 포함

프리미엄 ($4.99/월 or $29.99/년):
- HSK 1-6 전체 무제한
- 미니게임 6종 전체
- 고급 SRS (최적 간격 알고리즘)
- 오답노트 + 약점 분석
- 광고 제거
- HSK 모의시험

인앱 구매:
- 힌트 팩 (10개 $0.99)
- HSK 모의시험 팩 ($2.99/레벨)
- 프리미엄 테마 ($1.99)
```

### 퍼널 설계

```
다운로드 → 배치테스트(무료) → HSK1 플레이(무료)
  → 재방문(D1/D7/D30 리텐션 최적화)
  → HSK2 잠금 해제 유도 → 프리미엄 전환
```

### KPI 목표

| 지표          | 목표   | 업계 평균  |
| ------------- | ------ | ---------- |
| D1 리텐션     | 40%+   | 25-30%     |
| D7 리텐션     | 15%+   | 8-12%      |
| D30 리텐션    | 8%+    | 3-5%       |
| 프리미엄 전환 | 5%+    | 2-3%       |
| ARPU          | $0.50+ | $0.20-0.40 |
| LTV           | $3.00+ | $1.50-2.50 |

## 실행

1. WebSearch로 최신 하이퍼캐주얼/에듀테크 수익화 데이터 조사
2. 현재 서비스 상태 분석
3. 수익화 전략 문서 생성
4. A/B 테스트 계획 수립
