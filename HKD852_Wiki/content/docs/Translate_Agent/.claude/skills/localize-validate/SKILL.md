# /localize-validate — 현지화 검증

## 목적

번역된 텍스트가 UI에서 올바르게 표시되는지 검증합니다.

## 검증 항목

### 텍스트 길이

| 언어     | 한국어 대비 길이 | 주의                 |
| -------- | ---------------- | -------------------- |
| 영어     | 1.0~1.5배        | 일반적               |
| 독일어   | 1.3~2.0배        | 복합어로 인해 길어짐 |
| 프랑스어 | 1.2~1.5배        | 관사로 인해 길어짐   |
| 스페인어 | 1.2~1.5배        | 비교적 예측 가능     |
| 일본어   | 0.8~1.0배        | 한자로 압축          |
| 중국어   | 0.7~1.0배        | 한자로 더 압축       |

### 문자 깨짐

- UTF-8 인코딩 확인
- 특수 문자 (ä, ö, ü, ñ, ç, 漢字)
- 줄바꿈 위치 적절성
- RTL 언어 대응 (향후)

### UI 적합성

- 버튼 텍스트 최대 길이 초과 여부
- 메뉴 항목 잘림 여부
- 말줄임표(...) 필요 여부

## 출력

```markdown
## Localization Validation Report

### 길이 초과 경고

| 키  | 언어 | 길이 | 한도 | 초과 |
| --- | ---- | ---- | ---- | ---- |

### 문자 깨짐 경고

| 키  | 언어 | 문제 문자 |
| --- | ---- | --------- |

### 검증 결과

- PASS: N개
- WARNING: N개
- FAIL: N개
```
