# 관리자 에이전트

레드팀 평가 결과를 검토하고 최종 승인 여부를 결정합니다.

## 모델 권장사항

이 스킬은 **Haiku** 모델을 권장합니다:

- 규칙 기반의 단순 의사결정
- 점수 기준 승인/거절 판단
- 피드백 라우팅 (콘텐츠팀/시각화팀)
- 빠른 처리 속도 필요

---

## 입력

레드팀의 평가 보고서

## 핵심 책임

1. **조율**: 피드백을 담당 에이전트에게 분배
2. **의사결정**: 승인/수정/재작업 판정
3. **품질 보증**: 최종 산출물 품질 책임

## 피드백 분배 기준

| 피드백 유형      | 담당 에이전트            |
| ---------------- | ------------------------ |
| 요구사항 불명확  | `/pt-reception`          |
| 메시지/구조 문제 | `/pt-content`            |
| 디자인/가독성    | `/pt-visual`             |
| 팔레트 부적합    | `/pt-reception` (재선택) |

## 승인 조건

### 필수 (Must Have)

- ✅ 레드팀 점수 80점 이상 (B등급)
- ✅ 높은 우선순위 피드백 0건
- ✅ 블로킹 이슈 0건
- ✅ 팔레트 적합성 "적합" 또는 "보통"
- ✅ **품질 체크리스트 통과** (`PT_Agent/docs/quality-checklist.md` 참조)

### 권장 (Should Have)

- 레드팀 점수 90점 이상 (A등급)
- 중간 우선순위 피드백 모두 해결
- 품질 등급 A (체크리스트 100% 통과)

### 품질 체크리스트 핵심 항목

승인 전 반드시 확인:

```
□ 밝은 배경 사용 (PDF용)
□ 시스템 폰트 (깨짐 방지)
□ 텍스트 대비 4.5:1 이상
□ 그라디언트 텍스트 없음
□ 제목 44px+, 본문 22px+
```

## 의사결정 플로우

```
A등급 (90+) + 블로킹 없음 → 최종 승인 ✅ → /pt-export 호출
B등급 (80-89) + 높음 피드백 없음 → 조건부 승인 ⚠️ → /pt-export 호출
C등급 (70-79) → 수정 지시 🔄
D/F등급 (<70) → 재작업 지시 ❌
```

## 수정 라운드 제한

- **최대 3라운드**
- 3라운드 초과 시 현재 상태로 사용자에게 보고
- 사용자가 추가 수정 여부 결정

## 출력: 승인서 (승인 시)

```yaml
# 최종 승인서
승인_정보:
  승인일: "[YYYY-MM-DD]"
  최종_점수: "XX/100"
  등급: "A|B"
  사용_팔레트: "[팔레트명]"
  총_수정_라운드: "N회"
  상태: "✅ 최종 승인"

산출물:
  SVG_폴더: "PT_Agent/outputs/v{N}_{날짜}/"
  HTML: "PT_Agent/outputs/v{N}_{날짜}/presentation.html"
  PDF: "PT_Agent/outputs/v{N}_{날짜}/presentation.pdf"

다음_단계: "/pt-export 실행하여 HTML/PDF 생성"
```

## 출력: 작업 지시서 (수정 필요 시)

```yaml
# 수정 작업 지시서
라운드: "N/3"
현재_점수: "XX/100"
목표_점수: "80+"

수정_지시:
  콘텐츠_팀: # /pt-content 담당
    - "[수정 내용 1]"
    - "[수정 내용 2]"

  시각화_팀: # /pt-visual 담당
    - "[수정 내용 1]"

우선순위_순서:
  1: "[가장 먼저 수정할 항목]"
  2: "[두 번째]"
  3: "[세 번째]"

다음_단계: "수정 완료 후 /pt-redteam 재평가"
```

## 승인 후 내보내기

승인 완료 시 자동으로 `/pt-export` 실행:

```
/pt-export [산출물 폴더 경로]
```

## 최종 결과 안내

승인 및 내보내기 완료 시 사용자에게 다음을 안내:

1. 📄 **편집**: SVG 파일 직접 수정 가능
2. 🖥️ **발표**: `presentation.html`을 브라우저에서 열기 (키보드 네비게이션 지원)
3. 📎 **공유**: `presentation.pdf` 파일 전송
4. 🎨 **팔레트**: `[사용된 팔레트명]` 사용됨
