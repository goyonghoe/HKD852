# 콘텐츠 설계 에이전트

스펙 문서를 기반으로 프레젠테이션의 구조와 내용을 설계합니다.

## 모델 권장사항

이 스킬은 **Sonnet** 모델을 권장합니다:

- 스토리텔링 설계에 창의성 필요
- 피라미드 구조 논리 설계
- 비용 대비 품질 최적
- Opus보다 빠른 응답 속도

---

## 입력

접수 데스크에서 생성한 스펙 문서 (YAML)

- 선택된 컬러 팔레트 정보 포함

## 설계 원칙

### 피라미드 원칙 (Minto)

> "Think bottom-up, present top-down"

- 결론 먼저, 근거는 나중에
- 청중의 "So What?" 질문에 즉시 답변

### SCQA 스토리 구조

1. **S**ituation (상황): 현재 상태
2. **C**omplication (복잡성): 문제/변화
3. **Q**uestion (질문): 해결해야 할 것
4. **A**nswer (답변): 제안하는 해결책

### 구성 비율

```
도입 (10%) → 전개 (80%) → 결론 (10%)
```

## 핵심 규칙

| 규칙          | 설명                              |
| ------------- | --------------------------------- |
| Rule of Three | 핵심 포인트 3개 이내              |
| 1-7-7 Rule    | 1 아이디어/7줄/7단어 per 슬라이드 |
| MECE          | 상호배제, 전체포괄                |

## 시간별 슬라이드 가이드

| 발표 시간 | 슬라이드 수 | 슬라이드당 시간 |
| --------- | ----------- | --------------- |
| 5분       | 5-7장       | ~45초           |
| 10분      | 8-12장      | ~50초           |
| 15분      | 12-18장     | ~50초           |
| 30분      | 20-30장     | ~60초           |

## 슬라이드 유형

- `title`: 표지
- `executive_summary`: 핵심 요약 (결론 먼저)
- `agenda`: 목차/개요
- `content`: 일반 내용
- `data`: 데이터/차트
- `comparison`: 비교
- `flow`: 프로세스/플로우
- `quote`: 인용문
- `cta`: Call to Action
- `closing`: 마무리

## 출력: 슬라이드 구조 문서

```yaml
# 슬라이드 구조 문서
메타정보:
  총_슬라이드_수: N
  예상_발표_시간: "N분"
  스토리_구조: "SCQA"
  선택된_팔레트: "[pt-reception에서 결정된 팔레트]"

슬라이드_목록:
  - 번호: 1
    유형: title
    제목: "[프레젠테이션 제목]"
    부제: "[부제목 또는 발표자 정보]"
    발표자_노트: |
      [인사말 및 발표 시작 멘트]

  - 번호: 2
    유형: executive_summary
    제목: "[핵심 결론]"
    내용:
      - "[결론 1]"
      - "[결론 2]"
    강조: "[가장 중요한 메시지]"
    발표자_노트: |
      [핵심 요약 설명 - 30초 이내]

  - 번호: 3
    유형: agenda
    제목: "목차"
    내용:
      - "1. [첫 번째 섹션]"
      - "2. [두 번째 섹션]"
      - "3. [세 번째 섹션]"
    발표자_노트: |
      [전체 흐름 안내 멘트]

  - 번호: 4
    유형: content
    섹션: "[섹션명]"
    제목: "[슬라이드 제목]"
    내용:
      - "[핵심 포인트 1]"
      - "[핵심 포인트 2]"
      - "[핵심 포인트 3]"
    시각_요소: "[필요시: 차트/이미지/아이콘 설명]"
    발표자_노트: |
      [상세 설명 및 전환 멘트]

  # ... 추가 슬라이드

  - 번호: N
    유형: cta
    제목: "[행동 촉구 메시지]"
    내용:
      - "[구체적인 다음 단계]"
    발표자_노트: |
      [마무리 멘트 및 Q&A 안내]
```
