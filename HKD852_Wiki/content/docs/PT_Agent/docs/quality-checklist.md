## 1. PDF 변환 전 필수 체크

### 1.1 테마 & 배경

| 항목        | 권장                 | 금지                     |
| ----------- | -------------------- | ------------------------ |
| 배경색      | `#FFFFFF` (흰색)     | 다크 테마 (`#1a1a2e` 등) |
| 텍스트 대비 | 4.5:1 이상           | 낮은 대비                |
| 그라디언트  | 배경에만 제한적 사용 | 텍스트에 그라디언트      |

**이유**: PDF 렌더링에서 다크 테마는 프린트 시 잉크 소모가 크고, 그라디언트 텍스트는 렌더링 문제 발생

### 1.2 폰트

```css
/* 권장 폰트 스택 */
font-family: "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif;
```

| 항목 | 권장                               | 금지                     |
| ---- | ---------------------------------- | ------------------------ |
| 한글 | Apple SD Gothic Neo, Malgun Gothic | 커스텀 웹폰트            |
| 영문 | 시스템 sans-serif                  | Google Fonts (로딩 필요) |
| 코드 | SF Mono, Monaco, Menlo             | 외부 코드 폰트           |

**이유**: 시스템 폰트는 깨짐 없이 100% 렌더링 보장

### 1.3 폰트 크기

| 요소        | 최소 크기 | 권장 크기   |
| ----------- | --------- | ----------- |
| 제목 (h1)   | 40px      | **44-52px** |
| 부제목 (h2) | 28px      | **32px**    |
| 본문        | 20px      | **22-24px** |
| 테이블      | 16px      | **18px**    |
| 코드        | 14px      | **16px**    |

### 1.4 색상

```css
/* 권장 색상 체계 */
:root {
  --text-primary: #222222; /* 본문 */
  --text-secondary: #555555; /* 부가 정보 */
  --accent: #ff6b6b; /* 강조 (단일 색상) */
  --background: #ffffff; /* 배경 */
  --code-bg: #f5f5f5; /* 코드 배경 */
}
```

| 항목        | 권장                  | 금지                  |
| ----------- | --------------------- | --------------------- |
| 강조 색상   | 단일 색상 통일        | 여러 강조 색상 혼용   |
| 텍스트 색상 | `#222222` ~ `#444444` | 회색 이상 밝은 텍스트 |
| 링크 색상   | accent 색상과 통일    | 기본 파란색           |

## 2. 레이아웃 체크

### 2.1 여백 (Padding)

```css
section {
  padding: 50px 70px; /* 상하 50px, 좌우 70px */
}
```

### 2.2 줄 간격

```css
p,
li {
  line-height: 1.6 ~1.7;
}
```

### 2.3 슬라이드당 콘텐츠 양

| 유형        | 최대 권장 |
| ----------- | --------- |
| 불릿 포인트 | 5-6개     |
| 테이블 행   | 6-7행     |
| 텍스트 단락 | 3단락     |

## 3. 슬라이드 유형별 체크

### 3.1 타이틀 슬라이드

```markdown
<!-- _class: title -->
<!-- _paginate: false -->
```

- [ ] 중앙 정렬
- [ ] 그라디언트 배경 허용 (텍스트는 단색)
- [ ] 페이지 번호 숨김

### 3.2 섹션 구분 슬라이드

```markdown
<!-- _class: section -->
```

- [ ] 밝은 회색 배경 (`#F8F9FA`)
- [ ] 큰 제목만 표시
- [ ] 중앙 정렬

### 3.3 콘텐츠 슬라이드

- [ ] 제목 + 부제목 구조
- [ ] 불릿 또는 번호 리스트
- [ ] 핵심 내용 **강조** 표시

### 3.4 데이터/테이블 슬라이드

- [ ] 테이블 헤더 배경색 적용
- [ ] 짝수/홀수 행 구분
- [ ] 명확한 border

### 3.5 인용 슬라이드

```markdown
<!-- _class: quote -->
```

- [ ] 좌측 강조 바 (`border-left`)
- [ ] 이탤릭 스타일
- [ ] 출처 표기

### 3.6 엔딩 슬라이드

```markdown
<!-- _class: ending -->
<!-- _paginate: false -->
```

- [ ] 타이틀과 동일한 스타일
- [ ] CTA 또는 연락처 포함

## 4. 변환 명령어

### 4.1 Marp CLI (권장)

```bash
# 기본 PDF 변환
npx @marp-team/marp-cli input.md --pdf -o output.pdf

# 로컬 이미지 포함 시
npx @marp-team/marp-cli input.md --pdf --allow-local-files -o output.pdf

# HTML 변환 (프레젠테이션 모드)
npx @marp-team/marp-cli input.md --html -o output.html
```

### 4.2 변환 후 검증

- [ ] PDF 파일 열어서 전체 슬라이드 확인
- [ ] 폰트 깨짐 없음
- [ ] 색상 정확히 렌더링됨
- [ ] 레이아웃 유지됨
- [ ] 페이지 번호 정상 표시

## 5. 문제 해결 가이드

| 증상                      | 원인                      | 해결                         |
| ------------------------- | ------------------------- | ---------------------------- |
| 폰트 깨짐/네모 표시       | 웹폰트 사용               | 시스템 폰트로 변경           |
| 그라디언트 텍스트 안 보임 | `-webkit-text-fill-color` | 단색으로 변경                |
| 배경 안 나옴              | `backgroundColor` 누락    | CSS `background` 사용        |
| 코드 블록 잘림            | `overflow` 미설정         | `overflow-x: auto` 추가      |
| 테이블 border 안 보임     | `border-collapse` 문제    | 명시적 border 설정           |
| 이미지 안 나옴            | 로컬 파일 접근 제한       | `--allow-local-files` 플래그 |
