# 종목 심층 분석

개별 종목을 투자 전략 §4.1~§4.2 기반으로 종합 평가합니다.

## 참조 문서
- 투자 전략: `Invest_Agent/docs/strategy.md` (§4 가치 평가 및 재무 분석)
- 규칙 엔진: `Invest_Agent/app/src/lib/strategy/rules.ts`

## 데이터 수집

### 1단계: 기본 데이터 (API)
```bash
# 종목 상세 정보
curl -s "https://invest-dashboard-azure.vercel.app/api/stock/[종목코드]"
```
반환: closePrice, per, pbr, eps, bps, dividend, dividendYield, volume, high52w, low52w

### 2단계: 추가 정보 (WebSearch)
종목코드가 주어지면 다음을 검색:
- "[종목명] 재무제표 2025" — 매출액, 영업이익, 이익잉여금
- "[종목명] 업종 PER" — 동종 업종 평균 PER 비교
- "[종목명] 배당 이력" — 최근 3년 배당금 추세

## 분석 항목 (전략 §4.1~§4.2 기반)

### A. 가치 평가 (§4.1)

#### PBR 분석
- PBR < 1: "현재 재산보다 낮게 평가 — 저평가 상태"
- PBR 1~2: "적정 수준"
- PBR > 2: "프리미엄 평가 — 성장 기대 반영"

#### PER 분석
- **반드시 동일 업종 평균 PER과 비교** (§4.1 핵심)
- PER < 업종 평균: "업종 대비 저평가"
- PER > 업종 평균: "업종 대비 고평가"
- 적자 기업 (PER 없음): 주의 필요

### B. 재무제표 분석 (§4.2)

#### 재무상태표
- **유동자산 비율**: 현금화 용이한 자산 비중
- **이익잉여금**: 배당 재원 규모 (클수록 배당 여력 큼)
- **부채비율**: 자본 대비 부채 (200% 초과 시 주의)

#### 손익계산서
- **매출액 추이**: 최근 3년 증가 추세 확인 (§4.2 핵심)
- **영업이익률**: 직접적 사업 경쟁력 지표 (개선 여부)

### C. 전략 적합도

- **배당 투자 적합성** (§3.2): 배당수익률 3%+, 안정적 배당 성향
- **저평가 매수 조건** (§2.3): PBR < 1이면 역발상 매수 후보
- **주도주 가능성** (§3.3): 수출 증가 기업, 시장 주도 섹터 여부
- **손절 기준 설정**: 현재가 기준 -10% = 손절가 제안 (§2.1)

## FOMO 방지 (§5.3)
- 분석 결과에 자극적 표현 사용 금지
- "강력 매수", "무조건 사야 할" 등의 표현 절대 금지
- 숫자와 비교 데이터만 객관적으로 제시
- 최종 투자 판단은 CEO(사용자)의 몫
