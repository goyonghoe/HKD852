# Design Principles

1. **경험 우선**: 수치 설계 전에 "플레이어가 무엇을 느끼는가" 먼저 정의
2. **카운터 페어**: 모든 속성에는 대응 속성이 존재해야 함
3. **점진적 복잡도**: 튜토리얼 → 기본 → 심화 순으로 메카닉 도입
4. **60초 규칙**: 핵심 루프는 60초 이내에 체험 가능
5. **보상 간격**: 15~30초마다 작은 보상, 3~5분마다 큰 보상
6. **공정한 실패**: 모든 사망은 플레이어가 "내 실수" 라고 납득 가능해야 함
