3. ✅ `tests/core/ObjectPool.test.ts` — 12개 테스트

   - ObjectPool: 생성/재사용/초기크기/전체해제/리셋콜백/외부객체/파괴

4. ✅ GameScene 최적화 적용
   - 투사체 비주얼: `add.circle()` → `CirclePool.acquire/release`
   - XP젬 비주얼: `add.circle()` → `CirclePool.acquire/release`
   - 데미지 넘버: `add.text()` → `TextPool.acquire/release`
   - 배열 제거: `Array.splice()` → `swapRemove()` (적/투사체/XP젬)
   - 충돌 검사: `Math.sqrt()` → 제곱 거리 비교 (distSq < r²)
   - 씬 종료 시 풀 정리: `circlePool.destroy()` + `textPool.destroy()`

### 성능 개선 포인트

| 항목 | Before | After |
|------|--------|-------|
| 투사체 생성/파괴 | `new` + `destroy()` 매 프레임 | 풀 재사용 (GC 없음) |
| 데미지 넘버 | `new Text` + `destroy()` 매 히트 | 풀 재사용 |
| 배열 원소 제거 | `splice()` O(n) | `swapRemove()` O(1) |
| 충돌 거리 계산 | `Math.sqrt()` 매 쌍 | 제곱 비교 (sqrt 제거) |
