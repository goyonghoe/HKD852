# Neon Survivors — Team Communication Logs

## 구조

- `YYYY-MM-DD-session-NNN.md` — 세션별 원본 대화 로그 (raw)
- `YYYY-MM-DD-summary.md` — 일일 작업 요약
- Obsidian Vault 동기화: `/HKD852_Vault/02_Projects/ShamShuiPo/team-logs/`

## 로그 형식

각 에이전트 메시지는 다음 형식으로 기록됩니다:

```
### [HH:MM] sender → receiver
> 메시지 내용

**Context**: 작업 맥락
**Decision**: 결정 사항 (있을 경우)
```

## 에이전트 약칭

- **GD**: Game Designer
- **PG**: Programmer
- **AD**: Art Director
- **UID**: UI Designer
- **BD**: Balance Designer
- **AUD**: Audio Designer
- **ORCH**: Orchestrator (메인 세션)
