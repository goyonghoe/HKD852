## 1. 엘리베이터 피치 (확정)

> **"적을 죽여 네온 한자를 모으고, 한자 조합으로 무기를 변신시키고, 변신한 무기로 보스의 네온 방패를 깨는 게임."**

이 문장은 Vampire Survivors, Brotato, HoloCure, Soulstone Survivors 어떤 불릿 헤븐에도 적용할 수 없다. 네온 파편이 **무기 변환의 연료**이자 **보스 공략의 열쇠**이자 **경제 자원**으로 기능하기 때문이다.

## 3. 확정 코어 루프

### 3.1 루프 구조

```
Kill → 네온 파편 수집 (무기 친화도 기반)
  ↓
자동 콤보 매칭 → 복수 콤보 가능 시 2지선다 팝업 (3초 자동해제)
  ↓
  ├─ 무기 변환 (Transmute): 20초간 무기 변신, 파워 스파이크
  ├─ 대배당 (Dai Pai Dong): 코인으로 음식/파편 구매
  └─ 보스 실드 파쇄 (Shatter): 파편 직접 소비로 실드 해제
  ↓
크로노 핵: 슬로우 중 파편 수명 정지 + 마그넷 2배
  ↓
반복
```

### 3.2 핵심 변경 (SPEC-033 대비)

| 항목               | SPEC-033 (기각)                 | SPEC-034 (확정)          | 이유                                          |
| ------------------ | ------------------------------- | ------------------------ | --------------------------------------------- |
| 파편 종류          | 9종                             | **6종** (大吉火力金龍)   | 인지 부하 감소, 6종으로 8개 콤보 충분         |
| 파편 드롭률        | Tier1: 25%                      | **전체 17% 균등**        | 단일 권위 수치. 300킬/10분 기준 ~50 수집 역산 |
| 파편 보유 상한     | 5칸                             | **4칸**                  | 3파편 콤보 가능 + 비축 제한                   |
| 콤보 발동          | 수동 (NEON 버튼 + 3지선다 메뉴) | **자동 + 2지선다 팝업**  | 한 손 조작 보존                               |
| 보스 실드 해제     | 콤보 버프 상태에서 공격         | **파편 직접 소비**       | 비축 vs 변환 트레이드오프 강제                |
| 파편 인벤토리 수명 | 30초                            | **무제한** (필드만 20초) | 보스전 파편 보존 전략 허용                    |
| 대배당 파편 통화   | 파편으로 결제 가능              | **코인 전용** (MVP)      | 복잡도 축소, Phase 2에서 파편 통화 추가       |
| DPS 배율 상한      | 없음                            | **하드캡 3.0배**         | 크로노+콤보+음식 스택 폭발 방지               |

### 3.3 조작 흐름 (한 손 보존)

```
[기본 상태]
  왼손: 조이스틱으로 이동 (항상 유지)
  공격: 자동 (터치 불필요)

[파편 수집 → 콤보 가능]
  케이스 A: 콤보 1개만 가능
    → 자동 발동 (입력 불필요)
    → HUD에 "火力!" 텍스트 + 무기 변환 이펙트

  케이스 B: 콤보 2개 이상 가능
    → 화면 중앙 상단에 2지선다 팝업 표시
    → 왼쪽/오른쪽 탭으로 선택 (조이스틱과 간섭 없는 영역)
    → 3초 내 미선택 시 첫 번째 콤보 자동 발동
    → 전투 중단 없음 (팝업은 오버레이)

[대배당 상점]
  접근 → 즉시 메뉴 표시 + 1초 무적
  메뉴 항목 탭 → 구매 → 자동 닫힘
  이탈 시 자동 닫힘

[보스 실드 해제]
  보스 접근 시 HUD에 "파편 투척" 버튼 표시
  버튼 탭 → 보유 파편 중 실드 해제에 필요한 파편 자동 소비
  파편 부족 시 버튼 비활성 (실드는 시간 경과로도 서서히 약화)
```

### 3.4 60초 규칙 검증

| 초    | 플레이어 행동                        | 느끼는 감정                           |
| ----- | ------------------------------------ | ------------------------------------- |
| 0~15  | 적 처치, 첫 파편 1~2개 자동 수집     | "뭔가 빛나는 게 떨어진다"             |
| 15~30 | 파편 2개 → 자동 콤보 발동, 무기 변환 | "내 무기가 불타오른다!" (입력 불필요) |
| 30~45 | 변환된 무기로 적 무쌍                | 파워 판타지                           |
| 45~60 | 변환 종료, 다음 파편 수집 시작       | "또 변환하고 싶다"                    |

**60초 이내에 핵심 루프 전체를 체험한다. 조이스틱에서 손을 뗄 필요가 없다.**

### 4.3 무기-파편 친화도 (Weapon-Fragment Affinity)

각 무기는 하나의 PRIMARY 파편을 가진다. 해당 무기 보유 시 PRIMARY 파편의 드롭률이 가중 상승한다.

| 무기                        | 친화 파편 (PRIMARY) | 이유                  | 드롭률 보너스 |
| --------------------------- | ------------------- | --------------------- | ------------- |
| Neon Pistol (pistol)        | 力 (힘)             | 정밀 타격 = 집중된 힘 | +40% 가중     |
| Scatter Blaster (shotgun)   | 大 (크다)           | 넓은 확산 = 크기      | +40% 가중     |
| Beam Cutter (laser)         | 火 (불)             | 광선 에너지           | +40% 가중     |
| Homing Rocket (missile)     | 龍 (용)             | 추적하는 용           | +40% 가중     |
| Cyber Boomerang (boomerang) | 力 (힘)             | 물리적 투척           | +40% 가중     |
| Tesla Arc (lightning)       | 金 (금)             | 전기=금속             | +40% 가중     |
| Plasma Torch (flamethrower) | 火 (불)             | 화염 그 자체          | +40% 가중     |
| Drone Ring (orbital)        | 金 (금)             | 기계=금속             | +40% 가중     |

**가중 드롭 공식:**

```
파편 종류 선택 시:
  기본 확률 = 각 파편 16.67% (6종 균등)
  PRIMARY 파편: 16.67% x 1.40 = 23.33%
  나머지 5종: (100% - 23.33%) / 5 = 15.33% 각

복수 무기 보유 시:
  각 무기의 PRIMARY 가중치를 합산 후 정규화
  예: pistol(力 +40%) + flamethrower(火 +40%) 보유
    力: 23.33%, 火: 23.33%, 나머지 4종: 각 13.33%
```

### 4.6 보스 네온 실드

**핵심 변경**: 실드 해제는 콤보 버프 상태가 아니라 **파편을 직접 소비**하는 방식이다. 이로써 파편을 "변환에 쓸지, 실드 해제에 쓸지"의 트레이드오프가 발생한다.

| 보스                           | 실드 HP | 해제 방식             | 해제 시 파편 소비 | 데미지 감소 | 취약 시간 | 시간 경과 자동 약화    |
| ------------------------------ | ------- | --------------------- | ----------------- | ----------- | --------- | ---------------------- |
| Riot Commander (미니보스, 5분) | 200     | 아무 파편 2개 투척    | 2개               | -50%        | 10초      | 30초 후 실드 자동 해제 |
| Yakuza Mech (챕터보스, 8분)    | 500     | 火 포함 파편 3개 투척 | 3개               | -70%        | 8초       | 45초 후 실드 50% 약화  |
| Neon Overlord (최종보스, 9분)  | 800     | Phase별 다름 (아래)   | Phase당 3개       | -80%        | 6초       | 60초 후 실드 자동 해제 |

**최종 보스 Phase별 실드:**

| Phase   | HP 구간   | 해제 파편   | 해제 보상              |

**실드 해제 조작:**

- 보스 등장 시 HUD 상단에 "실드 해제 필요: [火] + 아무 2개" 표시
- 파편 충분 시 "SHATTER" 버튼 활성화 (화면 우측 상단, 조이스틱과 무간섭)
- 탭 1회로 해제 — 필요 파편 자동 소비
- 파편 부족해도 시간 경과로 실드 약화 → 완전 막힘 방지 (레드팀 이슈 대응)
