## 0. CEO 피드백 요약 및 진단

### 문제 진단

현재 Neon Survivors는 Vampire Survivors의 코어 루프 위에 3개의 "장식용 시스템"을 얹은 상태다.

| 시스템    | 현재 상태                                         | 문제                            |
| --------- | ------------------------------------------------- | ------------------------------- |
| 네온 사인 | 15% 랜덤 드롭 → 랜덤 파편 → 자동 조합 → 임시 버프 | 복권. 플레이어 에이전시 제로    |
| 대배당    | 3초 서서 기다리면 랜덤 음식 → 임시 버프           | 자판기. 의사결정 없음           |
| 크로노 핵 | 게이지 차면 탭 → 3초 슬로우모션                   | 범용 궁극기. 다른 시스템과 무관 |

**근본 문제**: Kill → XP 수집 → 레벨업 → 강화. 이것이 VS와 동일하다. 네온 파편, 음식, 슬로우모션은 이 루프 바깥에 "추가"된 것이지, 루프 자체를 바꾸지 못한다.

### 목표

**"이 게임이 VS가 아닌 이유"를 한 문장으로 말할 수 있게 만든다.**

## 1. 엘리베이터 피치

> **"적을 죽여 네온 한자를 모으고, 한자 조합으로 무기를 변신시키고, 변신한 무기로 보스의 네온 방패를 깨는 게임."**

이 문장은 Vampire Survivors, Brotato, HoloCure, Soulstone Survivors 그 어떤 불릿 헤븐 게임에도 적용할 수 없다. 네온 파편이 단순 버프가 아니라 **무기 변환의 연료**이자 **보스 공략의 열쇠**이자 **경제 자원**으로 기능하기 때문이다.

## 2. 리디자인된 코어 루프

### 2.1 기존 vs 신규 루프 비교

```
[기존 — VS 클론]
Kill → XP → Level Up → Weapon/Passive 선택 → 반복
         ↘ (가끔) 네온 파편 → 버프
         ↘ (가끔) 대배당 → 버프
         ↘ (가끔) 크로노 발동 → 슬로우

[신규 — 네온 연금술]
Kill → 네온 파편 수집 (XP 대체) → 파편 조합 선택
  ├─ 무기 변환 (Transmute): 파편 조합으로 현재 무기를 변신
  ├─ 대배당 소비 (Trade): 파편을 대배당에서 음식/영구 강화로 교환
  ├─ 보스 방패 파쇄 (Shatter): 특정 파편 조합으로 보스 네온 실드 해제
  └─ 크로노 핵 증폭 (Amplify): 슬로우 중 파편 상호작용 강화
```

**핵심 변경**: 네온 파편이 게임의 **중앙 자원(Central Resource)**이 된다. XP 시스템은 유지하되, 네온 파편이 "어떤 빌드를 만들 것인가"의 핵심 축이 된다.

### 2.2 60초 규칙 검증

| 초    | 플레이어 행동                              | 느끼는 감정                     |
| ----- | ------------------------------------------ | ------------------------------- |
| 0~15  | 적 처치, 첫 파편 2~3개 획득                | "오, 한자가 떨어진다"           |
| 15~30 | 파편 2개 조합 → 무기 변환 최초 체험        | "내 피스톨이 불 피스톨이 됐다!" |
| 30~45 | 변환된 무기로 적 무쌍                      | 파워 판타지                     |
| 45~60 | 변환 종료, 다음 조합을 위해 파편 관리 시작 | "이번엔 뭘 만들지?"             |

**60초 이내에 핵심 루프 전체를 체험한다.**

## 3. 시스템 1: 네온 사인 — 무기 변환 시스템 (Neon Transmutation)

### 3.1 개요

기존 SPEC-030의 "임시 버프" 시스템을 **무기 변환(Transmutation)** 시스템으로 전면 교체한다.

**핵심 변경점**:

- 파편은 더 이상 "랜덤 드롭 → 자동 조합 → 버프"가 아니다
- 파편은 **무기와 연결된 속성 자원**이며, 조합하면 **무기 자체가 변신**한다
- 보유한 무기 종류에 따라 **특정 파편의 드롭율이 변동**한다

### 3.2 무기-파편 속성 친화도 (Weapon-Fragment Affinity)

각 무기는 하나의 파편 속성에 친화도를 갖는다. 해당 무기를 보유하면 친화 파편의 드롭율이 상승한다.

| 무기                        | 친화 파편   | 이유 (테마)           | 드롭율 보너스 |
| --------------------------- | ----------- | --------------------- | ------------- |
| Neon Pistol (pistol)        | 力 (힘)     | 정밀 타격 = 집중된 힘 | +15%          |
| Scatter Blaster (shotgun)   | 大 (크다)   | 넓은 확산 = 크기      | +15%          |
| Beam Cutter (laser)         | 光 (빛)\*   | 광선 = 빛             | +15%          |
| Homing Rocket (missile)     | 龍 (용)     | 추적하는 용           | +15%          |
| Cyber Boomerang (boomerang) | 風 (바람)\* | 날아가는 궤적 = 바람  | +15%          |
| Tesla Arc (lightning)       | 雷 (번개)\* | 전기 체인 = 번개      | +15%          |

### 3.3 파편 드롭 시스템 변경

**기존**: 15% 균등 랜덤 드롭
**신규**: 적 티어별 차등 + 보유 무기에 따른 가중 드롭

| 적 티어                   | 기본 드롭 확률 | 드롭 파편 수 |
| ------------------------- | -------------- | ------------ |
| Tier 1 (drone, crawler)   | 25%            | 1개          |
| Tier 2 (enforcer, dasher) | 40%            | 1개          |
| Tier 3 (sentinel, bomber) | 60%            | 1~2개        |
| Mini Boss                 | 100%           | 3개          |
| Chapter Boss              | 100%           | 5개          |
| Final Boss                | 100%           | 7개          |

**드롭 확률 대폭 상승 이유**: 파편이 더 이상 "보너스 버프"가 아니라 게임의 핵심 자원이다. 플레이어가 60초마다 최소 1회 조합을 실행할 수 있어야 한다.

**가중 드롭 공식**:

```
각 파편 타입의 드롭 확률 = base_weight + Σ(보유 무기 친화 보너스)

예: pistol(力 +15%) + flamethrower(火 +15%) 보유 시
  力: 11.1% + 15% = 26.1%
  火: 11.1% + 15% = 26.1%
  나머지 7종: (100% - 52.2%) / 7 = 6.8% 각
```

이 시스템으로 플레이어는 **무기 선택이 곧 파편 전략**이 된다.

### 3.4 네온 변환 (Neon Transmutation) — 무기 변신

파편 조합으로 보유 무기를 **일시적으로 변신**시킨다. 이것이 VS 진화 시스템과 다른 점:

- VS 진화: 조건 충족 시 **영구적**이고 **자동** 발동. 한 번 하면 끝.
- 네온 변환: **수동 트리거**, **일시적**(20초), **반복 가능**, 조합에 따라 **다른 형태로 변환**.

#### 무기별 특수 변환 (Weapon-Specific Transmutation)

특정 무기를 보유한 상태에서 해당 무기의 친화 파편이 포함된 조합을 사용하면 **해당 무기만 특수 변신**한다.

| 무기         | 필요 조합 | 변환 이름         | 변환 효과 (20초)                                  |
| ------------ | --------- | ----------------- | ------------------------------------------------- |
| Pistol       | 力+任意   | **Neon Magnum**   | 단발이 3연발 버스트로. 각 탄환이 네온 잔상 남김   |
| Shotgun      | 大+任意   | **Neon Shredder** | 부채꼴 → 360도 전방위 발사. 탄환 수 3배           |
| Laser        | 光+任意   | **Neon Prism**    | 단일 빔 → 프리즘 분산 (3방향). 각 빔 색상 다름    |
| Missile      | 龍+任意   | **Neon Dragon**   | 미사일 → 추적 용 투사체. 적 관통 후 폭발+화염장판 |
| Boomerang    | 風+任意   | **Neon Typhoon**  | 하나 → 3개 동시 회전. 회전 범위 2배               |
| Lightning    | 雷+任意   | **Neon Tempest**  | 체인 3 → 체인 8 + 마비 0.5초                      |
| Flamethrower | 火+任意   | **Neon Inferno**  | 전방 콘 → 360도 화염 오라. 범위 2배               |

> "任意"는 아무 파편 1개를 의미. 즉 친화 파편 + 아무 파편 1개면 무기 특수 변환 가능.

### 3.5 파편 관리 UI

**변경 전**: 파편 수집 즉시 자동 조합
**변경 후**: 파편 수집 → HUD 슬롯에 보관 → **플레이어가 조합 버튼을 눌러 수동 발동**

| 속성        | 값                                             | 비고                   |
| ----------- | ---------------------------------------------- | ---------------------- |
| 최대 보유   | 5개 (기존 3 → 5)                               | 3파편 조합 + 여유분    |
| 파편 수명   | 30초 (기존 20 → 30)                            | 전략적 보관 시간 확보  |
| 조합 발동   | 화면 우측 "NEON" 버튼 탭                       | 자동 조합 폐지         |
| 조합 메뉴   | 보유 파편으로 가능한 조합 목록 표시 (최대 3개) | 플레이어가 선택        |
| 조합 실행   | 목록에서 원하는 조합 탭 → 즉시 발동            | 일시정지 없음 (실시간) |
| 파편 버리기 | 슬롯 길게 눌러 파편 드롭 (다른 파편 확보 위해) | 인벤토리 관리          |

**이 변경이 핵심인 이유**: 자동 조합은 플레이어에게 아무 의사결정을 주지 않았다. 수동 조합은 "지금 火力을 쓸까, 아니면 火를 아껴서 나중에 火雷龍을 만들까?"라는 **진짜 선택**을 만든다.

### 3.6 변환 시각 연출

1. 조합 선택 시: 파편들이 무기 아이콘 쪽으로 날아감 (0.3초)
2. 무기 변신: 기존 무기 스프라이트가 네온 빛으로 감싸지며 새 형태로 변환 (0.5초)
3. 변환 중: 무기에서 지속적 네온 파티클 + 투사체 색상 변경
4. 변환 종료: 무기가 원래 형태로 돌아감 + 네온 깨지는 이펙트

## 4. 시스템 2: 대배당 — 네온 시장 (Neon Market)

### 4.1 개요

기존 SPEC-031의 "3초 기다리면 랜덤 음식" 시스템을 **파편 통화 기반 상점**으로 전면 교체한다.

**핵심 변경점**:

- 랜덤 음식 → **메뉴판에서 직접 선택**
- 코인만 사용 → **코인 OR 네온 파편으로 결제** (기회비용 발생)
- 임시 버프만 → **런 영구 업그레이드 + 임시 버프 혼합**
- 안전한 위치 → **위험 지역에 출현** (리스크-리워드)

### 4.2 대배당 상점 메뉴

대배당에 접근하면 **즉시** 상점 메뉴가 열린다 (3초 대기 삭제). 단, 적의 공격은 계속된다.

### 4.3 기회비용 구조

이것이 대배당을 "자판기"가 아닌 **의사결정 포인트**로 만드는 핵심이다.

```
파편 2개를 대배당에서 "네온 회로"에 쓰면:
  → 런 영구 데미지 +10% 획득
  → 하지만 그 파편으로 무기 변환 1회를 포기한 것

파편 2개를 무기 변환에 쓰면:
  → 20초간 강력한 변환 무기 사용
  → 하지만 영구 강화 기회를 포기한 것
```

**"지금 강해질 것인가, 나중을 위해 투자할 것인가"** — 이것이 매 대배당 방문마다 발생한다.

## 6. 시스템 4: 보스 네온 실드 (Boss Neon Shield)

이것이 네온 파편을 "있으면 좋은 것"에서 **"보스를 잡기 위해 반드시 필요한 것"**으로 격상시킨다.

### VS(Vampire Survivors)와의 차이 체크리스트

| 항목              | VS                                    | Neon Survivors (리디자인 후)                 |

| 무기 강화         | 레벨업 → 중복 선택 → 진화 (1회, 영구) | 네온 변환 (반복적, 일시적, 상황 선택)        |
| 보스 공략         | DPS 체크 (그냥 때리면 됨)             | 네온 실드 해제 필요 (파편 전략)              |
| 상점              | 없음 (일부 작품에 있으나 코인 전용)   | 파편 OR 코인 이중 통화 (기회비용)            |

| 문화적 테마       | 고딕/판타지/일반                      | 홍콩 네온 간판 문화 (파편=한자, 상점=대배당) |
| 플레이어 의사결정 | 레벨업 시 선택 (30초마다)             | 파편 사용처 선택 (15~20초마다)               |
