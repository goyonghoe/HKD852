## Concept 1: 마작 서바이버 (Mahjong Survivor)

### 엘리베이터 피치

> **"네온 한자 마작패를 조합해서 무기를 발동시키고, 완성된 역(役)이 곧 궁극기가 되는, 마작 테이블 위에서 벌어지는 10분짜리 생존 전투."**

### 장르 DNA: 마작 × 불릿 헤븐

---

### 핵심 인터랙션 (Core Interaction)

**매 순간 플레이어가 하는 것:** 화면 하단의 "손패 5장" 중에서, 밀려오는 적을 막기 위해 어떤 패를 어떤 순서로 내려놓을지 고른다.

- **패 내기** = 공격 발동. 같은 종류 2~3장을 모아서 "쌍(雀頭)" 또는 "각자(刻子)"로 내면 더 강한 공격이 터진다
- **대기(待ち)** = 전략적 보류. 특정 패를 기다리며 버티면, 완성 시 화면 전체를 쓸어버리는 "역(役)" 공격이 폭발한다
- 적을 죽이면 새 패가 손으로 들어온다. 킬 속도 = 패 회전 속도 = 전투력

**VS와의 결정적 차이:**

- VS: 이동이 핵심 (어디로 도망가느냐)
- 마작 서바이버: **패 관리가 핵심** (무엇을 내고, 무엇을 기다리느냐). 플레이어는 화면 중앙에 고정, 적이 사방에서 몰려온다

**한 손 조작:**

- 손패 5장이 화면 하단에 반원형 배치
- 패를 위로 플릭 = 해당 패 사용 (공격 발동)
- 2~3장 동시 플릭 (멀티터치 or 순차 빠른 탭) = 콤보
- 왼손 엄지 하나로 모든 조작 가능

---

### 10분 런 시뮬레이션

**0~1분 (생존의 탁자)**

- 손패 3장으로 시작 (대, 화, 력). 적이 느리게 접근
- 패 1장 플릭 = 단발 공격. "아, 패를 내면 공격이 나가는구나"
- 30초: 첫 적 처치 → 새 패 드로우. 손패가 4장으로 증가
- 패를 아무거나 빠르게 내면 약한 공격, 같은 걸 모아 내면 강한 공격이라는 규칙 체득

**2~4분 (역을 노려라)**

- 손패 5장 풀 오픈. 적 종류 3~4가지 등장
- 2장 콤보(쌍) 자연스럽게 발견: "화+화를 내니까 화염 폭발이 터졌다!"
- 레벨업 시 "새 역 레시피" 해금: 예) 大大火 = "대화재" (화면 반 쓸어버림)
- 대배당 상인이 맵에 등장 — 코인으로 "조커패" 구매 가능 (아무 패로 치환)
- 긴장감: 역을 완성하려고 패를 비축 중인데, 적이 너무 가까이 오면 그냥 내야 함

**5~7분 (고수의 영역)**

- 역 레시피 3~4종 동시 진행 가능. "力力力 대기 중인데, 金이 들어오면 金龍도 가능한데..."
- 미니보스 등장 → 특정 역을 완성해야 실드 해제 (예: "龍 포함 3장 역")
- 화면에 적 40~50마리 + 패 회전이 미친듯이 빨라짐 → 판단 속도 자체가 스킬
- 크로노 핵: 발동 시 시간 정지 + 손패 전부 교체 (패산 새로고침)

**8~10분 (최종 역)**

- 최종보스 등장. "네온 만관(滿貫)" 달성 조건 제시: 특정 5장 조합
- 보스전 중 계속 패를 내서 공격하면서, 동시에 만관 조건 패를 모으는 이중 과제
- 만관 완성 → 화면 전체 네온 폭발 + 보스 즉사급 데미지 → 승리
- 미완성 시에도 시간 경과 약화로 클리어 가능하나, 만관 보너스 없음

### 수익화 적합성

- **코스메틱**: 패 스킨 (골드패, 옥패, LED패, 홀로그램패), 역 완성 이펙트 스킨, 테이블 배경
- **시즌**: 시즌별 특수 역 레시피 + 한정 패 스킨 세트 (설날 금룡패, 중추절 월병패 등)
- **광고 보상**: 런 시작 시 "보너스 드로우 1회" 또는 "사망 후 부활 + 손패 리셋"
- **F2P 잠재력**: 높음. 마작이라는 소재 자체가 수집+커스터마이징과 자연스럽게 맞물림

## Concept 2: 네온 회로 (Neon Circuit)

### 엘리베이터 피치

> **"손가락으로 네온 회로를 그려서 무기와 함정을 배치하고, 적이 내가 만든 회로망 위를 걸어다니며 감전사하는, 타워 디펜스와 라인 퍼즐이 만난 10분 서바이벌."**

### 장르 DNA: 라인 드로잉 퍼즐 × 타워 디펜스 × 불릿 헤븐 성장 엔진

---

### 핵심 인터랙션 (Core Interaction)

**매 순간 플레이어가 하는 것:** 화면 위에 손가락으로 "네온 회로선"을 긋는다. 회로선이 연결된 노드(발전기)에서 무기가 발사되고, 회로 위를 밟은 적은 감전 데미지를 입는다.

- **긋기** = 회로 설치. 짧은 선 = 약한 전류 + 빠른 설치. 긴 선 = 강한 전류 + 느린 충전
- **노드 연결** = 무기 활성화. 발전기 노드 2개를 회로로 연결하면 그 사이에 공격 패턴 발동 (레이저, 전기 아크, 파동 등)
- **회로 패턴** = 전략. 삼각형으로 그으면 내부 영역에 "전기장". 직선으로 길게 그으면 "레이저 울타리". 원형으로 그으면 "자기 방어막"
- 적을 처치하면 새 노드가 필드에 드롭 → 회로 확장 가능

**VS와의 결정적 차이:**

- VS: 플레이어가 움직이고 무기가 자동 공격
- 네온 회로: **플레이어가 세계를 직접 디자인한다**. "어디에 어떤 형태로 회로를 깔 것인가"가 전략의 전부. 플레이어 캐릭터는 회로 중앙의 발전기(코어)에 고정

**한 손 조작:**

- 엄지로 화면에 선 긋기 (드래그)
- 노드 탭 = 노드 타입 변경 (공격/방어/버프 순환)
- 회로 위 더블탭 = 회로 삭제 (에너지 일부 회수)
- 모든 조작이 "터치+드래그"로 통일

---

### 10분 런 시뮬레이션

**0~1분 (첫 번째 회로)**

- 중앙에 코어 발전기 1개. 상하좌우에 빈 노드 4개
- 적이 화면 밖에서 천천히 접근 (상단에서)
- "코어 → 상단 노드" 직선 회로 하나 그으면, 그 선 위를 적이 밟아 감전 + 노드에서 전기 탄 발사
- 15초: 하나 더 그으려 하면, 에너지 부족. 적을 죽여야 에너지 충전 → 킬-빌드 루프 체감

**2~4분 (회로 설계자)**

- 노드 8~10개로 증가. 4방향에서 적 진입
- 삼각형 회로 패턴 발견: 세 노드를 연결하면 내부에 "전기장" 생성 → 들어온 적 지속 데미지
- 레벨업: "회로 효율 +50%" vs "새 노드 타입: 슬로우 노드" 선택
- 대배당: 맵 구석에 나타나 특수 노드 판매 (폭발 노드, 분기 노드, 증폭 노드)
- 적 타입 분화: 비행형(회로 무시, 노드 공격만 유효), 중장갑(강한 회로만 데미지)

**5~7분 (네온 도시 건축)**

- 노드 15~20개. 회로망이 화면 전체를 덮기 시작
- **창발적 패턴**: 삼각형 3개를 이어 붙여 "벌집 구조"를 만들면 → 숨겨진 시너지 "하이브 마인드" 발동 (전 노드 공격력 2배)
- 미니보스: 회로를 부수며 진입. 부서진 회로를 빠르게 재건하거나, 보스 경로에 새 강화 회로를 급조하는 긴박감
- 크로노 핵: 적 정지 + 회로 무제한 설치 (4초 동안 회로 대건설 타임)

**8~10분 (마스터 아키텍트)**

- 최종보스: 화면 전체를 도는 거대 보스. 보스가 지나는 경로에 "과부하 회로" (노드 3중 연결)를 깔아야 데미지
- 보스가 회로를 밟으면 감전 + 플레이어 코어 에너지 소모. 에너지 관리가 승패 결정
- 최후의 순간: 남은 에너지 전부 투입한 "풀 맵 회로 과부하" → 화면 전체 네온 폭발 → 클리어

| 엔진                | 상태    | 설명                                                                                                        |
| ------------------- | ------- | ----------------------------------------------------------------------------------------------------------- |
| 압축된 영웅 서사    | ✅ 보존 | 노드 4개의 빈약한 회로 → 화면 전체를 뒤덮는 네온 도시. "내가 이 도시를 지었다"라는 성장감이 물리적으로 보임 |
| 통제된 랜덤         | ✅ 보존 | 드롭되는 노드 타입이 랜덤. 레벨업 시 회로 특성 선택. "이 노드 배치에서 어떤 패턴이 최적인가"의 전략         |
| 시스템적 서프라이즈 | ✅ 보존 | 회로 형태에 따른 숨겨진 패턴 보너스 (벌집, 격자, 나선형 등). 우연히 만든 형태가 강력한 시너지 발동          |
| 감각 포화           | ✅ 보존 | 회로 위를 흐르는 전류 이펙트 + 적 감전 이펙트 + 노드 발사체 → 화면이 네온 전기로 뒤덮임                     |
| 누적적 숙련         | ✅ 보존 | 메타: 시작 노드 수 증가, 영구 노드 타입 해금, 회로 패턴 레시피 도감. "이 패턴을 알면 초반이 쉬워진다"       |

| **네온 간판**   | 회로 자체가 네온 간판. 완성된 회로 패턴은 실제 홍콩 네온 간판 형태로 빛난다. "HOTEL" 형태로 회로를 그으면 보너스 → 간판 수집 도감                  |
| **길거리 음식** | 대배당에서 특수 노드 구매. "피쉬볼 노드 = 연쇄 폭발", "에그타르트 노드 = 회복장 생성". 음식 이름이 곧 노드 이름                                    |
| **밀집 도시**   | 좁은 화면 안에서 회로를 최대한 효율적으로 배치하는 것이 홍콩 밀집 빌딩의 공간 활용 그 자체. 맵 테마가 "빌딩 옥상 배선", "지하 전력실", "네온 골목" |

---

### 수익화 적합성

- **코스메틱**: 회로 색상/패턴 스킨 (골드 회로, 사이버 그린, 레트로 핑크), 노드 디자인 스킨, 코어 발전기 스킨
- **시즌**: 계절별 회로 이펙트 (벚꽃 전류, 크리스마스 조명선), 시즌 한정 노드 타입
- **광고 보상**: "보너스 노드 3개" 또는 "회로 에너지 풀 충전"
- **F2P 잠재력**: 중상. 회로 디자인 자체를 공유하는 커뮤니티 요소 가능 ("내 최강 회로 설계도 공유")

| **실패 가능성**    | "선 긋기"가 전투의 긴박함과 충돌. 정밀하게 선을 그으려면 시간이 필요한데, 적은 계속 밀려옴 → 조작 좌절. → 대응: 노드 사이를 탭-탭으로 자동 연결하는 "퀵 와이어" 모드 기본 제공. 정밀 드래그는 고급 옵션 |

## Concept 3: 야식 연금술사 (Midnight Kitchen)

### 엘리베이터 피치

> **"떨어지는 재료를 잡아서 요리를 만들고, 완성된 요리가 무기가 되어 적을 쓸어버리는, 쿠킹 퍼즐과 불릿 헤븐이 합체한 길거리 야식 전투."**

### 장르 DNA: 쿠킹 게임(Overcooked/Cook Serve Delicious) × 불릿 헤븐 성장 엔진

---

### 핵심 인터랙션 (Core Interaction)

**매 순간 플레이어가 하는 것:** 화면 상단에서 재료(면, 고기, 해산물, 양념 등)가 떨어진다. 화면 하단의 "웍(鑊)" 3~4칸에 재료를 배분하고, 레시피대로 모이면 요리가 완성 → 무기 발동.

- **재료 잡기** = 왼쪽/오른쪽 스와이프로 웍 위치 이동, 또는 떨어지는 재료를 탭해서 원하는 웍에 배치
- **요리 완성** = 공격 발동. 완탕면 = 전방 관통 파, 볶음밥 = 360도 산탄, 에그타르트 = 아군 회복 장판
- **콤보 요리** = 같은 웍에서 연속 요리 3회 → "화력(鑊氣)" 축적 → 궁극 요리 해금

**VS와의 결정적 차이:**

- VS: 적에게서 도망가며 자동 공격이 적을 처리
- 야식 연금술사: **요리 주문을 처리하듯 재료를 관리하는 것이 전투**. "적이 무섭다"가 아니라 "재료가 넘쳐서 웍이 터질 것 같다"가 긴장감의 원천. 적은 요리를 맞으면 죽고, 재료를 못 잡으면 바닥에 떨어져 적이 강해진다 (오염)

**한 손 조작:**

- 화면 하단 웍 3~4칸 사이를 좌우 스와이프로 "활성 웍" 전환
- 떨어지는 재료는 자동으로 활성 웍에 들어감
- 웍을 위로 플릭 = 즉시 요리 완성 (재료 부족해도 하급 요리 나옴)
- 웍을 아래로 플릭 = 웍 비우기 (잘못된 재료 폐기)
- 모든 것이 엄지 하나의 "좌우 스와이프 + 상하 플릭"

---

### 10분 런 시뮬레이션

**0~1분 (첫 번째 주문)**

- 웍 2칸, 재료 2종 (면, 고기). 적이 천천히 접근
- 면+고기가 웍에 들어가면 자동으로 "소고기면" 완성 → 전방에 면발 파동 공격
- "아, 재료를 모으면 공격이 나가는구나." 아무 재료나 넣어도 기본 공격은 나감
- 30초: 첫 레벨업 → "새 재료: 해산물" 또는 "웍 3칸째 해금" 선택

**2~4분 (주방이 바빠진다)**

- 재료 4~5종, 웍 3칸. 떨어지는 재료 속도 증가
- 레시피 도감에 "완탕면(면+해산물+양념)" 등장 → 더 강한 공격
- 전략: 웍 1에는 면 계열, 웍 2에는 고기 계열을 분리하면 레시피 완성 확률 상승
- **오염 메카닉**: 바닥에 떨어진 재료가 독 웅덩이가 되어 적을 강화 → 재료를 놓치면 안 됨!
- 대배당 상인: 고급 양념(유일 재료), 웍 업그레이드, 레시피 스크롤 판매

**5~7분 (미슐랭 스타)**

- 재료 6종, 웍 4칸. 화면 위에서 빗발치는 재료 + 사방의 적
- **궁극 요리 "만한전석(滿漢全席)"**: 4개 웍에서 각각 다른 고급 요리를 동시 완성하면 발동 → 화면 전체 초대형 불꽃쇼
- 미니보스: 특정 요리의 약점 보유 (해산물 알레르기! → 해산물 요리가 3배 데미지)
- 크로노 핵: 재료 낙하 정지 + 웍 정리 시간 (4초간 냉장 보관)

**8~10분 (전설의 야식 마스터)**

- 최종보스: "미식 비평가". 특정 요리를 요구하며, 요구 요리를 맞추면 실드 해제
- 재료 낙하가 미친듯이 빨라짐 → 반사적 재료 분배가 핵심
- 만한전석 2연속 달성 → 황금 용 이펙트 + 보스 격파 → 승리 화면에 "미슐랭 3스타" 표시

---

### 5대 엔진 보존 체크

| 엔진                | 상태    | 설명                                                                                                                      |
| ------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------- |

- **코스메틱**: 웍 스킨 (황금 웍, 사이버 웍, 고대 솥), 요리 이펙트 스킨 (골드 불꽃, 무지개 연기), 주방장 복장
- **시즌**: 시즌별 한정 레시피 + 문화 축제 연계 (중추절 월병, 설날 니엔꾸어, 단오절 쫑즈)
- **광고 보상**: "고급 재료 3개 즉시 획득" 또는 "웍 폭발 방지 1회"
- **F2P 잠재력**: 매우 높음. 요리+수집은 캐주얼 모바일 유저의 핵심 동기. Overcooked의 인기가 증명하듯 쿠킹 게임 소재는 범용 매력

## Concept 4: 비트 크래셔 (Beat Crasher)

### 엘리베이터 피치

> **"홍콩 사이버펑크 비트에 맞춰 탭하면 공격이 터지고, 콤보를 이어갈수록 무기가 진화하고, BPM이 올라갈수록 적도 미쳐 날뛰는, 리듬 액션 서바이벌."**

### 장르 DNA: 리듬 게임(Cytus/Beatstar) × 불릿 헤븐 성장 엔진

---

### 핵심 인터랙션 (Core Interaction)

**매 순간 플레이어가 하는 것:** 화면 중앙에서 비트 마커가 심장처럼 뛴다. 비트에 맞춰 탭하면 무기가 발사되고, 정확도에 따라 데미지 배율이 달라진다. 연속 정확 탭 = 콤보 → 무기 진화.

- **온비트 탭** = 공격 발사. Perfect/Great/Good/Miss 판정
- **콤보 유지** = 무기 진화 트리거. 10콤보 → 무기 Lv2, 30콤보 → Lv3, 50콤보 → 궁극 형태
- **비트 전환** = 전략 전환. BGM이 전환되면 (verse→chorus 등) 새로운 비트 패턴 + 적 웨이브 패턴 변경
- 방향 스와이프: 탭 방향(상하좌우)에 따라 공격 방향 지정. 사방에서 오는 적 중 가장 위험한 방향으로

**VS와의 결정적 차이:**

- VS: 시간이 흐르면 자동으로 강해짐 (레벨업 기반)
- 비트 크래셔: **플레이어의 리듬감이 곧 전투력**. 리듬감이 좋으면 30콤보를 일찍 쌓아 Lv3 무기를 2분 만에 해금하고, 리듬감이 나쁘면 5분이 걸림. "스킬 = 성장 속도"라는 공식

**한 손 조작:**

- 화면 아무 곳이나 비트에 맞춰 탭 = 공격 (방향은 자동 타겟팅)
- 비트 사이 스와이프 = 공격 방향 수동 지정 (선택적, 고급 플레이)
- "탭 한 번"이 전부. 세상에서 가장 단순한 조작

---

### 10분 런 시뮬레이션

**0~1분 (첫 번째 비트 — 80 BPM)**

- 느린 Lo-fi 비트. 초당 1~1.5회 탭이면 충분
- 화면 중앙에 원형 비트 링. 링이 수축할 때 탭하면 Perfect
- 적이 느리게 접근. 탭할 때마다 네온 총알 발사
- 5콤보: "GREAT!" 텍스트 + 총알 크기 증가. 10콤보: 무기 Lv2 진화 + 네온 이펙트 강화
- BGM이 서서히 빌드업

**2~4분 (빌드업 — 110 BPM)**

- 비트가 빨라지고, 탭 요구 빈도 증가 (초당 2회)
- 레벨업 시 "비트 패턴 변경"을 선택: 4/4박 → 셔플 → 신스웨이브 등. 각 패턴마다 장단점
- 30콤보 달성 → 무기 Lv3. 화면에 네온 파티클이 비트에 맞춰 펄스
- **그루브 게이지**: 연속 Perfect 5회 → 그루브 모드 진입 (화면 네온 필터 + 데미지 1.5배 + XP 2배)
- 미스 시 콤보 리셋은 아니지만, 콤보 수 10 감소 + 그루브 해제. 완전 리셋의 좌절감 방지

**5~7분 (드롭 — 140 BPM)**

- BGM이 클라이맥스 빌드업 → 드롭! 드롭 순간 모든 무기가 동시 발사 + 화면 폭발
- 50콤보: 궁극 무기 형태 해금. 매 탭이 화면 1/4을 쓸어버리는 네온 웨이브
- 미니보스: 보스 전용 비트 패턴 등장. 보스의 공격도 비트에 맞춰 옴 → 보스 공격 비트에 카운터 탭 = 반격
- 크로노 핵: BGM 슬로우 → 탭 윈도우 2배 확대 (쉬운 Perfect) + 콤보 보너스 3배

**8~10분 (앙코르 — 160+ BPM)**

- 최종보스: 전용 BGM 트랙. 보스와 "리듬 배틀"
- 보스가 네온 빔을 비트에 맞춰 발사 → 그 비트에 정확히 카운터 탭하면 빔 반사
- BPM 160~180. 초당 3회 탭 요구. 손가락이 춤춘다
- 100콤보 "MASTER" 달성 시 → 피날레 폭발 + BGM 브레이크다운 + 승리
- 콤보 미달성해도 시간+레벨로 클리어 가능하나, MASTER 보너스 없음

### 5대 엔진 보존 체크

## Concept 5: 네온 스택 (Neon Stack)

### 엘리베이터 피치

> **"떨어지는 네온 블록을 쌓아서 방어벽을 만들고, 완성된 줄이 무기가 되어 적을 쓸어버리는, 테트리스와 타워 디펜스와 불릿 헤븐이 하나가 된 게임."**

### 장르 DNA: 블록 스태킹(테트리스/Columns) × 타워 디펜스 × 불릿 헤븐 성장 엔진

---

### 핵심 인터랙션 (Core Interaction)

**매 순간 플레이어가 하는 것:** 화면 중앙에 9x6 그리드가 있다. 위에서 네온 블록(1~2칸)이 떨어진다. 좌우 스와이프로 위치 조정, 탭으로 즉시 드롭. 가로줄이 완성되면 → 그 줄이 "에너지 웨이브"로 변환되어 해당 방향의 적을 쓸어버린다. 동시에 여러 줄을 완성하면 더 강력한 공격.

- **블록 배치** = 방어+공격 자원 동시 관리. 블록 자체가 적의 진입을 막는 벽이자, 줄 완성 시 무기 발동의 연료
- **줄 완성** = 공격 발동. 1줄 = 기본 웨이브, 2줄 연속 = 강화 웨이브, 3줄 연속 = 궁극 "네온 쓰나미"
- **색상 매칭** = 보너스. 같은 색 블록으로 줄을 완성하면 해당 원소의 특수 공격 (빨강=화염, 파랑=빙결, 초록=독)
- 적이 그리드 측면에서 접근. 블록 벽을 부수며 들어오지만, 벽이 높을수록 들어오는데 시간이 걸림

**VS와의 결정적 차이:**

- VS: "어디로 도망가느냐"의 공간 전략
- 네온 스택: **"어디에 어떻게 쌓느냐"의 건축 전략**. 블록 배치가 방어(벽)와 공격(줄 완성)을 동시에 결정. 왼쪽에 적이 많으면 왼쪽 줄을 먼저 완성해야 하는 방향성 전략

**한 손 조작:**

- 좌우 스와이프: 블록 위치 이동
- 하단 스와이프: 즉시 드롭
- 탭: 블록 90도 회전
- 엄지 하나로 테트리스 조작 그대로. 이미 검증된 UX

---

### 10분 런 시뮬레이션

**0~1분 (첫 번째 벽)**

- 9x6 그리드, 블록 낙하 느림 (2초/칸). 오른쪽에서 적 접근
- 블록을 쌓으며 자연스럽게 첫 줄 완성 → 네온 웨이브 발사 → "줄 완성이 공격이구나!"
- 블록 자체가 적의 진입을 막는 벽 역할도 발견. "쌓으면 방어도 되네"
- 적이 벽을 1칸씩 부수며 접근 → 완전히 뚫리면 코어(그리드 중앙)에 데미지

**2~4분 (컬러 콤보)**

- 블록 색상 4종 등장. 같은 색 줄 완성 = 원소 공격
- 레벨업: "블록 낙하 속도 증가(더 많은 재료) + 공격력 상승" vs "특수 블록 해금(L자, T자)"
- 2줄 연속 완성 발견 → 강화 웨이브의 쾌감. "테트리스 잘하면 강해지는구나"
- 대배당 상인: 특수 블록(폭탄 블록=주변 3x3 파괴+공격, 무지개 블록=아무 색 역할) 구매
- 적이 좌우 양쪽에서 접근 → 양쪽 균형 있게 쌓아야 함

**5~7분 (테트리스 마스터)**

- 블록 낙하 빠름 (0.8초/칸). 적 4방향
- **빌딩 보너스**: 벽 높이 6칸(꽉 참) 유지하면 "요새 모드" → 코어 무적 + 파편 드롭 2배
- 하지만 벽이 높으면 줄 완성으로 공격하면 벽이 낮아짐 → **방어(벽 유지) vs 공격(줄 완성) 트레이드오프!**
- 미니보스: 벽을 3줄씩 한번에 파괴하는 거대 적. 빈 공간에 빠르게 블록을 채워야 함
- 크로노 핵: 블록 낙하 정지 + 4초간 자유 배치 (전략적 재건축 시간)

**8~10분 (네온 타워)**

- 최종보스: 그리드 상단에서 "보스 블록"을 떨어뜨림 (해골 형태, 파괴 불가)
- 보스 블록 주변에서 줄을 완성하면 보스에게 직접 데미지
- 동시에 자기 블록도 쌓아야 하고, 보스 블록 주변을 채워야 함 → 공간 퍼즐의 절정
- 4줄 동시 완성 "테트리스!" → 화면 전체 네온 폭발 + 보스 막대한 데미지
- 최종 "테트리스!" 성공 시 그리드 전체가 네온 간판으로 변하며 클리어

- **시즌**: 시즌별 특수 블록 팩 + 한정 색상 세트 + 특별 보스 패턴
- **광고 보상**: "다음 블록 미리보기 3개" 또는 "블록 홀드 2칸 (기본 1칸)"

> **설계자 추천**: 프로토타입 2개를 동시에 만든다면, **마작 서바이버**(최고 차별화) + **네온 스택**(최저 프로토타입 비용)의 조합을 추천합니다. 두 게임의 핵심 메카닉이 겹치지 않으므로, 플레이테스트 비교 결과가 명확할 것입니다.
