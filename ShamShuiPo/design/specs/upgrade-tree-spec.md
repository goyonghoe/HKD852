# Upgrade & Progression System Specification

> **게임**: Neon Survivors (네온 서바이버스)
> **버전**: v1.0 (프로토타입)
> **작성**: Game Designer
> **대상**: Programmer (구현용)

---

## 1. 개요

업그레이드 시스템은 3개 레이어로 구성된다:

1. **In-Run Passive** — 런 중 레벨업으로 획득하는 일시적 패시브 (12종)
2. **Meta Progression** — 런 간 영구 강화 (5종, 코인으로 구매)
3. **Equipment** — 장비 슬롯 (4종, 런 시작 전 장착)

---

## 2. In-Run Passive Upgrades (12종)

### 2.1 레벨업 메커니즘

- 적 처치 → XP 보석 획득 → XP 바 충전 → 레벨업 시 3개 선택지 제시
- 선택지는 **아직 Lv.5 미달인 패시브** + **보유하지 않은 무기** 풀에서 weighted random
- 최대 레벨: 15 (10분 런에서 달성 가능한 상한)
- 레벨업 시 게임 일시정지 (선택 완료까지)

| 4→5          | 75      | 30                | ~1:35          |
| 5→6          | 115     | 40                | ~2:10          |
| 6→7          | 165     | 50                | ~2:50          |
| 7→8          | 230     | 65                | ~3:40          |
| 8→9          | 310     | 80                | ~4:35          |
| 9→10         | 410     | 100               | ~5:35          |
| 10→11        | 530     | 120               | ~6:40          |
| 11→12        | 680     | 150               | ~7:50          |

| 14→15        | 1350    | 270               | ~10:00         |

### 3.2 XP 공식

```typescript
function xpForLevel(level: number): number {
  // level 1→2: 10, 증가량이 점점 커짐
  if (level <= 1) return 0;
  return Math.round(10 * Math.pow(1.25, level - 1));
}
```

### 3.3 설계 의도

- 레벨 1~5: 빠른 레벨업 (40~60초 간격) → 초반 파워 성장 체감
- 레벨 6~10: 보통 (50~70초 간격) → 빌드 완성 구간
- 레벨 11~15: 느림 (60~80초 간격) → 무기 진화/최종 빌드 구간
- 15레벨 도달 = 패시브 최대 15개 선택 = 무기 6개 + 패시브 9개 조합

## 4. 레벨업 선택지 시스템

### 4.1 선택지 풀 구성

```typescript
interface UpgradeChoice {
  type: "weapon" | "passive";
  id: string;
  currentLevel: number; // 0이면 미보유
  weight: number;
}
```

### 4.2 가중치 규칙

| 조건                           | weight               |
| ------------------------------ | -------------------- |
| 신규 무기 (미보유)             | 10                   |
| 보유 무기 레벨업               | 15                   |
| 신규 패시브 (미보유)           | 10                   |
| 보유 패시브 레벨업             | 12                   |
| 무기 진화 가능 (2개 모두 Lv.5) | **100** (최우선)     |
| 무기 슬롯 가득 (6개)           | 신규 무기 weight = 0 |
| 이미 Lv.5인 항목               | 풀에서 제외          |

### 4.3 선택지 개수

- 기본: 3개
- LUCK+ Lv.5 보유 시: 4개
- 진화 가능 시: 진화 옵션 1개 고정 + 나머지 2~3개 일반

### 4.4 Reroll

- 런당 무료 reroll: 1회
- 광고 시청 reroll: 추가 1회 (향후 구현)
- reroll 시 기존 3개 완전 교체 (중복 불가)

### 5.3 비용 공식

```typescript
function metaUpgradeCost(baseCost: number, level: number): number {
  // level은 구매할 레벨 (1부터 시작)
  // 대략 baseCost * level * (level + 1) / 2 패턴
  return Math.round(baseCost * Math.pow(level, 1.5));
}
```

### 5.4 메타 진행 속도 예상

- 좋은 런 (보스 클리어, 400킬): ~300 코인
- Base ATK 풀업(10레벨): 약 63런 소요
- 전체 풀업: 약 700런 소요 (장기 목표)

## 8. 드롭 테이블

### 8.1 적 사망 시 드롭

| 드롭 아이템  | 기본 확률 | 효과                         |
| ------------ | --------- | ---------------------------- |
| XP 보석      | 100%      | 해당 적 xp_drop 값           |
| HP 포션 (소) | 3%        | HP +15 회복                  |
| HP 포션 (대) | 0.5%      | HP +50 회복                  |
| 코인 주머니  | 5%        | 코인 5~15개                  |
| 자석         | 1%        | 화면 내 모든 XP 즉시 흡수    |
| 폭탄         | 0.3%      | 화면 내 모든 적에 200 damage |

> Luck+ 패시브에 의해 확률 증가: `실제확률 = 기본확률 * (1 + luck_bonus)`.

### 8.2 보스 사망 시 드롭

| 드롭      | 확률 | 내용                                |
| --------- | ---- | ----------------------------------- |
| 무기 상자 | 100% | 미보유 무기 1개 or 보유 무기 레벨업 |
| 코인 대량 | 100% | 코인 50~100개                       |
| 장비 상자 | 50%  | 랜덤 장비 1개 (Rare 이상 보장)      |

// 인런 패시브 상태
interface RunPassives {
  atk: number; // 0~5
  spd: number; // 0~5
  hp: number; // 0~5
  crit: number; // 0~5
  critDmg: number; // 0~5
  area: number; // 0~5
  cdr: number; // 0~5
  magnet: number; // 0~5
  armor: number; // 0~5
  regen: number; // 0~5
  proj: number; // 0~5
  xpBonus: number; // 0~5
  luck: number; // 0~5
}

// 메타 진행 (저장)
interface MetaProgress {
  coins: number;
  upgrades: {
    baseAtk: number; // 0~10
    baseHp: number; // 0~10
    baseSpd: number; // 0~10
    baseArmor: number; // 0~10
    revival: number; // 0~10
  };
  equipment: {
    weapon: Equipment | null;
    armor: Equipment | null;
    accessory: Equipment | null;
    pet: Equipment | null;
  };
  inventory: Equipment[]; // 미장착 장비
}

// 장비
interface Equipment {
  id: string;
  slot: "weapon" | "armor" | "accessory" | "pet";
  name: string;
  rarity: 1 | 2 | 3 | 4 | 5;
  stats: Record<string, number>;
}
