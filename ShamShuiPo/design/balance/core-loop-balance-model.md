> **게임**: Neon Survivors (네온 서바이버스 / ShamShuiPo)

> **작성일**: 2026-03-13
> **작성자**: Balance Designer (Opus)
> **목적**: 네온 사인 콤보를 부가 시스템에서 **핵심 메카닉**으로 격상. 모든 수치의 수학적 근거 제시.

## 설계 철학: 왜 네온 사인이 중심이어야 하는가

현재 시스템의 문제:

- 파편 드롭률 15% 균등 → 특정 무기와 파편 간 관계가 없어 전략적 깊이 부족
- 콤보 버프가 "있으면 좋고 없어도 됨" 수준 → 코어 루프에서 이탈
- 보스에게 콤보가 필수가 아님 → 시스템 무시 가능

재설계 목표:

- **Kill → Fragment → Combo → Power Spike** 가 10분 런의 핵심 리듬
- 무기 선택이 파편 드롭에 영향 → 빌드 다양성 증가
- 보스의 네온 실드로 콤보 강제화 → 시스템 학습 동기 부여
- 대배당에서 파편 거래 가능 → 경제 시스템 통합

## Section 1: 무기-파편 친화도 매트릭스 (Weapon-Fragment Affinity Matrix)

### 1.1 설계 원칙

각 무기는 **PRIMARY 파편** (드롭 확률 +40%) 과 **SECONDARY 파편** (드롭 확률 +20%) 을 가진다.
친화도가 없는 파편 4종은 기본 확률로 드롭된다.

**확률 분배 공식**:

```
기본 파편 확률 (6종 균등) = 각 16.67%

친화도 적용 시:
  PRIMARY 파편: 16.67% × 1.4 = 23.33%
  SECONDARY 파편: 16.67% × 1.2 = 20.00%
  나머지 4종: (100% - 23.33% - 20.00%) / 4 = 14.17% 각

검증: 23.33 + 20.00 + (14.17 × 4) = 100.01% (반올림 오차, 구현 시 정규화)
```

| 파편        | PRIMARY 무기 (23.33%)                    | SECONDARY 무기 (20.00%)                      | 총 친화 무기 |

| 吉 (luck)   | pistol, freeze_ray, void = **3**         | sniper, wind = **2**                         | 5            |
| 火 (fire)   | laser, plasma, flamethrower = **3**      | missile, blade, acid = **3**                 | 6            |

**분석**: 大와 力이 PRIMARY 4개로 가장 풍부하고, 吉이 3개로 가장 적다.
이는 의도적 설계: 大吉 콤보(럭 2배)를 만들려면 吉 파편이 상대적으로 희소하여, 大吉 달성에 전략적 무기 선택이 필요하다.

### 1.5 빌드-콤보 시너지 분석

**최적 빌드 예시: "火力" (데미지 2배) 콤보 특화**

```
무기 선택: flamethrower(火 PRIMARY) + blade(力 PRIMARY)
  → 火 파편 확률: 23.33% + 20.00% = 무기 2개에서 평균 21.67%
  → 力 파편 확률: 23.33% + 23.33% = 무기 2개에서 평균 23.33%
  → 두 파편 모두 높은 확률 → 火力 콤보 발동 빈도 대폭 증가
```

**대조군: 친화도 미고려 빌드**

```
무기 선택: pistol(吉 PRIMARY) + missile(大 PRIMARY)
  → 火 파편 확률: 14.17% + 20.00% = 평균 17.09%
  → 力 파편 확률: 14.17% + 14.17% = 평균 14.17%
  → 火力 콤보 달성 확률 크게 낮음
```

### 2.4 콤보 발동 빈도 모델

**2파편 콤보 달성 조건**: 보유 중인 파편 2개가 레시피에 매칭

```
2파편 콤보 달성 확률 (균등 분배, 무작위):
  특정 콤보 1종 = 2/6 × 1/5 × 2! = 6.67% (보유 2개 중 매칭)

3개 보유 시 임의 콤보 최소 1개 매칭 확률:
  = 1 - (모두 미매칭 확률)
  6종 중 3개 선택 = C(6,3) = 20 조합
  2파편 콤보 6종 중 매칭 가능한 쌍: 특정 3개 파편에서 2개 쌍 = C(3,2) = 3쌍
  3쌍 중 콤보 레시피 존재 확률 ≈ 3 × (6/15) = 1.2 → 약 50~60%
```

**실전 콤보 발동 추정**:

| 시나리오               | 파편 수집 | 콤보 발동 | 발동 간격 |
| ---------------------- | --------- | --------- | --------- |
| 친화도 미활용 (비최적) | 48개      | 6~8회     | ~80초     |
| 친화도 활용 (최적)     | 48개      | 10~14회   | ~50초     |
| 대배당 파편 구매 포함  | 48+6개    | 12~16회   | ~40초     |

**근거**: 친화도 활용 시 원하는 파편 2종의 비율이 14.17%→23.33%로 상승하여 매칭 확률이 약 1.6배 증가.

> \*吉金 DPS 근거: crit100% + critMul+0.5 = 모든 공격이 (1.5+0.5)=2.0배 → 기대 DPS 2.0/기존 기대값(1+0.05×0.5)=1.025 ≈ 1.95배
> \*\*大吉 DPS 근거: 럭 2배 → 드롭 개선으로 간접 DPS 증가 (크리율/업그레이드 레어도 향상)

### 2.6 변환(Transmutation) 시스템 (신규 제안)

파편 3개를 의도적으로 소모하여 원하는 파편 1개로 변환하는 메카닉.

| 속성      | 값                                | 근거                                   |
| --------- | --------------------------------- | -------------------------------------- |
| 변환 비율 | 3:1                               | 3개 소비 → 1개 선택 생성               |
| 변환 시간 | 1.5초                             | 전략적 판단 시간 (대배당 3초보다 짧음) |
| 쿨다운    | 15초                              | 남용 방지                              |
| 발동 조건 | 파편 3개 보유 시 전용 버튼 활성화 | UI 하단                                |
| 슬로우 중 | 변환 시간 1.5초 유지 (유리)       | 크로노 핵 시너지                       |

**밸런스 근거**: 변환이 없으면 보유 파편 3개가 모두 원치 않는 종류일 때 "막힘"이 발생한다. 3:1 변환은 기회비용(파편 3개 소모 = 콤보 1회 포기)이 크므로 남용되지 않으면서도 빌드 유연성을 제공한다.

### 2.7 파편 인벤토리 관리 전략

최대 보유 3개 제한의 전략적 함의:

```
시나리오 A: 즉시 콤보 (공격적)
  → 파편 2개 모이면 바로 콤보 발동
  → 장점: 높은 콤보 빈도 (분당 1~2회)
  → 단점: 3파편 콤보 불가, 버프 전략적 타이밍 어려움

시나리오 B: 축적 후 콤보 (전략적)
  → 파편 3개까지 모아 3파편 레어 콤보 도전
  → 장점: 3배 데미지/5배 드롭 가능
  → 단점: 파편 소멸 리스크 (20초 수명), 2파편 콤보 기회 상실

시나리오 C: 대배당 복합 전략 (고급)
  → 파편 2개 보유 + 대배당에서 부족한 파편 구매
  → 장점: 원하는 콤보 확정 달성
  → 단점: 코인/파편 자원 소모, 대배당 위치까지 이동 필요
```

## Section 3: 보스 네온 실드 밸런스 (Boss Neon Shield Balance)

### 3.1 네온 실드 개념

보스는 일반 HP 외에 **네온 실드**를 갖는다. 네온 실드는 일반 무기로 파괴할 수 없으며, 오직 네온 콤보 버프 활성 상태에서의 공격만 실드에 데미지를 준다.

```
보스 HP 구조:
  [네온 실드] → 이것을 먼저 벗겨야 함
  [일반 HP]  → 실드 해제 후 일반 데미지 적용
```

### 3.2 보스별 네온 실드 수치

| 보스                      | 일반 HP | 네온 실드 HP | 필요 콤보 종류      | 요구 콤보 수\*\* | 실드 재생               |
| ------------------------- | ------- | ------------ | ------------------- | ---------------- | ----------------------- |
| Riot Commander (미니보스) | 800     | 200          | 아무 2파편 콤보     | 1~2회            | 없음                    |
| Yakuza Mech (챕터보스)    | 2,500   | 600          | 火 계열 콤보 필수\* | 2~3회            | 페이즈 전환 시 200 재생 |
| Neon Overlord (최종보스)  | 5,000   | 1,500        | 페이즈별 지정 콤보  | 4~6회            | 페이즈마다 500 재생     |

> \*火 계열 = 火力, 火龍, 大火力 중 하나
> \*\*요구 콤보 수 = 네온 실드 HP / (콤보 활성 중 DPS × 콤보 지속시간) 기반

### 3.3 네온 실드 데미지 공식

```
네온 실드 데미지 = 무기 데미지 × 콤보 배율 × 실드 효과 계수

실드 효과 계수:
  - 올바른 콤보 타입: 1.0× (정상 데미지)
  - 잘못된 콤보 타입: 0.3× (30%만 적용, 패널티)
  - 콤보 미활성: 0.0× (데미지 불가)
```

### 3.4 보스별 콤보 요구사항 상세

```
데미지 시뮬레이션:
  - 火力 콤보 (dmg×2) 활성 중 DPS 120 기준:
    15초 × 120 × 2.0 × 1.0 = 3,600 → 실드 200 즉파

    25초 × 120 × 1.75 × 1.0 = 5,250 → 실드 200 즉파

```

#### Yakuza Mech (챕터보스, 8분)

```
  - 잘못된 콤보 (吉金 등):
    300 / (180 × 1.75 × 0.3) = 3.17초 → 콤보 1회 내 가능하지만 비효율
```

```
요구: 페이즈별 다른 콤보
  - 페이즈 1: 火 계열 (공격적 접근)

  - 페이즈 3: 龍 계열 (金龍, 火龍, 金吉龍) — 최종 시험

페이즈 3 시뮬레이션 (DPS 200 기준):
  - 火龍 콤보 (aura+무기):
    DPS = (200 × 1.0 + 15) × 1.0 = 215
    500 / 215 = 2.3초 → 20초 지속이니 1회로 충분
  - 金龍 콤보 (coin, 비전투용):
    DPS = 200 × 1.0 × 0.3 = 60 (패널티)
    500 / 60 = 8.3초 → 20초 내 가능하지만 매우 비효율

총 요구: 3종 계열 콤보 각 최소 1회 = 최소 3회 콤보 (실제로는 4~6회)
```

### 3.6 잘못된 콤보 패널티 설계 근거

**0.3× 패널티 (30%)** 선택 이유:

```
0.0× (완전 무효): 너무 가혹 → 잘못된 콤보를 쓰면 그 콤보 지속시간이 완전히 낭비
                   → 보스전에서 좌절감 과다, 공정한 실패 원칙 위반

0.3× (30% 효과): 적절한 패널티 → "잘못된 콤보도 느리지만 효과는 있다"
                   → 3.3배 더 오래 걸림 = 시간 비용이 패널티
                   → 올바른 콤보 학습 동기 제공 + 완전 막힘 방지

0.5× (50% 효과): 패널티 약함 → 아무 콤보나 써도 2배만 느린 정도
                   → 콤보 선택의 전략적 의미 약화
```

## Section 5: 크로노-네온 시너지 수치 (Chrono-Neon Synergy)

### 5.1 크로노 중 파편 동결 (Fragment Freeze)

| 속성                    | 값                   | 근거                       |
| ----------------------- | -------------------- | -------------------------- |
| 필드 파편 수명 정지     | 완전 정지 (0초 소모) | 3초 슬로우 동안 파편 보존  |
| 인벤토리 파편 수명 정지 | 완전 정지            | 보스전 직전 파편 보존 전략 |
| 적 파편 드롭            | 정상 (킬 시 드롭)    | 슬로우 중에도 킬 = 드롭    |
| 파편 마그넷 수집 속도   | 정상 (1.0×)          | 플레이어 속도 정상이므로   |

**전략적 함의**: 크로노 핵 발동 타이밍에 필드 위 파편이 많을수록 수집 효율 극대화. 숙련 플레이어는 "파편 많이 깔린 구간에서 크로노 발동" 패턴을 학습.

### 5.2 콤보 미터 가속률 (Combo Meter Acceleration)

크로노 중 적 킬 속도가 증가하므로 (적은 느리고, 플레이어 DPS는 1.5배):

```
기본 킬 속도 (적 1마리 처치 시간):
  Drone (15HP): 0.75초 (pistol) → 슬로우 중 0.50초 (1.5× dmg)
  Enforcer (60HP): 3.0초 → 2.0초
  Sentinel (150HP): 7.5초 → 5.0초

크로노 3초 동안 추가 킬:
  Tier1 밀집 상황: 기본 4킬 → 크로노 중 6킬 (+2킬)
  Tier2 혼합: 기본 1킬 → 크로노 중 1.5킬 (+0.5킬)

크로노 3초 동안 게이지 재충전:
  6킬 × T1(1%) + 1킬 × T2(2%) = 8% 충전
  → 크로노 종료 후 게이지 8% 상태에서 시작
```

### 5.3 DPS 비교: 전투용 vs 수집용 크로노

| 크로노 활용                | 전투 DPS 증가        | 파편 수집 추가             | 크로노 게이지 재충전 | 총 가치\* |
| -------------------------- | -------------------- | -------------------------- | -------------------- | --------- |
| 전투 집중 (적 밀집 구간)   | +180 DPS ×3초 = +540 | +1~2개 (킬 드롭)           | +8~10%               | 1,080     |
| 수집 집중 (파편 산재 구간) | +180 DPS ×3초 = +540 | +3~5개 (필드 수집)         | +5~6%                | 1,290     |
| 보스전 집중                | +180 DPS ×3초 = +540 | +2개 (보스 드롭 해당 없음) | +20% (보스킬 시)     | 1,340     |
| 대배당 진입 지원           | +0 (대배당 이용 중)  | +0                         | +0                   | 음식 가치 |

> \*총 가치 = DPS 기여 + (파편 수 × 콤보 기대 가치 150)

**결론**:

- 보스전 크로노가 가장 효율적 (DPS + 게이지 재충전)
- 파편 수집용 크로노는 보스전 직전에 파편 비축할 때 유효
- 대배당 크로노는 상황적 (적이 몰려올 때 안전하게 주문 완료)

### 5.4 크로노-콤보 동시 발동 시너지

```
시나리오: 크로노 핵 + 火力 콤보 동시 활성

기본 DPS: 120
크로노 배율: ×1.5
콤보 배율: ×2.0
크리 확률: 5% + 30%(크로노) = 35%
크리 배율: 1.5

기대 DPS = 120 × 1.5 × 2.0 × (1 + 0.35 × 0.5) = 120 × 1.5 × 2.0 × 1.175
         = 423 DPS

기본 대비 = 423 / 120 = 3.53배

3초 지속 중 추가 데미지 = (423 - 120) × 3 = 909 추가 데미지
```

**이것은 "God Mode Moment"**: 10분 런에서 1~2회 발생하는 극적 순간.
설계 의도: 크로노+콤보 동시 달성에 필요한 조건(게이지 100% + 올바른 파편 보유)이 까다로우므로 보상이 강력해도 밸런스 유지.

## 부록 C: 친화도 미활용 vs 활용 비교 시뮬레이션

### 시나리오: 6분 경과 시점, 총 킬 500마리

**빌드 A (친화도 무시)**: pistol + missile + lightning + orbital

```
파편 분포 (균등): 각 16.67% = 약 4개씩 × 6종
火 파편: 4개, 力 파편: 4개
火力 콤보 매칭 확률: 기대 콤보 ~4회
```

**빌드 B (火力 특화)**: flamethrower(火P) + blade(力P) + lightning + shotgun(力P)

```
파편 분포:
  火: 23.33% (flame) + 14.17%×3 = 23.33 + 42.51 = 65.84% 가중 → 약 7개
  力: 23.33%×2 (blade+shotgun) + 14.17%×2 = 46.66 + 28.34 = 75% 가중 → 약 8개
  (정규화 후 火 약 6개, 力 약 7개)
火力 콤보 매칭 확률: 기대 콤보 ~7회
```

**결과**: 빌드 B는 콤보 발동 **1.75배 증가** → 무기 선택이 파편 전략과 직결
