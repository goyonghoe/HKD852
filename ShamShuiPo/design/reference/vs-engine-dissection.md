# Vampire Survivors 핵심 구동 원리 해부

> **목적**: VS의 표면 메카닉이 아닌, "왜 작동하는가"의 심층 원리를 추출한다.
> **용도**: ShamShuiPo 및 HKD852 게임 프로젝트의 설계 원칙 레퍼런스
> **작성일**: 2026-03-14

---

## 1. VS의 5대 중독 엔진 (Addiction Engines)

VS가 "한 판만 더"를 만드는 것은 단일 요소가 아니다. 5개의 독립적 엔진이 동시에 구동되며, 각 엔진이 서로의 효과를 증폭한다. 하나라도 빠지면 전체 시스템의 점성(粘性)이 급격히 떨어진다.

---

### Engine 1: 압축된 성장 서사 (Compressed Hero's Journey)

#### 핵심 원리

VS의 한 판(~30분)은 "무력한 인간 → 세계를 멸하는 신"으로의 변신 서사를 극도로 압축한 것이다. 이 여정이 감동적인 이유는 **위험 곡선(Danger Curve)과 파워 곡선(Power Curve)의 교차** 때문이다.

#### 두 곡선의 교차 역학

```
위험도 ▲
       │          ╱ 적 밀도·속도·체력
       │        ╱     (지수 증가)
       │      ╱
       │    ╱  ✕ ← 교차점 (4~8분)
       │  ╱  ╱
       │╱  ╱  파워 (S자 곡선: 느린 시작 → 폭발 → 포화)
       └──────────────────────→ 시간
            5분    15분    30분
```

**0~3분 (생존 위기)**

- 파워: 단일 무기, 낮은 DPS. 적 1마리도 위협.
- 위험: 적 소수지만, 플레이어 파워 대비 치명적.
- 심리: **긴장감 → 집중력 강제 동원**. 플레이어는 "살아남아야 한다"는 원시적 본능에 몰입한다.
- 이 시기의 설계 목적: **이탈 방지**. 3분 안에 첫 레벨업이 오고, "아 이게 이렇게 강해지는구나"를 맛보게 한다.

**4~8분 (교차 구간 = 게임의 심장)**

- 파워와 위험이 교차하는 구간. **가장 중요한 시간대.**
- 플레이어는 "거의 죽을 뻔한" 순간을 반복 경험한다.
- 이것이 **Near-Miss Psychology(아차 심리학)** — 도박 심리학에서 가장 강력한 동기 부여 메커니즘 중 하나.
- 슬롯머신에서 체리-체리-레몬이 나오면 "다음엔 될 것 같다"고 느끼는 것과 동일.
- VS에서는 HP 1칸 남기고 레벨업 → 회복 → "휴, 살았다" → **안도감이 쾌감으로 전환**.
- 이 구간에서 플레이어는 **자신의 빌드 선택이 생사를 결정한다고 느낀다** (실제로는 거의 모든 빌드가 통과 가능하도록 설계됨).

**9~20분 (역전 = 파워 판타지 시작)**

- 파워 곡선이 위험 곡선을 추월하기 시작.
- 무기 2~4개 보유, 진화 시작. 적을 "학살"하기 시작.
- 심리: **역전의 쾌감**. "아까까지 나를 괴롭히던 놈들이 이제 경험치 사료에 불과하다."
- XP 젬이 화면 가득 쏟아지며 레벨업 빈도 증가 → 보상 주기가 점점 빨라짐.

**20~30분 (무적의 신 = 감각적 포화)**

- 화면이 이펙트와 데미지 숫자로 뒤덮인다.
- 플레이어는 거의 아무것도 안 해도 적이 죽는다.
- 심리: **명상적 플로우 + 전지전능 환상**. 뇌가 "나는 강하다"를 반복 확인.
- 이 단계가 유지되는 이유: 적의 밀도가 계속 증가하므로 "완전한 안전"은 오지 않는다. **약간의 긴장이 남아있어서 지루해지지 않는다.**

#### "거의 죽을 뻔" 순간이 중요한 진짜 이유

아차 효과(Near-Miss Effect)는 단순한 안도감이 아니다. 신경과학적으로:

1. **도파민 이중 분비**: 위험 인식 시 도파민 분비 → 위험 회피 성공 시 추가 도파민 분비. 한 번의 이벤트에서 두 번의 쾌감.
2. **자기 효능감(Self-Efficacy) 착각**: "내가 잘해서 살아남았다"고 느낀다 (실제로는 레벨업 시 무적 시간이 주어져서 살아남은 것).
3. **기억 편향**: 아차 순간은 편안했던 순간보다 강하게 기억된다. 게임 끝나고 "아까 그 순간 진짜 아슬아슬했는데..."라고 떠올리며 다시 시작.

#### 최소 필수 조건

| 요소                 | 필수 여부 | 이유                                                     |
| -------------------- | --------- | -------------------------------------------------------- |
| 시작이 약해야 함     | **필수**  | 성장 대비(contrast)가 없으면 성장 쾌감도 없다            |
| 교차 구간 존재       | **필수**  | 아차 순간이 없으면 긴장 없는 파밍 게임으로 전락          |
| 성장이 체감되어야 함 | **필수**  | 숫자만 올라가고 화면이 안 변하면 뇌는 성장을 인식 못한다 |
| 정확히 30분일 필요   | 불필요    | 5분이든 60분이든, 곡선의 형태만 유지하면 된다            |
| 이동만으로 회피      | 불필요    | 곡선 형태가 보존되면 어떤 회피 메카닉이든 가능           |

### Engine 2: 통제된 무작위 (Controlled Randomness)

#### 핵심 원리

VS의 레벨업 시스템은 **변동비율 강화 스케줄(Variable Ratio Reinforcement Schedule)**의 게임화된 형태다. 이것이 슬롯머신보다 강력한 이유는 **"선택의 환상"**을 추가했기 때문이다.

#### 왜 "3개 중 1개 선택"이 최적인가

**Hick의 법칙(Hick's Law)**: 선택지가 많을수록 결정 시간이 로그적으로 증가한다.

- 2개: 너무 적다 → "선택이 아니라 강제"로 느낀다.
- 3개: **최적** → 0.5~2초 내 결정 가능. "내가 선택했다"는 자율감(autonomy) 확보.
- 5개 이상: 결정 피로(Decision Fatigue) 유발. 플로우 깨짐.

**3개가 만드는 심리적 구조**:

```
선택지 A (원하는 것)  → "좋아, 이걸로!" → 만족
선택지 B (괜찮은 것)  → "A가 있으니까 패스" → A의 가치 강화
선택지 C (필요 없는 것) → "이건 아니지" → 판단력 행사 쾌감
```

3개 중 하나를 고르는 행위 자체가 **"나는 이 게임의 전략가"라는 정체성을 부여**한다. 실제 영향이 미미해도 "내 선택이 이 런을 만들었다"고 기억한다.

#### 변동비율 강화가 고정비율보다 강한 이유

**고정비율**: "적 100마리 잡으면 레벨업" → 플레이어가 예측 가능 → 보상 직전에만 흥분, 보상 직후 동기 하락 (Post-Reinforcement Pause).

**변동비율** (VS의 XP 시스템):

- XP 젬 크기가 무작위 (1, 3, 7, 25...).
- 레벨업까지 필요 경험치는 고정이지만, XP 젬 획득 타이밍이 불규칙.
- 결과: **"언제 터질지 모른다"는 기대감이 지속** → 도파민은 보상 자체보다 **보상의 예측 불가능성**에 반응.
- Skinner의 연구: 변동비율 스케줄은 고정비율 대비 **소거 저항(Resistance to Extinction)이 가장 높다**. 즉, 보상이 잠시 멈춰도 행동이 계속된다.

#### XP "젬"의 디자인이 "코인"과 다른 이유

| 속성        | XP 젬                                   | 일반 코인              |
| ----------- | --------------------------------------- | ---------------------- |
| 시각 피드백 | 빛나는 결정체, 색상 다양                | 단조로운 금색          |
| 물리 행동   | 바닥에 흩어졌다 → 자석처럼 빨려온다     | 고정 위치 or 즉시 획득 |
| 수집 순간   | "쉬이잉" 사운드 + 연속 흡수 = 연쇄 쾌감 | 단일 "딸깍"            |
| 축적 피드백 | 경험치 바가 실시간으로 차오름           | 숫자만 변경            |

VS의 XP 젬이 만드는 쾌감의 핵심은 **"자석(Magnet) 효과"**다. 적을 처치하면 젬이 바닥에 흩어지고, 플레이어가 근처를 지나가면 수십 개의 젬이 한꺼번에 빨려온다. 이것은:

1. **소유 확인의 쾌감**: "이 보상은 내 것"이라는 물리적 확인.
2. **연속 보상 효과**: 하나하나 오는 게 아니라 "다다다다다" 하고 연속으로 → 뇌가 연속 도파민 분비.
3. **공간적 보상**: 특정 위치를 지나가면 보상이 온다 → 맵 탐색의 부가 동기.

#### 보물 상자 = 미니 슬롯머신

레벨업 선택이 "통제된 무작위"라면, 보물 상자는 **"순수한 무작위"**다.

- 10분마다 보스가 상자를 드랍.
- 상자를 열면 보유 무기 중 하나가 강제 강화.
- 어떤 무기가 강화될지 모른다 → 슬롯머신의 릴 돌아가는 순간과 동일한 도파민 스파이크.
- 때로는 "원하지 않던 무기"가 강화됨 → 좌절이 아니라 "다음 상자에서는..." → 기대감 유지.

#### 최소 필수 조건

| 요소                  | 필수 여부 | 이유                                        |
| --------------------- | --------- | ------------------------------------------- |
| 변동비율 보상 스케줄  | **필수**  | 고정 간격 보상은 예측 가능 → 지루함         |
| 제한된 선택지 (2~4개) | **필수**  | 자율감 + 결정 피로 방지의 균형점            |
| 보상의 물리적 연출    | **필수**  | 숫자만 바뀌면 뇌가 보상으로 인식하지 않음   |
| XP 젬이어야 할 필요   | 불필요    | 어떤 형태든 "흩어짐 → 흡수" 피드백이면 작동 |
| 보물 상자 메카닉      | 불필요    | 핵심은 "통제 불가능한 랜덤 보너스"의 존재   |

### Engine 3: 시스테믹 서프라이즈 (Systemic Surprise)

#### 핵심 원리

VS에서 무기+패시브 아이템의 조합이 새로운 진화 무기를 만드는 순간, 플레이어는 **"아하! 모먼트(Eureka Moment)"**를 경험한다. 이것은 단순한 보상이 아니라 **발견의 쾌감** — 인간의 탐구 본능을 자극하는 가장 원초적인 동기 부여다.

#### 레시피를 "숨기는" 이유

VS는 무기 진화 조합을 공식적으로 알려주지 않았다 (초기). 이후 힌트 시스템을 추가했지만, 핵심은 **"숨겨진 것이 있다"는 사실 자체가 동기**라는 것이다.

**정보 격차 이론 (Information Gap Theory — Loewenstein, 1994)**:

- 인간은 "모르는 것이 있다"는 사실을 인지하면 그 격차를 메우려는 강렬한 동기가 생긴다.
- VS는 이 격차를 의도적으로 설계한다:
  - 레벨업 화면에 "???" 아이템이 보인다 → "뭐지?" → 궁금증.
  - 특정 조합을 갖추면 진화한다는 소문 → "나도 해봐야지" → 실험 동기.
  - 진화 성공 → "나만 아는 비밀을 발견한 것 같은" 우월감.

#### 조합 시스템이 만드는 리플레이 구조

```
첫 번째 런: 랜덤 빌드 → "오, 이런 무기도 있네" (발견)
두 번째 런: "아까 그 무기 더 키워볼까" (심화)
세 번째 런: "이 무기랑 저 아이템 합치면?" (실험)
네 번째 런: "진화했다! 개사기!" (아하!)
다섯 번째 런: "다른 조합은?" (탐구)
...
N번째 런: "모든 진화 해봤으니 최적 빌드를 만들자" (최적화)
```

이 구조에서 **같은 게임을 반복하는 것이 아니라, 매번 다른 질문에 답하는 것**이 된다. 리플레이가 반복이 아니라 탐구가 되는 이유.

#### "우연한 발견"의 설계

VS의 빌드 시스템에서 플레이어가 의도한 조합을 완성하는 것보다 **의도하지 않았던 시너지를 발견하는 순간**이 더 강한 쾌감을 준다. 이것이 **세렌디피티(Serendipity) 설계**다.

- 레벨업 선택지가 무작위이므로, 원하는 아이템이 안 나올 때가 많다.
- 어쩔 수 없이 선택한 무기가 기존 빌드와 예상 외로 시너지 → "오, 이것도 되네?"
- 이 순간이 **"내가 만든 유일한 빌드"라는 소유감**을 만든다.

#### Union(융합) 시스템의 추가 심리

VS는 진화(Evolution) 외에 Union(두 무기 합체) 메카닉도 있다:

- 진화: 무기 + 패시브 → 강화된 무기 (슬롯 유지)
- Union: 무기 + 무기 → 합체 무기 (슬롯 1개 절약)
- Union은 **"리소스 효율의 쾌감"**을 추가한다. "2칸 쓰던 게 1칸으로 줄었다 = 더 많은 무기를 장착할 수 있다."

#### 최소 필수 조건

| 요소               | 필수 여부 | 이유                                       |
| ------------------ | --------- | ------------------------------------------ |
| 조합/진화 시스템   | **필수**  | 발견의 쾌감이 리플레이의 핵심 동력         |
| 레시피 일부 은폐   | **필수**  | 정보 격차가 탐구 동기를 만든다             |
| 무작위 선택지 제공 | **필수**  | 계획 외 조합 = 세렌디피티 = 소유감         |
| 무기+패시브 구조   | 불필요    | 어떤 조합 체계든 "A+B=C"의 놀라움이면 작동 |
| 방대한 아이템 풀   | 권장      | 조합 가능성 공간이 넓을수록 탐구 수명이 김 |

### Engine 4: 감각적 포화 (Sensory Saturation)

#### 핵심 원리

VS의 후반부 화면은 **의도적으로 인간의 시각 처리 한계를 초과**하도록 설계되어 있다. 수백 마리의 적, 수십 개의 무기 이펙트, 쏟아지는 데미지 숫자, XP 젬 — 이 모든 것이 동시에 화면을 덮는다. 이것은 버그가 아니라 **설계의 핵심**이다.

#### "뇌 정지 쾌감"의 과학

인간의 의식적 정보 처리 용량은 초당 약 120비트다. VS의 후반부는 이 한계를 의도적으로 넘긴다. 그 결과:

1. **분석적 사고 정지**: 뇌가 개별 적이나 이펙트를 추적하려는 시도를 포기한다.
2. **패턴 인식으로 전환**: 의식적 분석 대신, 전체 화면의 "흐름"을 직관적으로 읽는 모드로 전환.
3. **명상적 플로우 진입**: 의식적 사고가 줄어들고, 행동이 자동화되며, 시간 감각이 사라진다.

이것이 VS가 "릴랙싱 게임"이라는 평가를 받는 역설적 이유다. **화면은 카오스지만 플레이어의 정신은 고요해진다.**

#### 아이들(Idle) 게임과의 교차점

VS의 후반부는 사실상 **액션 게임의 탈을 쓴 아이들 게임**이다:

| 아이들 게임             | VS 후반부                    |
| ----------------------- | ---------------------------- |
| 수치가 알아서 올라간다  | 무기가 알아서 적을 잡는다    |
| 로그 보며 만족          | 화면 가득한 이펙트 보며 만족 |
| 가끔 업그레이드 클릭    | 가끔 레벨업 선택             |
| 화면을 보고 있으면 행복 | 화면을 보고 있으면 행복      |

차이는 **액션 게임의 감각적 피드백이 추가**된다는 것. 아이들 게임의 "숫자가 올라가는 만족감"에 "폭발, 사운드, 화면 가득한 적 소멸"이라는 시청각 레이어가 얹어진다.

#### 피드백 설계의 층위

VS가 "쥬시(Juicy)"한 이유는 피드백이 **다층적(multi-layered)**이기 때문이다:

```
Layer 1: 시각 — 적 소멸 이펙트 (파편, 빛, 페이드)
Layer 2: 청각 — 타격음, 소멸음, XP 흡수음
Layer 3: 공간 — 적이 밀려남 (넉백), 빈 공간 생성
Layer 4: 누적 — 데미지 숫자 흐름, 킬 카운터 증가
Layer 5: 리듬 — 무기 발사 주기가 만드는 시각적 박동
```

이 5개 층이 동시에 작동하면서 하나의 행위(적 처치)가 **5중 확인**된다. 뇌는 하나의 행동에 대해 5번의 "잘했다" 피드백을 받는다.

#### 화면 흔들림(Screen Shake)과 히트 스탑(Hit Stop)

게임 필(Game Feel) 연구에 따르면:

- **히트 스탑**: 0.1초의 정지 프레임이 타격의 체감 강도를 약 30% 증가시킨다.
- **화면 흔들림**: 강한 공격 시 카메라 진동 → "이 공격은 세상을 흔들 정도로 강하다"는 메시지.
- VS는 이 두 요소를 절제하되, 대신 **"양(quantity)으로 밀어붙이는" 전략**을 택했다. 하나의 강한 타격보다 백 개의 동시 타격이 주는 과부하 쾌감.

#### 최소 필수 조건

| 요소                           | 필수 여부 | 이유                                                      |
| ------------------------------ | --------- | --------------------------------------------------------- |
| 시각적 과부하 구간 존재        | **필수**  | 분석적 사고 정지 → 플로우 진입의 트리거                   |
| 다층적 피드백 (시각+청각 최소) | **필수**  | 단일 채널 피드백은 포화를 만들 수 없다                    |
| 성장에 따른 이펙트 스케일링    | **필수**  | 파워가 커져도 화면이 안 변하면 성장을 못 느낀다           |
| 적의 물량                      | 권장      | VS 스타일의 핵심이지만 "밀도"를 표현하는 다른 방법도 가능 |
| 탑다운 뷰                      | 불필요    | 어떤 시점이든 감각 포화가 가능하면 작동                   |

### Engine 5: 축적되는 마스터리 (Cumulative Mastery)

#### 핵심 원리

VS에서 "이번 런은 졌지만, 다음 런은 더 강해진다." 이것이 메타 진행(Meta Progression)의 핵심이다. 하지만 VS의 메타 진행은 Rogue Legacy나 Hades와는 근본적으로 다른 방식으로 작동한다.

#### 세 가지 메타 진행 비교

|                 | Rogue Legacy         | Hades              | Vampire Survivors                    |
| --------------- | -------------------- | ------------------ | ------------------------------------ |
| 메타 영구 강화  | 매우 강함 (성 건설)  | 중간 (미러, 관계)  | **약함** (파워업 미미)               |
| 런 내 성장 비중 | 50%                  | 60%                | **90%**                              |
| "한 판 더" 동기 | "다음엔 충분히 강해" | "스토리 보고 싶어" | **"다른 조합 해보고 싶어"**          |
| 실패 시 감정    | 분함 (시간 낭비감)   | 아쉬움 (서사 미완) | **무덤덤 (어차피 새 발견이 있었다)** |

VS의 천재적 설계는 **영구 강화가 약하다는 것 자체가 장점**이라는 점이다.

#### 왜 약한 메타 진행이 더 강한가

**강한 메타 진행의 함정**:

- Rogue Legacy: 20시간 후 캐릭터가 너무 강해져서 "던전이 쉬워지면" Engine 1(위험 곡선)이 무너진다.
- 해결: 난이도 스케일링 도입 → 결국 "런 안에서의 성장 서사"가 희석됨.

**VS의 접근**:

- 골드로 구매하는 파워업은 미미한 % 증가 (이동속도 +5%, 대미지 +5% 등).
- 진짜 메타 진행은 **캐릭터/스테이지/아르카나 언락**.
- 즉, 강해지는 것이 아니라 **새로운 경험을 여는 것**.

```
Rogue Legacy: 실패 → 더 강해짐 → 같은 도전 재시도 (양적 진행)
VS:          실패 → 새 캐릭터 언락 → 다른 경험 시작 (질적 진행)
```

#### "한 판 더" 심리의 3단 구조

VS는 한 판이 끝날 때마다 세 가지 당근을 동시에 제시한다:

**당근 1: 미완의 과제 (Zeigarnik Effect)**

- "아 맞다, 이번 런에서 진화 하나 못 했는데..."
- 인간은 완료한 과제보다 미완의 과제를 더 강하게 기억한다.
- VS의 진화/언락 리스트가 "??? ???"로 보이는 이유 — 미완을 상기시키려고.

**당근 2: 다음 언락의 근접성 (Goal Gradient Effect)**

- "골드 300만 더 모으면 새 캐릭터인데..."
- 목표에 가까울수록 동기가 급증하는 효과.
- VS는 파워업 가격을 의도적으로 "1~2런이면 구매 가능"하게 설정.

**당근 3: 미시도 조합의 호기심**

- "이번에 whip 안 써봤는데 진화하면 어떻게 되지?"
- Engine 3(시스테믹 서프라이즈)와의 시너지. 메타 진행이 새 조합 실험의 동기가 된다.

#### 업적 시스템의 심리

VS의 업적(Achievement) 리스트는 **외재적 동기(Extrinsic Motivation)**와 **내재적 동기(Intrinsic Motivation)**를 동시에 자극한다:

- 외재적: "업적 달성 → 새 캐릭터/무기 언락" (보상)
- 내재적: "이런 조건으로도 클리어할 수 있을까?" (도전)
- 업적 리스트가 길면 길수록 "할 것이 남아있다"는 안도감 → 게임의 수명 연장.

#### 최소 필수 조건

| 요소                  | 필수 여부 | 이유                                          |
| --------------------- | --------- | --------------------------------------------- |
| 런 간 영구 진행       | **필수**  | "시간 낭비가 아니다"라는 확인이 없으면 이탈   |
| 질적 언락 (새 경험)   | **필수**  | 양적 강화만으로는 Engine 1과 충돌             |
| 명확한 다음 목표 제시 | **필수**  | 목표 없는 상태에서 "한 판 더"는 나오지 않는다 |
| 골드/화폐 시스템      | 불필요    | 언락 조건이 업적 기반이어도 작동              |
| 수백 개의 업적        | 권장      | 많을수록 "할 것이 남아있다"는 심리 지속       |

## 3. VS에서 제거해도 되는 것 (Sacred Cows to Kill)

VS의 표면적 특징 중 "VS이기에 그런 것"일 뿐, 엔진 작동과 무관한 요소들.

### 3-1. 자동 공격 → 제거 가능

**VS의 자동 공격이 존재하는 이유**: 조작 복잡도를 제거하여 "이동에만 집중"하게 하려는 설계.

**그러나**: 에이밍이 있어도 5대 엔진은 모두 작동한다.

- 조건: 에이밍 난이도가 Engine 4(감각 포화)를 방해하지 않을 것.
- 잘못된 적용: 하나하나 정밀 조준해야 하는 시스템 → 적이 수백 마리일 때 조작 과부하 → 플로우 깨짐.
- 올바른 적용: "대략적 방향 지정" 수준의 에이밍 (Brotato 스타일) → 엔진 보존.

### 3-2. 조이스틱/WASD 이동 → 제거 가능

**VS에서 이동이 하는 역할**: 위험 회피 + 보상(XP 젬) 수집의 공간적 의사결정.

**대체 가능한 이동 방식**:

- 터치/스와이프 (모바일)
- 경로 지정 (타워 디펜스 하이브리드)
- 자동 이동 + 방향 전환만 조작 (원 버튼)
- 조건: "공간적 위험 회피"의 의사결정이 남아있어야 함.

### 3-3. 실시간 → 변형 가능

**VS가 실시간인 이유**: Engine 4(감각 포화)와 Engine 1(연속적 위험 곡선)에 최적.

**그러나**: 턴제+실시간 하이브리드도 가능.

- 예: 이동은 턴제, 전투는 실시간 (Into the Breach 변형)
- 예: 평소 실시간, 레벨업 시 시간 정지 (이미 VS가 이렇게 함)
- 주의: **완전 턴제는 Engine 4(감각 포화)와 심각하게 충돌**. 시각적 과부하의 쾌감은 연속적 시간 흐름을 필요로 한다.

### 3-4. 톱다운 뷰 → 제거 가능

**VS가 톱다운인 이유**: 360도 방향에서 오는 적을 관리하기 위한 최적의 시점.

**대체 가능한 시점**:

- 사이드뷰: 적이 좌우+위에서 접근 (더 방향 제한적이지만 작동)
- 3D 삼인칭: Overcooked 스타일 카메라
- 조건: 플레이어가 **"둘러싸여 있다"는 공간적 압박**을 느낄 수 있어야 함. 일렬로 오는 적은 Engine 1의 위험 곡선을 약화시킨다.

### 3-5. 30분 세션 → 조정 가능

**VS의 30분이 의미하는 것**: Engine 1의 위험 곡선이 펼쳐지기에 충분한 시간.

**조정 가능 범위**:

- **최소 5분**: 이보다 짧으면 교차 구간이 너무 짧아서 아차 심리가 형성되지 않음.
- **최대 60분**: 이보다 길면 성장 서사의 밀도가 희석되어 "압축된 여정" 효과 상실.
- **최적 구간**: 10~20분. 모바일이면 5~10분도 가능하지만, 성장 곡선 압축도가 높아야 함.

### 3-6. 걸어다니는 히어로 → 제거 가능

**VS에서 캐릭터의 역할**: 피격 판정 박스 + 시점 중심 + 성장의 주체.

**대체 가능한 주체**:

- 거점/타워 (타워 디펜스)
- 차량/함선 (슈터)
- 추상적 커서 (RTS)
- 조건: **플레이어가 감정적으로 동일시할 수 있는 "나의 것"**이 있어야 한다.

### 상세 충돌 분석

#### 완전 턴제 ✕ Engine 4 (감각 포화)

감각 포화는 **연속적 시각 정보의 홍수**에서 발생한다. 턴제는 본질적으로 이산적(discrete)이다. 턴 사이에 생각할 시간이 있으면 분석적 사고가 유지되고, 명상적 플로우에 진입할 수 없다.

**우회 방법**: 턴제지만 턴 시간 제한을 짧게 (3초 이내) 설정하여 사실상 실시간과 유사한 압박감 유지. 또는 전투만 실시간으로 처리.

#### 긴 세션 ✕ Engine 1 (압축 성장)

30분 안에 "무에서 신으로"가 VS의 핵심. 2시간 세션이면 성장 곡선이 늘어져서 "교차 구간"에서 아차 심리가 여러 번 반복 → 효과 감소(Habituation).

**우회 방법**: 긴 세션 안에 "미니 런"을 여러 번 넣는다. 각 미니 런이 독립적 성장 서사를 가지되, 미니 런 간 메타 진행이 존재.

#### 정밀 에이밍 ✕ Engine 4 (감각 포화)

적이 수백 마리일 때 하나하나 조준하면 **인지 과부하(Cognitive Overload)**가 된다. 감각 포화는 "뇌가 포기하고 직관 모드로 전환"해야 쾌감이 되는데, 정밀 에이밍은 뇌에게 "포기하지 마, 계속 분석해"라고 요구한다.

**우회 방법**: "영역 공격" 또는 "자동 추적" 무기 비중을 높여서, 에이밍이 필요한 무기는 전체의 1~2개로 제한.

#### 높은 스킬 장벽 ✕ Engine 1 (위험 곡선)

VS의 위험 곡선은 **스킬이 아니라 빌드로 극복**되도록 설계되어 있다. 높은 스킬 장벽을 도입하면 "약한 시작"이 "못하는 시작"이 되고, 교차 구간에서의 죽음이 "아차"가 아니라 "좌절"이 된다.

**우회 방법**: 스킬 장벽은 "선택적 도전(Optional Challenge)"으로 제공. 기본 난이도에서는 빌드만으로 클리어 가능하게.

#### PvP ✕ Engine 1+2

PvP는 상대 플레이어가 위험 곡선을 제어한다. 따라서 **예측 가능한 성장 서사가 파괴**된다. 또한 패배 시의 감정이 "아쉬움"이 아니라 "분노/좌절"이 되어 "한 판 더"가 아니라 "꺼버림"이 된다.

**우회 방법**: 비동기 PvP(유령 데이터 경쟁). 상대가 실시간으로 방해하지 않으므로 성장 서사 보존.

#### 영구 죽음 ✕ Engine 5 (메타 진행)

순수 로그라이크의 영구 죽음은 "런 간 아무것도 남지 않는다." 이것은 Engine 5를 완전히 제거한다.

**우회 방법**: 로그라이트(Roguelite) 방식 — 죽어도 일부 진행은 보존. VS가 이미 이 방식.

### 가장 호환성 높은 장르 조합

| 조합                 | 이유                                                                                                   |
| -------------------- | ------------------------------------------------------------------------------------------------------ |
| VS + 타워 디펜스     | 거점 방어가 "둘러싸임"의 공간 압박 유지. 타워 배치가 조합 시스템 역할. 물량전 유지로 감각 포화 보존    |
| VS + 오토 배틀러     | 자동 전투가 감각 포화 유지. 팀 구성이 조합/진화 역할. 짧은 라운드가 압축 성장 보존                     |
| VS + 덱 빌딩         | 카드 선택이 "3개 중 1개 고르기" 확장. 카드 조합이 시너지 발견 역할. 단, 감각 포화를 별도로 설계해야 함 |
| VS + 팩토리 (자동화) | 생산 라인 구축이 조합 시스템. 기하급수적 생산량이 감각 포화. 최적화 탐구가 리플레이 동기               |

## 부록: 5대 엔진 상호작용 맵

```
    ┌─────────────────────────────────────────────┐
    │                                             │
    │   E1 (위험곡선)                              │
    │      │                                      │
    │      │ 교차 구간의 긴장 →                     │
    │      ▼                                      │
    │   E2 (변동보상) ──── 무작위 선택 ────→ E3 (조합발견)
    │      │                                 │    │
    │      │ 파워 증가 →                      │    │
    │      ▼                                 │    │
    │   E4 (감각포화) ◄── 새 조합 = 새 이펙트 ─┘    │
    │      │                                      │
    │      │ "더 보고 싶다" →                      │
    │      ▼                                      │
    │   E5 (메타진행) ──── 새 캐릭터 = 새 곡선 ──→ E1
    │                                             │
    └─────────────────────────────────────────────┘

핵심: 5개 엔진은 순환한다.
E1의 긴장 → E2의 보상으로 해소 → E3의 발견으로 심화 →
E4의 포화로 절정 → E5의 당근으로 재시작
```

## 핵심 요약: 한 문장으로

> **VS의 정수는 "10분 안에 거지에서 신이 되는 여정을 무작위 선택과 우연한 발견으로 채우고, 감각적 과부하로 절정을 맞이하게 한 뒤, 다음 여정을 위한 당근을 보여주는 것"이다.**

이 한 문장에서 빠져도 되는 것: 톱다운 뷰, 자동 공격, 조이스틱 이동, 뱀파이어 테마, 픽셀 아트.
이 한 문장에서 빠지면 안 되는 것: 압축된 성장, 무작위 선택, 조합 발견, 감각 포화, 메타 당근.
