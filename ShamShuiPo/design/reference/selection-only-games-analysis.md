# Selection-Only 게임 심층 분석

> **목적**: 플레이어의 유일한 인터랙션이 "선택/결정"인 게임들의 성공 원리를 해부한다.
> **용도**: ShamShuiPo 프로젝트의 셀렉션 메카닉 설계 레퍼런스
> **작성일**: 2026-03-14

---

## 핵심 전제: "Selection-Only"란 무엇인가

Selection-Only 게임에서 플레이어의 인터랙션은 다음 세 단계로 압축된다:

```
관찰 (Observe) → 결정 (Decide) → 선택 (Select) → 결과 관전 (Watch with Anticipation)
```

수동 민첩성(Manual Dexterity)은 요구되지 않는다. 조이스틱, 에이밍, 타이밍 입력이 없다. 플레이어의 "스킬"은 판단력이지 반사 신경이 아니다. 그리고 놀랍게도, 이 구조가 가장 중독적인 게임들을 만들어냈다.

### 1. Balatro (2024) — 포커 핸드 선택 + 조커 시너지

> 1인 개발자 LocalThunk이 만든 포커 로그라이크. 2024년 올해의 게임 수상. 500만+ 카피 판매.

#### The Selection Moment (선택의 순간)

**무엇을 선택하는가:**

1. **핸드 선택**: 8장의 카드 중 5장을 골라 포커 핸드를 제출. 라운드당 최대 4회 핸드 플레이.
2. **디스카드**: 최대 4회 카드를 버리고 새로 드로우. "이 카드를 버리면 더 좋은 조합이 올까?"
3. **상점 선택**: 라운드 사이 상점에서 조커, 행성 카드, 타로 카드, 바우처 중 구매. 슬롯 제한(5개)이 선택에 무게를 부여.

**선택지 수와 시간 압박:**

- 핸드 선택: 8장에서 5장 = C(8,5) = 56가지 조합. 실전에서는 3~5개의 유력 후보로 수렴.
- 상점: 2~4개의 구매 가능 아이템. 골드 제한이 자연스러운 필터.
- **시간 압박: 없음.** 무제한 숙고 가능. 이것이 핵심 — 시간 압박이 없어도 선택의 긴장감이 유지된다.

**왜 시간 압박 없이도 긴장되는가:**

- **비가역성(Irreversibility)**: 디스카드한 카드는 돌아오지 않는다. 조커 슬롯에 넣은 조커는 제거 비용이 든다.
- **자원 고갈(Resource Depletion)**: 핸드 횟수와 디스카드 횟수가 유한. 매 선택이 "이 자원을 여기에 쓸 것인가"의 경제적 결정.
- **점수 목표의 압박**: 블라인드마다 최소 점수를 달성해야 한다. 점수가 기하급수적으로 증가하므로, 빌드가 안 맞으면 6라운드 쯤에 벽에 부딪힌다.

#### The Anticipation Loop (기대감 루프)

**선택과 선택 사이에 흥분을 만드는 것:**

1. **점수 계산 애니메이션**: 카드가 하나씩 뒤집히며, 각 카드의 칩(Chips)과 배율(Mult)이 실시간으로 누적된다. 조커 효과가 순차적으로 적용되며 숫자가 폭발적으로 올라간다.
2. **"이거 되나?" 순간**: 새로 획득한 조커가 기존 빌드와 시너지를 만들지 확인하는 첫 핸드. "Steel 카드 + Mime 조커 + Blueprint 조커를 합치면... 세상에, 배율이 ×256이 됐다!"
3. **규칙 위반의 쾌감**: 포커에서 "파이브 오브 어 카인드"는 불가능하다. Balatro에서는 가능하다. 규칙을 깨는 순간 — 모든 카드를 에이스로 바꾸거나, 플러시에 스트레이트를 겹치거나 — 이 순간이 "아하!"를 만든다.

**핵심 공식**: `익숙한 규칙 (포커) + 규칙을 깨는 도구 (조커) = 발견의 쾌감`

| 엔진                    |   존재 여부   | Balatro에서의 형태                                                                                                                          |
| ----------------------- | :-----------: | ------------------------------------------------------------------------------------------------------------------------------------------- |

#### "One More Run" Hook

1. **Zeigarnik 효과**: "아까 그 조커 조합이 잘 될 뻔했는데..." → 미완의 빌드를 완성하고 싶은 욕구
2. **천문학적 점수의 유혹**: 이전 런 최고 점수를 깨고 싶다. 숫자가 커질수록 "더 큰 숫자"에 대한 탐욕이 커진다.
3. **"이번엔 다른 조합"**: 150+개 조커 중 한 런에 5개만 사용 → 시도하지 않은 조합이 항상 존재
4. **스테이크 난이도**: 클리어 후 더 높은 난이도 해금 → "이 난이도에서도 이길 수 있을까?"

### 2. Slay the Spire (2019) — 카드 선택 덱빌더

> 로그라이크 덱빌딩 장르를 창조한 게임. Steam에서 수백만 카피 판매. 2026년 속편이 Steam 역대 최대 로그라이크 덱빌더 기록.

#### The Selection Moment

**무엇을 선택하는가:**

1. **카드 선택 (전투 후)**: 3장의 카드 중 1장을 덱에 추가하거나, **아무것도 안 고른다(Skip)**. Skip이 가능하다는 것이 설계의 핵심 — 덱을 얇게 유지하는 것도 전략.
2. **카드 플레이 (전투 중)**: 매 턴 5장을 드로우, 에너지 제한(3) 내에서 플레이할 카드와 순서 결정. 이것은 "선택"이지 "액션"이 아니다 — 턴 기반이므로 시간 압박 없음.
3. **경로 선택**: 맵에서 다음 노드를 선택. 엘리트(위험+보상), 상점(자원 투자), 캠프파이어(회복/강화), 이벤트(랜덤).
4. **보스 유물**: 보스 처치 후 3개의 유물 중 1개 선택. 런 전체를 바꿀 수 있는 결정.

**선택지 수와 시간 압박:**

- 카드 보상: 3장 + Skip 옵션 = 4개 선택지. **Hick의 법칙 최적 범위.**
- 전투 중: 5장 × 에너지 3 = 실질적으로 2~4개의 의미 있는 플레이 조합
- **시간 압박: 없음.** 무한 숙고 가능. 하지만 "이 카드를 고르면 덱이 어떻게 변하지?"를 계산하는 것 자체가 mental challenge.

**선택에 무게를 부여하는 것:**

- **덱 오염(Deck Dilution)**: 카드를 마구 추가하면 덱이 뚱뚱해져서 핵심 콤보를 드로우할 확률이 낮아진다. "이 좋은 카드를 포기해야 하나?" — Skip의 고통.
- **시너지 의존성**: Ironclad의 Strength 빌드는 Heavy Blade가 핵심이지만, Heavy Blade 없이 Strength만 쌓으면 비효율적. "아직 Heavy Blade가 안 나왔는데 Limit Break를 지금 고를까?"
- **경로의 기회비용**: 엘리트를 가면 유물을 얻지만 HP를 잃는다. 캠프파이어를 가면 카드를 강화하지만 유물을 놓친다.

#### The Anticipation Loop

**선택과 선택 사이의 흥분:**

1. **카드 드로우**: 턴 시작 시 5장을 뒤집는 순간. "Catalyst가 나왔다! Noxious Fumes가 3턴째 독을 쌓았으니, 지금 쓰면 독이 3배!" — 드로우 순간의 도파민.
2. **유물 효과의 축적**: 유물은 영구 효과. Dead Branch(카드 버릴 때마다 랜덤 카드 생성) + Corruption(스킬 비용 0이 되지만 사용 후 버려짐) = 매 턴 덱이 완전히 바뀌는 카오스. 이 시너지를 발견하는 순간.
3. **경로 미리보기**: 맵에서 앞으로의 경로를 보며 "여기서 엘리트를 잡고, 상점에서 카드 제거하고, 캠프파이어에서 강화하면..." 미래를 계획하는 쾌감.
4. **보스전의 긴장**: "이 덱이 보스를 이길 수 있을까?" → 실제로 이기는 순간의 안도감.

#### VS 5대 엔진 분석

| 엔진                    |   존재 여부   | Slay the Spire에서의 형태                                                                                                          |
| ----------------------- | :-----------: | ---------------------------------------------------------------------------------------------------------------------------------- |
| E1: 압축된 성장 서사    |   **강함**    | Act 1(생존) → Act 2(빌드 완성) → Act 3(빌드 시험) → Heart(궁극 도전). 명확한 3막 구조                                              |
| E2: 통제된 무작위       | **매우 강함** | 카드 보상 랜덤 + 유물 랜덤이지만, 모두 플레이어가 선택. "이 카드 풀에서 내 빌드에 맞는 걸 골라야 해"                               |
| E3: 시스테믹 서프라이즈 |   **극강**    | 카드+유물 시너지가 장르의 심장. "Dead Branch + Corruption"을 처음 발견하는 순간은 게이머 인생의 아하 순간                          |
| E4: 감각적 포화         |   **약함**    | 턴제 특성상 시각적 카오스는 없음. 대신 **정보 포화** — "적의 의도 + 내 카드 + 유물 효과 + 포션"을 동시에 고려해야 하는 인지적 밀도 |
| E5: 축적되는 마스터리   |   **강함**    | 새 캐릭터 해금, Ascension 난이도 20단계. 지식이 곧 메타 진행 — "Silent의 Shiv 빌드는 이제 알겠고, Poison 빌드를 마스터해야지"      |

#### "One More Run" Hook

1. **"이번엔 Poison 빌드가 될 것 같아"**: 매 런마다 다른 빌드 방향 → 무한 변주
2. **Ascension 20**: 최고 난이도에서의 클리어가 게이머로서의 자존심이 됨
3. **4번째 캐릭터(Watcher)의 깊이**: 캐릭터마다 완전히 다른 게임 → 4배의 콘텐츠
4. **"아까 그 유물만 나왔으면..."**: 아쉬운 패배가 재시작 동기

### 3. Teamfight Tactics / Auto Chess (2019~) — 유닛 배치 + 아이템 선택

> 마작에서 영감받은 Drodo Studio가 Dota 2 모드로 시작. TFT는 Riot Games의 공식 오토배틀러. 5개월 만에 800만 플레이어.

#### The Selection Moment

**무엇을 선택하는가:**

1. **유닛 구매**: 매 라운드 5명의 랜덤 유닛 상점. 비용(1~5골드)과 시너지를 고려하여 구매. 리롤(2골드) 가능.
2. **유닛 배치**: 헥사곤 보드 위에 유닛을 어디에 놓을지. 근접 유닛은 앞줄, 원거리는 뒷줄이 기본이지만, 적의 어쌔신 포지션 등을 고려한 심화 배치.
3. **아이템 조합**: 컴포넌트 2개를 합쳐 완성 아이템 제작. 어떤 유닛에 장착할지.
4. **증강(Augment) 선택**: 3개 중 1개의 증강 선택. 런 전체의 전략을 결정짓는 중대한 분기점.
5. **경제 관리**: 레벨업에 골드를 쓸지, 리롤에 쓸지, 이자를 위해 50골드 유지할지.

**선택지 수와 시간 압박:**

- 유닛 상점: 5개 + 리롤 옵션 = 사실상 무한.
- 증강: 3개 중 1개. VS의 레벨업과 동일한 구조.
- **시간 압박: 있음.** 라운드 사이 준비 시간이 ~30초. 이 시간 내에 구매, 배치, 아이템 조합을 모두 해야 한다. 이것이 "선택"에 긴박감을 더한다.

#### The Anticipation Loop

**선택과 선택 사이의 흥분:**

1. **전투 관전**: 유닛을 배치하고 나면 전투는 완전 자동. 플레이어는 "내 배치가 맞았을까?"를 확인하며 관전한다. 핵심 유닛이 궁극기를 쓰는 순간, 팀 싸움의 흐름이 뒤집히는 순간 — 이 모든 것이 플레이어가 만든 "선택의 결과"다.
2. **3성 업그레이드**: 같은 유닛 3개를 모으면 2성, 2성 3개로 3성. 마지막 1개를 찾는 순간의 흥분. "제발 이번 리롤에서 나와라..."
3. **시너지 완성**: "요들 4개를 모으면 전체 회피율 50%..." 마지막 유닛을 넣는 순간 시너지 아이콘이 빛나며 팀 전체가 강해진다.
4. **캐러셀(회전목마)**: 꼴찌 플레이어부터 유닛+아이템을 고를 수 있는 공동 풀. 원하는 아이템이 달린 유닛이 눈앞에서 다른 플레이어에게 잡혀가는 긴장감.

**핵심 공식**: `선택(구매/배치) → 관전(자동 전투) → 피드백(승패/HP 변동) → 적응(다음 라운드 준비)`

이 루프에서 "관전" 페이즈가 핵심이다. 자동 전투를 보면서 "아, 배치를 이렇게 했어야 했는데" 또는 "내 빌드가 완벽하게 작동했다!"를 확인하는 것이 기대감을 만든다.

#### VS 5대 엔진 분석

### 4. Luck be a Landlord (2021) — 슬롯머신 심볼 선택

> 슬롯머신 + 로그라이크 덱빌더. 인디 게임이지만 장르 하이브리드의 정수를 보여준다.

#### The Selection Moment

**무엇을 선택하는가:**

1. **심볼 추가**: 매 스핀 후 3개의 심볼 중 1개를 슬롯에 추가. "고양이를 추가하면 우유와 시너지가 될 텐데... 하지만 벌을 추가하면 꽃과 시너지가..."
2. **아이템 선택**: 특정 라운드에서 아이템 선택. 아이템은 기존 심볼의 효과를 변형하거나 강화.
3. **심볼 제거 (간접)**: 일부 심볼이 다른 심볼을 "파괴"하는 효과 → 원치 않는 심볼을 제거하는 간접적 덱 관리.

**선택지 수와 시간 압박:**

- 3개 중 1개. 언제나 3개. Hick의 법칙 최적.
- **시간 압박: 없음.** 턴 기반. 무한 숙고 가능.

**선택에 무게를 부여하는 것:**

- **슬롯 오염**: 심볼은 추가만 가능, 직접 제거 불가(특수 효과 제외). 잘못된 심볼이 들어가면 평균 수익이 떨어진다.
- **임대료 스케일링**: 매 층(Floor)마다 임대료가 급증. "이 정도 시너지로 다음 임대료를 감당할 수 있을까?"
- **인접 효과**: 심볼의 효과가 슬롯 내 인접한 심볼에 따라 달라진다. 위치를 제어할 수 없으므로 "확률적 시너지"를 계산해야 한다.

#### The Anticipation Loop

**이 게임의 핵심은 "스핀 관전"이다:**

1. **릴 회전 → 정지**: 슬롯머신의 릴이 돌아가고 멈추는 순간. 각 심볼이 어디에 착지했는지 확인하는 순간이 순수한 도파민 스파이크.
2. **인접 효과 발동 체인**: 고양이가 우유 옆에 → 우유 소비 → 코인 생성 → 그 코인이 도둑 옆에 → 도둑이 코인 복사 → ... 이 연쇄가 화면에 순차적으로 표시되며, 예상치 못한 체인이 터질 때의 쾌감.
3. **"한 칸만 옆이었으면..."**: 시너지 심볼이 인접하지 못해서 효과가 발동하지 않는 아차 순간. Near-Miss 심리 → "다음 스핀에서는..."
4. **임대료 결산**: 모든 스핀이 끝나고 수입 총합 vs 임대료. "딱 맞네..." 또는 "넘겼다!" — 이 순간의 안도감/쾌감.

**핵심 공식**: `심볼 선택 → 스핀(통제 불가) → 결과 관전 → 인접 효과 체인 관전 → 임대료 결산`

이 게임은 **"선택의 결과를 즉시 볼 수 없는" 지연(delay)**이 기대감의 핵심이다. 선택(심볼 추가) 후 여러 번의 스핀을 거쳐야 그 선택의 효과를 체감한다.

### 5. Dicey Dungeons (2019) — 주사위 할당

> Terry Cavanagh(VVVVVV, Super Hexagon 개발자)의 로그라이크. 주사위를 장비 슬롯에 할당하는 독특한 메카닉.

#### The Selection Moment

**무엇을 선택하는가:**

1. **주사위 할당**: 턴 시작 시 주사위를 굴리고, 결과 눈금을 장비 슬롯에 배치. Sword(5 이하) → 그 수만큼 데미지. Shield(4 이하) → 그 수만큼 방어. 어떤 주사위를 어디에 넣을지가 핵심 결정.
2. **장비 선택**: 전투 후 새 장비 획득. 장비 슬롯이 제한되므로 교체 여부 결정.
3. **주사위 조작**: 일부 장비는 주사위를 분할, 합산, 리롤 가능. "6을 3+3으로 쪼갠다 vs 그대로 사용" — 조작 도구의 활용이 전략 깊이.

**선택지 수와 시간 압박:**

- 주사위 할당: 주사위 수(보통 2~4개) × 장비 수(4~6개) = 수십 가지 조합. 하지만 실질적으로 유효한 선택은 3~5개.
- **시간 압박: 없음.** 턴 기반.

**선택에 무게를 부여하는 것:**

- **주사위 결과의 비가역성**: 굴린 주사위 결과를 바꿀 수 없다(특수 장비 제외). "3이 나왔는데 5가 필요했는데..." → 차선의 결정.
- **장비 간 의존성**: Boomerang(짝수만)은 높은 짝수가 필요하고, Dagger(홀수만)는 홀수가 필요. 주사위 결과에 따라 장비 활용 전략이 달라진다.
- **적의 능력과의 상호작용**: 적이 주사위를 잠그거나, 특정 수를 방어하거나 → 할당 결정이 적 능력 대응까지 포함.

#### The Anticipation Loop

1. **주사위 굴리기**: 턴 시작의 주사위 굴리기가 **미니 슬롯머신**. "6이 나와라... 6이 나와라..." → 물리적 기대감.
2. **장비 활성화 연출**: 주사위를 장비에 넣으면 효과가 발동. Fireball로 적 전체 공격, Shield로 방어막 생성 — 각 할당이 시각적/청각적 피드백으로 확인됨.
3. **적 턴 관전**: 내 턴이 끝나면 적의 주사위 굴리기와 행동을 관전. "적이 큰 공격을 준비하는데 내 방어가 충분할까?"
4. **Limit Break(리밋 브레이크)**: 특정 클래스(Warrior)는 턴 끝에 사용하지 않은 주사위로 추가 행동. "이 남은 2를 어디에 쓰지?"

**핵심 공식**: `주사위 굴리기(무작위) → 할당 결정(통제) → 효과 확인(피드백) → 적 반응 관전(긴장)`

### 6. Vampire Survivors (2022) — 실은 90%가 선택인 게임

> "액션 게임"으로 분류되지만, 실제 의미 있는 인터랙션의 90%는 레벨업 선택이다.

#### The Selection Moment

**무엇을 선택하는가:**

1. **레벨업 선택**: 3~4개의 무기/패시브 중 1개. 15~30초마다 발생. 이것이 게임의 실질적 코어 루프.
2. **보물 상자 (간접)**: 보스 드롭 상자는 보유 무기를 랜덤 강화. 선택은 없지만 "어떤 무기가 강화될까"의 기대감.
3. **진화 조건 관리 (메타 선택)**: "King Bible을 진화시키려면 Spellbinder가 필요해. 다음 레벨업에서 Spellbinder가 나오면 무조건 골라야 해" — 미래의 선택을 위해 현재 선택을 조율.

**선택지 수와 시간 압박:**

- 3~4개 중 1개. **항상.** Hick의 법칙 최적.
- **시간 압박: 사실상 없음.** 레벨업 화면에서 게임이 멈추므로, 무한 숙고 가능. 이것이 VS의 천재적 설계 — "액션 게임에서 시간을 멈추고 선택하게 한다."
- **Banish 메카닉**: 원하지 않는 선택지를 영구 제거(최대 10회). 이것이 "3~4개 중 1개"를 더 의미 있게 만든다 — "이 무기를 밴하면 나중에 원하는 무기가 나올 확률이 올라간다."

**왜 VS의 선택이 특별한가:**

- **실시간 맥락**: 선택 직전까지 플레이어는 적에게 쫓기고 있었다. 아드레날린이 흐르는 상태에서 레벨업 화면이 등장 → "살았다!" + "뭘 고르지?" = 안도감과 기대감의 동시 경험.
- **즉각적 피드백**: 선택 후 게임이 재개되면 즉시 새 무기/강화 효과를 볼 수 있다. "Holy Water를 골랐더니 내 주변에 푸른 원이 생겼다!" — 선택의 결과가 물리적으로 보인다.
- **복리 효과**: 초반 선택이 후반 폭발에 영향. "2분째에 고른 Garlic이 20분째에 진화하여 Soul Eater가 되어 화면을 뒤덮는다" — 초반 선택의 장기적 보상.

#### The Anticipation Loop

**VS에서 선택과 선택 사이:**

1. **적 물량의 증가**: 선택 후 게임이 재개되면, 강해진 무기로 적을 쓸어내는 쾌감. 그리고 적이 다시 밀려오며 긴장이 쌓인다.
2. **XP 젬 흡수**: 적을 처치하면 XP 젬이 바닥에 흩어지고, 근처를 지나가면 "쉬이잉" 하며 빨려온다. 이 물리적 흡수가 연속적 소규모 보상.
3. **"다음 레벨업에서 뭐가 나올까?"**: 항상 머릿속에 있는 질문. 경험치 바가 차오르는 것을 보며 기대감이 축적된다.
4. **진화 달성**: 무기+패시브 조합이 완성되면 진화 무기가 등장. 이 순간의 "유레카!" — 화면이 더 화려해지고, 파워가 체감적으로 급상승.
5. **보스 등장**: 10분마다 보스가 등장하고, 보스를 처치하면 보물 상자 드롭 → "뭐가 강화될까?"

**핵심 공식**: `레벨업 선택 → 즉각적 파워 확인 → 적과의 전투(관전에 가까움) → XP 수집 → 다음 레벨업 기대`

## 크로스-게임 패턴 분석

### 패턴 1: 선택이 의미 있게 "느껴지는" 조건

"명백한 최선(Obvious Best)"을 고르는 것은 선택이 아니다. 진정한 선택의 즐거움은 **트레이드오프(Trade-off)**에서 온다. 분석 대상 6개 게임 모두에서 공통적으로 사용되는 트레이드오프 기법:

| 기법                | 설명                                                                               | 사용 게임                                     |
| ------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------- |
| **시너지 불확실성** | "이 선택이 내 빌드와 시너지가 될까 안 될까?" — 정답이 불확실할 때 선택은 의미 있다 | 전체 6개                                      |
| **자원 경쟁**       | 골드, 슬롯, 에너지 등 유한 자원을 두고 경쟁하는 선택지                             | Balatro(슬롯 5), StS(에너지 3), TFT(골드)     |
| **단기 vs 장기**    | 지금 당장 강한 것 vs 나중에 더 강해질 것                                           | VS(진화 재료), Balatro(페어 vs 풀하우스 빌드) |
| **리스크 vs 보상**  | 높은 보상이지만 실패 확률이 있는 것 vs 안전한 것                                   | StS(엘리트 경로), TFT(올인 리롤 vs 경제 안정) |
| **덱/풀 오염**      | 추가하면 전체 품질이 떨어질 수 있는 딜레마                                         | StS(Skip), LBAL(잘못된 심볼), VS(Banish)      |

**핵심 인사이트: "선택의 즐거움 = 확실한 최선이 없을 때 내 판단을 믿는 행위"**

모든 게임에서 실제로는 "어느 정도 괜찮은 선택"이 여러 개 있다. 완전한 오답이 적다. 하지만 플레이어는 "내가 최선을 골랐다"고 느낀다. 이 **자기 효능감(Self-Efficacy)**이 중독의 핵심이다.

### 패턴 2: 기대감(Anticipation)의 제조 기법

선택과 결과 사이의 **지연(Delay)**이 기대감을 만든다. 6개 게임의 기대감 제조 기법:

#### 기법 A: 시각적 지연 연출

| 게임    | 기법                                          | 효과                                                               |
| ------- | --------------------------------------------- | ------------------------------------------------------------------ |
| Balatro | 카드가 하나씩 뒤집히며 점수가 순차 누적       | 각 카드가 뒤집힐 때마다 "다음 카드는 몇 점이지?" → 미니 클리프행어 |
| LBAL    | 릴이 회전하고 멈추며 심볼이 하나씩 드러남     | 슬롯머신의 원초적 기대감                                           |
| TFT     | 유닛이 전장에서 실시간 전투, 궁극기 발동 순간 | "내 유닛이 궁을 쓸까 말까" → 극적 순간                             |
| Dicey   | 주사위가 굴러가다 멈추는 물리 애니메이션      | 주사위 결과가 나오기 전 0.5~1초의 순수한 기대                      |

#### 기법 B: 정보 은폐와 점진적 공개

| 게임    | 기법                                            | 효과                                              |
| ------- | ----------------------------------------------- | ------------------------------------------------- |
| Balatro | 조커 효과의 "???" 표시                          | "이 조커가 뭘 하는 거지?" → 궁금증 → 구매 후 발견 |
| StS     | 보스 유물 3개가 한꺼번에 공개됨 (직전까지 미지) | "무슨 유물이 나올까?" → 공개 순간의 환희/실망     |
| VS      | 진화 레시피 미공개 (초기)                       | "이 무기가 진화하면 어떻게 변하지?" → 실험 동기   |
| TFT     | 증강 선택지가 라운드 시작 시 공개               | "이번 증강은 뭐가 나올까?" → 팝업 순간의 도파민   |

#### 기법 C: 연쇄 반응 (Chain Reaction)

| 게임    | 기법                                                         | 효과                                                    |
| ------- | ------------------------------------------------------------ | ------------------------------------------------------- |
| Balatro | 조커 효과가 순차 적용되며 배율이 연쇄적으로 증폭             | "×2 → ×4 → ×16 → ×256!" — 기하급수적 증가의 시각적 표현 |
| LBAL    | 심볼 인접 효과가 순차적으로 발동                             | "고양이→우유→치즈→쥐→..." — 예상 못한 체인              |
| VS      | 무기 이펙트가 동시 다발적으로 화면에 표시                    | 4~6개 무기의 동시 공격이 만드는 시각적 연쇄             |
| StS     | 카드 효과 연쇄 (Shiv 생성 → Shiv 플레이 → After Image → ...) | 의도한 콤보가 작동하는 순간의 쾌감                      |

**핵심 인사이트: "기대감 = 결과가 나오기까지의 지연 × 결과의 불확실성 × 결과의 시각적 연출"**

세 요소 중 하나라도 0이면 기대감이 사라진다:

- 지연 없이 즉시 결과 → 서프라이즈 없음
- 결과가 확실 → 기대할 것이 없음
- 시각적 연출 없음 → 결과를 "느끼지" 못함

### 패턴 3: "Kitchen Sink" 문제 — 선택지 과부하 방지

선택 기반 게임의 최대 적은 **결정 피로(Decision Fatigue)**다. 선택지가 너무 많으면 즐거움이 아니라 스트레스가 된다. 6개 게임이 이를 해결하는 방법:

#### 방법 1: 물리적 선택지 제한

| 게임    | 제한                                       | 효과                                          |
| ------- | ------------------------------------------ | --------------------------------------------- |
| VS      | 3~4개 중 1개                               | 1~3초 내 결정 가능. 플로우 유지               |
| StS     | 3장 + Skip                                 | 덱빌딩 지식이 있으면 즉시 판단 가능           |
| LBAL    | 3개 중 1개                                 | 항상 동일한 구조                              |
| TFT     | 증강 3개 중 1개                            | 구매는 5개 유닛이지만, 실질 고려 대상은 1~2개 |
| Dicey   | 주사위 수 × 장비 수 (실질 3~5개 유효 조합) | 수학적으로는 많지만 직관적으로 수렴           |
| Balatro | 조커 슬롯 5개, 핸드 5장                    | 물리적 슬롯 제한이 "최적화 퍼즐"을 만듦       |

#### 방법 2: 점진적 복잡도 도입

| 게임    | 기법                                                                       |
| ------- | -------------------------------------------------------------------------- |
| VS      | 첫 레벨업은 무기 2~3개만. 30개 이상의 무기/패시브는 게임 후반에야 등장     |
| StS     | Act 1은 단순 공격/방어. Act 2부터 시너지 카드 등장. Act 3에서 콤보 완성    |
| TFT     | 스테이지 1은 저비용 유닛만. 스테이지 4~5에서야 5코스트 전설 유닛 등장      |
| Balatro | 첫 Ante는 기본 핸드로 충분. Ante 5부터 조커 시너지가 필수                  |
| Dicey   | Warrior(기본) → Thief(분할) → Robot(계산) → Witch(변환) 순으로 복잡도 증가 |

#### 방법 3: "선택하지 않는 것"에도 가치 부여

| 게임 | 기법                                                                                                      |
| ---- | --------------------------------------------------------------------------------------------------------- |
| StS  | Skip(카드 안 고르기)이 종종 최선의 선택 → "안 고르는 것도 전략"                                           |
| VS   | Banish(선택지 영구 제거)가 10회로 제한 → "뭘 밴할지"가 메타 결정                                          |
| TFT  | 리롤하지 않고 골드를 저축 → 이자 수입으로 후반 폭발                                                       |
| LBAL | 때때로 3개 모두 안 좋을 때 "가장 덜 나쁜 것" 고르기 → 역설적으로 이것이 가장 어려운(= 가장 재미있는) 선택 |

**핵심 인사이트: "3개 중 1개 선택"이 황금 비율이다.**

- 2개: 이진 선택. "선택"보다 "강제"에 가깝게 느껴진다.
- 3개: 비교와 판단의 최소 단위. 0.5~2초 내 결정 가능. 자율감 확보.
- 5개 이상: 결정 피로 시작. 최적화 압박이 즐거움을 압도.
- 예외: TFT의 상점(5개)은 비용 필터링으로 실질 선택을 2~3개로 줄인다.

### 패턴 4: "One More Run"의 보편적 구조

6개 게임 모두에서 "한 판만 더"를 만드는 심리적 트리거가 공유된다:

```
┌─ 미완의 과제 (Zeigarnik Effect)
│   "아까 그 빌드가 완성될 뻔했는데..."
│
├─ 미시도 조합의 호기심 (Information Gap)
│   "이 조커/카드/심볼은 아직 안 써봤는데..."
│
├─ 아차 순간의 기억 (Near-Miss)
│   "1코인/1HP/1점만 더 있었으면..."
│
├─ 다음 목표의 근접성 (Goal Gradient)
│   "한 판만 더 하면 새 캐릭터/난이도 해금인데..."
│
└─ 자기 효능감 (Self-Efficacy)
    "이번에 진 건 운이 나빠서야. 내 전략은 맞았어."
```

이 5가지가 동시에 작동할 때 "한 판만 더" 충동이 가장 강해진다.

### 패턴 5: "선택 = 정체성" — 왜 Selection-Only 게임이 스트리머 친화적인가

6개 게임 모두 **스트리머/유튜버에게 인기**가 높다. 그 이유:

1. **관전자도 선택에 참여할 수 있다**: 채팅에서 "왼쪽 골라!", "조커 2번!" → 관전이 인터랙티브해짐
2. **선택 과정이 곧 콘텐츠**: 액션 게임은 "기술"을 보여주지만, 선택 게임은 "사고 과정"을 보여준다. 후자가 교육적이고 토론 가능.
3. **드라마 구조**: 선택 → 기대 → 결과 = 미니 스토리. 매 선택이 "이야기의 분기점"처럼 기능한다.
4. **실패도 재미있다**: 잘못된 선택의 결과가 황당하고 웃긴 상황을 만든다. "이 조커를 골랐더니 점수가 마이너스가 됐다?!"

## Selection-Only 게임의 설계 원칙 종합

### 원칙 1: 선택의 3요소

```
의미 있는 선택 = 트레이드오프 + 불가역성 + 맥락 의존성
```

- **트레이드오프**: 모든 선택에는 포기하는 것이 있어야 한다
- **불가역성**: 선택을 되돌릴 수 없어야 무게가 있다
- **맥락 의존성**: 같은 선택지라도 현재 빌드에 따라 가치가 달라져야 한다

### 원칙 2: 기대감의 3요소

```
기대감 = 지연(Delay) × 불확실성(Uncertainty) × 연출(Presentation)
```

- **지연**: 선택과 결과 사이에 0.5~3초의 간격
- **불확실성**: 결과가 100% 예측 가능하면 기대감 없음
- **연출**: 시각적/청각적 피드백이 결과를 "느끼게" 만듦

### 원칙 3: 복잡도 관리의 3요소

```
최적 복잡도 = 제한된 선택지(2~4개) + 점진적 도입 + 직관적 표현
```

- **제한된 선택지**: Hick의 법칙. 3개가 황금 비율.
- **점진적 도입**: 처음엔 단순, 게임이 진행될수록 깊어짐
- **직관적 표현**: 텍스트보다 아이콘/색상으로 효과를 즉시 전달

### 원칙 4: 랜덤의 2층 구조

```
통제된 무작위 = 무작위 선택지 제공(시스템) + 선택권(플레이어)
```

- 시스템이 "뭘 고를 수 있는지"를 무작위로 결정
- 플레이어가 "뭘 고를지"를 통제
- 이 이중 구조가 "운과 실력 모두 영향을 미친다"는 인식을 만든다

### 원칙 5: 숫자의 쾌감

```
성장의 시각화 = 작은 숫자에서 시작 → 기하급수적 증가 → 숫자가 화면을 뒤덮음
```

- Balatro: 50점 → 500,000점 → 5.3e+15점
- VS: DPS 5 → DPS 500 → DPS 50,000
- LBAL: 1코인 → 10코인 → 100코인 → 1,000코인
- 숫자의 기하급수적 증가 자체가 "성장 서사"의 시각적 표현

## ShamShuiPo 프로젝트를 위한 시사점

### Selection-Only의 본질과 ShamShuiPo의 접점

ShamShuiPo는 불릿헤븐(이동 + 자동 공격)이지만, 이 분석에서 밝혀진 핵심 인사이트는 **VS조차 90%가 선택 게임**이라는 것이다. 이것은 ShamShuiPo의 "선택" 메카닉을 더 강화할 여지가 있음을 시사한다.

### 적용 가능한 기법

1. **레벨업 선택의 기대감 연출 강화**: 현재 VS 표준(3개 중 1개 팝업)에 Balatro식 "순차 공개 애니메이션"을 결합. 선택지가 하나씩 뒤집히며 공개 → 마지막 선택지에서 "!"이 나오는 연출.

2. **조합 발견의 깊이**: Balatro/StS 수준의 시너지 공간을 만들려면, 무기+패시브 외에 **"조커" 같은 제3의 메카닉 레이어**가 필요. 마작의 역(役) 시스템이나 네온 간판 조합이 이 역할을 할 수 있다.

3. **"선택하지 않는 것"의 전략적 가치**: VS의 Banish를 확장하여, "이번 레벨업을 스킵하고 다음 레벨업에서 4개 대신 6개 선택지를 받는" 같은 메타 선택 도입 가능.

4. **점수/코인 연쇄 연출**: Balatro의 점수 계산 애니메이션, LBAL의 심볼 연쇄 효과처럼, 선택의 결과가 **순차적으로, 연쇄적으로** 화면에 표시되게.

5. **"One More Run"의 5중 트리거**: 미완의 과제 + 미시도 조합 + 아차 순간 + 다음 목표 근접 + 자기 효능감 — 이 5가지를 모두 런 종료 화면에 배치.
