# UI/UX 가이드라인 — ShamShuiPo (Neon Survivors)

> 모바일 불릿 헤븐 액션 로그라이크 UI/UX 가이드 (720x1280 포트레이트, 한 손 조이스틱)

---

## 1. 디자인 랭귀지: Dark Cyberpunk Glassmorphism

### 1.1 핵심 원칙

- **반투명 패널**: 배경이 비치는 글래스 효과로 깊이감 연출
- **불투명도 범위**: 0.15 ~ 0.40 (용도별 차등)
- **테두리**: 1px, alpha 0.3, `#4a6fa5`
- **코너 라디우스**: 12px 표준 (컴포넌트 크기에 따라 8~24px)
- **배경 블러**: 네이티브 미지원 시 어두운 반투명으로 대체
- **네온 악센트**: 사이버펑크 느낌의 네온 컬러 포인트 (핑크, 시안, 퍼플)

### 1.2 패널 불투명도 가이드

| 용도                 | Alpha | 라디우스 |
| -------------------- | ----- | -------- |
| 배경 오버레이 (모달) | 0.40  | 24px     |
| HUD 패널             | 0.25  | 12px     |
| 카드/셀              | 0.20  | 12px     |
| 힌트/툴팁            | 0.15  | 8px      |

### 2.1 폰트 스케일

| 용도           | 크기  | 굵기           | 비고                        |
| -------------- | ----- | -------------- | --------------------------- |
| 타이틀 (Title) | 48px  | Bold (700)     | 화면 타이틀                 |
| 헤딩 (Heading) | 32px  | Bold (700)     | 섹션 헤딩, 카드 타이틀      |
| 서브헤딩       | 22px  | SemiBold (600) | 부제목, 항목명, 버튼 라벨   |
| 본문 (Body)    | 16px  | Regular (400)  | 일반 텍스트, 정보 라벨      |
| 캡션 (Caption) | 14px  | Regular (400)  | 각주, 버전, 최소 허용 크기  |
| 스코어 (Score) | 32px+ | Bold (700)     | 점수/타이머 표시, monospace |

### 2.2 폰트 규칙

- 스코어/숫자: **monospace** 폰트 사용 (자릿수 변경 시 레이아웃 안정)
- 한글 지원: 시스템 폰트 폴백 (`sans-serif`)
- 텍스트 컬러: `#ecf0f1` (기본), `#bdc3c7` (보조), `#e94560` (강조)
- 그림자: `2px 2px 4px rgba(0,0,0,0.5)` -- 배경 위 가독성 확보
- **최소 폰트 크기: 16px** -- 14px는 캡션 전용, 14px 미만 절대 금지

## 6. 패널 컴포넌트 스펙

### 6.1 표준 글래스 패널

```typescript
function drawGlassPanel(
  graphics: Phaser.GameObjects.Graphics,
  x: number,
  y: number,
  w: number,
  h: number,
  alpha: number = 0.25,
  radius: number = 12,
): void {
  graphics.fillStyle(0x1a1a2e, alpha);
  graphics.fillRoundedRect(x, y, w, h, radius);
  graphics.lineStyle(1, 0x4a6fa5, 0.3);
  graphics.strokeRoundedRect(x, y, w, h, radius);
}
```

### 6.2 패널 변형

| 변형              | Alpha | Border  | 용도                           |
| ----------------- | ----- | ------- | ------------------------------ |
| 기본형 (Standard) | 0.25  | 1px 0.3 | HUD, 일반 패널                 |
| 모달 (Modal)      | 0.40  | 1px 0.5 | 레벨업 선택, 일시정지 오버레이 |
| 카드 (Card)       | 0.20  | 1px 0.2 | 무기/패시브 선택 카드          |
| 미니멀 (Minimal)  | 0.15  | none    | 툴팁, 데미지 넘버              |

### 10.3 적응형 레이아웃 규칙

- 모든 좌표는 **기준 해상도 기반 비율**로 계산
- 노치/펀치홀 영역: 상단 16px, 하단 16px safe area
- 태블릿: 좌우 패딩 자동 증가 (최대 영역 유지)
- 가로 모드: 미지원 (세로 고정)

## 11. 스크롤 가능 리스트 / 콘텐츠 오버플로 규칙

### 11.1 뷰포트 바운드 원칙

- **기준 높이**: GAME_HEIGHT = 1280px. 모든 콘텐츠는 이 범위 내에 표시되어야 함
- **동적 리스트**: 아이템 수가 가변적인 리스트는 반드시 총 높이를 사전 계산
  - `totalHeight = startY + ceil(itemCount / cols) * (cardH + gap) + footerH`
  - `totalHeight > GAME_HEIGHT`이면 **DragScroll 필수 적용**
- **현재 수가 맞더라도** 향후 아이템 추가 가능성이 있으면 스크롤 선제 적용 권장

### 11.2 고정 네비게이션 버튼

- Back, Close, Home 등 **네비게이션 버튼은 스크롤 컨테이너 외부에 고정 배치**
- 권장 위치: 화면 하단 safe area (y = GAME_HEIGHT - 80 ~ GAME_HEIGHT - 40)
- 네비게이션 버튼이 콘텐츠와 함께 스크롤되면 안 됨 (화면 밖으로 밀려남)
- 고정 영역 높이: 최소 80px (버튼 52px + 상하 패딩 14px)

### 11.3 스크롤 영역 설계

| 속성             | 값                                                |
| ---------------- | ------------------------------------------------- |
| 스크롤 가능 영역 | startY ~ (GAME_HEIGHT - fixedFooterH)             |
| 고정 헤더 영역   | 0 ~ startY (타이틀, 카운터 등)                    |
| 고정 푸터 영역   | (GAME_HEIGHT - 80) ~ GAME_HEIGHT (Back 버튼)      |
| 최대 가시 아이템 | `floor((scrollAreaH) / (cardH + gap))` 행         |
| DragScroll 유틸  | `src/utils/DragScroll.ts` -- `enableDragScroll()` |

## 12. 접근성

- 색상만으로 정보 구분하지 않음 (아이콘/심벌 병행)
- 터치 타겟 최소 48dp 준수
- 텍스트 대비 비율 4.5:1 이상
- 애니메이션 축소 옵션 (prefers-reduced-motion 존중)
- 적 유형은 형태(shape)로도 구분 가능하게 설계
