# SSBL (SUPERSTAR THEBLACKLABEL)

K-pop 리듬 게임 프로젝트 — 기획/아트/수익화/런칭 통합 관리 에이전트

## 개요

SUPERSTAR THEBLACKLABEL은 THEBLACKLABEL 소속 아티스트(TAEYANG, JEON SOMI, MEOVV, ADP)를 기반으로 한 K-pop 리듬 게임입니다.

## 소속
