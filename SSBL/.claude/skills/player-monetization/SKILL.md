# /player-monetization — 플레이 기록 ↔ 과금 유저 상관관계 분석

## 목적

플레이 기록 데이터에서 과금 유저 특성을 도출하고, 수익화 전략에 활용할 수 있는 인사이트를 생성합니다.

## 입력

사용자가 다음 중 하나 이상을 제공합니다:

- **데이터 파일**: CSV/JSON 형식의 플레이 기록 또는 과금 데이터 (`SSBL/data/` 내)
- **분석 요청**: 특정 분석 프레임워크 지정 (세그먼트 분석, 전환 포인트, LTV 등)
- **가설**: 검증하고 싶은 가설 (예: "D3 리텐션 70% 이상 유저의 첫 결제 확률이 높다")

데이터가 없을 경우 **프레임워크 설계 모드**로 전환하여 분석 계획서를 산출합니다.

## 분석 프레임워크

### 1. 유저 세그먼트 분류

| 세그먼트            | 정의             | 핵심 지표                   |
| ------------------- | ---------------- | --------------------------- |
| Whale (고래)        | 월 $100+ 과금    | ARPPU, 세션당 과금액        |
| Dolphin (돌고래)    | 월 $10~99 과금   | 과금 빈도, 구매 아이템 패턴 |
| Minnow (작은물고기) | 월 $10 미만 과금 | 첫 결제 시점, 패키지 선호   |
| Free (무과금)       | 과금 이력 없음   | 리텐션, 광고 시청률         |

### 2. 플레이 패턴 클러스터링

분석 차원:

- **세션 길이**: 평균/중앙값/P95
- **세션 빈도**: 일/주간 접속 횟수
- **진행도**: 클리어 스테이지, 수집 카드 수
- **소셜**: 랭킹 참여, 길드 가입, 친구 수
- **콘텐츠 소비**: 이벤트 참여율, 신규 곡 플레이 비율

### 3. 전환 포인트 식별

무과금 → 첫 결제 트리거 탐색:

- **시점**: D1/D3/D7/D14/D30 기준 첫 결제 분포
- **콘텐츠**: 첫 결제 직전 플레이한 콘텐츠
- **난관**: 진행 블로커 (에너지 부족, 고난도 곡 실패)
- **유인**: 특가 패키지 노출 시점, 이벤트 기간
- **소셜 압력**: 랭킹 근접, 친구 비교

### 4. LTV 예측 인자

조기 행동 지표(D1~D7)로 장기 가치 예측:

- D1 세션 수 / 플레이 곡 수
- D3 리텐션 여부
- D7 누적 플레이 시간
- 첫 주 이벤트 참여 횟수
- 친구 추가 / 길드 가입 여부

### 5. 이탈 위험 지표

과금 유저 리텐션 보호:

- **하락 신호**: 세션 빈도 감소, 이벤트 미참여, 과금 주기 변화
- **세그먼트별 이탈률**: 고래 vs 돌고래 vs 작은물고기
- **재참여 패턴**: 이탈 후 복귀 유저의 행동 특성

## 산출물

### 데이터 있을 때

```
SSBL/outputs/monetization_analysis_YYYYMMDD.html
```

- 인터랙티브 HTML 보고서
- 세그먼트별 행동 차트
- 전환 퍼널 시각화
- 핵심 인사이트 & 액션 아이템

### 데이터 없을 때 (프레임워크 모드)

```
SSBL/outputs/monetization_framework_YYYYMMDD.md
```

- 데이터 수집 요구사항
- 분석 파이프라인 설계
- KPI 정의서
- 대시보드 와이어프레임

## 실행 절차

1. `SSBL/data/` 내 데이터 파일 확인
2. 데이터 존재 시 → 탐색적 분석 (EDA) 수행
3. 세그먼트 분류 → 패턴 클러스터링 → 전환 포인트 → LTV 인자 도출
4. HTML 보고서 생성 (`outputs/`)
5. 데이터 미존재 시 → 프레임워크 설계 모드 실행
6. 핵심 인사이트 3~5개 + 즉시 실행 가능한 액션 2~3개 제시
