# 품질 기준

HKD852 전체 에이전트 산출물에 적용되는 품질 관리 체계입니다.

## CFMC 매트릭스

모든 산출물은 4가지 기준으로 평가됩니다 (각 25점, 총 100점):

| 기준 | 영문 | 평가 내용 |
|------|------|-----------|
| 완성도 | Completeness | 요구사항 충족 여부, 누락 항목 없는지 |
| 충실도 | Fidelity | 원본 의도/스펙과의 일치 정도 |
| 유지보수성 | Maintainability | 코드 구조, 문서화, 확장 용이성 |
| 준수성 | Compliance | 보안 규칙, 코딩 컨벤션, 정책 준수 |

### 등급 기준

| 등급 | 점수 | 조치 |
|------|------|------|
| A | 90-100 | 자동 승인 |
| B | 80-89 | 자동 승인 (경미한 피드백) |
| C | 70-79 | 수정 후 재평가 |
| D | 60-69 | 대폭 수정 필요 |
| F | 60 미만 | CEO 에스컬레이션 |

**통과 기준: 80점 이상 (B 등급)**

## 품질 파이프라인

```
에이전트 산출물
  → Quality Gate (CFMC 평가)
    → 80+ : Shield Agent (보안 검토)
      → 통과 : RedTeam Agent (적대적 리뷰)
        → APPROVE : 최종 승인
        → REJECT : 재작업
    → 80 미만 : 재작업 반환
```

## CEO 에스컬레이션 조건

다음 상황은 자동 처리하지 않고 CEO에게 즉시 보고합니다:

- **Shield Agent**: `SECURITY_HOLD` 판정
- **Quality Gate**: `F` 등급 (60점 미만)
- **RedTeam Agent**: `REJECT` 판정
- **프로덕션 배포**: 모든 실서비스 배포
- **게임 컨셉**: 핵심 디자인 변경 승인

## 자동 처리 범위

- Quality Gate A/B 등급 산출물
- 일반 코드 리뷰
- 스토어 메타데이터 업데이트
- 문서 수정 및 오타 교정
