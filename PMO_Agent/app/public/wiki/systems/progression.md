## XP 및 레벨업

> 관련 파일: `src/core/XpTable.ts`, `src/managers/ProgressionManager.ts`

### XP 획득

- 일반 적 처치: 기본 XP (적 정의에 따름)
- 엘리트 적 처치: ×5 XP
- 메타 XP 부스터: 최대 +60% XP 획득

### 레벨업 필요 XP

```
requiredXP[level] = ceil(basePerLevel × growthFactor^(level-1))
basePerLevel = 10, growthFactor = 1.25
```

예시: 레벨 1→2: 10XP, 레벨 5→6: ~25XP

## 레벨업 업그레이드 선택

> 관련 파일: `src/core/UpgradeSelector.ts`

레벨업 시 **3개 선택지**가 제시됩니다. 5초 후 자동 선택.

### 선택지 우선순위

1. **진화(Evolution)**: T2 무기 합성 조건 충족 시 **보장** 등장 (최우선)
2. **무기 업그레이드**: 보유 중인 T1 무기 레벨업
3. **새 무기 획득**: 빈 슬롯이 있을 때 (T2 무기는 진화로만 획득 가능)
4. **패시브 업그레이드/획득**: 캐릭터 전용 패시브는 2배 가중치

### 캐릭터 전용 패시브

| 캐릭터 | 패시브 ID    | 효과                                   |
| ------ | ------------ | -------------------------------------- |
| HAI    | `gust`       | 넉백 +50%/레벨                         |
| HAI    | `dash_trail` | 이동 중 범위 40px 데미지               |
| NOVA   | `frost_shot` | 20%/레벨 확률로 적 30% 슬로우 2초      |
| NOVA   | `torrent`    | 3연속 히트마다 공속 +30% 3초           |
| SOL    | `burn`       | 15%/레벨 확률로 DOT (30% 데미지 × 6틱) |
| SOL    | `ignite`     | HP 20% 이하 적에 +25%/레벨 데미지      |
| MEI    | `refraction` | 30%/레벨 확률로 투사체 바운스          |
| MEI    | `lightspeed` | 킬 시 이동속도 +20%/레벨 5초           |
| KAI    | `thorns`     | 기지 피격 시 15/레벨 반사 데미지       |
| KAI    | `fortify`    | 5초 미피격 시 방어력 +40%/레벨         |

### 럭(Luck) 보너스

메타 업그레이드 `meta_luck` 레벨업 시 새 무기 선택지 가중치 증가. 5% 럭마다 +1 추가 가중치.

## 스테이지 진행

> 관련 파일: `src/core/StageProgression.ts`, `src/managers/PhaseManager.ts`

### 스테이지 구조

16 스테이지 = 8 구역 × (웨이브 1스테이지 + 보스 1스테이지)

```
Stage 1 (웨이브, 60초) → Stage 2 (보스) → Stage 3 (웨이브) → ... → Stage 16 (보스)
```

### 스테이지 클리어 보상

- 기지 HP **20%** 회복 (`clearHealPercent`)
- "STAGE CLEAR" 오버레이 2초 표시
- 다음 스테이지로 자동 진행

### 미드 샵 (30초 트리거)

웨이브 스테이지 30초 경과 시 보급 상점 등장. 선택지:

| 아이템    | 비용   | 효과             | 자동선택 조건 |
| --------- | ------ | ---------------- | ------------- |
| 기지 수리 | 15골드 | 기지 HP 30% 회복 | HP 70% 이하   |
| 화력 강화 | 20골드 | 전체 데미지 +25% | —             |
| 방어 강화 | 20골드 | 기지 방어력 +25% | —             |

## 메타 프로그레션

> 관련 파일: `src/core/MetaProgression.ts`, `src/scenes/MetaScene.ts`

런 종료 후 획득한 골드로 영구 업그레이드를 구매합니다.

### 골드 획득원

| 원천                   | 획득량     |
| ---------------------- | ---------- |
| 일반 적 처치           | 1골드      |
| 엘리트 처치            | 5골드      |
| 보스 처치              | 50골드     |
| 데일리 리워드 (일~7일) | 50~300골드 |

### META_UPGRADES (7종)

| ID            | 이름         | 효과                      | 최대 레벨 | 비용 (레벨별)       |
| ------------- | ------------ | ------------------------- | --------- | ------------------- |
| `meta_damage` | 기본 화력    | 기본 공격력 +10%/레벨     | 5         | 50/100/200/400/800  |
| `meta_hp`     | 기지 강화    | 기지 HP +15%/레벨         | 5         | 50/100/200/400/800  |
| `meta_xp`     | XP 부스터    | XP 획득량 +20%/레벨       | 3         | 100/250/600         |
| `meta_crit`   | 정밀 조준    | 치명타 확률 +3%/레벨      | 5         | 60/120/250/500/1000 |
| `meta_magnet` | XP 흡수 범위 | XP 흡수 범위 +20%/레벨    | 3         | 100/200/400         |
| `meta_armor`  | 기지 방어력  | 기지 방어력 +8%/레벨      | 5         | 80/160/250/400/600  |
| `meta_luck`   | 행운         | 레어 무기 드롭률 +5%/레벨 | 3         | 150/300/600         |

## 상점 시스템

> 관련 파일: `src/core/ShopLogic.ts`, `src/managers/ShopManager.ts`

미드 샵 외에도 `MID_SHOP` 설정에 따라 런 중 단 1회만 등장합니다. 자동선택(5초) 미적용 — 플레이어가 수동 선택.

방어력 계산: `armorMultiplier` = `1 - armorBonusPercent`. 최솟값 0.1 (무적 방지).
