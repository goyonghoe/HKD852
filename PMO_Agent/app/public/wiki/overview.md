# WanChai 소개

> 홍콩을 배경으로 한 사이버펑크 오토슈터 서바이버 게임

관련 파일: `WanChai/.claude/CLAUDE.md`, `src/config/balance.ts`

---

## 게임 개요

**WanChai NeonSurvivor**는 Phaser 3 기반의 세로형(Portrait) 오토슈터 서바이버 게임입니다. 플레이어는 홍콩의 사이버펑크 거리를 배경으로 위에서 쏟아지는 적들을 자동 무기로 격퇴하며 생존합니다.

| 항목   | 내용                                      |
| ------ | ----------------------------------------- |
| 장르   | 오토슈터 서바이버 (Auto-Shooter Survivor) |
| 배경   | 사이버펑크 홍콩 8개 구역                  |
| 시점   | 세로 스크롤, 상단에서 적이 하강           |
| 해상도 | 720 × 1280 (9:16 세로형, 모바일 퍼스트)   |
| 플랫폼 | 웹 (모바일/PC), Vercel 배포               |

## 게임플레이 핵심

- 플레이어는 화면 하단에 고정 (Y=1200), 좌우로만 이동 (기본 이동속도 300 px/s)
- 무기가 자동으로 가장 가까운 적을 조준하여 발사 (최대 4종 무기 동시 장착)
- 적을 처치하면 XP 획득 → 레벨업 시 무기/패시브 업그레이드 선택 (3선택지, 5초 자동선택)
- 60초 웨이브를 버티면 보스 등장, 보스 처치 시 다음 구역 진행
- 기지(Base) HP 600이 0이 되면 게임 오버

## 프로젝트 구조 요약

```
WanChai/
├── src/
│   ├── config/         # 게임 상수 (balance, weapons, colors, characters 등)
│   ├── core/           # 순수 TS 로직 (Phaser 임포트 금지 — M-001)
│   ├── scenes/         # Phaser 씬 10개
│   ├── managers/       # 씬 내 서브시스템 매니저 11개
│   ├── objects/        # 게임 오브젝트 (Player, Enemy, Projectile, Critter)
│   ├── ui/             # UI 컴포넌트
│   ├── utils/          # 유틸리티
│   ├── types/          # TypeScript 타입 정의
│   ├── audio/          # 사운드 시스템
│   └── lib/            # i18n, analytics 등
├── tests/              # Vitest 단위/통합 테스트 (73 파일)
├── design/             # 설계 문서
│   └── reference/      # 수치 바이블, UI/UX 가이드, 아트 스타일
├── .claude/            # 에이전트 설정
│   ├── agents/         # 6개 전문 에이전트
│   ├── rules/          # 실수 레지스트리 (M-001~M-016), 검증 게이트
│   └── skills/         # 칸반 및 개발 스킬 (46개)
└── public/             # 정적 에셋 (스프라이트, 사운드)
```

## 에이전트 팀

WanChai 개발은 6개 전문 에이전트가 협업합니다.

| 에이전트           | 역할                                    | 스킬 수 | 모델   |
| ------------------ | --------------------------------------- | ------- | ------ |
| `game-designer`    | 경험 설계, 메카닉, 레벨, 밸런스 정의    | 7개     | Opus   |
| `programmer`       | 코드 구현, 배선 검증, 플레이테스트 체크 | 8개     | Sonnet |
| `art-director`     | 프로시저럴 텍스처, VFX                  | 4개     | Sonnet |
| `ui-designer`      | 레이아웃, 애니메이션, UX 게이트         | 5개     | Sonnet |
| `balance-designer` | DPS/TTK 분석, 성장 곡선, 경제 시뮬      | 6개     | Opus   |
| `audio-designer`   | 프로시저럴 BGM/SFX, 사이버펑크 음향     | 4개     | Sonnet |
