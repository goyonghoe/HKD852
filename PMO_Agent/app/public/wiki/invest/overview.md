# Invest Agent 개요

한국 주식 배당 투자 대시보드를 제공하는 웹 애플리케이션입니다.

## 프로젝트 정보

| 항목 | 내용 |
|------|------|
| 에이전트 | Invest_Agent |
| 서비스 | KRX 배당주 스크리너 + 포트폴리오 관리 |
| 프레임워크 | Next.js 14 (App Router) + TypeScript |
| 배포 | Vercel |
| 경로 | `Invest_Agent/app/` |

## 기술 스택

- **데이터 소스**: KRX API + Naver Finance 크롤링
- **스타일링**: Tailwind CSS (금융 다크 테마)
- **차트**: 자체 컴포넌트 (배당 캘린더, 바벨 차트)
- **상태 관리**: 로컬 스토리지 기반

## 핵심 기능

| 기능 | 설명 |
|------|------|
| 배당 스크리너 | 배당률, 시가총액, 업종별 필터링 |
| 포트폴리오 | 보유 종목 등록 + 수익률 추적 |
| 배당 캘린더 | 월별 배당 일정 시각화 |
| 시장 브리핑 | 코스피/코스닥 요약 + 금리 추적 |
| 투자 일지 | 매매 기록 + 투자 판단 메모 |

## 주요 페이지

```
/              # 배당주 스크리너 (메인)
/portfolio     # 포트폴리오 관리
/briefing      # 시장 브리핑
/screener      # 상세 필터 스크리너
/journal       # 투자 일지
```

## 투자 전략

바벨 전략 기반 — 안전 자산(고배당 대형주)과 성장 자산(중소형 성장주)을 양극단에 배치하여 리스크 관리와 수익 추구를 동시에 달성합니다.
