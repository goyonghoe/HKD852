## 업무 흐름

### 흐름 A: 게임 기능 기획 → 발표

```
대표 "배틀패스 검토해줘"
  │
  ▼
COO (업무 판단·배치)
  │
  ▼
기획팀장 → 시장조사 → 기획서 → 밸런스 → 수익화 → PD리뷰
  │         [분석파트]              [분석파트]    [PD파트]
  │                                    │
  ├─ 아트디렉터 "이 기능 아트 되나?" ────┘
  │
  ▼
QA 매니저 (품질 검증)
  │
  ▼
커뮤니케이션 디렉터 (발표자료 제작)
  │
  ▼
현지화 매니저 (필요 시 번역)
  │
  ▼
비서실장 (결과 요약 보고)
```

### 흐름 B: 수익 사업

```
대표 "이번 주 아이디어 돌려봐"
  │
  ▼
사업개발 매니저 → 스캔 → 검증 → 비판 → 계획 → 제작 → 출시
  │                                              │
  ├─ 마케팅 매니저 (ASO + 홍보 카피 + 런칭 플랜) ──┘
  │
  ├─ 커뮤니케이션 디렉터 (마케팅 자료 필요 시)
  │
  ▼
비서실장 (주간 성과 요약)
```

### 흐름 C: 일상 운영

```
매일 아침
  비서실장 → "어제 한 일, 오늘 할 일, 이슈" 브리핑

수시
  인사팀장 → 조직도 업데이트, 인력 재배치 제안
  기술지원 → 영상 분석 요청 처리
```

> 로컬 영상 파일의 인코딩 분석 및 ffmpeg 명령어 생성

- 영상 코덱/포맷/해상도/비트레이트/FPS 추출
- 동일 인코딩 재현 ffmpeg 명령어 생성
- 필수 도구: ffprobe, ffmpeg

## 운영총괄 (COO) 판단 흐름

```
사용자 요청
    │
    ├─ 단순 → 직접 처리
    ├─ 전문 → 스킬 파이프라인 (한 에이전트 내)
    ├─ 연계 → 부서 간 파이프라인 (에이전트 간)
    └─ 복합 → 에이전트 팀 (병렬 협업)
```
