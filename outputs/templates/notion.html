🌍 개요

LangMaster는 HSK 어휘 데이터를 기반으로 구축된 AI 기반 언어 학습 플랫폼입니다. 숙련도 수준별 구조화된 단어 목록을 처리하여 전 세계 학습자를 위한 적응형 학습 자료를 생성합니다.

이 위키는 아키텍처 결정사항, 데이터 스키마, 팀 프로세스, 진행 중인 리서치를 하나의 참조 지점으로 통합합니다.

ℹ️
이 페이지는 LangMaster 프로젝트의 단일 진실 소스(SSOT)입니다. 모든 팀원은 새로운 작업을 시작하기 전에 이 문서를 참조해야 합니다.

🏗️ 아키텍처

플랫폼은 데이터 수집 계층, 처리 엔진, 배포 API의 3티어 아키텍처를 따릅니다. HSK 어휘 데이터는 구조화된 JSON 파일에서 정규화 파이프라인을 거쳐 학습 모듈에 전달됩니다.

data/hsk/*.json → Normalizer → Study Engine → REST API → Client

각 HSK 레벨 파일은 일관된 스키마를 따릅니다:

{ "level": 1, "words": [ { "id": "hsk1-001", "simplified": "...", "pinyin": "...", "english": "...", "category": "..." } ] }

프로젝트 전반에 사용되는 핵심 기술:

  • 런타임: Node.js 20 LTS
  • 프레임워크: Next.js 14 (App Router)
  • 데이터베이스: PostgreSQL + Drizzle ORM
  • AI: Claude API 기반 적응형 콘텐츠
  • 배포: Vercel
좋은 문서화란 모든 것을 적는 것이 아닙니다. 사람들이 찾을 수 있도록 적절한 내용을 적절한 위치에 적는 것입니다.
