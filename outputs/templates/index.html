Template Library

주제에 따라 적절한 스타일을 선택하세요. 각 템플릿은 독립적인 HTML 파일로, 콘텐츠만 교체하면 바로 사용 가능합니다.
24 templates

사용법

HTML 산출물 생성 시 템플릿을 지정하면 해당 스타일로 생성됩니다. 지정하지 않으면 주제에 맞게 자동 선택합니다.

# 템플릿 지정 예시
"시장 분석 보고서를 editorial 템플릿으로 만들어줘"
"KPI 대시보드를 dashboard 템플릿으로"
"API 문서를 stripe 스타일로 만들어줘"

# 자동 선택
"이 데이터를 인포그래픽으로 만들어줘" → 주제 분석 후 최적 템플릿 선택
