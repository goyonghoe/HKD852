# 🎨 아트 드로잉 쇼츠 자동화
## Claude Code로 콘텐츠 제작 10배 빠르게

**for 틱톡 & 유튜브 쇼츠 크리에이터**

---

# 😫 이런 고민 있으신가요?

- "오늘은 뭘 그리지?" **매일 주제 고민**
- "요즘 뭐가 핫하지?" **트렌드 파악 어려움**
- "스크립트 쓰는 시간이 너무 오래 걸려"
- "조회수 터지는 패턴을 모르겠어"

---

# 💡 Claude Code가 해결해드립니다

| 기존 방식 | Claude Code |
|----------|-------------|
| 트렌드 수동 검색 (30분+) | **자동 분석 (2분)** |
| 주제 브레인스토밍 (1시간) | **즉시 10개 제안** |
| 스크립트 작성 (30분) | **1분 내 생성** |
| 감에 의존 | **데이터 기반 추천** |

---

# 🔄 자동화 파이프라인

```
[1] 트렌드 분석
    ↓ "요즘 아트 쇼츠에서 뭐가 핫해?"
[2] 주제 추천
    ↓ "조회수 잘 나올 주제 10개 추천해줘"
[3] 스크립트 생성
    ↓ "이 주제로 60초 스크립트 써줘"
[4] 해시태그 최적화
    → "바이럴 해시태그 조합 추천해줘"
```

---

# 📊 실제 사용 예시 1: 트렌드 분석

**입력:**
```
아트 드로잉 틱톡에서 최근 1주일간
조회수 높은 콘텐츠 유형 분석해줘
```

**Claude Code 결과:**
| 순위 | 유형 | 평균 조회수 | 특징 |
|-----|------|-----------|------|
| 1 | 캐릭터 변환 | 500K+ | "OO를 내 스타일로" |
| 2 | 타임랩스 | 300K+ | 10초 내 완성 |
| 3 | 비포/애프터 | 250K+ | 극적인 대비 |

---

# 📝 실제 사용 예시 2: 스크립트 생성

**입력:**
```
"포켓몬을 지브리 스타일로 그리기"
60초 쇼츠 스크립트 써줘.
Hook이 강력해야 해.
```

**Claude Code 결과:**
```
[0-3초] Hook: "피카츄가 토토로 옆에 있다면?"
[3-10초] 스케치 시작 "일단 실루엣부터..."
[10-30초] 채색 "지브리 특유의 파스텔 톤으로"
[30-50초] 디테일 "눈에 생기를..."
[50-60초] 완성 + CTA "다음엔 뭘 그릴까요?"
```

---

# 🎯 조회수 터지는 주제 패턴

Claude Code가 분석한 **바이럴 공식**:

### 1. 변환/크로스오버
- "OO를 XX 스타일로"
- "만약 OO가 XX였다면"

### 2. 챌린지/트렌드 참여
- 현재 유행하는 밈 + 드로잉

### 3. 감정 자극
- 비포/애프터, 성장 스토리
