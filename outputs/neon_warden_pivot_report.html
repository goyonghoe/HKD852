02 — Player Psychology

재미의 과학

Player Psychologist가 도출한 핵심 원칙

30초 온보딩 법칙

77% Day 1 이탈. 튜토리얼 텍스트 = 사망 선고. "Do, Don't Read" — 첫 3초 안에 코어 메카닉을 행동으로 가르쳐야 함. Flappy Bird는 실패한 탭 1번으로 전체 게임을 가르침.

원 메카닉 멀티 퍼포즈

Downwell의 건부츠: 이동 + 공격 + 콤보 + 자원관리를 버튼 1개로. 메카닉 수가 아니라 메카닉 간 상호작용이 깊이를 만든다.

주스(Juice) 스택

히트스톱(2-5프레임) → 방향성 스크린 셰이크(2-4px) → 파티클 버스트(8-16개) → 햅틱 피드백 → 오디오 16ms 내 동기화. 이 5단계가 "탭 한 번"을 만족감으로 바꿈.

5분 플로우 스테이트

Nature Communications(2024): 적응형 난이도가 플로우 유도의 핵심. 매 0.5-2초 피드백. 세션 내 난이도 상승. 중단 없는 연속 플레이.

프로시저럴 = 프리미엄

Geometry Wars 증명: 벡터 셰이프 + 블룸/글로우 + 파티클 = 스프라이트 없이 고급스러운 느낌. 4-6색 팔레트, 이징 애니메이션, 여백이 핵심.

스크린샷 테스트

Monument Valley: 아무 프레임이나 일시정지해도 배경화면 품질. 모든 프레임이 공유 가능한 이미지여야 바이럴. 점수 + 아름다운 배경 = 공유 트리거.

⚠
이전 Neon Warden이 실패한 이유 (심리학 관점): 6개 스탯 읽기 요구 (Do, Don't Read 위반), EH 공식 이해 필요 (30초 온보딩 실패), Papers Please 클론 느낌 (신규 메카닉 부재), 20초 대기 후 첫 게이트 (즉각 만족감 부재).
03 — Pivot Concepts

10개 컨셉 중 Top 5

Game Designer가 발명한 10개 컨셉을 시장성, 기술 실현성, 독창성, 감정 곡선 기준으로 평가하여 상위 5개를 선정했습니다.

#1

TENDRIL

"네온 토양에 뿌리를 그려서 생명체들을 연결하라. 부패가 가장자리에서 침식해 온다."

손가락으로 드래그하여 빛나는 줄기(텐드릴)를 그리면, 연결된 생명체끼리 에너지를 공유합니다. 줄기는 시간이 지나면 소멸하고, 화면 가장자리에서 부패가 침식해 옵니다. 당신의 줄기는 부패를 차단하는 방벽이기도 합니다.

코어 메카닉

드래그로 빛나는 줄기 그리기. 줄기 = 에너지 공유 + 부패 차단. 동시에 두 가지 역할.

30초 온보딩

밝은 점(에너지 있음)과 어두운 점(죽어가는 중). 드래그로 연결 → 에너지 흐름 → 부패 등장 → 줄기로 차단. 텍스트 0.

독창성

그리기 자체가 게임플레이. Flight Control은 경로 지시, 여기서는 인프라 자체를 그린다. 줄기가 서로 교차하면 노드 생성 → 에너지 부스트.

왜 #1인가

프로시저럴 그래픽 최적 (빛나는 선 on 어두운 배경). 스크린샷 = 네온 캘리그래피. 터치에 최적화. 세션마다 고유한 패턴.

#2

PULSE

"당신이 네온 도시의 심장박동이다 — 탭으로 리듬을 유지하면 생태계가 살고, 리듬을 놓치면 죽는다."

화면을 탭하면 에너지 파동이 방사됩니다. 리듬에 맞춰 탭하면 생명체가 번성하고, 박자를 놓치면 죽기 시작합니다. 핵심: 정해진 BPM이 없습니다 — 당신이 템포를 정하고, 생태계가 적응합니다. 느리면 안정적이지만 취약, 빠르면 강하지만 위험.

코어 메카닉

탭으로 리듬 생성. 생태계가 플레이어의 템포에 동기화. 속도 조절 = 전략.

왜 #2인가

감정 곡선 최강 (절박한 탭 → 리듬 발견 → 위기 통과 → 몰입). 리듬 게임이지만 정답이 없는 리듬 게임 = 전무후무.

#3

SPLIT

"화면을 가르는 장벽을 그어서 생태계를 분할하라. 격리된 종은 서로 다르게 진화한다."

드래그로 빛나는 장벽을 그으면 화면이 구역으로 나뉩니다. 각 구역의 생명체는 독립적으로 진화 — 밀집 구역은 공격적(빨강), 넓은 구역은 생산적(초록). 장벽을 제거하면 진화한 종들이 만나 예측 불가능한 상호작용 발생.

코어 메카닉

선 그리기 하나. 장벽 = 분할 + 진화 유도. 제거 = 재결합. 지리적 큐레이션.

왜 #3인가

극도로 단순한 조작 (선 긋기)에서 무한한 다양성. "다르게 갈랐으면?" = 리플레이. 실제 생물학 원리(이소 종분화)를 게임화.

06 — Design Principles

피봇 후 지켜야 할 원칙

1. 한 문장으로 설명 안 되면 만들지 마라

이전 NW: "생태계 큐레이션 로그라이크에서 생명체를 입장/거절하여 자율 방어 시스템을 구축하는..." → 이미 실패. TENDRIL: "빛나는 줄기를 그려서 생명체를 연결하고 부패를 막아라." 끝.

2. 읽기 전에 하기 (Do Before Read)

화면 터치 후 3초 안에 "아, 이렇게 하는 거구나" 느낌. 텍스트 튜토리얼 0개. UI에 숫자 최소화. 시각적 피드백으로 모든 것을 전달.

3. 스크린샷이 아름다워야 한다

매 프레임이 공유 가능한 이미지. 네온 줄기가 어두운 배경 위에 만드는 패턴은 프로시저럴이지만 예술적. TikTok/인스타 바이럴의 전제조건.

4. 웹에서 먼저 검증

Poki/CrazyGames에서 D1 리텐션 30%+ 확인 후 모바일 투자. 97%의 모바일 게임이 실패 — 웹 검증으로 이 리스크를 0원에 제거 가능.
