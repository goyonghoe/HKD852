SECTION 04

AI 에이전트 프레임워크 심층 비교

단순 자동화를 넘어 "에이전트"가 자율적으로 판단하며 영상을 만들려면, 전문 프레임워크가 필요하다.

Python 프레임워크

ShortGPT

YouTube 쇼츠/TikTok 자동화 전용. ContentShortEngine, ContentVideoEngine, ContentTranslationEngine 3가지 엔진 내장. LLM + ElevenLabs/EdgeTTS + Pexels + FFmpeg 통합. 2025년 Gemini API 지원 추가.

에이전트 오케스트레이션

CrewAI

역할 기반 자율 에이전트 팀. Content Researcher, Scriptwriter, Keyword Researcher, Title Writer 등 역할 분담. 순차적 파이프라인에 강점. YouTube 채널 자동화 튜토리얼 다수.

그래프 기반 워크플로우

LangGraph

DAG(방향 비순환 그래프) 기반 워크플로우. 각 노드가 에이전트 액션, 엣지가 데이터 흐름. 복잡한 분기/조건 로직에 강점. 상태 관리와 체크포인트 내장.

HKD852 현재 방식

Claude Code + Skills

ShortsFactory_Agent가 6개 스킬로 파이프라인 운영 중. topic-mine → shorts-script → shorts-render → shorts-review. MCP 서버 연동, 로컬 FFmpeg 렌더링. 24개 에이전트 생태계와 통합.

5-B. AI 콘텐츠 정책 핵심

"YouTube는 AI 사용 자체를 금지하지 않는다. 금지하는 것은 '비진정 콘텐츠(Inauthentic Content)'다 — 템플릿 변형만 최소화한 대량 생산, 쉽게 복제 가능한 콘텐츠가 타겟이다." — YouTube 정책 업데이트, 2025년 7월 15일

안전한 방법: AI를 도구로 활용하되, 자체 인사이트·코멘터리·스토리텔링을 주입하면 수익화에 문제없다.

위험한 방법: Wikipedia나 Reddit을 그대로 긁어 AI 나레이션만 입힌 콘텐츠 팜 운영 — "비진정 콘텐츠"로 분류, 수익화 거부.

공개 의무: 2025년 5월 21일부터, 실제 인물·장소·사건으로 오해할 수 있는 합성 콘텐츠는 반드시 AI 생성 공개 필요.

  • 4~7일차 — 파이프라인 MVP 구축. n8n 또는 ShortGPT로 최소 파이프라인 완성. 수동으로 1편 완주하여 전체 흐름 검증.
  • 8~14일차 — 일일 1편 생산 시작. 자동화 비율 70% 이상 목표. 인간 검수(품질 게이트)는 유지.
  • 15~21일차 — 분석 + 최적화. 조회수 상위 5편 패턴 분석. 훅·썸네일·제목 A/B 테스트. TTS 속도/톤 미세 조정.
  • 22~28일차 — 멀티 채널 또는 다국어 확장. 성과 좋은 스크립트를 영어/일본어로 번역 게시. 또는 2번째 니치 채널 론칭.
  • 29~30일차 — 월간 리뷰 + 수익화 체크. 총 조회수, 구독자 성장, RPM 추정. 수익화 조건(500/3M) 달성률 점검.

리스크 및 주의사항

정책 리스크

"비진정 콘텐츠" 판정

템플릿 변형만 최소화한 대량 생산 시 수익화 거부. 대응: 각 에피소드마다 고유 인사이트/코멘터리 삽입, 스크립트 다양성 확보.

품질 리스크

"AI 슬롭" 인식

시청자가 AI 생성물을 저품질로 인식할 위험. 대응: 품질 게이트 필수, 인간 감수, 차별화된 스토리텔링.

비용 리스크

API 비용 누적

ElevenLabs + 이미지 생성 + LLM API가 편당 $0.50~$3.00. 일 1편 기준 월 $15~$90. 대응: EdgeTTS + Flux 오픈소스로 비용 절감.

저작권 리스크

AI 생성물 저작권

AI 생성 이미지/영상의 저작권 소유권 불명확. 대응: 상업용 라이선스 명시된 도구만 사용, 오리지널 프롬프트 보관.

결론: 핵심 권고

채널을 조립 라인처럼 운영하라 — 전문 AI 도구가 스크립트, 음성, 비주얼, 음악을 만들고, 자동화 엔진이 합성한다. 이렇게 하면 주 1편에서 일 1편으로 스케일링할 수 있다. — Thinkpeak AI, YouTube Automations 2026 Guide

1. 시작은 n8n + ShortGPT로 빠르게. 기존 검증된 템플릿으로 MVP를 48시간 내에 구축하고, 첫 10편을 수동 감수와 함께 게시한다.

2. 확장은 에이전트 프레임워크로. CrewAI 또는 Claude Code Skills 기반으로 토픽 선정·스크립트·렌더링·업로드를 자율 에이전트 파이프라인으로 전환한다.

3. 품질 게이트는 절대 건너뛰지 마라. YouTube의 "비진정 콘텐츠" 정책은 2025년 7월부터 강화됐다. AI를 도구로 쓰되, 각 영상에 고유 인사이트를 반드시 삽입한다.

4. 고RPM 니치를 선점하라. 금융/AI/B2B 니치는 RPM $15~$40으로, 월 30만 조회 시 $4,500~$12,000 수익이 가능하다.

5. HKD852 자산을 최대 활용하라. 이미 ShortsFactory_Agent + ShortsFleet + 112개 스킬이 있다. 이것 자체가 "쇼츠 생산 라인 구축 서비스"로 판매 가능한 포트폴리오다.
