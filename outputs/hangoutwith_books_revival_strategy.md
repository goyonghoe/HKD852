## 2. YouTube AI 콘텐츠 정책 (2025.07.15~)

### 수익화 가능 조건

- AI를 **도구**로 활용하되 **독창적 해석/논평** 추가
- 인간의 큐레이션, 편집, 스토리텔링이 반영된 콘텐츠
- 출처 명시 + 원본 대비 **변형(transformation)** 충분

### 수익화 제한 대상

- AI로 대량 양산된 템플릿 영상
- 단순 요약/번역만 한 콘텐츠 (변형 없음)
- 인간 검증 없이 자동 발행된 콘텐츠

### "책봐서 뭐하니?"에 적용

**핵심 원칙: AI는 생산 효율화, 최종 가치는 인간의 관점**

- 스크립트 초안 → AI 생성, **CEO의 독서 경험/인사이트 추가** → 차별화
- 나레이션 → AI TTS + **인트로/아웃트로는 실제 목소리** (또는 일관된 AI 페르소나)
- 비주얼 → AI 이미지 + 키워드 타이포그래피 + 북커버 인용
- 메타데이터 → AI 최적화, 인간 최종 검토

## 3. 전략: 듀얼 포맷 (쇼츠 + 롱폼)

### Phase 1: 쇼츠 블리츠 (1~3개월) — 수익화 재활성화

**목표**: 쇼츠 10M 조회 또는 시청시간 4,000시간 달성

| 항목        | 설정                                                    |
| ----------- | ------------------------------------------------------- |
| 포맷        | YouTube Shorts (30~55초)                                |
| 업로드 빈도 | **매일 1~2개** (주 7~14개)                              |
| 콘텐츠 유형 | "1분 핵심" — 책 한 권의 가장 강력한 인사이트 1개        |
| 구조        | Hook(3초) → 핵심(25~40초) → CTA(5초)                    |
| 언어        | 한국어 (기존 구독자 기반)                               |
| 보이스      | AI TTS (`calm-female` 또는 `storyteller-female` 프리셋) |
| 비주얼      | 미니멀 문학풍 이미지 + 키워드 자막                      |

**콘텐츠 카테고리 (검증된 고성과)**:

1. **학습법/자기계발** — 울트라러닝 337K 조회수 검증
2. **베스트셀러 핵심 한 줄** — 퓨처셀프 33K 검증
3. **심리학/행동경제학** — 메타인지 4K 검증
4. **부/성공 마인드셋** — 역행자, 슈퍼노멀 패턴

**쇼츠 스크립트 구조 예시**:

```
[Hook] "이 책 읽고 공부법 완전히 바꿨다"
[Body] "울트라러닝의 핵심은 '직접성 원칙'이야.
        배우고 싶은 걸 실제로 해보는 거지.
        영어 배우려면 교재 말고 외국인이랑 대화해.
        코딩 배우려면 강의 말고 직접 앱을 만들어."
[CTA]  "어떤 책이 궁금해? 댓글로 알려줘"
```

**예상 시나리오**:

- 일 1개 × 90일 = 90개 쇼츠
- 평균 쇼츠 조회수 50K 가정 → 4.5M (보수적)
- 평균 쇼츠 조회수 120K 가정 → 10.8M (쇼츠 YPP 달성)
- 시청시간 경로: 롱폼 병행 시 4,000시간 동시 달성 가능
