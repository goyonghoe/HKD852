02
엘리베이터 피치

새로운 한 문장 정의

"적을 죽여 네온 한자를 모으고,
한자 조합으로 무기를 변신시키고,
변신한 무기로 보스의 네온 방패를 깨는 게임."
이 문장은 Vampire Survivors, Brotato, HoloCure, Soulstone Survivors — 어떤 불릿 헤븐에도 적용할 수 없습니다. 네온 파편이 무기 변환의 연료이자 보스 공략의 열쇠이자 경제 자원으로 동시에 기능하기 때문입니다.
🔵 VS와 다른가?
VS의 핵심 자원은 XP (레벨업용). 우리의 핵심 자원은 네온 파편 (변환·실드·상점 3용도). 구조적으로 근본이 다릅니다.
🟣 레드팀 검증
차별성 판정 통과. "중앙 자원의 3용도 기회비용 구조는 장르 내 전례 없음"으로 확인됨.
🩷 홍콩 아이덴티티
한자 네온 파편, 대배당 상점, 사이버펑크 구룡 — 문화적으로 독보적이고 NA/EU에서도 이국적 매력 발휘.
왜 이 게임인가? — 이것이 비전이 아닌 검증 가능한 구조여야 합니다. 네온 파편이라는 단 하나의 자원이 (1) 무기를 일시 변환하고, (2) 보스의 방어막을 직접 해제하며, (3) 상점에서 경제 자원으로도 쓰인다는 3중 기회비용 구조는 Brotato의 웨이브 간 상점, Binding of Isaac의 아이템 시너지와 어깨를 나란히 하는 독자적 메카닉입니다. 차별화는 이미 설계 수준에서 존재합니다. 이제 실증이 필요합니다.

04
레드팀 검증

CRITICAL 4건 — 문제와 해결

레드팀 에이전트(Opus)가 SPEC-033을 대상으로 6개 관점, 26개 이슈를 보고했습니다. CRITICAL 4건은 모두 해결되었으며, SPEC-034가 최종 확정판입니다.
1
파편 6종 vs 9종 — 두 문서가 다른 게임 설계 Critical
SPEC-033은 光·風·雷 추가하여 9종, 밸런스 모델은 6종 기준으로 작성. 전체 시스템 기반이 다름. 프로그래머에게 동시에 주면 구현 불가능한 수준의 불일치.
✅ 해결
확정: 6종 (大·吉·火·力·金·龍). 9종은 오버스코프. 6종이 문화적으로 완결성 있고 (大吉=대길, 火力=화력, 金龍=금룡), 8개 콤보 레시피에 충분. 인지 부하 대폭 감소.
2
드롭률 8배 차이 — SPEC(25%) vs 밸런스 모델(3%) Critical
SPEC-033의 Tier1 드롭률 25%, 밸런스 모델의 드롭률 3%. 8배 이상 차이. 두 문서가 완전히 다른 게임의 파편 경제를 설계하고 있었음.
✅ 해결
확정: 17% 균등. 10분간 ~300킬 기준 ~50 파편 수집 목표로 역산. 단일 권위 수치. 밸런스 시뮬레이션 재실행 완료. 콤보 발동 주기 평균 40~50초/회 달성.
3
한 손 조작의 물리적 한계 — 전투 중 다중 UI 상호작용 불가 Critical
SPEC-033은 조이스틱 조작 중 NEON 버튼 탭, 3지선다 메뉴 선택, 파편 버리기, 대배당 메뉴 선택이 실시간 동시에 요구됨. 한 손으로 물리적으로 불가능.
✅ 해결
자동 콤보 + 선택 팝업 방식. 수동 메뉴 폐지. 콤보 가능 시 자동 발동. 복수 콤보 가능 시 화면 중앙 상단에 2지선다 팝업 (3초 자동해제). 조이스틱 간섭 없는 영역 배치. 한 손 조작 완전 보존.
4
GameScene.ts 3,131줄 한계 — 신규 시스템 추가 불가 Critical
현재 GameScene.ts 3,131줄에 변환 시스템, 보스 실드, 대배당 UI, 크로노 연동을 추가하면 5,000줄+ 파일이 됨. 유지보수 불가능한 구조.
✅ 해결
Phase 1 전 리팩터 필수. NeonTransmuteManager(~400줄), DaiPaiDongManager(~300줄), BossShieldManager(~250줄), ChronoNeonManager(~150줄) 분리. GameScene 잔여 ~2,000줄. Week 0에 전담 일정 확보.
✓ 레드팀 최종 판정: 조건부 승인 → 전건 해결 → 확정 승인
설계 방향 올바름. "중앙 자원의 3용도 기회비용 구조는 장르 내 전례 없음" 확인. CRITICAL 4건 + HIGH 10건 + MEDIUM 8건 전건 해결 완료. SPEC-034가 유일한 권위 소스.

Top 5 리스크와 대응

리스크 확률 × 영향도 매트릭스
R1
"자동 콤보가 재미없다" — 의사결정 부재로 플레이어가 파편 무시
MVP 프로토타입 후 검증 전까지 가장 큰 미검증 리스크. 자동 발동이 긴장감을 제거할 수 있음. 레드팀이 지적한 "블루오션 vs 검증 실패" 가능성 중 핵심.
확률 中 / 영향 치명
외부 테스터 3명 이상 플레이테스트. 재미없으면 전략 모드(수동 조합)를 기본값으로 전환.
R2
보스 실드 좌절감 — 특정 파편 부족으로 막힘
보스 공략에 파편이 필수인 구조이므로, 특정 파편을 얻지 못하면 완전 막힘 발생 가능. 캐주얼 유저의 이탈 원인.
확률 中 / 영향 高
시간 경과 자동 약화 탑재. 미니보스는 아무 파편 2개로 해제. 보스 경고 시 HUD에 필요 파편 표시.
R3
GameScene 리팩터 일정 초과 — 기존 기능 파손
3,131줄 파일에서 서브 매니저 분리 시 기존 기능 연결이 끊어질 위험. 테스트 커버리지가 낮은 영역에서 예상치 못한 버그 발생 가능.
확률 中 / 영향 高
리팩터 전용 브랜치. 기존 테스트 전체 통과 후 머지. 리팩터 기간 5일→7일 여유 확보.
R4
파편 드롭률 17% 밸런스 문제 — 초반 과다 또는 부족
드롭률이 높으면 파편이 너무 많아 전략적 의사결정이 사라지고, 낮으면 콤보 발동이 불가능해 시스템이 무의미해짐.
확률 高 / 영향 中
balance.ts 단일 상수이므로 핫픽스 가능. 플레이테스트 후 12~22% 범위 내 조정. 친화도 보너스(1.40)도 레버.
R5
한자 파편의 NA/EU 시장 장벽 — 아이콘만으로 차별화 부족
타겟 시장 우선순위 NA > EU이지만, 한자 기반 게임 메카닉은 서양 플레이어에게 진입 장벽이 될 수 있음.
확률 低 / 영향 中
아이콘+색상이 기본 식별 수단. 한자는 이국적 플레이버로만 기능. NA/EU 테스터 피드백 수집 후 한자 표시 수준 조정.
