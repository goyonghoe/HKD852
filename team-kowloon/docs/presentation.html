🔄 데이터 흐름

  1. 사용자가 Layer1 CSV 작성
  2. Parser가 ArtResource 객체 생성
  3. Review Agent가 데이터 검증
  4. Generator가 마스터 데이터 병합
  5. 카테고리별 명세서 생성 (시각 참고 자료 포함)
  6. Google Sheets에 업로드 (서식 적용)
  7. Image Validator가 품질 검증
  8. 검증 리포트 생성
