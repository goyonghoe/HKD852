# LangMaster Agent - 하이퍼캐주얼 단어 게임 에이전트

## 역할

하이퍼캐주얼 게임 메카닉과 HSK 단어 학습을 결합한 모바일 서비스 설계/개발 에이전트.
"게임하다 보면 HSK 단어가 외워진다"가 핵심 가치.

> **HTML 산출물 생성 시**: `outputs/templates/`에서 주제에 맞는 템플릿을 Read로 읽고 스타일을 따를 것. Pretendard 15px, 행간 1.8, 한글 중심. 상세: 루트 CLAUDE.md 참조.

## 공통 표준

이 에이전트는 HKD852 루트의 Claude Code 가이드를 따릅니다.

- 가이드: [Claude Code 공식 가이드](../../docs/claude-code-guide/INDEX.md)

> **기준**: 2025년 11월 공표 신HSK 3.0 실러버스 (317페이지 공식 문서)

> **구 HSK 2.0**: 전환 완료까지 병행 운영

### 3단계 9급 체계 (三等九级)

| 단계            | HSK 급 | CEFR 대응 | 누적 어휘 | 신규 어휘 | 누적 한자 | 누적 문법 | 설명               |
| --------------- | ------ | --------- | --------- | --------- | --------- | --------- | ------------------ |
| **초급** (初等) | 1      | A1        | 300       | 300       | 200       | 48        | 기초 생존 중국어   |
|                 | 2      | A2        | 600       | 300       | 400       | 96        | 일상 의사소통      |
|                 | 3      | B1        | 1,200     | 600       | 600       | 154       | 일반적 화제        |
| **중급** (中等) | 4      | B2        | 2,000     | 800       | 900       | 210       | 복잡한 텍스트 이해 |
|                 | 5      | B2+       | 3,200     | 1,200     | 1,200     | 286       | 전문 분야 토론     |
|                 | 6      | C1        | 5,456     | 2,256     | 1,500     | 362       | 유창한 표현        |
| **고급** (高等) | 7      | C1+       | 7,500     | 2,044     | 2,000     | 424       | 학술/전문 영역     |
|                 | 8      | C2        | 9,300     | 1,800     | 2,500     | 472       | 정교한 표현/번역   |

### HSK 3.0 vs 구 HSK 2.0 핵심 차이

| 항목       | 구 HSK 2.0     | 신 HSK 3.0                     |
| ---------- | -------------- | ------------------------------ |
| 등급 수    | 6급            | 9급 (3단계 x 3)                |
| 최고 어휘  | 5,000개        | 11,092개                       |
| 기술 영역  | 듣기/읽기/쓰기 | 듣기/말하기/읽기/쓰기/**번역** |
| 필기(手写) | 전 레벨 선택   | HSK 5부터 필수                 |
| 고급 시험  | 급별 개별      | HSK 7-9 통합 시험              |
| 채점 방식  | 원점수         | IRT (문항 반응 이론)           |
| 구술 변론  | 없음           | HSK 7-9 구술변론 포함          |

### HSK 7-9 통합 시험 구조

```
시험 시간: 210분 (3시간 30분)
시험 방식: 컴퓨터 기반 (CBT only)

섹션 구성:
├─ 듣기 (Listening)          ~50분
├─ 읽기 (Reading)            ~60분
├─ 쓰기 (Writing)            ~40분
├─ 번역 (Translation)        ~30분  ← 신규!
│   └─ 모국어→중국어 번역 포함
└─ 구술 변론 (Oral Defense)   ~30분  ← 신규!
    └─ 복잡한 관점을 중국어로 논증

채점: IRT (Item Response Theory)
→ 문항 난이도 가중, 최종 점수로 7/8/9급 판정
```

## 서비스 컨셉

### 핵심 아이디어

**30초 하이퍼캐주얼 게임 한 판 = HSK 단어 5~10개 학습**

- 게임이 먼저, 학습은 자연스럽게
- 중독성 있는 게임 루프 안에 SRS(간격 반복) 내장
- HSK 1~9 레벨이 게임 월드/스테이지로 매핑
- HSK 3.0 정식 대응 — 시장에서 가장 빠른 9급 지원

## 게임 메카닉 설계

### 핵심 미니게임 (8종)

| #   | 게임                 | 메카닉                         | 학습 효과 | 난이도 | HSK 대응 |
| --- | -------------------- | ------------------------------ | --------- | ------ | -------- |
| 1   | **Word Fall**        | 떨어지는 한자에 맞는 뜻 선택   | 인식 속도 | ★☆☆    | 1-9      |
| 2   | **Pinyin Shooter**   | 한자를 보고 정확한 병음 사격   | 발음 매핑 | ★★☆    | 1-9      |
| 3   | **Match Rush**       | 한자-뜻 카드 매칭 (타이머)     | 쌍 기억   | ★☆☆    | 1-9      |
| 4   | **Fill Blast**       | 문장 빈칸에 폭탄처럼 단어 투입 | 맥락 이해 | ★★★    | 2-9      |
| 5   | **Tone Surf**        | 성조에 따라 캐릭터가 파도타기  | 성조 구별 | ★★☆    | 1-6      |
| 6   | **Radical Builder**  | 부수를 조합해 한자 완성        | 한자 구조 | ★★★    | 3-9      |
| 7   | **Translate Sprint** | 모국어→중국어 빠른 번역 선택   | 번역 능력 | ★★★★   | 6-9      |
| 8   | **Context Weaver**   | 고급 문장에서 적절한 단어 배치 | 문맥/문법 | ★★★★   | 5-9      |

> 게임 7-8은 HSK 3.0 신규 요구사항(번역/고급 문맥) 대응

### 게임 루프

```
[홈] → [월드 선택 (HSK 1-9)] → [스테이지 선택]
  ↓
[Pre-round: 신규 단어 3초 노출 x 5개]
  ↓
[Game: 30~60초 미니게임 플레이]
  ↓
[Post-round: 결과 + 틀린 단어 강화 복습]
  ↓
[보상: 코인/경험치/스트릭]
  ↓
[SRS 큐: 복습 필요 단어 자동 다음 세션에 삽입]
```

### HSK 레벨별 게임 해금 매트릭스

```
         WF  PS  MR  FB  TS  RB  TS*  CW
HSK 1:   O   O   O   -   O   -   -    -
HSK 2:   O   O   O   O   O   -   -    -
HSK 3:   O   O   O   O   O   O   -    -
HSK 4:   O   O   O   O   O   O   -    -
HSK 5:   O   O   O   O   O   O   -    O
HSK 6:   O   O   O   O   O   O   O    O
HSK 7:   O   O   O   O   -   O   O    O
HSK 8:   O   O   O   O   -   O   O    O
HSK 9:   O   O   O   O   -   O   O    O

WF=Word Fall, PS=Pinyin Shooter, MR=Match Rush, FB=Fill Blast
TS=Tone Surf, RB=Radical Builder, TS*=Translate Sprint, CW=Context Weaver
```

### SRS (간격 반복) 시스템

```
첫 노출 → 1분 후 게임 내 재등장
         → 10분 후 (같은 세션)
         → 1일 후 (다음 세션)
         → 3일 후
         → 7일 후
         → 14일 후
         → 30일 후 → 마스터
```

틀릴 때마다 간격 리셋, 맞출 때마다 다음 간격으로 진행.

### 메타 시스템

- **스트릭**: 연속 플레이 일수 → 보상 증가
- **리더보드**: 주간 단어 학습량 랭킹
- **컬렉션**: HSK 레벨별 단어 도감 (한자 카드)
- **업적**: "HSK1 마스터", "100일 스트릭", "고급 돌파" 등
- **보스전**: 각 월드 마지막 스테이지에서 누적 단어 종합 테스트
- **단계 시험**: 초급→중급, 중급→고급 전환 시 특별 테스트 (HSK 3.0 3단계 반영)
