# Income Factory - AI 기반 수익 자동화 시스템

## 목표
- **단기 (3개월):** 월 100-300만원 (유튜브 쇼츠)
- **중기 (6개월):** 월 500-700만원 (게임 + 유튜브)
- **장기 (12개월):** 월 1,000만원+ (복합 수익)

## 제약 조건
- 일일 투자 시간: 30분 ~ 1시간
- 초기 자본: 0원
- 코딩 능력: Claude Code에 의존

## 수익 파이프라인

### Phase 1: 유튜브 쇼츠 자동화
- **니치:** 금융/투자 + AI/테크
- **형태:** 얼굴 없는 채널 (Faceless)
- **목표:** 일 2-3개 쇼츠 업로드

### Phase 2: 하이퍼캐주얼 게임
- **플랫폼:** Google Play / App Store
- **수익모델:** 광고 (AdMob)
- **목표:** 월 2-3개 게임 출시

### Phase 3: 웹 서비스/SaaS
- **타겟:** 게임 기획자/크리에이터
- **수익모델:** 구독 또는 일회성 결제

---

## 에이전트 구조

```
Income_Factory/
├── agents/           # 개별 에이전트 정의
│   ├── research/     # 트렌드/주제 리서치
│   ├── script/       # 스크립트 생성
│   ├── content/      # 콘텐츠 관리
│   └── analytics/    # 성과 분석
├── workflows/        # 워크플로우 정의
├── outputs/          # 생성된 결과물
├── data/             # 데이터 저장소
└── configs/          # 설정 파일
```

## 일일 루틴 (30분)

1. **5분:** 트렌드 확인 (Research Agent)
2. **15분:** 스크립트 검토/수정 (Script Agent 결과)
3. **10분:** 업로드 및 성과 체크

## 시작하기

```bash
# Claude Code에서 실행
cd Income_Factory
```
