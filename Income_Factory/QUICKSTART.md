# Quick Start Guide - 오늘부터 시작하기

## 오늘 해야 할 일 (30분)

### Step 1: 유튜브 채널 설정 (5분)
1. 새 구글 계정 생성 (브랜드 계정)
2. 유튜브 채널 만들기
3. 채널명 예시: "돈이 되는 AI", "부자습관", "재테크 1분"

### Step 2: 첫 영상 제작 (20분)
**이미 스크립트가 준비되어 있습니다!**
→ [outputs/2024-02-03_scripts.md](outputs/2024-02-03_scripts.md)

**제작 순서:**
1. **CapCut 다운로드** (무료)
   - PC: capcut.com
   - 모바일: App Store / Play Store

2. **스톡 영상 다운로드** (5분)
   - Pexels.com에서 검색:
     - "money" "computer" "typing" "chart"
   - 3-5개 클립 다운로드

3. **CapCut에서 편집** (10분)
   - 클립 조합 (60초)
   - 자막 추가 (스크립트 복붙)
   - 텍스트 오버레이 추가
   - BGM 추가 (CapCut 내장)

4. **내보내기** (1분)
   - 1080x1920 (세로)
   - 60fps 권장

### Step 3: 업로드 (5분)
1. YouTube Studio 접속
2. "만들기" → "동영상 업로드"
3. 제목/설명/해시태그 복붙 (스크립트에 있음)
4. 쇼츠로 업로드

## 채널 성장 팁

### 알고리즘 해킹
1. **업로드 시간:** 오후 6-9시 (한국 기준)
2. **일관성:** 매일 같은 시간에 업로드
3. **첫 1시간:** 좋아요/댓글 최대한 유도
4. **해시태그:** 5-10개 (관련성 높은 것)

### 성장 가속
1. **시리즈화:** "부자습관 Day 1, 2, 3..."
2. **트렌드 잭:** 핫한 뉴스에 빠르게 대응
3. **댓글 유도:** 질문으로 끝내기 "여러분 생각은?"
4. **다른 플랫폼:** 틱톡, 인스타 릴스에 동시 업로드
