# Daily Shorts Workflow (30분 루틴)

## 개요
하루 30분 투자로 유튜브 쇼츠 2-3개를 생산하는 워크플로우입니다.

---

## Step 1: 트렌드 리서치 (5분)
**Claude에게 요청:**
```
오늘 유튜브 쇼츠로 만들기 좋은 금융/AI 트렌드 주제 5개를 찾아줘.
- 각 주제의 후킹 문장
- 바이럴 가능성 평가
- CPM 예상치
```

**결과:** 5개 주제 → 상위 3개 선정

---

## Step 2: 스크립트 생성 (10분)
**Claude에게 요청:**
```
[선정된 주제]로 유튜브 쇼츠 스크립트 3개 작성해줘.
- 각 60초 이내
- 첫 3초 강력한 훅
- 얼굴 없이 제작 가능
- 시각 자료 가이드 포함
```

**결과:** 3개 스크립트 완성

---

## Step 3: 콘텐츠 제작 가이드 (5분)
**Claude에게 요청:**
```
위 스크립트를 바탕으로 영상 제작 가이드를 만들어줘.
- 사용할 무료 스톡 영상/이미지 키워드
- 텍스트 오버레이 내용
- BGM 분위기
- 편집 타이밍
```

---

## Step 4: 영상 제작 (10분) - 직접 수행
**사용 도구 (무료):**
- **CapCut** - 영상 편집 (모바일/PC)
- **Pexels/Pixabay** - 무료 스톡 영상
- **Canva** - 썸네일/텍스트

**제작 순서:**
1. 스톡 영상 다운로드 (2분)
2. CapCut에서 조합 (5분)
3. 텍스트/자막 추가 (2분)
4. BGM 추가 및 내보내기 (1분)

---

## Step 5: 업로드 (자동화 가능)
**최적 업로드 시간:**
- 한국: 오후 6-9시
- 미국: 오전 9-11시 (EST)

**메타데이터 (Claude가 생성):**
- 제목 (검색 최적화)
- 설명
- 해시태그
- 썸네일 텍스트

---

## 일일 목표
| 지표 | 목표 |
|------|------|
| 스크립트 생성 | 3개 |
| 영상 제작 | 2-3개 |
| 업로드 | 2개 |

## 주간 목표
- 업로드: 14개 이상
- 조회수: 10만 이상
- 구독자: +500명

## 월간 목표 (3개월 후)
- 일일 조회수: 5만+
- 월 조회수: 150만+
- 예상 수익: 100-300만원

---

## 자동화 확장 (선택)
1. **n8n/Make**: 스크립트 자동 저장
2. **YouTube API**: 예약 업로드
3. **Google Sheets**: 성과 자동 기록
