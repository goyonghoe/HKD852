## 카테고리 1: 스마트스토어 상품 상세페이지

### 프롬프트 1: 상품 상세 설명 생성

**용도**: 스마트스토어 상품 등록 시 설득력 있는 상세 설명이 필요할 때

**프롬프트**:
```
당신은 15년 경력의 네이버 스마트스토어 전문 카피라이터입니다. 다음 상품 정보를 바탕으로 구매 전환율을 높이는 상세 설명을 작성해주세요.

[작성 규칙]
- 첫 문단: 고객의 고민/문제 공감으로 시작
- 둘째 문단: 제품이 해결하는 솔루션 제시
- 셋째 문단: 핵심 기능/성분/스펙 3가지
- 마지막: 구매 결정을 돕는 한 줄 클로징 멘트
- 총 200-300자 내외, 친근하고 신뢰감 있는 반말 톤

[상품 정보]
상품명: {상품명}
카테고리: {카테고리}
주요 특징: {특징 1-3개}
타겟 고객: {고객층}
```

**Before (입력 예시)**:
> 상품명: 프리미엄 라벤더 디퓨저 300ml
> 카테고리: 홈 프래그런스
> 주요 특징: 천연 라벤더 오일, 12주 지속, 무알코올
> 타겟 고객: 20-40대 여성, 집에서 힐링을 원하는 사람

**After (출력 예시)**:
> "퇴근 후 집에 들어서면 맡아지는 찌든 냄새, 스트레스만 더 쌓이죠. 우리 프리미엄 라벤더 디퓨저는 천연 라벤더 오일 100%로 당신의 공간을 힐링 공간으로 바꿔드려요. 무알코올 포뮬라로 안전하고, 12주 동안 은은하게 퍼지는 향기가 매일 집에 오는 게 기다려질 거예요. 하루 500원으로 누리는 나만의 아로마테라피, 지금 바로 시작해보세요."

**활용 팁**: 감성적인 표현과 구체적인 숫자(12주, 하루 500원)를 함께 사용하면 설득력이 배가됩니다.

### 프롬프트 2: 구매 전환 유도 문구

**용도**: 상세페이지 하단이나 중간에 삽입할 구매 결정 촉진 문구가 필요할 때

**프롬프트**:
```
네이버 스마트스토어에서 구매 전환율을 높이는 CTA(Call-to-Action) 문구를 작성해주세요. 고객의 망설임을 해소하고 즉시 구매를 유도하는 3가지 버전을 만들어주세요.

[작성 규칙]
- 버전 1: 희소성 강조 (재고/시간 제한)
- 버전 2: 혜택 강조 (할인/사은품/무료배송)
- 버전 3: 사회적 증거 (리뷰/판매량)
- 각 버전 1-2줄, 이모지 활용, 긴박감 조성

[상품 정보]
상품명: {상품명}
프로모션: {현재 진행 중인 프로모션}
리뷰 수/평점: {리뷰 정보}
```

**Before (입력 예시)**:
> 상품명: 무선 목 마사지기
> 프로모션: 오늘만 35% 할인 + 무료배송
> 리뷰 수/평점: 4,827개 리뷰 / 4.8점

**After (출력 예시)**:
> **버전 1**: ⏰ 오늘 자정까지만! 35% 특가 재고 83개 남음 — 내일은 정가로 돌아갑니다
> **버전 2**: 💰 지금 구매하면 35% 할인 + 무료배송 + 전용 파우치 증정 (34,900원 혜택)
> **버전 3**: ⭐ 4,827명이 선택한 베스트 마사지기 (평점 4.8/5.0) — 이미 만족한 고객들과 함께하세요

**활용 팁**: 3가지 버전을 A/B 테스트로 돌려보고 전환율이 높은 문구를 메인으로 사용하세요.

### 프롬프트 3: 상품 장점 불릿포인트

**용도**: 상세페이지 상단에 배치할 핵심 장점 요약이 필요할 때

**프롬프트**:
```
스마트스토어 상품 상세페이지 최상단에 들어갈 '한눈에 보는 핵심 장점' 불릿포인트를 작성해주세요. 고객이 3초 안에 구매 이유를 파악할 수 있도록 만들어주세요.

[작성 규칙]
- 총 5개 불릿포인트
- 각 불릿: 아이콘 이모지 + 장점 키워드 + 한 줄 설명
- 장점 순서: 1) 차별화 포인트 → 2-3) 기능적 장점 → 4) 고객 편의 → 5) 신뢰 요소
- 각 줄 15자 내외로 간결하게

[상품 정보]
상품명: {상품명}
주요 장점: {장점 5개 이상 나열}
```

**Before (입력 예시)**:
> 상품명: 올인원 보습 크림 100ml
> 주요 장점: 세라마이드 5종 함유, 24시간 보습, 피부과 테스트 완료, 무향, 민감성 피부 가능, 끈적임 없음, 빠른 흡수

**After (출력 예시)**:
> ✅ **세라마이드 5종 고농축** — 피부 장벽 집중 케어
> 💧 **24시간 촉촉 지속** — 수분 증발 차단 기술
> 🧴 **끈적임 제로, 3초 흡수** — 바르자마자 보송
> 🎁 **대용량 100ml** — 얼굴+목+데콜테 3개월 사용
> 🏥 **피부과 테스트 완료** — 민감 피부도 안심

**활용 팁**: 불릿포인트는 상세페이지 최상단 + 모바일 썸네일 이미지에 텍스트로 함께 배치하면 효과적입니다.

### 프롬프트 4: FAQ 자동 생성

**용도**: 고객 문의를 줄이고 구매 결정을 돕는 FAQ가 필요할 때

**프롬프트**:
```
스마트스토어 상품 상세페이지에 넣을 FAQ 섹션을 작성해주세요. 실제 고객들이 자주 궁금해하는 질문 5개와 친절한 답변을 만들어주세요.

[작성 규칙]
- 질문 유형: 1) 사용법 2) 사이즈/스펙 3) 배송/교환 4) 효과/성능 5) 비교 질문
- 답변 톤: 친절하고 구체적이며, 추가 구매 유도 요소 포함
- 각 답변 2-3줄 내외
- 질문은 실제 고객이 사용할 법한 구어체로

[상품 정보]
상품명: {상품명}
카테고리: {카테고리}
특이사항: {배송, 사이즈, 사용법 등 특이사항}
```

**Before (입력 예시)**:
> 상품명: 차량용 무선 고속 충전거치대
> 카테고리: 자동차용품
> 특이사항: 15W 고속충전, 자동 개폐, 송풍구+흡착 겸용, 아이폰/갤럭시 모두 호환

**After (출력 예시)**:
> **Q1. 내 차에도 설치 가능한가요?**
> A. 송풍구형과 흡착형 거치대가 모두 포함되어 있어 99% 차량에 설치 가능합니다. 송풍구 간격이 좁은 차량은 흡착형으로 대시보드나 유리에 부착하시면 돼요.
>
> **Q2. 아이폰도 고속충전 되나요?**
> A. 네! 아이폰 12 이상 모델은 15W 고속충전, 갤럭시는 최대 15W 무선 고속충전을 지원합니다. 일반 유선 충전보다 빠르게 충전돼요.
>
> **Q3. 폰 케이스 끼고도 충전 되나요?**
> A. 7mm 이하 일반 케이스는 착용한 상태로 충전 가능합니다. 단, 카드 수납 케이스나 링 거치대는 무선충전 방해 요소라 제거 후 사용 권장드려요.
>
> **Q4. 자동 개폐가 뭔가요?**
> A. 폰을 가까이 대면 센서가 감지해서 자동으로 거치대가 열립니다. 운전 중 한 손으로 쉽게 거치/탈거 가능해서 안전운전에 도움 돼요.
>
> **Q5. 배송은 얼마나 걸리나요?**
> A. 평일 오후 2시 이전 주문 시 당일 발송되며, 평균 1-2일 내 수령 가능합니다. 제주/도서산간은 +1일 추가 소요돼요.

**활용 팁**: 실제 문의 게시판이나 리뷰에서 자주 나오는 질문을 참고해 FAQ를 업데이트하면 고객 만족도가 올라갑니다.

### 프롬프트 5: 리뷰 유도 문구

**용도**: 구매 고객에게 리뷰 작성을 유도하는 메시지나 동봉 카드 문구가 필요할 때

**프롬프트**:
```
스마트스토어 판매자가 상품 배송 시 동봉하거나 카카오톡으로 발송할 리뷰 유도 메시지를 작성해주세요. 고객이 부담 없이 리뷰를 남기도록 유도하는 친근한 톤으로 작성해주세요.

[작성 규칙]
- 첫 줄: 감사 인사 및 상품 만족 확인
- 둘째 줄: 리뷰 작성 혜택 안내 (포토리뷰 적립금 등)
- 셋째 줄: 리뷰 작성 방법 간단 안내
- 마지막: 피드백 환영 및 재방문 유도
- 총 100-150자, 이모지 활용, 부담스럽지 않은 톤

[상품 정보]
상품명: {상품명}
리뷰 혜택: {포토리뷰 적립금 등}
```

**Before (입력 예시)**:
> 상품명: 프리미엄 스테인리스 텀블러 세트
> 리뷰 혜택: 포토리뷰 3,000원 적립금 + 일반리뷰 1,000원 적립금

**After (출력 예시)**:
> "안녕하세요! 프리미엄 텀블러 잘 받으셨나요? 😊
> 만족스러우셨다면 사용 후기를 남겨주시면 정말 감사하겠습니다.
>
> 📸 **포토리뷰** 작성 시 → 3,000원 적립금
> ✍️ **일반리뷰** 작성 시 → 1,000원 적립금
>
> [마이페이지 > 구매내역 > 리뷰작성]에서 30초면 완료!
>
> 소중한 의견은 다른 고객님께 큰 도움이 되고, 저희에게는 더 나은 제품을 만드는 원동력이 됩니다. 💚
> 다음 쇼핑에서 또 만나요!"

**활용 팁**: 리뷰 유도 메시지는 상품 수령 2-3일 후 카카오톡 알림톡으로 발송하면 가장 높은 응답률을 보입니다.

## 카테고리 2: 인스타그램/SNS 마케팅

### 프롬프트 6: 인스타 캡션 생성 (해시태그 포함)

**용도**: 인스타그램 피드 게시물에 사용할 매력적인 캡션과 해시태그가 필요할 때

**프롬프트**:
```
한국 인스타그램에 최적화된 게시물 캡션을 작성해주세요. MZ세대 감성과 한국 SNS 트렌드를 반영한 자연스러운 캡션을 만들어주세요.

[작성 규칙]
- 첫 줄: 시선을 끄는 후킹 멘트 (이모지 포함)

```

- 설명 2 (45자 이내): [차별화 포인트 또는 프로모션]

4. 네이버 광고 금지어 (최고급, 1위 등) 사용 금지
5. 3개 버전 제공 (A/B 테스트용)

> - 설명 2: 첫 구매 고객 20% 할인 + 무료배송 / 오늘만 특가
>
> **버전 B**
> - 제목: 강아지간식 무첨가 수제
> - 설명 1: 수의사가 추천하는 100% 국내산 프리미엄 간식
> - 설명 2: 신규회원 20% 즉시할인 / 2만원 이상 무료배송
>
> **버전 C**

> - 설명 1: 화학첨가물 제로! 사람도 먹을 수 있는 안전한 간식
> - 설명 2: 지금 가입하면 20% 할인쿠폰 / 당일발송 가능

**활용 팁**: 3개 버전을 동시에 돌려보고 클릭률(CTR)을 비교하세요. 보통 숫자가 들어간 버전이 클릭률이 10-15% 높습니다.

### STEP 2: 원하는 카테고리 찾기
Excel 파일 하단의 탭을 클릭하여 카테고리를 선택합니다.

**10개 카테고리 목록**
- 📦 상품명 제작

- 📧 이메일 마케팅
- 🎯 광고 카피
- ⭐ 리뷰 관리
- 🎁 프로모션 기획
- 📊 분석 리포트
- 🤝 고객 응대
- 🚀 브랜딩

### STEP 3: 프롬프트 복사
원하는 프롬프트를 **전체 선택 (Ctrl+A 또는 Cmd+A)** 후 **복사 (Ctrl+C 또는 Cmd+C)** 합니다.

### STEP 4: AI에 붙여넣기
ChatGPT, Claude, Gemini 중 하나를 열고 복사한 프롬프트를 **붙여넣기 (Ctrl+V 또는 Cmd+V)** 합니다.

### STEP 5: 정보 입력
프롬프트에서 요구하는 정보를 입력합니다.

**예시**: 상품명 프롬프트
```
[상품 카테고리]: 여성 의류

[타겟 고객]: 20-30대 여성
[판매 채널]: 네이버 스마트스토어
```

### STEP 6: 결과 받기
AI가 자동으로 최적화된 카피를 생성합니다. 마음에 드는 것을 선택하거나, "더 만들어줘"라고 요청하면 추가 옵션을 받을 수 있습니다.

#### 방법 A: 기본 사용 (복사 붙여넣기)
1. Excel 파일에서 프롬프트 복사
2. ChatGPT 입력창에 붙여넣기
3. 요구사항 입력
4. Enter 키로 실행

#### 방법 B: Custom Instructions 활용 (고급)
**설정 위치**: 좌측 하단 프로필 → Settings → Custom instructions

**What would you like ChatGPT to know about you?**
```
나는 한국 이커머스 셀러입니다.
- 판매 플랫폼: 네이버 스마트스토어, 쿠팡
- 주요 상품: [여기에 입력]
- 타겟 고객: [여기에 입력]
```

**How would you like ChatGPT to respond?**
```
- 모든 카피는 한국어로 작성
- 이커머스 플랫폼 최적화 고려

- Before/After 예시와 함께 설명

이렇게 설정하면 매번 동일한 정보를 입력하지 않아도 됩니다.

| 한국어 자연스러움 | 보통 | 매우 자연스러움 |
| 응답 속도 | 빠름 | 보통 |
| 월 비용 | 무료 | $20 |

**결론**: 무료 버전으로도 충분히 사용 가능하지만, 품질을 원한다면 유료 추천.

### 4. ChatGPT 프롬프트 팁

#### 팁 1: 명확한 지시
❌ 나쁜 예: "상품명 만들어줘"
✅ 좋은 예: "네이버 스마트스토어용 상품명 10개 만들어줘. 키워드는 '여성 티셔츠', '반팔', '순면 100%'이고, 타겟은 20-30대 직장인 여성이야."

#### 팁 2: 반복 요청
- "더 만들어줘" → 추가 옵션 10개 생성
- "더 짧게 만들어줘" → 간결한 버전 생성
- "이모지 빼고 만들어줘" → 이모지 제거 버전

#### 팁 3: 대화 이어가기
ChatGPT는 대화 맥락을 기억하므로, 한 대화 안에서 계속 수정 요청 가능합니다.

```
사용자: [프롬프트 붙여넣기 + 정보 입력]
ChatGPT: [결과 10개 제공]
사용자: 이 중에서 3번이 마음에 드는데, 좀 더 고급스럽게 바꿔줘
ChatGPT: [3번 기반 고급 버전 5개 제공]
```

## Claude에서 사용하는 법

### 2. Claude 특징
Claude는 ChatGPT보다 **긴 문장**과 **복잡한 지시**에 강합니다.
특히 **상세페이지 카피**나 **블로그 글 작성**에 우수한 성능을 보입니다.

### 3. Claude 사용 팁

#### 팁 1: 파일 업로드 활용
Claude는 파일 업로드를 지원합니다.

**활용 예시**:
1. 경쟁사 상세페이지를 스크린샷으로 저장
2. Claude에 업로드
3. "이 이미지를 참고해서 우리 제품 상세페이지 카피를 작성해줘" 요청

#### 팁 2: 긴 카피 작성 시 활용
ChatGPT보다 긴 글을 한 번에 작성하는 데 강합니다.

**예시**:
```
아래 프롬프트를 사용해서 3,000자 분량의 상세페이지 카피를 작성해줘.
제품명: [입력]
타겟 고객: [입력]
핵심 베네핏: [입력]
```

#### 팁 3: 비판적 검토 요청
Claude는 **분석**과 **평가**에도 강합니다.

**예시**:
```
내가 작성한 상품명: "여성 반팔 티셔츠 20컬러"
위 상품명의 문제점을 분석하고, 개선안 5개를 제시해줘.
```

### Q1. 프롬프트를 사용하려면 AI 유료 버전이 필요한가요?

| AI | 무료 버전 | 유료 버전 | 권장 사항 |
|----|----------|-----------|----------|
| **ChatGPT** | GPT-3.5 (무료) | GPT-4 ($20/월) | 유료 권장 (품질 차이 큼) |
| **Claude** | Sonnet (무료) | Opus ($20/월) | 무료도 충분 |
| **Gemini** | 무료 | Advanced ($20/월) | 무료도 충분 |

**결론**: ChatGPT는 유료 추천, Claude/Gemini는 무료로도 OK.

### Q2. 프롬프트 결과가 마음에 안 들 때는?

**A.** 다음과 같이 수정 요청하세요.

#### 방법 1: 구체적으로 피드백
❌ 나쁜 예: "다시 만들어줘"
✅ 좋은 예: "2번이 괜찮은데, 좀 더 고급스러운 느낌으로 바꿔줘. 이모지는 빼고."

#### 방법 2: 다른 AI 시도
ChatGPT 결과가 마음에 안 든다면 Claude나 Gemini를 시도해보세요.
각 AI마다 스타일이 다릅니다.

#### 방법 3: 프롬프트 커스터마이징
제약 조건을 추가하거나, 예시를 제공하세요.

```
[예시 제공]
이런 느낌으로 만들어주세요:
"[오늘출발] 프리미엄 순면 100% 여성 라운드 반팔 티셔츠 | 빅사이즈 ~3XL | 20컬러"

### Q4. 네이버/쿠팡 정책에 위반되지 않나요?

**A.** 본 프롬프트는 각 플랫폼의 정책을 준수하도록 설계되었습니다.

**준수 사항**:
- ✅ 과대 광고 금지 ("100% 효과", "세계 최고" 등 지양)
- ✅ 의료 광고 제한 준수 (질병 치료 효과 표현 금지)
- ✅ 비교 광고 금지 (경쟁사 제품 언급 금지)
- ✅ 저작권 침해 방지 (유명인 이름 무단 사용 금지)

**최종 검토 책임**:
AI가 생성한 카피는 판매자가 최종 검토 후 사용해야 합니다.
특히 건강식품, 화장품은 식약처 광고 심의 규정을 확인하세요.

### Q7. ChatGPT, Claude, Gemini 중 어떤 걸 써야 하나요?

**A.** 작업에 따라 다릅니다.

| 작업 | 추천 AI | 이유 |

| **분석 리포트** | Gemini | Google 검색 데이터 활용 |
| **고객 응대** | Claude | 세심하고 친절한 응답 |

**결론**: 여러 AI를 함께 사용하는 것을 권장합니다.
ChatGPT로 초안 → Claude로 다듬기 → Gemini로 키워드 검증

**중복 방지 팁**:
1. 동일한 프롬프트를 여러 번 실행하면 다른 결과 획득
2. "기존과 다른 스타일로" 요청
3. 제약 조건을 다르게 설정

**경쟁사와의 중복**:
동일한 프롬프트를 사용하더라도, 입력 정보(상품, 브랜드, 타겟)가 다르므로 결과가 다릅니다.
