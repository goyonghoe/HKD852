## 빠른 시작 (2분 가이드)

### STEP 1: 파일 열기
구매 후 받으신 `마케팅_프롬프트_마스터팩.xlsx` 파일을 엑셀 또는 구글 시트로 엽니다.

### STEP 2: 원하는 카테고리 찾기
Excel 파일 하단의 탭을 클릭하여 카테고리를 선택합니다.

**10개 카테고리 목록**
- 📦 상품명 제작
- 📝 상세페이지 카피
- 💬 SNS 마케팅
- 📧 이메일 마케팅
- 🎯 광고 카피
- ⭐ 리뷰 관리
- 🎁 프로모션 기획
- 📊 분석 리포트
- 🤝 고객 응대
- 🚀 브랜딩

### STEP 3: 프롬프트 복사
원하는 프롬프트를 **전체 선택 (Ctrl+A 또는 Cmd+A)** 후 **복사 (Ctrl+C 또는 Cmd+C)** 합니다.

### STEP 4: AI에 붙여넣기
ChatGPT, Claude, Gemini 중 하나를 열고 복사한 프롬프트를 **붙여넣기 (Ctrl+V 또는 Cmd+V)** 합니다.

### STEP 5: 정보 입력
프롬프트에서 요구하는 정보를 입력합니다.

**예시**: 상품명 프롬프트
```
[상품 카테고리]: 여성 의류
[주요 키워드]: 티셔츠, 반팔, 순면
[타겟 고객]: 20-30대 여성
[판매 채널]: 네이버 스마트스토어
```

### STEP 6: 결과 받기
AI가 자동으로 최적화된 카피를 생성합니다. 마음에 드는 것을 선택하거나, "더 만들어줘"라고 요청하면 추가 옵션을 받을 수 있습니다.

## ChatGPT에서 사용하는 법

### 1. ChatGPT 접속
**무료 버전 (GPT-3.5)**
https://chat.openai.com → 로그인 → New Chat

**유료 버전 (GPT-4)** 권장
왼쪽 상단에서 "GPT-4" 선택

### 2. 프롬프트 입력 방식

#### 방법 A: 기본 사용 (복사 붙여넣기)
1. Excel 파일에서 프롬프트 복사
2. ChatGPT 입력창에 붙여넣기
3. 요구사항 입력
4. Enter 키로 실행

#### 방법 B: Custom Instructions 활용 (고급)
**설정 위치**: 좌측 하단 프로필 → Settings → Custom instructions

**What would you like ChatGPT to know about you?**
```
나는 한국 이커머스 셀러입니다.
- 판매 플랫폼: 네이버 스마트스토어, 쿠팡
- 주요 상품: [여기에 입력]
- 타겟 고객: [여기에 입력]
```

**How would you like ChatGPT to respond?**
```
- 모든 카피는 한국어로 작성
- 이커머스 플랫폼 최적화 고려
- SEO 키워드 자연스럽게 포함
- Before/After 예시와 함께 설명
```

이렇게 설정하면 매번 동일한 정보를 입력하지 않아도 됩니다.

### 3. ChatGPT 무료 vs 유료 비교

| 기능 | 무료 (GPT-3.5) | 유료 (GPT-4) |
|------|----------------|--------------|
| 프롬프트 사용 | ✅ 가능 | ✅ 가능 |
| 카피 품질 | ⭐⭐⭐ 보통 | ⭐⭐⭐⭐⭐ 우수 |
| 창의성 | 보통 | 높음 |
| 한국어 자연스러움 | 보통 | 매우 자연스러움 |
| 응답 속도 | 빠름 | 보통 |
| 월 비용 | 무료 | $20 |

**결론**: 무료 버전으로도 충분히 사용 가능하지만, 품질을 원한다면 유료 추천.

### 4. ChatGPT 프롬프트 팁

#### 팁 1: 명확한 지시
❌ 나쁜 예: "상품명 만들어줘"
✅ 좋은 예: "네이버 스마트스토어용 상품명 10개 만들어줘. 키워드는 '여성 티셔츠', '반팔', '순면 100%'이고, 타겟은 20-30대 직장인 여성이야."

#### 팁 2: 반복 요청
- "더 만들어줘" → 추가 옵션 10개 생성
- "더 짧게 만들어줘" → 간결한 버전 생성
- "이모지 빼고 만들어줘" → 이모지 제거 버전

#### 팁 3: 대화 이어가기
ChatGPT는 대화 맥락을 기억하므로, 한 대화 안에서 계속 수정 요청 가능합니다.

```
사용자: [프롬프트 붙여넣기 + 정보 입력]
ChatGPT: [결과 10개 제공]
사용자: 이 중에서 3번이 마음에 드는데, 좀 더 고급스럽게 바꿔줘
ChatGPT: [3번 기반 고급 버전 5개 제공]
```

## Claude에서 사용하는 법

### 1. Claude 접속
**무료 버전 (Claude Sonnet)**
https://claude.ai → 로그인 → New Conversation

**유료 버전 (Claude Opus)** 권장
좌측 상단에서 "Claude Opus" 선택

### 2. Claude 특징
Claude는 ChatGPT보다 **긴 문장**과 **복잡한 지시**에 강합니다.
특히 **상세페이지 카피**나 **블로그 글 작성**에 우수한 성능을 보입니다.

### 3. Claude 사용 팁

#### 팁 1: 파일 업로드 활용
Claude는 파일 업로드를 지원합니다.

**활용 예시**:
1. 경쟁사 상세페이지를 스크린샷으로 저장
2. Claude에 업로드
3. "이 이미지를 참고해서 우리 제품 상세페이지 카피를 작성해줘" 요청

#### 팁 2: 긴 카피 작성 시 활용
ChatGPT보다 긴 글을 한 번에 작성하는 데 강합니다.

**예시**:
```
아래 프롬프트를 사용해서 3,000자 분량의 상세페이지 카피를 작성해줘.
제품명: [입력]
타겟 고객: [입력]
핵심 베네핏: [입력]
```

#### 팁 3: 비판적 검토 요청
Claude는 **분석**과 **평가**에도 강합니다.

**예시**:
```
내가 작성한 상품명: "여성 반팔 티셔츠 20컬러"
위 상품명의 문제점을 분석하고, 개선안 5개를 제시해줘.
```

## Gemini에서 사용하는 법

### 1. Gemini 접속
**무료 버전**
https://gemini.google.com → 로그인

**유료 버전 (Gemini Advanced)**
Google One AI Premium 구독 필요

### 2. Gemini 특징
Gemini는 **Google 검색 데이터**를 활용할 수 있어, **트렌드 분석**과 **키워드 리서치**에 강합니다.

### 3. Gemini 사용 팁

#### 팁 1: 실시간 트렌드 반영
```
현재 네이버 쇼핑에서 가장 많이 검색되는 '여성 티셔츠' 키워드를 찾아서,
그 키워드를 포함한 상품명 10개를 만들어줘.
```

#### 팁 2: 경쟁사 분석
```
쿠팡에서 '여성 반팔 티셔츠' 검색 1위 상품을 분석하고,
우리 제품이 이길 수 있는 상품명 5개를 제안해줘.
```

#### 팁 3: 이미지 기반 카피 작성
Gemini는 이미지 인식이 가능합니다.

**예시**:
1. 제품 사진 업로드
2. "이 제품의 특징을 분석해서 상세페이지 카피를 작성해줘" 요청

## 프롬프트 커스터마이징 가이드

### 기본 프롬프트 구조 이해

모든 프롬프트는 다음 구조로 되어 있습니다.

```
[역할 설정]
당신은 한국 이커머스 전문 카피라이터입니다.

[작업 지시]
아래 정보를 바탕으로 네이버 스마트스토어용 상품명 10개를 작성해주세요.

[입력 정보]
- 상품 카테고리: [입력]
- 주요 키워드: [입력]
- 타겟 고객: [입력]
- 판매 채널: [입력]

[출력 형식]
1. 상품명 (50자 이내)
2. 주요 키워드: [추출]
3. 예상 클릭률: [평가]

[제약 조건]
- 50자 이내로 작성
- 이모지는 최대 2개까지
- 숫자와 특수문자 활용
```

### 커스터마이징 방법

#### 1. 역할 변경
**기본**: "당신은 한국 이커머스 전문 카피라이터입니다."
**커스터마이징**: "당신은 **프리미엄 화장품 브랜드**의 카피라이터입니다. 고급스러운 톤앤매너를 유지하세요."

#### 2. 제약 조건 추가
**예시**:
```
[추가 제약 조건]
- 브랜드명 "ABC코스메틱" 필수 포함
- 이모지 사용 금지 (프리미엄 브랜드 이미지)
- 모든 상품명은 [대괄호]로 시작
```

#### 3. 출력 형식 변경
**기본**: 텍스트로 10개 나열
**커스터마이징**:
```
[출력 형식]
아래 표 형식으로 제공해주세요.

| 번호 | 상품명 | 주요 키워드 | 글자 수 | 예상 클릭률 |
|------|--------|-------------|---------|-------------|
| 1    | [입력] | [추출]      | [계산]  | [평가]      |
```

#### 4. Before/After 예시 추가 요청
```
[추가 요청]
각 상품명마다 "일반적인 상품명 vs AI 생성 상품명" 비교 예시를 함께 제공해주세요.
```

## 업종별 활용 예시

### 1. 카페 / 베이커리

#### 사용 시나리오
스마트스토어에서 홈베이킹 재료, 원두, 머그컵 등을 판매하는 사업자

#### 추천 프롬프트
- **상품명 제작**: 네이버 검색 최적화 (예: "프리미엄 원두", "홈카페")
- **SNS 마케팅**: 인스타그램 카페 콘텐츠
- **프로모션 기획**: 시즌별 이벤트 (예: "봄맞이 벚꽃 라떼 레시피")

#### 실제 활용 예시
**Before (일반 상품명)**:
```
콜롬비아 원두 200g
```

**After (프롬프트 사용)**:
```
[당일로스팅] 콜롬비아 수프리모 핸드드립 원두 200g | 산미 낮음 | 홈카페 추천 ☕
```

**커스터마이징 팁**:
```
[추가 제약 조건]
- 타겟 고객: 홈카페 입문자 (커피 전문 용어 최소화)
- 톤앤매너: 친근하고 따뜻한 느낌
- 필수 키워드: "홈카페", "당일로스팅", "초보자 추천"
```

### 2. 의류 / 패션

#### 사용 시나리오
쿠팡, 지마켓에서 여성 의류를 판매하는 셀러

#### 추천 프롬프트
- **상품명 제작**: 플랫폼별 최적화 (쿠팡/지마켓)
- **상세페이지 카피**: 핏/소재 강조
- **광고 카피**: 시즌 프로모션 (예: "여름 신상 할인")

#### 실제 활용 예시
**Before (일반 상세페이지)**:
```
이 티셔츠는 순면 100%로 만들어져서 편안합니다.
사이즈는 S, M, L이 있습니다.
```

**After (프롬프트 사용)**:
```
🤍 하루 종일 입어도 답답하지 않은 비밀?

✓ 프리미엄 순면 100% (인증서 첨부)
✓ 4중 통기성 구조로 땀 흡수 빠름
✓ 세탁 100회 테스트 완료 (늘어남 없음)

📐 사이즈 가이드
- S (44~55kg) | M (55~66kg) | L (66~77kg)
- 빅사이즈 걱정 NO! XL~3XL까지 준비

💬 2,847명의 고객이 선택한 이유
"사무실에서 입기 딱 좋아요!" ⭐⭐⭐⭐⭐ (구매자 김○○)
"세탁해도 전혀 늘어나지 않네요" ⭐⭐⭐⭐⭐ (구매자 박○○)
```

**커스터마이징 팁**:
```
[추가 정보 입력]
- 상품 USP: 세탁 100회 테스트, 늘어남 없음
- 고객 페인포인트: 세탁 후 늘어남, 사이즈 불안
- 타겟 고객: 20-30대 직장인 여성
```

#### 추천 프롬프트

- **리뷰 관리**: 긍정 리뷰 답글 템플릿

#### 실제 활용 예시

```
신제품 출시했어요! 많이 사주세요~
```

**After (프롬프트 사용)**:
```
아침에 일어나면 피부가 건조해서 화장이 들뜨는 당신에게 💧

✨ 밤새 수분 잡아주는 비밀?
히알루론산 10% + 세라마이드 5중 복합체

🧪 피부과 전문의 테스트 완료

🎁 론칭 기념 이벤트
지금 구매 시 미니어처 3종 증정 (선착순 100명)

#민감성피부화장품 #수분크림추천 #건조한피부
#20대스킨케어 #피부과전문의추천 #무향크림

**커스터마이징 팁**:
```
[브랜드 톤앤매너]
- 전문성: 피부과 전문의 테스트, 임상 데이터 강조
- 친근함: 고객 페인포인트 공감 ("화장이 들뜬다")
- 신뢰성: 성분 함량 명시, 인증서 강조

### 4. 식품 / 건강식품

#### 사용 시나리오
쿠팡에서 건강 간식, 다이어트 식품을 판매하는 셀러

#### 추천 프롬프트
- **상품명 제작**: 건강 키워드 (예: "무첨가", "유기농")
- **상세페이지 카피**: 성분 강조, 인증서 표시
- **광고 카피**: FOMO 기반 프로모션 (예: "한정 수량")

#### 실제 활용 예시
**Before (일반 상품명)**:
```
프로틴바 10개입
```

**After (프롬프트 사용)**:
```
[쿠팡 랭킹 1위] 무설탕 프로틴바 10개입 | 단백질 20g | 다이어트 간식 | HACCP 인증
```

**커스터마이징 팁**:
```
[식품 특화 제약 조건]
- 인증 정보 필수 표시: HACCP, 유기농, 비건 인증 등
- 성분 투명성: "무첨가", "Non-GMO", "글루텐프리" 명시
- 타겟 키워드: "다이어트", "헬스", "저칼로리"
```

## 자주 묻는 질문

### Q1. 프롬프트를 사용하려면 AI 유료 버전이 필요한가요?

**A.** 무료 버전으로도 충분히 사용 가능합니다.

| AI | 무료 버전 | 유료 버전 | 권장 사항 |
|----|----------|-----------|----------|
| **ChatGPT** | GPT-3.5 (무료) | GPT-4 ($20/월) | 유료 권장 (품질 차이 큼) |
| **Claude** | Sonnet (무료) | Opus ($20/월) | 무료도 충분 |
| **Gemini** | 무료 | Advanced ($20/월) | 무료도 충분 |

**결론**: ChatGPT는 유료 추천, Claude/Gemini는 무료로도 OK.

---

### Q2. 프롬프트 결과가 마음에 안 들 때는?

**A.** 다음과 같이 수정 요청하세요.

#### 방법 1: 구체적으로 피드백
❌ 나쁜 예: "다시 만들어줘"
✅ 좋은 예: "2번이 괜찮은데, 좀 더 고급스러운 느낌으로 바꿔줘. 이모지는 빼고."

#### 방법 2: 다른 AI 시도
ChatGPT 결과가 마음에 안 든다면 Claude나 Gemini를 시도해보세요.
각 AI마다 스타일이 다릅니다.

#### 방법 3: 프롬프트 커스터마이징
제약 조건을 추가하거나, 예시를 제공하세요.

```
[예시 제공]
이런 느낌으로 만들어주세요:
"[오늘출발] 프리미엄 순면 100% 여성 라운드 반팔 티셔츠 | 빅사이즈 ~3XL | 20컬러"
```

### Q4. 네이버/쿠팡 정책에 위반되지 않나요?

**A.** 본 프롬프트는 각 플랫폼의 정책을 준수하도록 설계되었습니다.

**준수 사항**:
- ✅ 과대 광고 금지 ("100% 효과", "세계 최고" 등 지양)
- ✅ 의료 광고 제한 준수 (질병 치료 효과 표현 금지)
- ✅ 비교 광고 금지 (경쟁사 제품 언급 금지)
- ✅ 저작권 침해 방지 (유명인 이름 무단 사용 금지)

**최종 검토 책임**:
AI가 생성한 카피는 판매자가 최종 검토 후 사용해야 합니다.
특히 건강식품, 화장품은 식약처 광고 심의 규정을 확인하세요.

### Q5. 한 번 구매하면 계속 사용 가능한가요?

**A.** 네, 영구 사용 가능합니다.

**라이센스 정책**:
- ✅ 구매자 개인/회사 내부 사용: 무제한
- ✅ 여러 브랜드/쇼핑몰에서 사용: 가능
- ❌ 제3자에게 재판매: 불가
- ❌ 무단 재배포: 불가

**업데이트 정책**:
- 기본/스탠다드: 구매 시점 버전 제공
- 프리미엄: 평생 업데이트 무료

### Q6. 프롬프트 사용 시간이 얼마나 걸리나요?

**A.** 익숙해지면 카피 하나당 **3~5분**입니다.

**시간 비교**:
| 작업 | 수작업 | AI 프롬프트 | 시간 절감 |
|------|--------|-------------|----------|

| 상세페이지 카피 | 2시간 | 15분 | **87%** |
| 인스타그램 콘텐츠 한 달 치 | 8시간 | 1시간 | **87%** |
| 광고 카피 20개 | 1시간 | 5분 | **92%** |

**학습 곡선**:
- 1일차: 프롬프트 이해 (1시간)
- 2일차: 기본 사용 숙달 (30분)
- 3일차: 커스터마이징 시작 (1시간)
- 7일차: 완전 자동화 (3분)

### Q7. ChatGPT, Claude, Gemini 중 어떤 걸 써야 하나요?

**A.** 작업에 따라 다릅니다.

| 작업 | 추천 AI | 이유 |
|------|---------|------|
| **상품명** | ChatGPT | 짧고 임팩트 있는 카피 생성 우수 |
| **상세페이지** | Claude | 긴 글 작성 능력 뛰어남 |
| **SNS 콘텐츠** | ChatGPT | 트렌디한 표현 생성 |
| **광고 카피** | ChatGPT | 짧고 강력한 메시지 |
| **분석 리포트** | Gemini | Google 검색 데이터 활용 |
| **고객 응대** | Claude | 세심하고 친절한 응답 |

**결론**: 여러 AI를 함께 사용하는 것을 권장합니다.
ChatGPT로 초안 → Claude로 다듬기 → Gemini로 키워드 검증

**수정 예시**:

- 출력 형식 변경

**주의사항**:
프롬프트 핵심 구조를 유지하면서 수정하는 것을 권장합니다.
너무 많이 바꾸면 AI가 이해하지 못할 수 있습니다.

### Q9. 결과가 중복될 수 있나요?

**A.** AI는 매번 다른 결과를 생성하므로 중복 확률은 매우 낮습니다.

**중복 방지 팁**:
1. 동일한 프롬프트를 여러 번 실행하면 다른 결과 획득
2. "기존과 다른 스타일로" 요청
3. 제약 조건을 다르게 설정

**경쟁사와의 중복**:
동일한 프롬프트를 사용하더라도, 입력 정보(상품, 브랜드, 타겟)가 다르므로 결과가 다릅니다.

### Q10. 환불 가능한가요?

**A.** 디지털 상품 특성상 다운로드 후에는 환불이 어렵습니다.

**구매 전 확인 방법**:
1. **샘플 프롬프트 요청**: 문의 주시면 3개 무료 제공
2. **Before/After 예시**: 상품 페이지에서 확인
3. **사용자 후기**: 크몽 리뷰 참고

**환불 가능한 경우**:
- 파일이 손상되어 열리지 않는 경우
- 상품 설명과 내용이 현저히 다른 경우

위 경우 구매 후 7일 이내 요청 시 전액 환불해드립니다.
