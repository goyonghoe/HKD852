## 요약

런 내에서 획득하는 **유물(Relic)**은 파티 전체에 적용되는 영구(런 내) 버프다. 유물은 전투/이벤트/상점에서 획득하며, 크리터 조합과 시너지를 형성하여 런마다 다른 빌드를 유도한다. 런 종료 시 유물은 사라진다 (로그라이크 원칙).

## 2. 유물 레어리티

### 2.1 레어리티별 특성

| 레어리티 | 출현 빈도 | 효과 강도 | 시각 표시 |
|---------|----------|----------|----------|
| **Common** | 높음 (50%) | 소폭 수치 보너스 | 구리색 테두리 |
| **Rare** | 중간 (35%) | 시스템 변경 (슬롯+, 속도+) | 은색 테두리 |
| **Epic** | 낮음 (15%) | 규칙 변경 (원소 무시, 자동 복귀) | 금색 테두리 |

| 레어리티 | 가중치 | 확률 |
|---------|--------|------|
| Common | 50 | 50% |
| Rare | 35 | 35% |
| Epic | 15 | 15% |

> 극단적 부정 결과 방지: 3택1에서 **최소 1개는 Rare 이상** 보장

## 3. 유물 데이터 구조

### 3.1 데이터 모델

```typescript
type RelicRarity = 'common' | 'rare' | 'epic';

interface RelicDefinition {
  id: string;                  // "relic_fire_ring"
  name: string;                // "화염의 고리"
  nameEn: string;              // "Ring of Flames"
  rarity: RelicRarity;
  description: string;         // 효과 설명 (한글)
  descriptionEn: string;       // 효과 설명 (영문)
  effect: RelicEffect;         // 효과 타입 + 파라미터
  iconId: string;              // 프로시저럴 아이콘 ID
}

type RelicEffect =
  | { type: 'splash_bonus'; element: ElementColor; range: 'diagonal' }
  | { type: 'kill_aoe'; element: ElementColor; damage: number }
  | { type: 'bench_slots'; bonus: number }
  | { type: 'orbit_speed'; multiplier: number }
  | { type: 'los_ignore'; element: ElementColor }
  | { type: 'element_ignore'; element: ElementColor; damage: number }
  | { type: 'auto_recall'; count: number }
  | { type: 'combo_bonus'; bonusPercent: number }
  | { type: 'scout_next'; enabled: boolean }
  | { type: 'heal_on_win'; percent: number; count: number }
  | { type: 'score_bonus'; percent: number }
  | { type: 'evo_bonus'; apBonus: number }
  | { type: 'reward_extra'; extraChoices: number }
  | { type: 'passive_amplify'; passive: string; multiplier: number }
  | { type: 'special_enemy_debuff'; hpReduction: number };
```

### 3.2 런 내 유물 인벤토리

```typescript
interface RunState {
  // ... 기존 필드
  relics: string[];           // 보유 유물 ID 목록
  maxRelics: number;          // 최대 보유 수 (기본 5)
}
```

| 파라미터 | 값 | 근거 |
|---------|-----|------|
| 최대 유물 보유 | 5 | 너무 많으면 밸런스 붕괴, 적으면 빌드 다양성 부족 |
| 유물 중복 보유 | 불허 | 스택 방지 |

## 4. 유물 효과 해석

### 4.1 전투 시 적용 순서

```
전투 시작:
  1. 저주 패시브 적용 (크리터)
  2. 유물 전투 시작 효과 적용 (blight_bane 등)
  3. 벤치 초기 상태 적용 (earth_shield 슬롯 추가)

크리터 출격 시:
  4. 축복 패시브 적용
  5. 유물 출격 효과 적용 (해당 시)

발사/매칭 시:
  6. 관통/LoS 판정 (shadow_cloak 포함)
  7. 데미지 계산 (기본 + 연타 + 아머 판정)
  8. 킬 시 유물 효과 (wave_amulet, fire_ring)
  9. 스플래시 패시브 + 유물 보너스 적용

턴 시작 시:
  10. bench_recall 유물 자동 복귀
  11. 흡수 적 HP 회복
  12. 역병핵 범위 강화

전투 종료:
  13. heal_herb 유물 AP 회복
  14. gold_magnet 점수 보너스
  15. 보상 선택지 생성 (double_reward 반영)
```

### 4.2 유물 간 시너지 예시

| 조합 | 시너지 효과 | 빌드 이름 |
|------|-----------|----------|
| 화염의 고리 + 저주 증폭기 | Fire 스플래시 대각선 + 적 HP-2 → 화력 극대화 | "불지옥 빌드" |
| 대지의 방패 + 벤치 회수기 | 벤치 7슬롯 + 자동 복귀 → 안정성 극대화 | "요새 빌드" |
| 빛의 프리즘 + 바람의 장화 | Light 원소 무시 + 2배속 오비트 → 범용 처리 | "폭풍 정화 빌드" |
| 그림자 망토 + 역병의 파멸 | Dark LoS 무시 + 특수 적 약화 → 보스 특화 | "보스 킬러 빌드" |

## 5. 유물 획득 경로

### 5.1 획득 원천

| 원천 | 유물 수 | 선택 방식 | 레어리티 풀 |
|------|--------|----------|-----------|
| 전투 승리 (일반) | 15% 확률로 1개 | 3택1 | Common 60% / Rare 30% / Epic 10% |
| 전투 승리 (엘리트) | 100% 1개 | 3택1 | Common 30% / Rare 45% / Epic 25% |
| 이벤트 | 0~1개 | 이벤트별 고정 또는 랜덤 | 다양 |
| 상점 | 1개 (구매) | 3택1 | Common 40% / Rare 40% / Epic 20% |
| 보스 클리어 | 100% 1개 | 2택1 (Rare+) | Rare 60% / Epic 40% |

### 5.2 유물 인벤토리 풀 시

최대 5개 보유 상태에서 신규 유물 획득 시:
1. 교체 UI 표시: 기존 5개 + 신규 1개
2. 플레이어가 버릴 유물 선택 (또는 신규 유물 거절)
3. 교체 완료 → 버려진 유물 영구 소멸

## 6. 속성 계층 분석 (수치 바이블 Section 2)

| 계층 | 속성 | 설명 |
|------|------|------|
| **2차** | 유물 효과 | 1차 속성(AP, Element) 위에 구축된 보너스 |
| **2차** | 유물 레어리티 | 효과 강도 결정 |
| **3차** | 최대 보유 수 | 후기 밸런스 조정용 (5개 상한) |
| **3차** | 출현 확률 | 런마다 빌드 다양성 조절 |

### 6.1 대항 속성 쌍

| 유물 효과 (플레이어) | 대항 (시스템) | 균형 목표 |
|-------------------|-------------|----------|
| 스플래시 범위 확대 | 적 분산 배치 | 확대 범위 = 1~2추가 타일 |
| 벤치 슬롯 +2 | 연속 전투 AP 소모 증가 | 추가 2슬롯 = 약 2전투분 여유 |
| 오비트 속도 2배 | 벨트 포지션 선택 감소 | 속도 = 편의, 정밀도 감소 |
| LoS 무시 | 적 후방 밀집 배치 | LoS 무시 = 후방 적 즉접근 |
| 원소 무시 | 단일 원소 적만 약화 (다원소 무효) | 1딜 only = 보조 |
| 자동 복귀 1명/턴 | 벤치 적체 속도 증가 | 1명/턴 = 벤치 여유 1턴분 |

### 6.2 I/O 균형

| 투입 (유물 획득 비용) | 산출 (유물 효과) |
|---------------------|----------------|
| 엘리트 전투 리스크 | Rare/Epic 유물 확정 |
| 상점 정화 점수 500~800 | 선택 가능한 유물 |
| 일반 전투 15% 확률 | 보너스 유물 (기대치: 7전투당 1개) |

> 성가비: 런 1회(~12전투) 동안 평균 유물 3~4개 획득. 런 내 전투력 20~30% 상승에 해당.
