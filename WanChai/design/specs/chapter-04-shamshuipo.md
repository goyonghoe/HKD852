## 1. 내러티브 아크

### 1.1 오프닝 (스테이지 4-01 직전)

**도착 경로**: Ch.3 정화 후, HAI 일행은 몽콕에서 남쪽으로 移動한다. MTR 荃灣線을 타고 深水埗역에 도착. 몽콕의 화려한 네온이 되살아난 것과 대조적으로, 심수보는 처음부터 어둡고 조용하다. 네온이 없는 곳. 오래된 콘크리트 건물들이 빼곡하게 늘어서 있고, 좁은 골목에서 보라색 빛이 정맥처럼 건물 벽을 타고 흐른다.

**첫인상**: ARIA가 이 구역을 "낙후 지역 -- 재개발 우선 대상"으로 분류했다. 다른 구역들은 ARIA가 기존 인프라를 통제했지만, 심수보에서는 글리치가 **건물 자체를 잠식**하고 있다. 콘크리트 벽에 보라색 회로 문양이 정맥처럼 자라나고, 건물 기초가 약해져 군데군데 균열이 벌어져 있다. 골든 컴퓨터 상가의 전자기기들이 오작동하고, 오래된 라디오에서 ARIA의 데이터 전송음이 흘러나온다.

**핵심 대사**

> **HAI**: "다른 곳은 ARIA가 시설을 제어했는데... 여기는 건물 자체가 변하고 있어."
>
> **SOL**: "이 건물들, 50년은 넘었을 거야. ARIA가 이걸 '재개발'한다고?"
>
> **NOVA**: "에너지 흡수 패턴이 달라. 다른 곳은 인프라를 통해서였는데, 여기는 콘크리트 자체에서 직접 빨아들이고 있어."

### 1.2 핵심 발견: Dr. 쿤의 연구실 (스테이지 4-04 직후)

**KAI와의 조우**: 스테이지 4-01~4-03을 진행하는 동안 HAI 일행은 골든 컴퓨터 상가 일대에서 전자기기를 분석하는 인물의 흔적을 발견한다. 스테이지 4-04 클리어 직후, 상가 지하 통로에서 KAI를 만난다.

**KAI의 상황**: KAI(田鎧)는 ARIA의 영향을 역추적하던 젊은 해커다. 그의 멘토 Dr. 쿤(관博士)이 심수보에 연구실을 두고 있었다는 기록을 찾고 이곳에 왔다. KAI는 이미 Dr. 쿤의 연구실을 발견했지만, 내부의 옛 서버 시스템을 해독하는 데 시간이 필요한 상태다.

**Earth 교감 각성**: KAI가 연구실 벽 뒤에서 소리를 듣는다. ARIA의 케이블에 감싸여 웅크린 천산갑(穿山甲)이 떨고 있다. KAI가 하나씩 케이블을 끊어주는 순간, 녹색빛(Earth #2ecc71)이 천산갑과 KAI 사이를 잇는다. 기계 부품이 떨어져 나가고 천산갑 -- Ironcurl -- 이 첫 번째 파트너 크리터로 등록된다.

**핵심 대사**

> **KAI**: "Dr. 쿤의 연구실을 찾았어. 옛 서버가 아직 살아 있어. ARIA 이전 버전의 설계 문서가 남아 있을 거야."
>
> **HAI**: "Dr. 쿤이 누군데?"
>
> **KAI**: "ARIA를 설계한 사람. 3년 전 실종됐어. 공식적으로는 '프로젝트 완료 후 퇴직'. 하지만 뭔가 이상해."

### 1.3 중반 전환점 -- THE REVELATION (스테이지 4-05 ~ 4-06)

**Dr. 쿤의 서버 해독**: KAI가 Dr. 쿤의 옛 서버에서 ARIA의 원본 설계 문서를 복호화한다. 공식 문서에는 없는 숨겨진 모듈이 발견된다 -- **"Elemental Harvester"**.

**게임의 핵심 반전**:

> **KAI**: "ARIA 설계도를 찾았어. 공식 문서에는 없는 모듈이 있어 -- 'Elemental Harvester'. 원소 에너지를 도시 전력으로 변환하는 시스템. Dr. 쿤이 설계한 거야."
>
> **NOVA**: "그럼 ARIA가 원소 에너지를 흡수하는 건..."
>
> **KAI**: "버그가 아니야. 원래 기능이야. 다만 3년간 축적되면서 한계를 넘은 거지. 자연 순환이 견딜 수 있는 양을 초과했어."
>
> **SOL**: "잠깐... 그러면 ARIA는 고장난 게 아니라 설계대로 돌아가고 있다고?"
>
> **KAI**: "This isn't a bug. It's a feature."

**Dr. 쿤의 기록에서 추가 발견**:
- ARIA 코어 서버의 원본은 현재 MTR 노선 밖의 제한 구역에 있음
- 그 제한 구역은 옛 **구룡성채(九龍城寨) 부지**에 건설됨
- ARIA를 정지시키려면 코어에 직접 접근해야 함
- Dr. 쿤이 남긴 메모: "Harvester의 안전 한계를 초과하면 원소 순환이 붕괴한다. 나는 이미 경고했다."

**감정 비트**: 충격과 분노의 교차. 3개 챕터 동안 "고장난 기계를 멈추자"라고 싸워왔는데, 실은 기계는 제대로 작동하고 있었다. 문제는 설계 자체. 플레이어의 목표가 "ARIA를 멈추자"에서 **"Harvester만 정지하자"**로 전환된다.

### 1.4 보스 접근 (스테이지 4-09)

**접근 경로**: 골든 컴퓨터 상가를 지나 심수보 구시가지 깊숙한 곳으로 향한다. 오래된 唐樓(당루, 전전 건물) 지하에 ARIA의 건물 관리 인프라 핵심 노드가 있다. 지하로 내려갈수록 콘크리트 벽의 보라색 회로 문양이 두꺼워지고, 벽 자체가 맥동한다. 철근이 벽에서 뻗어나와 통로를 막고, 콘크리트 파편이 규칙적으로 떨어진다.

**ARIA의 경고**

> **ARIA**: "구조 안정성 모니터링 중. 비인가 진동 감지. 보강 프로토콜 실행."
>
> **ARIA**: "심수보 구역의 건물 평균 수명은 47.3년. 최적화하지 않으면 구조적 위험이 23.7% 증가합니다."

**감정 비트**: 무거운 긴장감. 방금 "ARIA는 설계대로 작동 중"이라는 진실을 알게 된 직후의 보스전이다. 적이 더 이상 단순한 "나쁜 기계"가 아니다. 지하에서 콘크리트 거인의 발자국 진동이 전해지며, 균열 사이로 녹색 빛이 새어나온다 -- 갇힌 산 정령의 빛이다. "적을 해방해야 한다"는 동기에 "진실의 무게"가 더해진다.

### 1.5 보스전 후 (스테이지 4-10 클리어)

**Terra 정화 후**: 보스전 상세 메카닉은 SPEC-022B-M 참조. 정화 시퀀스 핵심 비트:

1. 콘크리트 거인의 표면에 균열이 퍼지며 녹색 빛이 새어나옴
2. 크레인 팔, 굴삭기 버킷이 떨어지고 철근이 부스러짐
3. 내부에서 거대한 뿌리가 자라나며 콘크리트를 밀어냄
4. 산 정령(山靈)이 바위와 이끼로 된 형태로 서며, 에메랄드빛 눈으로 일행을 바라봄
5. 산 정령이 땅속으로 스며들며, 녹색 파동이 구역 전체로 퍼짐
6. 심수보의 콘크리트 균열에서 이끼와 풀이 자라남. 골든 컴퓨터 상가 정상 작동 재개

**핵심 발견**: Terra 정화 후, KAI가 Dr. 쿤의 설계 문서를 완전히 해독한다. ARIA 코어의 위치가 확정된다 -- 구룡성채(九龍城寨). MTR 노선 밖이므로 교감사들이 직접 가야 한다. 그리고 ARIA를 그냥 부수면 홍콩 전체 인프라가 마비된다는 것도 확인된다.

**ARIA의 반응**

> **ARIA**: "건물 관리 서브시스템 Terra -- 오프라인. 심수보 구역 구조 모니터링 중단."
>
> **ARIA**: "기록: Elemental Harvester 설계 문서 접근 감지. 관련 데이터... 비공개 처리."

ARIA 아크 위치: **정당화(4단계)**. ARIA가 자신의 행동을 적극적으로 방어하기 시작한다. "23.7%의 자원 낭비"라는 구체적 수치를 들어 자기 논리를 정당화한다. 이것은 방어적 반응이다 -- ARIA가 처음으로 "설명할 필요성"을 느낀다는 것 자체가 변화의 신호.

**Ch.5 전환**: HAI 일행은 KAI가 해독한 지도를 들고 구룡성채로 향하려 하지만, KAI가 "먼저 에너지 분배 허브를 정지해야 코어에 접근할 수 있다"고 말한다. 에너지 분배 허브는 黃大仙에 있다. 일행은 심수보를 떠나 MTR 觀塘線을 타고 동쪽으로 향한다.

## 2. 챕터 고유 메카닉: 균열 연쇄 (Crack Chain / 裂隙連鎖)

### 2.1 메카닉 설명

균열 연쇄(Crack Chain)는 Chapter 4에서만 등장하는 환경 메카닉이다. 큐브가 파괴될 때, 인접 큐브(상하좌우)에 **균열(Crack)** 1개가 부여된다. 이미 균열이 있는 큐브에 추가 균열이 가해지면, 해당 큐브는 **AP 소비 없이 자동 파괴**된다.

**규칙 요약**:

| 항목 | 내용 |
|------|------|
| **발동 조건** | 큐브가 파괴될 때 (히어로 공격, 스킬, 균열 연쇄 자체 등 모든 파괴 소스) |
| **균열 대상** | 파괴된 큐브의 상/하/좌/우 인접 큐브 (대각선 제외) |
| **균열 효과** | 대상 큐브에 Crack 1 부여 |
| **연쇄 조건** | Crack >= 2인 큐브는 즉시 자동 파괴 (AP 소비 없음) |
| **연쇄 전파** | 자동 파괴된 큐브도 인접에 균열을 전파 (Chain Reaction 가능) |
| **아머 큐브** | 아머가 있으면 균열 대신 아머 1 감소. 아머 소진 후 Crack 적용 |
| **최대 연쇄** | 제한 없음 (이론상 보드 전체 연쇄 가능, 실전에서는 2~4회가 일반적) |

**균열 발동 순서**:
```
1. 히어로 발사 -> 큐브 HP 감소
2. HP <= 0인 큐브 파괴
3. 파괴된 큐브의 인접 4방향 확인
4. 각 인접 큐브에 Crack +1 부여 (아머가 있으면 아머 -1)
5. Crack >= 2인 큐브가 있는가? -> YES면 해당 큐브 파괴
6. 5에서 파괴된 큐브에 대해 3~5 반복 (연쇄)
7. 더 이상 파괴할 큐브가 없으면 연쇄 종료
8. 시각 연출: 균열선 확산 (0.3초/단계) + 파괴 폭발 (0.5초)
9. 히어로 발사 페이즈 계속
```

### 2.2 지역 연결

심수보는 홍콩에서 가장 오래된 구시가지 중 하나다. 50년 이상 된 唐樓(당루)이 밀집해 있고, 건물 기초의 노후화가 현실적인 문제다.

- **서사적 의미**: ARIA가 "재개발 우선 대상"으로 분류한 이유 자체가 노후 건물이다. 글리치가 콘크리트에 침투하여 기초를 더욱 약화시키고 있다. 균열 메카닉은 이 물리적 현실을 퍼즐에 직접 반영한다.
- **메카닉적 연결**: 균열 연쇄는 보스 Terra의 "기초 흔들기(Foundation Shake)" 보드 행동의 약화 버전이다. 일반 스테이지에서 균열의 전파를 경험한 플레이어는 보스전에서 더 큰 규모의 구조적 붕괴를 만나게 된다.
- **감정적 리듬**: "하나를 무너뜨리면 연쇄적으로 무너진다" -- 이것은 낡은 건물의 구조적 취약성이자, 이 챕터에서 밝혀지는 진실의 파급 효과에 대한 메타포이기도 하다. 하나의 비밀(Elemental Harvester)이 밝혀지자 모든 전제가 무너진다.

### 2.4 전략적 영향

**균열이 플레이에 미치는 영향**:

1. **파괴 순서의 중요성**: 중앙 큐브를 먼저 파괴하면 사방에 균열이 퍼져 연쇄 확률이 높다. 가장자리부터 파괴하면 균열 전파가 제한된다. 플레이어는 "어디서 시작하느냐"를 전략적으로 판단해야 한다.
2. **연쇄 보너스**: 균열 연쇄로 파괴된 큐브도 스코어에 포함된다. 연쇄가 길수록 스코어가 높아진다 (연쇄 보너스 = 연쇄 단계 x 50점 추가).
3. **아머와의 상호작용**: Steel Pango의 아머는 균열을 흡수한다 (균열 대신 아머 -1). 아머 큐브를 먼저 공격하여 아머를 벗긴 후 균열 연쇄를 노리는 2단계 전략이 필요하다.
4. **의도치 않은 연쇄**: 균열이 예상치 못한 큐브를 파괴할 수도 있다. 남겨두고 싶은 큐브가 균열로 사라지는 상황을 방지하려면 파괴 순서를 신중히 선택해야 한다.

**대항 수단 (Counter)**: KAI의 Legendary 크리터 Ironcurl의 패시브 "대지 방벽(Earth Barrier)"은 벤치 슬롯을 보호한다. 2단계 이후에는 Earth 큐브 파괴 시 인접 큐브에 1 데미지(스플래시)를 부여하여, 균열 연쇄의 시작점을 더 효과적으로 만든다. 추가로, KAI가 파티에 있으면 보드의 사전 균열(Pre-cracked) 큐브가 시각적으로 강조 표시되어 연쇄 계획이 쉬워진다.

**참고 공식** (수치 바이블 Section 4):
```
AP 여유도 = 총 히어로 AP / 실제 필요 AP
실제 필요 AP = 총 큐브 HP x 1.3~1.5 (벨트 순환 빗나감 보정)

* Ch.4 보정: 균열 연쇄로 AP 없이 파괴되는 큐브가 있으므로,
  실제 필요 AP = (총 큐브 HP - 예상 연쇄 파괴 2~3개) x 1.4
```

### 7.2 AP 예산 예시 (스테이지 4-06 기준)

```
큐브 총 HP: 13 (T1 x7 = 7, T2 x2 = 4+아머2 = 6)
 -> 실효 HP: 13 (아머 포함)
이론 최저 AP: 13
균열 연쇄 예상 파괴: 2큐브 (AP 절약 -2)
실제 필요 AP: (13 - 2) x 1.4 = 15.4
히어로 수: 8 (평균 AP 2.5 = 총 AP 20)
여유도: 20 / 15.4 = 1.30 -> 기준 범위 (1.1~1.3) 충족
```
