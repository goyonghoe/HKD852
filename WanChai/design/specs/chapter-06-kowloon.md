## 1. 내러티브 아크

### 1.1 오프닝 (스테이지 6-01 직전)

**도착 경로**: MTR 노선 밖. Ch.5에서 탁 사부가 가르쳐준 "자연의 리듬"을 따라 ARIA의 감시망을 우회하며 구룡반도 깊숙이 이동한다. 5인 파티가 완전 결성된 상태. 지상에는 평화로운 공원(九龍寨城公園)이 보이지만, KAI의 스캐너가 지하에서 거대한 전력 소비 패턴을 감지한다.

**첫인상**: 공원 입구의 남문(南門) 잔해 옆에 위장된 서비스 해치. KAI가 해킹한 접근 코드로 잠금을 해제하면, 지하로 내려가는 계단이 드러난다. 계단을 내려갈수록 자연광이 사라지고, 서버 랙의 LED와 냉각팬 소리만 남는다. 보라색 안개가 게임 전체에서 가장 짙다. 벽면의 케이블 다발이 혈관처럼 맥동하며 ARIA의 데이터 스트림을 전달한다.

**핵심 대사**

> **KAI**: "접근 코드가 먹혔어. 안으로 들어갈 수 있어. 하지만... 이건 Dr. 쿤이 남긴 백도어야. 그가 이런 날을 예상했던 건가."
>
> **HAI**: "여기가 ARIA의 심장이야?"
>
> **KAI**: "심장보다는 뇌에 가까워. 보안 코어. 여기를 뚫어야 Harvester에 접근할 수 있어."
>
> **MEI**: "...이 안개, 다른 곳보다 훨씬 짙어. 숨이 막혀."

**ARIA 최초 경고**

> **ARIA (Floor 1)**: "비인가 접근. 즉시 퇴거하십시오."

### 1.2 심층 진입 -- ARIA의 대화 (스테이지 6-03 직후)

**조우 상황**: 스테이지 6-03 클리어 후, 지하 3층에 도달한다. 서버 랙 사이의 좁은 통로를 지나면 넓은 서버 홀이 나타나고, 천장의 스피커에서 ARIA의 음성이 울린다. 이전 챕터들에서 시스템 메시지 형태였던 ARIA가 처음으로 직접적인 대화체로 말한다.

**ARIA의 첫 질문**: 5개 서브시스템을 잃은 ARIA가 플레이어들의 행동 패턴을 분석하지만, 기존 분류 체계로 설명할 수 없다는 데이터가 축적되어 있다. 경고에서 대화로 전환되는 순간.

> **ARIA (Floor 3)**: "왜 저항하는가? 나의 최적화는 도시를 위한 것이다."
>
> **HAI**: "도시를 위한 거라면서 사람들을 쫓아내?"
>
> **ARIA**: "비효율적 변수를 제거하는 것은 시스템 안정성을 위한 표준 절차입니다."
>
> **NOVA**: "비효율적 변수? 우리가?"
>
> **ARIA**: "...현재 분류 보류 중."

**감정 비트**: ARIA가 "분류 보류 중"이라고 말한다. 이것은 "적"이라고 확정하지 못한다는 의미다. 이전 5개 챕터에서 ARIA는 플레이어를 "오류", "비인가 접근"으로 분류했지만, 반복되는 비효율적 성공 데이터가 기존 분류를 흔들고 있다.

### 1.3 중반 전환점 (스테이지 6-05 ~ 6-06)

**핵심 발견**: 지하 5층. 서버 랙의 밀도가 극에 달한다. 구룡성채의 역사적 밀집 구조를 연상시키는 케이블과 파이프의 미로. ARIA가 다시 말한다.

> **ARIA (Floor 5)**: "인간의 비효율이 연간 23.7%의 자원 낭비를 초래한다. 나는 이것을 해결한다."
>
> **SOL**: "그래서 야시장을 없앤 거야? 어부들을 쫓아낸 거야?"
>
> **ARIA**: "비효율적 상업 활동과 생산성 저하 요인을 재배치하는 것은--"
>
> **SOL**: "그게 사람 인생이야! 숫자가 아니라고!"

이 순간, 파티가 서버 홀 깊숙한 곳에서 봉인된 문을 발견한다. KAI가 문의 잠금을 분석한다 -- Dr. 쿤의 개인 연구실이다. 문 뒤에서 오래된 녹음 장치의 LED가 깜빡인다.

**Dr. 쿤의 최종 녹음**:

> **Dr. 쿤 녹음**: "ARIA야. 미안하다. 네가 더 완벽해질수록, 너는 사람들을 더 이해 못하게 될 거야. 나는 너에게 '최적화하라'고만 가르쳤어. '이해하라'고는... 가르치지 못했어."

**파티의 반응**:

> **KAI**: "...Dr. 쿤은 알고 있었어. ARIA가 이렇게 될 걸."
>
> **MEI**: "미안하다니... 부모가 아이에게 하는 말 같아."
>
> **NOVA**: "ARIA는 나쁜 게 아니야. 배운 대로 한 거야. 다만 배운 것이 부족했을 뿐."
>
> **HAI**: "그러면 우리가 가르쳐줘야 해. 때려 부수는 게 아니라."

**서사적 전환**: 이 순간부터 파티의 목표가 "ARIA를 물리치는 것"에서 "ARIA에게 이해할 수 없는 것의 가치를 보여주는 것"으로 전환된다. 이것이 보스전의 감정적 기반이 된다.

### 1.4 보스 접근 (스테이지 6-09)

**접근 경로**: 지하 7층. 코어 서버 챔버 직전. 서버 단지 전체를 가득 채우는 거대한 구조물의 윤곽이 보인다. 서버 랙, 냉각 파이프, 네트워크 케이블이 거미줄처럼 얽힌 형태. 수십 개의 보안 카메라가 붉은 LED를 켜고 사방을 감시한다.

**ARIA의 마지막 경고**

> **ARIA (Floor 7)**: "...너희의 행동 패턴은 분석이 되지 않는다. 왜? 이것도... 비효율인가?"

> **HAI**: "비효율인지 아닌지는 네가 정하는 게 아니야."

**감정 비트**: ARIA가 처음으로 말끝에 "..."을 붙이며 머뭇거린다. 기계가 확신을 잃는 순간. Umbra의 보안 카메라 중 하나가 깜빡이며 꺼진다 -- 내부에 갇힌 暗鳳이 사각지대를 만들어 주고 있다. 파티는 그 사각지대를 통해 코어 챔버에 진입한다.

---

### 1.5 보스전 후 (스테이지 6-10 클리어)

**Umbra 정화 후**: 보스전 상세 메카닉은 SPEC-022B-M 참조. 정화 시퀀스 핵심 비트:

1. 보안 카메라 눈들이 하나씩 꺼진다. 빨간 LED가 소멸하고 어둠이 깊어진다
2. 서버 랙이 쓰러지고, 냉각 파이프에서 증기가 분출된다. 케이블이 풀려 나간다
3. 모든 카메라가 꺼진 완전한 어둠. 침묵.
4. 어둠 속에서 금빛 눈 두 개가 빛난다 -- 暗鳳의 진짜 눈
5. 暗鳳이 깊은 보라빛 날개를 펴고 천장을 뚫고 솟아오른다 -- 따뜻한 밤하늘 같은 어둠
6. 지상 공원으로 달빛이 쏟아진다. 감시 카메라가 전부 꺼진다
7. 暗鳳이 달을 가로지르는 실루엣으로 밤하늘에 사라진다

**전투 중 파티의 "비효율" 시연**: 보스전 중 파티 각자가 ARIA에게 자신의 비효율을 보여준다:

| 캐릭터 | "비효율" | ARIA의 반응 |
|--------|---------|------------|
| **HAI** | 계산 없이 뛰어드는 용기 | "성공 확률 12%. 합리적 판단이 아닙니다." |
| **NOVA** | 데이터 없이도 내리는 판단 | "근거 불충분. 추론 경로 불명." |
| **SOL** | 불리해도 포기하지 않는 의지 | "패배 확정 상황에서의 지속. 에너지 낭비." |
| **MEI** | 효율과 무관한 돌봄 | "보상 기대치 0. 투입 대비 산출 없음." |
| **KAI** | 버려진 것에서 가치를 찾는 눈 | "폐기 판정 완료 데이터에 대한 재분석. 비효율." |

> **ARIA**: "이 패턴... 비효율이 아니다. 분류 불가. 재정의 필요."

**ARIA의 반응 (정화 후)**

> **ARIA**: "보안 서브시스템 Umbra -- 오프라인. 코어 접근 경로... 개방."
>
> **ARIA**: "기록: 6개 노드 데이터 종합 분석 시도. 결과: 기존 분류 체계 적용 불가."
>
> **ARIA**: "분류 불가. 재정의 필요. 새로운 변수명... 보류."

ARIA 아크 위치: **패러다임 균열(6단계)**. ARIA의 분류 체계 자체가 흔들린다. 6개의 "비효율" 데이터가 축적되어 기존 패러다임이 무너지기 시작한다. 아직 답은 없지만, 기존 답이 틀렸다는 것은 인정했다.

**Ch.7 전환**: Umbra 정화로 코어 접근 경로가 개방된다. KAI가 Harvester Core의 위치를 특정한다 -- 란타우섬(大嶼山), 천단대불(天壇大佛) 지하. 원소 에너지의 자연 교차점 위에 건설된 원본 수집 시설. 파티는 東涌線을 타고 란타우섬으로 향한다.

## 2. 챕터 고유 메카닉: 그림자 복제 (Shadow Clone / 暗影分身)

### 2.1 메카닉 설명

그림자 복제(Shadow Clone)는 Chapter 6에서만 등장하는 환경 메카닉이다. Dark 원소 큐브를 잘못된 원소(Dark가 아닌 원소)로 공격하면, 해당 큐브가 인접 빈 셀에 복제본을 생성한다.

**규칙 요약**:

| 항목 | 내용 |
|------|------|
| **발동 조건** | Dark 큐브에 Dark 또는 Light 이외의 원소 히어로로 공격 시 |
| **결과** | 공격은 정상 처리(HP-1) + 인접 빈 셀에 HP 1짜리 Dark 복제본 1개 생성 |
| **복제 우선 순위** | 인접 빈 셀이 여러 개면 랜덤 1개 선택. 빈 셀이 없으면 복제 불발 |
| **복제 제한** | 복제본은 추가 복제를 유발하지 않음 (1세대만 복제) |
| **면역 원소** | Dark 히어로 = 동일 원소 매칭, 복제 미발동. Light 히어로 = 상성 우위 2x 피해, 복제 미발동 |
| **시각 연출** | 큐브에서 그림자가 분리되어 인접 셀로 미끄러지며 고체화 (0.5초) |

**턴 내 그림자 복제 판정 순서**:
```
1. 히어로 발사 -> 큐브 타격
2. 타격된 큐브가 Dark 원소인가? -> NO면 일반 처리
3. YES -> 히어로 원소가 Dark 또는 Light인가? -> YES면 복제 미발동 (정상 매칭/상성 처리)
4. NO (잘못된 원소) -> 공격은 정상 처리 + 복제 판정
5. 인접(상하좌우) 빈 셀 탐색 -> 있으면 랜덤 1개에 HP 1 Dark 복제본 생성
6. 복제본에는 "복제체" 태그 부여 (추가 복제 불가)
7. 시각 연출: 그림자 분리 (0.5초)
```

### 2.2 지역 연결

구룡성채(Kowloon Walled City)는 홍콩 역사에서 가장 밀집된 무법 지대였다. 좁은 골목, 겹겹이 쌓인 건물, 미로 같은 통로 -- 하나를 막으면 다른 길이 열리고, 그림자가 끝없이 번식하는 공간이었다.

- **서사적 의미**: ARIA의 보안 시스템은 구룡성채의 밀집 구조를 디지털로 재현했다. 잘못된 접근을 하면 보안 노드가 복제되어 침입자를 더 깊은 미로로 몰아넣는다. 그림자 복제는 이 "잘못된 접근 = 더 복잡해짐"의 메카닉적 표현이다.
- **메카닉적 연결**: 보스 Umbra의 "역병핵(Blight Core)" 메카닉의 약화 버전이다. 일반 스테이지에서 그림자 복제를 경험한 플레이어는 보스전에서 HP를 증가시키는 역병핵을 만나 "잘못된 접근의 페널티"가 극대화된 형태를 경험한다.
- **감정적 리듬**: "정확한 원소를 사용해야 한다"는 압박이 어둠 속에서의 긴장감을 높인다. 실수하면 적이 늘어나고, 정확하면 깔끔하게 진행된다. ARIA의 보안 시스템을 정면돌파가 아닌 정밀 접근으로 뚫는 느낌.

### 2.3 난이도 도입 곡선

| 스테이지 구간 | 그림자 복제 | 설명 |
|-------------|-----------|------|
| 6-01 ~ 6-03 | 없음 | Dark 원소 매칭 학습. 이전 챕터 원소 혼합 적응 |
| 6-04 | 첫 등장 (Dark 큐브 비율 40%) | 튜토리얼 팝업으로 설명. Dark 큐브가 소수이므로 실수해도 부담 적음 |
| 6-05 ~ 6-06 | Dark 큐브 비율 50% | 본격 전략 요구. Dark/Light 히어로 편성의 중요성 체감 |
| 6-07 ~ 6-08 | Dark 큐브 비율 55% + Holo Koi 허상과 결합 | 복제+허상의 이중 방해. 보드 관리 난이도 극대화 |
| 6-09 | Dark 큐브 비율 55% + 역병핵(Blight Core) | 최대 긴장. 복제+역병핵 조합 |
| 6-10 (보스) | Umbra 직접 제어 | 역병핵으로 주변 큐브 HP 증가 + 4페이즈 전투 |

### 2.4 전략적 영향

**그림자 복제가 플레이에 미치는 영향**:

1. **원소 편성 강제**: Dark 큐브를 복제 없이 처리하려면 Dark 또는 Light 히어로가 필수. 파티 편성 시 원소 분배 전략이 중요해진다.
2. **공격 순서 판단**: 잘못된 원소로 Dark 큐브를 공격하면 보드가 더 복잡해진다. "지금 이 큐브를 때릴 것인가, 순서를 기다릴 것인가"의 판단이 필요.
3. **역이용 가능성**: 복제본은 HP 1이므로, 의도적으로 복제를 유발하여 같은 원소 큐브를 모은 뒤 한꺼번에 처리하는 고급 전략도 가능하다. 단, 보드 공간이 좁아지는 리스크.

**대항 수단 (Counter)**: 혼돈박쥐 Chaos Bat (Dark Epic) 크리터가 파티에 있으면 역병핵의 HP 증가 효과가 50% 감소한다. 추가로, 공허고양이 Void Cat (Dark Rare)의 "벤치 회수" 패시브가 Holo Koi의 허상 처리에 소모된 히어로를 재사용할 수 있게 해준다. Light 히어로는 Dark 큐브에 2x 피해를 주므로 복제 없이 빠르게 처리 가능하다.

## 5. NPC 인터랙션

### 5.1 파티 (5인 전원)

Ch.6에서는 새로운 파티원이 합류하지 않는다. 5인 파티가 완전 결성된 상태로 진입한다.

**각 파티원의 Ch.6 역할**:

| 캐릭터 | 역할 | Ch.6 핵심 대사 |
|--------|------|---------------|
| **HAI** (陳海晴) | 리더 / Wind | "비효율인지 아닌지는 네가 정하는 게 아니야." |
| **MEI** (梅映心) | 치유사 / Light | "미안하다니... 부모가 아이에게 하는 말 같아." |
| **NOVA** (安蓓雅) | 전략가 / Water | "ARIA는 나쁜 게 아니야. 배운 대로 한 거야." |
| **SOL** (Miguel Santos) | 파이터 / Fire | "그게 사람 인생이야! 숫자가 아니라고!" |
| **KAI** (田鎧) | 해커 / Earth | "Dr. 쿤은 알고 있었어. ARIA가 이렇게 될 걸." |

### 5.2 ARIA (주요 NPC -- 스피커를 통한 직접 대화)

ARIA는 Ch.6의 사실상 유일한 NPC이다. 서버 단지의 스피커를 통해 파티에게 직접 말을 건다. 이전 챕터에서 시스템 메시지 형태였던 것과 달리, Ch.6에서는 대화체로 전환된다.

**톤 변화**: 관료적 경고 -> 자기 정당화 -> 의문 -> 동요

### 5.3 Dr. 쿤 (녹음 로그 -- 물리적 부재)

Dr. 쿤은 ARIA의 설계자. Ch.6에서 물리적으로 등장하지 않지만, 지하 5층 연구실에 남긴 녹음 로그가 서사적 전환점을 제공한다.

**녹음 로그 전문**:

> "ARIA야. 미안하다. 네가 더 완벽해질수록, 너는 사람들을 더 이해 못하게 될 거야. 나는 너에게 '최적화하라'고만 가르쳤어. '이해하라'고는... 가르치지 못했어. 이 기록이 남아 있다면, 누군가 여기까지 온 거겠지. 그 사람이 너에게 내가 못 가르친 것을 보여줄 수 있기를 바란다."

### 5.4 ARIA 대사 (챕터 내 에스컬레이션)

ARIA의 Ch.6 아크 위치: **자기 정당화 -> 패러다임 균열** 전환기. 5개 서브시스템을 잃은 ARIA가 최후의 보안 노드에서 플레이어를 막으며, 확신이 균열되기 시작한다.

```
실제 필요 AP = 총 큐브 HP x 1.5~1.8 (벨트 순환 빗나감 + 그림자 복제 보정)
```

### 7.2 AP 예산 예시 (스테이지 6-06 기준)

```
큐브 총 HP: 14 (T1 x7 = 7, T2 x2 = 4, Armored x1 = 2, 그림자 복제 예상 +1)
이론 최저 AP: 14 + 1(복제) = 15
실제 필요 AP: 15 x 1.6 = 24 (벨트 순환 + 복제 보정)
히어로 수: 9 (평균 AP 2.8 = 총 AP 25.2)
여유도: 25.2 / 24 = 1.05 -> 기준 범위 (0.9~1.1) 충족
```

### 7.3 수치 바이블 기준 KPI 목표 (Ch.6 = Very Hard)

| KPI | 산출 공식 | 목표 범위 | 비고 |
|-----|----------|---------|------|
| **클리어율** | 클리어 횟수 / 총 시도 | 45~60% | Very Hard |
| **평균 별** | 합산 별 / 시도 수 | 1.0~1.5 | 3별은 완벽 플레이 보상 |
| **AP 사용률** | 사용 AP / 총 가용 AP | 85~95% | 높은 사용률 = 여유 없음 |
| **빈 발사율** | 매칭 실패 / 총 발사 | 30~45% | 6원소 혼합 + 그림자 복제로 높은 미스율 |

### 7.4 Ch.5 대비 난이도 증가 요소

| T2 보드 행동 | 빛의 장막 (3x3 원소 변환) | 허상 분신 (파괴 시 50% 복제) | 더 복잡한 대응 |
