## 요약

기존 추상적 히어로(원형 원소 구체)를 **동물 기반 수집 유닛 "크리터(Critter)"**로 대체한다. 원소별 3종씩 총 18종의 기본 크리터가 있으며, 각각 레벨업/진화/패시브 스킬을 보유한다. 크리터는 영구 컬렉션에 수집되며, 런마다 파티를 편성하여 출격한다.

## 2. 크리터 스탯 구조

### 2.1 데이터 모델

```typescript
interface CritterDefinition {
  id: string;                  // "fire_fox", "water_otter" 등
  name: string;                // "불여우"
  nameEn: string;              // "Flame Fox"
  element: ElementColor;       // "fire"
  rarity: 'common' | 'rare' | 'epic';
  baseAP: number;              // 기본 AP (레벨 1 기준)
  passive: PassiveSkillId;     // 패시브 스킬 ID
  secondPassive?: PassiveSkillId; // 레벨 7에서 해금
  ultimate?: UltimateSkillId;  // 레벨 10에서 해금
  evolutionId?: string;        // 진화 후 크리터 ID
  evolutionLevel: number;      // 진화 가능 레벨 (기본 5)
  description: string;         // 도감 설명 (한글)
  descriptionEn: string;       // 도감 설명 (영문)
}

interface CritterInstance {
  definitionId: string;        // CritterDefinition.id 참조
  instanceId: string;          // 개체 고유 UUID
  level: number;               // 현재 레벨 (1~10)
  exp: number;                 // 현재 경험치
  isEvolved: boolean;          // 진화 여부
}
```

### 2.2 속성 계층 분류 (수치 바이블 Section 2)

| 계층 | 속성 | 설명 |
|------|------|------|
| **1차** | AP (Attack Power) | 정화 에너지, 전투 직접 참여 |
| **1차** | Element (원소) | 매칭 대상 결정 |
| **2차** | 패시브 스킬 | 조건부 보너스, 전투 양상 변화 |
| **2차** | 레어리티 | 기본 AP 차이, 패시브 풀 범위 |
| **3차** | 레벨 | AP 보정값, 패시브 강화 |
| **3차** | 진화 | 패시브/AP 추가 보정 |

### 2.3 AP 패널 공식

```
실제 AP = baseAP + levelBonus + evolutionBonus + relicBonus + hometownBonus

levelBonus  = floor((level - 1) / 2)    → Lv1=0, Lv2=0, Lv3=1, Lv4=1, Lv5=2, ...Lv10=4
evolutionBonus = isEvolved ? 1 : 0
relicBonus  = 유물 효과 (런 내)
hometownBonus = 대장간 레벨 (영구)
```

| 레어리티 | Base AP | Lv1 | Lv3 | Lv5 | Lv7 | Lv10 | 진화 후 Lv10 |
|---------|---------|-----|-----|-----|-----|------|-------------|
| Common | 2 | 2 | 3 | 4 | 5 | 6 | 7 |
| Rare | 3 | 3 | 4 | 5 | 6 | 7 | 8 |
| Epic | 4 | 4 | 5 | 6 | 7 | 8 | 9 |

### 2.4 대항 속성 쌍 (수치 바이블 Section 8)

| 크리터 속성 | 대항 속성 | 균형 메카닉 |
|-----------|----------|-----------|
| AP (공격력) | 적 HP (내구도) | AP 1 = 적 HP 1 소거 |
| 레벨 (AP+) | Floor 난이도 (적 HP+) | 레벨업 속도 < 난이도 스케일링 |
| 패시브 (특수 효과) | 적 특수 능력 (아머, 흡수 등) | 패시브 1개 = 특수 적 1종 상쇄 |
| 파티 크기 (9) | 보드 크기 + 원소 다양성 | 원소 커버리지 = 1.0 유지 |

## 3. 레벨 시스템

### 3.1 레벨업 테이블

| 레벨 | 필요 경험치 | 누적 경험치 | 해금 | AP 변화 |
|------|-----------|-----------|------|---------|
| 1 | - | 0 | 기본 상태 | baseAP |
| 2 | 100 | 100 | - | baseAP (변화 없음) |
| 3 | 200 | 300 | 패시브 강화 | baseAP + 1 |
| 4 | 350 | 650 | - | baseAP + 1 |
| 5 | 500 | 1150 | **진화 가능** | baseAP + 2 |
| 6 | 700 | 1850 | - | baseAP + 2 |
| 7 | 1000 | 2850 | **2번째 패시브 해금** | baseAP + 3 |
| 8 | 1400 | 4250 | - | baseAP + 3 |
| 9 | 1900 | 6150 | - | baseAP + 4 |
| 10 | 2500 | 8650 | **궁극기 해금** | baseAP + 4 |

### 3.2 경험치 획득원

| 원천 | 경험치 | 조건 |
|------|--------|------|
| 전투 출격 | 50~100 | 스테이지 클리어 시 출격 크리터 |
| 킬 기여 | 20/kill | 직접 파괴한 적 수 |
| 런 클리어 | 200 | 보스 격파 시 파티 전원 |
| 휴식 노드 훈련 | 150 | 택1 효과로 선택 시 |
| 상점 레벨업 | 즉시 레벨업 | 정화 점수 소비 |
| 홈타운 훈련소 | 일일 50 | 메타 진행 |

### 3.3 성장 곡선 (수치 바이블 Section 6)

경험치 요구량은 **가속 성장 곡선**을 따른다:

```
필요 경험치(n) = 100 * n^1.3   (소수점 절사, 100 단위 반올림)
```

이는 초반 빠른 레벨업 → 후반 느린 성장으로, 단기 성취감 + 장기 목표를 모두 제공한다.

```
레벨업 속도 그래프 (런 횟수 기준):
  Lv
  10 ┤                          ●
   8 ┤                    ● ●
   6 ┤              ● ● ●
   4 ┤        ● ● ●
   2 ┤  ● ● ●
   0 ┼──────────────────────────
     0  2  4  6  8  10  12  런 횟수
```

## 5. 진화 시스템

### 5.1 진화 조건

| 조건 | 값 |
|------|-----|
| 최소 레벨 | 5 |
| 진화 재료 | 같은 원소 크리터 1마리 (소멸) |
| 진화 비용 | 정화 점수 500 (메타 통화) |

### 5.2 진화 효과

| 항목 | 변화 |
|------|------|
| AP | +1 (영구) |
| 외형 | 진화 스프라이트로 변경 |
| 이름 | 진화명으로 변경 |
| 패시브 | 변화 없음 (레벨 기반 강화는 유지) |
| 레어리티 | 변화 없음 |

### 5.3 진화 트리

```
Common (Lv5+) ──진화──→ Common+ (진화명)
Rare (Lv5+)   ──진화──→ Rare+ (진화명)
Epic (Lv5+)   ──진화──→ Epic+ (진화명)
```

진화는 **1단계만** 존재한다 (추후 2단계 진화 확장 여지).

### 5.4 진화 전/후 비교 예시

| 크리터 | 진화 전 (Lv5) | 진화 후 (Lv5) | 진화 후 (Lv10) |
|--------|-------------|-------------|--------------|
| 불여우 → 화염여우 | AP=4, 관통(강화) | AP=5, 관통(강화) | AP=7, 관통+흡수, 궁극기 |
| 화염도롱뇽 → 용암도롱뇽 | AP=5, 스플래시(강화) | AP=6, 스플래시(강화) | AP=8, 스플래시+저주, 궁극기 |
| 아기용 → 화염드레이크 | AP=6, 연타(강화) | AP=7, 연타(강화) | AP=9, 연타+스플래시, 궁극기 |

추가로 **바람토끼**(Wind Common)와 **빛사자**(Light Common)를 무료 지급하여 초기 파티 5명 확보.

### 6.2 획득 경로

| 경로 | 크리터 종류 | 빈도 |
|------|-----------|------|

|---------|--------|------|
| Common | 60 | 60% |
| Rare | 30 | 30% |
| Epic | 10 | 10% |
