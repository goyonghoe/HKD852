## 2. 페이즈 구조 & HP 배분

**총 HP: 50** (Ch.5 x1.7 스케일링)

| 페이즈 | HP | 비율 | 명칭 | 기계 상태 |
|--------|-----|------|------|----------|
| Phase 1 | 20 | 40% | **프리즘 관측 모드** | 결정체 전면(全面) 건재, 위성 궤도 안정, 보라색 필터 최대 |
| Phase 2 | 18 | 36% | **빛의 분산 모드** | 결정체 표면 균열 시작, 위성 궤도 불안정, 보라색 필터 약화, 순백광 누출 |
| Phase 3 | 12 | 24% | **기린의 각성** | 위성 추락, 결정 면 다수 탈락, 기린의 눈 -- 연민의 시선 가시 |

### 페이즈 전환 연출

- **P1->P2**: 결정체 표면에 첫 번째 균열이 달리며 프리즘 면이 갈라진다. 무지갯빛 파편이 사방으로 흩어진다 (1초). 기린의 뿔에서 나오는 빛이 보라색 필터를 뚫고 순백 광선 하나를 쏘아올린다. ARIA 대사: "에너지 관리 효율 저하 중. 질문: 이 공간에서 소비되는 에너지는 무엇을 생산하는가? ...이것도 비효율인가?"
- **P2->P3**: 위성들이 궤도를 잃고 하나씩 보드 주변으로 떨어진다 (1.5초). 결정체 핵심부에서 순백색 빛의 기둥이 치솟으며, 기린의 실루엣이 또렷해진다. 기린의 눈이 보인다 -- 분노도 슬픔도 아닌, 깊은 연민의 시선. 플레이어를 향한 따뜻한 빛.

## 3. 페이즈별 퍼즐 기믹

### Phase 1: 프리즘 관측 모드

**보스 패시브 -- Prism Refraction (프리즘 굴절)**
- **타이밍**: 매 2턴 종료 시 (턴 2, 4, 6...)
- **효과**: 보드 내 큐브 1개를 랜덤 선택하여 원소를 사이클 상 다음 원소로 변환
- **원소 사이클**: Fire -> Wind -> Earth -> Water -> Fire (4원소 순환), Light <-> Dark (상호 전환)
- **대상 선택**: 보드 내 모든 큐브 중 랜덤 1개. 이미 Light인 큐브도 대상 가능 (Light -> Dark 변환)
- **시각**: 결정체에서 프리즘 광선이 대상 큐브를 비추며, 큐브 색이 무지갯빛으로 회전한 뒤 새 원소로 안착 (0.5초)
- **영향**: 보드 원소 구성이 서서히 변화. 플레이어가 계획한 매칭 타겟이 변경될 수 있음. 1개뿐이므로 영향은 제한적

**보스 액티브 -- 없음** (Phase 1은 패시브만)

**학습 의도**: Ch.5 전체에서 경험한 Prism Reflect(빛 큐브 파괴 시 반사 피해)의 반대 관점. 보스가 보드를 직접 변형한다. 1개 큐브만 변하므로 압도적이지 않으면서 "보스가 원소를 조작한다"를 체감시킴. Light->Dark 변환 가능성은 Dark 큐브 출현을 예고하며, Light<->Dark 상성을 활용한 2x 피해 기회를 제공한다.

### Phase 2: 빛의 분산 모드

**보스 패시브 -- Prism Refraction+ (강화)**
- Phase 1과 동일 사이클/타이밍이지만, 매 2턴에 **2개** 큐브를 동시에 변환
- 2개 큐브는 각각 독립 랜덤 선택 (같은 큐브 중복 선택 불가)
- **시각**: 프리즘 광선이 2갈래로 갈라져 각각 큐브를 비춤

**보스 액티브 -- Light Barrier (빛의 보호막)**
- **발동 조건**: Phase 2 HP가 9 이하로 떨어지는 순간 (50% 임계값)
- **효과**: 보스가 즉시 HP +2 자가 회복 (1회 한정, 재발동 없음)
- **시각**: 결정체가 순간적으로 밝아지며 무지갯빛 실드 이펙트 (0.8초). 회복량이 HP바 위에 +2 팝업으로 표시
- **대항**: 1회 한정이므로 전략적 대응 불필요. 실질적으로 Phase 2의 유효 HP를 18 -> 20으로 만드는 효과. 플레이어에게 "보스가 버틴다"는 긴장감 제공

**학습 의도**: Prism Refraction이 2배로 강화되어 보드 변동성 증가. Light Barrier는 "보스가 자기 자신을 보호한다"는 개념 도입. 1회 한정이므로 위협보다는 서사적 강조 -- 기린이 해방되기를 거부하는 ARIA의 저항. 난이도 실질 증가는 원소 변환 2개에 의한 계획 교란.

### Phase 3: 기린의 각성

**보스 패시브 -- Prism Refraction++ (최대 강화)**
- 매 2턴에 **3개** 큐브를 동시에 변환
- 3개 큐브는 각각 독립 랜덤 선택 (중복 없음)
- **시각**: 프리즘 광선이 3갈래로, 결정체 균열 사이에서 직접 발사

**보스 액티브 -- Element Storm (원소 폭풍)**
- **타이밍**: 매 4턴 종료 시 (턴 4, 8, 12...)
- **효과**: 보드 위 **모든** 큐브의 원소가 사이클 상 다음 원소로 1단계 동시 회전
  - Fire -> Wind, Wind -> Earth, Earth -> Water, Water -> Fire
  - Light -> Dark, Dark -> Light
- **영향**: 보드 전체의 원소 맵이 한 번에 뒤집힌다. 원소 비율 자체는 유지되지만 위치별 원소가 바뀌므로, 플레이어의 매칭 계획이 전면 재수립 필요. 4턴 주기이므로 2~3턴의 안정 구간이 보장됨
- **시각**: 결정체에서 무지갯빛 충격파가 원형으로 퍼지며 (0.7초), 모든 큐브가 동시에 색상 전환 애니메이션 재생. 화면 가장자리에 무지갯빛 프레임 이펙트
- **대항 속성 쌍**: Element Storm(원소 재배치) <-> 히어로 원소 다양성(5원소 커버리지). 풀 파티(5원소)이므로 어떤 원소 배치가 와도 매칭 가능. 단일 원소 편중 편성일수록 불리

**학습 의도**: Ch.5 최종 시험. Prism Refraction 3개 + Element Storm 전체 회전이 결합되어 보드가 끊임없이 변한다. 그러나 5인 풀 파티의 5원소 커버리지가 이를 상쇄한다. 핵심 교훈: "변화에 대응하려면 다양성이 필요하다" -- 탁 사부의 "자연의 리듬" 가르침의 메카닉적 표현. 기린의 눈이 보이는 Phase 3에서 전투가 격렬할수록, 기린의 고요한 시선이 대비를 이루어 "아름다운 것을 부수어야 한다"는 감정적 긴장을 극대화한다.

### 4.3 원소 분포 상세

| 원소 | 비율 | 큐브 수 (30칸 중) | 근거 |
|------|------|-----------------|------|
| **Light** | 65~70% | 19~21 | Ch.5 주 원소. 보스 테마 + Prism Fly/Fiber Lion |
| **Dark** | ~5% | 1~2 | Light<->Dark 상성 2x 피해 기회 제공. Ch.6 예습 |
| **Wind** | ~8% | 2~3 | HAI 매칭 대상 |
| **Fire** | ~7% | 2 | SOL 매칭 대상 |
| **Earth** | ~7% | 2 | KAI 매칭 대상 |
| **Water** | ~5% | 1~2 | NOVA 매칭 대상 |

> **설계 의도**: Light 과다 분포는 MEI(Light)에 유리하지만, 나머지 4인의 매칭 타겟이 부족. Prism Refraction이 원소를 변환하면 비Light 큐브가 생성되어 다른 히어로의 기회가 열린다. 보스 기믹이 오히려 파티 전체에 이득이 되는 역설적 구조 -- 탁 사부의 "꺾인 빛이 더 먼 곳을 비추기도 하지" 테마.

### 4.4 페이즈별 보드 변화

- **Phase 1**: T1 Prism Fly (HP 1) 주력. T2 Fiber Lion (HP 2) 소수 (1~2마리). Prism Refraction 1개/2턴에 의한 완만한 원소 변화
- **Phase 2**: T2 Fiber Lion 비율 증가 (30% -> 40%). Fiber Lion의 Light Veil이 비Light 큐브를 Light로 변환 -> Prism Refraction이 이를 다시 변환하여 혼란 증가. Light Barrier +2 HP 1회 회복
- **Phase 3**: T2 Fiber Lion 비율 50%. Element Storm에 의해 전체 원소가 4턴마다 사이클 회전. 보드가 무지갯빛으로 끊임없이 변화하는 시각적 스펙터클

## 5. 히어로 큐 가이드라인

| 항목 | 값 |
|------|-----|
| **큐 열 수** | 5열 (Wind, Water, Fire, Light, Earth) |
| **Light 큐 비율** | 35% (MEI 주력) |
| **Wind 큐 비율** | 20% (HAI) |
| **Earth 큐 비율** | 20% (KAI) |
| **Fire 큐 비율** | 15% (SOL) |
| **Water 큐 비율** | 10% (NOVA) |
| **평균 AP** | Light 3.0, Wind 2.8, Earth 2.8, Fire 2.5, Water 2.5 |
| **벤치 슬롯** | 3개 |
| **자동 추천** | Light 우선 (보드 Light 비율 > 60%) |

### 전략 가이드

- **기본 전략**: MEI(Light) 히어로로 T1 Prism Fly를 빠르게 처리하며, 프리즘 반사(Ch.5 메카닉)로 인접 큐브에 보너스 1 HP 피해. T2 Fiber Lion은 HP 2이므로 2회 타격 또는 상성 2x 피해로 1회 처리
- **Dark 큐브 활용**: Light<->Dark 상성에 의해 MEI(Light)가 Dark 큐브 공격 시 2x 피해, 1.5x 스코어. 소수의 Dark 큐브는 높은 점수 기회
- **비Light 원소 역할**: Prism Refraction이 매 2턴 원소를 변환하므로 비Light 큐브가 새로 생성됨. HAI(Wind), KAI(Earth), SOL(Fire), NOVA(Water)가 이를 처리. Element Storm(Phase 3) 후에는 보드 전체 원소가 1단계 회전하므로 5원소 모두 활용
- **벤치 활용**: 현재 보드에 매칭 타겟이 적은 원소의 히어로를 벤치에 보관. Prism Refraction/Element Storm 후 보드 상태를 확인하고 벤치에서 꺼내 투입
- **Fiber Lion Light Veil 대응**: Fiber Lion이 3턴마다 인접 큐브를 Light로 변환. 이를 역이용하여 반사 네트워크 확장 가능. 또는 Fiber Lion을 우선 처리하여 변환 중단

## 6. 정화 시퀀스

> SPEC-022B 6.6 참조. 7-beat 해방 연출.

1. **균열**: 결정체 표면에 균열이 달리고, 보라색으로 필터링되던 빛이 순수한 백색으로 새어나온다
2. **프리즘 해체**: 결정체 면이 하나씩 떨어져 나간다. 각 면이 떨어질 때마다 무지갯빛 파편이 흩어진다
3. **빛의 기둥**: 결정체 핵심부에서 순백색 빛의 기둥이 사자산 정상에서 하늘로 솟아오른다
4. **기린 출현**: 빛 기둥 안에서 기린이 한 발자국씩 걸어 나온다. 뿔에서 부드러운 빛, 발자국마다 꽃
5. **축복**: 기린이 고개를 숙이고, 뿔에서 빛의 고리가 퍼져나간다. 사원 등불이 다시 타오른다
6. **승천**: 기린이 빛의 길을 따라 하늘로 올라간다. 사자산 위에 별 하나가 반짝인다
7. **구역 변화**: 황대선사 등불 점등, 정원 물 순환 재개, 향 연기 자연 피어오름. 탁 사부가 "자연의 리듬"을 전수

## 7. ARIA 대사

> SPEC-022B 6.5 참조. 전투 전(효율의 제단), 전투 중(의심의 시작), 정화 후(분류 불가의 고백).

**전투 전 -- 효율의 제단**
> "에너지 효율 최적화 모드. 비효율적 원소 배치를 재정렬합니다."
> "이 사원의 연간 에너지 소비량은 주거 건물 120호 분입니다. 비생산적 공간으로 분류합니다."

**전투 중 -- 의심의 시작 (P2 전환 시)**
> "에너지 관리 효율 저하 중. 질문: 이 공간에서 소비되는 에너지는 무엇을 생산하는가? ...이것도 비효율인가?"

**정화 후 -- 분류 불가의 고백**
> "에너지 관리 서브시스템 Lumen -- 오프라인. 전 구역 에너지 분배 수동 전환."
> "기록: 비생산적 공간에서 관측 불가능한 출력 감지. 분류... 보류."
> "...너희의 행동 패턴은 분석이 되지 않는다. 왜? 이것도... 비효율인가?"

ARIA 아크 위치: **의심 시작(5단계)**. "분류 보류"는 ARIA로서 전례 없는 판단 유보.

| **AP 효율 마진** | 1.0~1.2 (Hard) | CH-05 7.1: Ch.5 목표 여유도 |
| **총 AP 공급 (예상)** | ~65 AP (20턴 기준) | 5열 평균 AP 2.72 x 약 4.8히어로/열/20턴 |
| **클리어 기대 턴수** | 16~22턴 | AP 65 / HP 52 = 마진 1.25 (반사 미활용) / 반사 활용 시 실질 여유도 ~1.1 |
| **T2 비율** | 30~50% (페이즈별) | CH-05 4.1: 5-10 보스 스테이지 T2 비율 |
| **프리즘 반사 보정** | AP 실질 필요량 10~15% 감소 | CH-05 7.1: 반사에 의한 "무료 피해" |

### 8.2 AP 예산 상세 분석

```
총 보스 HP: 50 (+ Light Barrier 2 = 실질 52)
이론 최저 AP: 52 (매 발사 적중 시)
벨트 순환 빗나감 계수: x1.5
실제 필요 AP (반사 미활용): 52 x 1.5 = 78
프리즘 반사 보정 (Light 65% 보드): x0.85
실제 필요 AP (반사 활용): 78 x 0.85 = 66.3
상성 보정 (Dark 큐브 2x + 반사 활용): x0.90
실제 필요 AP (최적 플레이): 66.3 x 0.90 = 59.7

히어로 공급:
  - 5열, 평균 AP 2.72
  - 20턴 기준: ~65 AP (큐 소진 + 벤치 활용)
  - 22턴 기준: ~72 AP

여유도:
  - 반사 미활용 (20턴): 65 / 78 = 0.83 -> 클리어 불가능 (AP 부족)
  - 반사 활용 (20턴): 65 / 66.3 = 0.98 -> 매우 타이트
  - 최적 플레이 (20턴): 65 / 59.7 = 1.09 -> Hard 적정
  - 최적 플레이 (22턴): 72 / 59.7 = 1.21 -> Hard 상한
```

> **핵심**: 프리즘 반사를 활용하지 않으면 클리어가 사실상 불가능한 설계. Ch.5 고유 메카닉 학습이 보스전 클리어의 전제 조건. 반사 + 상성 활용을 모두 적용한 최적 플레이가 1.0~1.2 여유도.

### 8.3 별(Star) 기준

| 별 | 조건 | 난이도 |
|----|------|--------|
| ★ | 클리어 (HP 0 도달) | 기본 |
| ★★ | 20턴 이내 클리어 | 보통 |
| ★★★ | 16턴 이내 + AP 사용률 60%+ | 어려움 |

### 8.4 ★★★ 달성 분석

```
16턴 AP 공급: ~52 AP (5열 x 16턴 x 평균 3.25히어로/턴)
실질 HP: 52
필요 효율: 52 / 52 = 1.0 (AP 100% 적중 + 반사 최대 활용 필수)
AP 사용률 60%+ 조건: 사용 AP / 총 가용 AP >= 0.6
  - 16턴 총 가용 AP ~52 -> 사용 AP >= 31.2
  - 반사로 절약한 AP가 "미사용"으로 카운트되므로, 반사를 극대화하면서도 60%를 넘어야 함
  - 실질적으로 반사 최적화 + 빈 발사 최소화가 동시에 필요
```

> ★★★ 달성은 반사 전략 마스터리 + 원소 상성 활용 + Element Storm 대응을 모두 요구하는 최상위 도전.

### 8.5 실패 안전장치

- **Phase 1의 완만한 도입**: Prism Refraction 1개만 변환, 20 HP로 적당한 길이. 보스전 리듬을 파악할 시간 제공
- **Light Barrier 1회 한정**: Phase 2에서 1회만 발동하므로 예측 가능. 무한 회복에 의한 교착 없음
- **Element Storm 4턴 주기**: Phase 3에서도 3턴의 안정 구간이 보장됨. "폭풍 후 고요"의 리듬
- **5원소 풀 파티**: 어떤 원소 배치에도 최소 1명의 히어로가 매칭 가능. 단일 원소 편성의 취약점을 파티 구성으로 상쇄
- **반사 메카닉**: Light 큐브 비율 65~70%이므로 반사 기회가 풍부. 의도하지 않은 반사 피해가 클리어를 보조
- **재도전**: 실패 시 즉시 재도전 가능

## 9. 기믹 상세 규칙

### 9.1 Prism Refraction 원소 변환 규칙

| 현재 원소 | 변환 결과 | 비고 |
|----------|----------|------|
| Fire | Wind | 4원소 순환 |
| Wind | Earth | 4원소 순환 |
| Earth | Water | 4원소 순환 |
| Water | Fire | 4원소 순환 |
| Light | Dark | 상호 전환 |
| Dark | Light | 상호 전환 |

- 변환된 큐브의 HP는 변하지 않음 (원소만 변환)
- T2 Fiber Lion도 변환 대상이 될 수 있음 (Light -> Dark 시 Light Veil 능력 유지, 원소만 변경)
- 시각: 대상 큐브에 무지갯빛 회전 이펙트 0.5초 -> 새 원소색으로 안착

### 9.2 Light Barrier 상세 규칙

| 항목 | 값 |
|------|-----|
| **발동 조건** | Phase 2에서 보스 잔여 HP <= 9 (50% 임계값) |
| **효과** | 보스 HP +2 즉시 회복 |
| **발동 횟수** | 1회 한정 (Phase 2 전체에서 1번만) |
| **발동 타이밍** | HP 감소 판정 직후, 다음 턴 시작 전 |
| **시각** | 결정체 무지갯빛 실드 0.8초 + "+2" 팝업 |
| **대항** | 1회 한정이므로 돌파 전략 불필요. 총 HP 52로 계산하면 됨 |

### 9.3 Element Storm 상세 규칙

| 항목 | 값 |
|------|-----|
| **발동 페이즈** | Phase 3 전용 |
| **타이밍** | 매 4턴 종료 시 |
| **효과** | 보드 위 모든 큐브가 사이클 상 다음 원소로 동시 변환 |
| **예외** | 없음 (T2 Fiber Lion 포함 전체 적용) |
| **HP 영향** | 없음 (원소만 변환) |
| **시각** | 무지갯빛 충격파 원형 확산 0.7초 -> 전체 큐브 색상 동시 전환 |
| **Prism Refraction과의 중첩** | Element Storm이 먼저 적용 -> 이후 같은 턴에 Prism Refraction이 추가 적용 가능 (같은 턴이면 Storm 후 Refraction 순서) |

### 9.4 기믹 타임라인 예시 (Phase 3)

```
턴 1: Prism Refraction 미발동 (홀수턴)
턴 2: Prism Refraction 3개 변환
턴 3: 안정
턴 4: Element Storm (전체 회전) -> Prism Refraction 3개 변환 (같은 턴)
턴 5: 안정
턴 6: Prism Refraction 3개 변환
턴 7: 안정
턴 8: Element Storm (전체 회전) -> Prism Refraction 3개 변환
...
```

> **리듬**: 4턴 중 턴 2는 소규모 변환, 턴 4는 대규모 전면 변환 + 소규모 변환. 턴 1, 3은 안정. 플레이어는 이 리듬을 읽고 안정 턴에 핵심 매칭을 집중하는 전략이 유효.
