### 페이즈 전환 연출

- **P1→P2** (HP 66%): 터빈 2기가 과열 → 폭발. 기계 파편 낙하 (1초). 화면 흔들림 (`BOSS_PHASE2_VFX: shakeIntensity 0.01, 300ms`). 균열 사이로 금빛 바람이 새어 나옴. ARIA 대사: "풍속 제어 노드 효율 저하 감지."
- **P2→P3** (HP 33%): 기상 위성 안테나 왕관이 꺾이며 떨어짐 (1.5초). 독수리 울음소리가 기계 노이즈 사이로 들림. 보라색 에너지 약화, 금빛 강화. 보스 글로우 변경 (`bossPhase2GlowColor`).

## 3. 페이즈별 전투 메카닉

### Phase 1: 기상 관측 모드 (HP 100% → 67%)

**보스 행동 — boss_burst 기본**

- 느린 이동 (속도 15 px/s) — 화면 좌우를 천천히 오감
- 기본 범위 공격 (데미지 45)

**바람 소용돌이 — Wind Deflection (Phase 1 전용)**

| 항목     | 내용                                                                       |
| -------- | -------------------------------------------------------------------------- |
| **효과** | 플레이어 투사체가 보스 주변 200px 내 진입 시 진행 방향에서 ±15도 편향      |
| **영향** | bullet/homing 타입 명중률 약 80%로 저하. laser(관통 99)는 영향 없음        |
| **시각** | 보스 주위로 회전하는 바람 소용돌이 이펙트 (보라색 입자)                    |
| **대응** | 레이저 계열 무기 우선, 가까운 거리에서 사격하여 편향 최소화                |
| **상수** | `BOSS_AERO_WIND_DEFLECT_ANGLE: 15` (도), `BOSS_AERO_WIND_RADIUS: 200` (px) |

**학습 의도**: "이 보스는 원거리에서 쏘면 안 맞는다" → 가까이 접근하거나 관통 무기를 사용해야 함. 첫 보스이므로 편향 각도가 작아 체감 난이도는 낮음.

### Phase 2: 돌풍 강화 모드 (HP 66% → 34%)

**보스 행동 — boss_burst Phase 2**

- 속도 x1.3 (15 → ~20 px/s)
- 데미지 x1.3 (45 → ~59, maxBossAtk 200 캡 내)

**Wind Deflection 유지** (Phase 1과 동일)

**돌풍 강화 — Gust Surge (Phase 2 신규)**

| 항목     | 내용                                                                      |
| -------- | ------------------------------------------------------------------------- |
| **효과** | 적 스폰율 50% 증가. drone형 적(shooter) 추가 스폰                         |
| **주기** | Phase 2 진입 즉시 적용, 지속                                              |
| **시각** | 화면 상단에서 돌풍 이펙트와 함께 적 대량 하강                             |
| **영향** | 보스 + 다수 잡몹 동시 대응 필요. AOE/체인 무기 가치 상승                  |
| **대응** | 범위 무기(에너지 폭탄, 네이팜, 체인 라이트닝)로 잡몹 처리하면서 보스 딜링 |
| **상수** | `BOSS_AERO_SPAWN_BOOST: 1.5`, `BOSS_AERO_DRONE_TYPE: 'shooter'`           |

**학습 의도**: "보스전에서도 잡몹 관리가 중요하다." 빌드 완성도(무기 4종)가 드러나는 구간.

### Phase 3: 최후 저항 (HP 33% → 0%)

**보스 행동 — boss_burst Phase 3**

- Phase 2 속도/데미지 유지 (x1.3)
- 이동 패턴 변경: 좌우 이동 → 대각선 지그재그 (기존 zigzag 패턴 적용)

**Wind Deflection 강화**

| 항목     | 내용                                                                   |
| -------- | ---------------------------------------------------------------------- |
| **효과** | 편향 각도 15도 → 25도. 편향 범위 200px → 250px                         |
| **영향** | 원거리 bullet 명중률 약 60%로 급감. 근접 또는 관통 필수                |
| **상수** | `BOSS_AERO_WIND_DEFLECT_ANGLE_P3: 25`, `BOSS_AERO_WIND_RADIUS_P3: 250` |

**최후 저항 — Eagle Dive (Phase 3 신규)**

| 항목          | 내용                                                                                                       |
| ------------- | ---------------------------------------------------------------------------------------------------------- |
| **효과**      | 10초마다 화면 전체에 돌풍 발생 — 플레이어를 3초간 좌측으로 밀어냄 (속도 -100 px/s)                         |
| **시각**      | 독수리 실루엣이 화면을 가로질러 날아가며, 강한 바람 이펙트                                                 |
| **영향**      | 플레이어 위치 강제 이동 → 적에게 노출되는 위치로 밀려남                                                    |
| **대응**      | 돌풍 방향 반대로 이동 입력하여 위치 유지. 또는 밀린 후 빠르게 복귀                                         |
| **기지 영향** | 돌풍 중 적이 기지를 공격할 확률 증가 (플레이어 견제 불가)                                                  |
| **상수**      | `BOSS_AERO_DIVE_INTERVAL_MS: 10000`, `BOSS_AERO_DIVE_PUSH_SPEED: -100`, `BOSS_AERO_DIVE_DURATION_MS: 3000` |

**학습 의도**: 첫 "화면 전체 영향" 메카닉. 위치 선택의 중요성을 가르치며, Phase 3의 극적 긴장감을 제공. 10초 주기이므로 예측 가능하고, 밀림 속도가 기본 이동속도(300)보다 훨씬 낮아 대응 가능.

## 4. 정화 시퀀스

> 보스 HP 0 도달 시 자동 트리거.

### 5-Beat 해방 연출

1. **Beat 1** (1초): 터빈이 하나씩 멈추고, 기계 외장에 균열 -- 균열 사이로 금빛 바람
2. **Beat 2** (1초): 기상 위성 안테나 왕관 추락, 풍향계 꼬리 꺾임, 기계 파편 낙하
3. **Beat 3** (1.5초): 금빛 빛이 강렬해지며 독수리의 실루엣이 선명해짐
4. **Beat 4** (2초): 잔여 기계 구조 일제 붕괴 -- 순수한 금빛 독수리 정령 비상
5. **Beat 5** (2초): 독수리가 원형의 바람 궤적을 남기며 피크 상공으로 상승. 중환의 보라색 안개가 걷히기 시작

**연출 총 시간**: ~7.5초

### 정화 후 효과

- 화면 밝기 증가, 보라 안개 소멸
- 에스컬레이터 정상 방향 복귀 (배경 아트 변경)
- "STAGE CLEAR" 오버레이 → 챕터 완료 화면
