## 2. 페이즈 구조 & HP 배분

**총 HP: 60** (Ch.6 x2.0 배율. SPEC-013B Section 6.3 기준)

| 페이즈 | HP | 비율 | 명칭 | 기계 상태 |
|--------|-----|------|------|----------|
| Phase 1 | 18 | 30% | **감시 전개 모드** | 보안 카메라 전수 점등, 서버 랙 전가동, 방화벽 완전 가동. 케이블이 거미줄처럼 촘촘 |
| Phase 2 | 15 | 25% | **방화벽 강화 모드** | 카메라 30% 파손, 서버 랙 일부 과부하. 방화벽 배리어가 보드에 개입. 케이블 균열로 보라빛 데이터 스트림 누출 |
| Phase 3 | 15 | 25% | **추적 프로토콜** | 카메라 60% 파손, 서버 대량 재부팅. 역병핵 2개 활성. 냉각 시스템 고장으로 증기 분출. 暗鳳의 날갯짓 잔상이 사각지대에 보임 |
| Phase 4 | 12 | 20% | **최후 데이터 분석** | 카메라 90% 파손. 기계 외장 반파. Umbra가 5개 정화된 보스의 데이터를 호출하여 마지막 저항. 暗鳳의 금빛 눈이 어둠 사이로 선명 |

### 페이즈 전환 연출

- **P1 -> P2**: 보안 카메라 눈들이 하나씩 꺼지며 암전된다(0.8초). 어둠이 깊어지고, 꺼지지 않은 카메라의 LED가 더 짙은 적색으로 전환된다. 서버 랙 일부에서 스파크가 튀며, 방화벽 배리어 이펙트가 보드 위에 처음 출현한다. ARIA 대사: "보안 프로토콜 2단계. 방화벽 증폭."

- **P2 -> P3**: 서버 랙이 도미노처럼 쓰러진다(1.2초). 방화벽 배리어가 산산이 깨지며 유리 파편 이펙트. 냉각 파이프가 파열되고 증기가 화면을 뒤덮었다가 걷힌다. 증기가 걷힌 자리에 역병핵 2개가 빛나고 있다. 케이블 다발 사이, 카메라가 볼 수 없는 사각지대에서 暗鳳의 날갯짓 잔상이 처음 포착된다. ARIA 대사: "보안 프로토콜 무력화 중. 재분석... 실패. 당신들은... 무엇인가?"

- **P3 -> P4 (가장 극적인 전환)**: 화면이 완전히 암전된다(1.0초). 순수한 검은 화면. 침묵. 그리고 어둠 속에서 금빛 눈 두 개가 천천히 빛난다 -- 暗鳳의 눈(0.5초 페이드인). 눈이 빛나는 순간 저주파 바람 소리. 그 직후 Umbra의 기계 구조가 다시 불을 밝히지만, 외장이 절반 이상 파손되어 暗鳳의 보라빛 윤곽이 선명하다. ARIA 대사: "이 패턴... 비효율이 아니다. 분류 불가. 재정의 필요." 동시에 이전 5개 보스의 아이콘이 화면 상단에 순차 점등되며, Past Boss Echo 시스템 활성화를 예고한다.

## 3. 페이즈별 퍼즐 기믹

### Phase 1: 감시 전개 모드

**보스 패시브 -- Shadow Core (역병핵)**
- **효과**: 전투 시작 시 보드 위 랜덤 위치에 역병핵(Plague Core) 1개 배치
- **역병핵 스탯**: HP 3, Dark 원소, 파괴 가능한 특수 오브젝트
- **역병핵 효과**: 역병핵 중심 3x3 범위 내의 모든 큐브가 **3턴마다 HP +1** (최대 HP 3까지)
- **시각**: 역병핵에서 보라색 맥동이 3x3 범위로 퍼지며, 영향 받는 큐브에 보라빛 테두리 표시. HP가 증가할 때 큐브가 짧게 진동
- **대항 수단**: 역병핵 자체를 직접 공격하여 파괴 가능 (HP 3). Light 히어로로 공격 시 상성 우위 2x -> 2타에 파괴. 다른 원소는 3타 필요
- **영향**: 역병핵을 방치하면 주변 큐브 HP가 증가하여 처리에 더 많은 AP 소모. 역병핵 우선 파괴 vs 일반 큐브 처리의 전략적 판단 강제

**보스 액티브 -- 없음** (Phase 1은 패시브만)

**학습 의도**: Ch.6-09에서 이미 경험한 역병핵 메카닉의 보스전 버전. Phase 1에서는 역병핵 1개만 등장하므로 보스전 리듬에 적응하는 구간. "역병핵을 먼저 처리하면 나머지가 수월해진다"는 핵심 전략을 확인.

### Phase 2: 방화벽 강화 모드

**보스 패시브 -- Shadow Core (역병핵, 재생성)**
- Phase 1과 동일한 역병핵 1개 활성
- **추가 규칙**: 역병핵을 파괴하면 **2턴 후 랜덤 위치에 재생성**된다. 영구적으로 제거할 수 없음
- **시각**: 파괴된 역병핵 자리에서 보라빛 잔상이 남았다가, 2턴 후 다른 위치에서 보라빛이 응축되며 새 역병핵 생성
- **재생성 규칙**: 이전 역병핵 위치에서 최소 2칸 이상 떨어진 곳에 생성 (같은 자리 반복 방지)

**보스 액티브 -- Firewall (방화벽)**
- **타이밍**: 매 4턴마다 (턴 4, 8, 12...)
- **효과**: 보드의 랜덤 1열(column)이 방화벽 쉴드로 차폐됨. 해당 열의 큐브는 **1턴 동안 타겟팅 불가** (히어로 발사가 해당 큐브를 관통하지 못함)
- **대상 선택**: 5열 중 랜덤 1열. 역병핵이 있는 열 우선 선택 (40% 가중치)
- **시각**: 선택된 열에 반투명 보라색 방화벽 배리어가 세로로 내려오고, 해당 큐브들이 어둡게 처리됨. 배리어에 ARIA 코드 문자열이 흐름
- **영향**: 1턴이라는 짧은 차폐이지만, 역병핵 열을 차폐할 경우 역병핵 파괴 타이밍이 1턴 밀림 -> HP 증가 기회 발생. 플레이어는 방화벽 타이밍을 예측하여 발사 순서를 조절해야 함

**학습 의도**: "영구적으로 제거할 수 없는 위협"의 첫 등장. 역병핵을 파괴해도 돌아온다는 것을 학습하고, "관리"의 관점으로 전환. 방화벽은 보안 시스템 보스다운 차폐 기믹으로, 타이밍 판단을 강제.

### Phase 3: 추적 프로토콜

**보스 패시브 -- Shadow Core x2 (역병핵 2개)**
- **역병핵이 최대 2개 동시 활성** (각각 독립된 3x3 범위, HP 3)
- 하나를 파괴하면 2턴 후 재생성 (Phase 2와 동일)
- 2개의 3x3 범위가 겹칠 경우, 겹치는 큐브는 **3턴마다 HP +2** (중첩 효과)
- 2개 모두 파괴 시, 2턴 후 **1개만 재생성** (잠시 숨 돌리기 허용)

**보스 액티브 -- Firewall+ (방화벽 강화)**
- **타이밍**: 매 3턴마다 (턴 3, 6, 9...) -- Phase 2의 4턴에서 빈도 증가
- 효과는 Phase 2와 동일 (1열 차폐, 1턴 지속)

**보스 액티브 -- Camera Sweep (카메라 일제 스캔)**
- **타이밍**: 매 3턴마다 (턴 3, 6, 9...) -- Firewall+와 같은 턴에 동시 발동
- **효과**: Umbra의 잔존 카메라가 보드를 일제 스캔. **보드 전체 큐브가 1턴간 공개(이미 공개 상태이므로 추가 이득 없음)되지만, 동시에 랜덤 큐브 2개의 HP가 +1 증가** ("감시가 방어를 강화한다")
- **대상 선택**: HP가 가장 낮은 큐브 2개 우선 선택 (이미 약한 대상을 보강하는 보안 AI 논리)
- **시각**: 카메라 렌즈 아이콘이 화면을 스캔하는 스윕 이펙트(좌->우, 0.5초). 선택된 큐브에 적색 레이저 포인트가 잠시 비추고, HP 증가 + 쉴드 이펙트
- **영향**: Firewall과 Camera Sweep가 동시에 발동하므로, 한 턴에 "1열 차폐 + 2큐브 HP 증가"가 동시에 발생. 보드 압박 극대화

**학습 의도**: Phase 2의 모든 메카닉이 강화되고, Camera Sweep가 추가된다. "감시 = 방어 강화"라는 Umbra의 보안 시스템 테마를 체현. 역병핵 2개의 범위 중첩은 최우선 처리 대상을 판단하는 전략적 깊이를 추가. Phase 4를 위한 최종 준비 구간.

### Phase 4: 최후 데이터 분석 -- Previous Boss Echo

**보스 패시브 -- Shadow Core x2 (Phase 3과 동일)**
- 역병핵 2개 유지, 재생성 규칙 동일

**보스 액티브 -- Previous Boss Echo (이전 보스 반향)**

Phase 4의 핵심이자 게임 전체에서 가장 독특한 기믹. ARIA가 이미 정화된 5개 보스의 전투 데이터를 호출하여, **매 턴 하나의 이전 보스 기믹을 약화된 형태로 재현한다.** 5턴 주기로 순환.

| 턴 (Phase 4 기준) | 반향 보스 | 약화 기믹 | 원본 대비 | 시각 |
|-------------------|----------|---------|---------|------|
| **턴 1, 6, 11...** | Aero (Wind) | **Wind Vortex**: 컨베이어 벨트 +1칸 시계방향 추가 이동 | 원본과 동일 (이미 약한 기믹) | 바람 소용돌이 잔상. Aero 아이콘 잠시 표시 |
| **턴 2, 7, 12...** | Hydra (Water) | **Rising Tide**: 보드 최하단 행의 큐브 1개를 1행 위로 밀어올림. 빈 셀이 없으면 미발동 | 원본 조수의 1행 제한 버전 | 파도 이펙트가 하단에서 올라옴. Hydra 아이콘 |
| **턴 3, 8, 13...** | Blaze (Fire) | **Neon Surge**: 보드 빈 셀 1곳에 HP 1 Fire 큐브 1개 생성 | 원본 네온 과부하의 1큐브 축소 버전 | 네온 불꽃 이펙트. Blaze 아이콘 |
| **턴 4, 9, 14...** | Terra (Earth) | **Foundation Shake**: 보드 내 랜덤 큐브 1개에 아머 +1 부여 (현재 HP에 +1) | 원본 기초 흔들기의 1큐브 버전 | 지진 파편 이펙트. Terra 아이콘 |
| **턴 5, 10, 15...** | Lumen (Light) | **Prism Refraction**: 보드 내 랜덤 큐브 1개의 원소를 인접 큐브의 원소로 변환 | 원본 프리즘 굴절의 1큐브 버전 | 무지개 빛 굴절 이펙트. Lumen 아이콘 |

**Echo 규칙**:
- 5턴 주기로 반드시 순환 (Aero -> Hydra -> Blaze -> Terra -> Lumen -> Aero...)
- Echo는 턴 시작 시 역병핵 효과 이전에 적용 (판정 순서: Echo -> Shadow Core HP증가 -> 플레이어 행동)
- Echo 효과는 역병핵과 중첩 가능 (예: Neon Surge로 생성된 Fire 큐브가 역병핵 3x3 범위 안이면 HP 증가 대상)
- 각 Echo 발동 시 화면 상단의 해당 보스 아이콘이 잠시 밝아지며, 해당 보스의 원소색 파동이 보드를 스친다 (0.3초)

**서사적 의미**: ARIA가 5개 정화된 서브시스템의 잔존 데이터를 최후의 보안 분석에 투입한다. "과거의 모든 패턴을 한꺼번에 재현"이라는 보안 시스템의 최종 수단. 플레이어에게는 "지금까지 배운 모든 것을 동시에 대처하라"는 종합 시험.

**학습 의도**: Phase 4는 순수한 신규 기믹 없이, 이전 5개 챕터에서 학습한 기믹의 약화판을 조합한다. 플레이어가 각 기믹의 대처법을 기억하고 있는지 확인하는 역할. 개별 Echo는 약하지만, 역병핵 x2 + 매 턴 다른 Echo가 중첩되면 보드 상황이 매 턴 변화하여 높은 적응력을 요구한다.

## 4. 보드 레이아웃

### 4.1 기본 보드 구성

| 항목 | 값 |
|------|-----|
| **보드 크기** | 7x5 (7열 x 5행) |
| **컨베이어 벨트** | 외곽 20칸 순환 |
| **히어로 그리드** | 5열 (Wind, Light, Water, Fire, Earth) |
| **보스 위치** | 보드 상단 전체 행을 차지 (별도 스프라이트, 7열 폭) |

### 4.2 초기 큐브 배치

```
Phase 1 초기 보드 (7x5):
[BOSS][BOSS][BOSS][BOSS][BOSS][BOSS][BOSS]   <- 보스 스프라이트
[ D   D   D   L   D   D   D ]
[ D   L   D   D   D   L   D ]
[ D   D   D  [P]  D   D   D ]
[ D   D   L   D   D   D   D ]
[ L   D   D   D   D   D   L ]

D = Dark (60%), L = Light (15%), 나머지 25% = Wind/Water/Fire/Earth 랜덤 혼합
[P] = 역병핵 (Plague Core, HP 3)
보스 HP 큐브는 T1 Proxy Cat (HP 1) + T2 Holo Koi (HP 2)로 구성
```

### 4.3 원소 분포

| 원소 | 비율 | 역할 |
|------|------|------|
| **Dark** | 60% | 주 원소. Proxy Cat + Holo Koi + 역병핵 |
| **Light** | 15% | Dark 상성 카운터. MEI(Light)의 주 타겟 |
| **Wind/Water/Fire/Earth** | 25% (혼합) | 이전 챕터 복습. 각각 5~8% |

### 4.4 적 구성

| 적 종류 | HP | 비율 | 특수 능력 |

- **Phase 1**: 기본 배치. Proxy Cat 주력 + Holo Koi 소수. 역병핵 1개
- **Phase 2**: Holo Koi 비율 상승 (30% -> 35%). 역병핵 재생성 시작. 방화벽 배리어 등장
- **Phase 3**: Holo Koi 비율 40%. 역병핵 2개. Camera Sweep로 랜덤 큐브 HP 증가. 보드 전반적 HP 밀도 증가
- **Phase 4**: Phase 3 기반 + 매 턴 Echo 효과로 보드 상태 동적 변화 (새 큐브 생성, HP 변경, 원소 변환, 벨트 이동 등)

### 전략 가이드

- **핵심 전략: Light 히어로 최우선 투입**. Dark 큐브에 상성 우위 2x 피해를 주며, 그림자 복제(Ch.6 고유 메카닉)를 방지한다. 역병핵(HP 3)도 Light로 2타에 파괴 가능
- **보조 전략: 5원소 균형 편성**. 보드의 25%가 Wind/Water/Fire/Earth 혼합이므로, Light 일변도 편성은 위험하다. 이전 챕터 원소 큐브를 효율적으로 처리할 수 있는 파티 구성 필요
- **벤치 활용**: 벤치 3슬롯은 Phase 4의 Echo 기믹 대응에 핵심. Neon Surge(Fire 큐브 생성)나 Prism Refraction(원소 변환)에 대응하기 위해 다른 원소 히어로를 벤치에 보관하고 적시에 투입
- **Dark 히어로 부재의 의미**: Dark 히어로가 없으므로 Dark 큐브에 동일 원소 매칭 불가. Light 이외의 원소로 Dark 큐브를 공격하면 중립 피해(1x)지만, Ch.6 그림자 복제 메카닉에 의해 복제본 생성 위험 존재. **보스전에서 그림자 복제가 발동하는지 여부는 보스 고유 기믹(역병핵/방화벽/Echo)이 우선하므로 발동하지 않음 -- 보스전은 챕터 고유 메카닉이 보스 기믹으로 대체된다**
- **Holo Koi 대응**: 허상(Decoy) 생성은 AP를 낭비하게 만든다. 연속 3회 허상 후 확정 미발동을 활용하여 타이밍을 관리. Holo Koi는 역병핵 근처에서 HP가 증가하기 전에 우선 처리 권장

## 6. 정화 시퀀스

> SPEC-022B Section 7.6 참조. 7-beat 해방 연출. 게임 전체에서 가장 극적인 정화.

**Beat 1 -- 셧다운**: 보안 카메라 눈들이 하나씩 꺼진다. 빨간 LED가 순차적으로 소멸하며 어둠이 깊어진다. 방화벽 배리어 쉴드가 유리처럼 깨진다.

**Beat 2 -- 해체**: 서버 랙이 도미노처럼 쓰러진다. 냉각 파이프에서 증기가 분출된다. 케이블이 풀려 나가며 촘촘했던 구조가 해체된다.

**Beat 3 -- 사각지대**: 모든 카메라가 꺼진 완전한 어둠. 1초간의 순수한 침묵. 화면이 완전히 검어진다.

**Beat 4 -- 두 개의 눈**: 완전한 어둠 속에서 금빛 눈 두 개가 천천히 빛난다. 暗鳳의 진짜 눈. 카메라가 아닌 진짜 눈이 처음으로 보이는 순간.

**Beat 5 -- 그림자 비상**: 暗鳳이 깊은 보라빛 날개를 펼친다. 날개는 빛이 아닌 깊은 어둠이다 -- 주변의 빛을 흡수하는 실루엣. 하지만 그 어둠은 차갑지 않다. 따뜻한 밤하늘 같은 어둠.

**Beat 6 -- 자유**: 暗鳳이 천장을 뚫고 날아오른다. 구룡성채 지상의 공원으로 달빛이 쏟아진다. 暗鳳이 달을 가로지르는 실루엣이 보인다.

**Beat 7 -- 구역 변화**: 감시 카메라가 전부 꺼진다. 서버 단지가 비활성화되며 케이블의 보라빛이 사라진다. 자연스러운 달빛과 별빛이 구룡성채 공원을 비춘다. 감시받지 않는 자유.

### 8.2 AP 예산 상세

```
총 큐브 HP: 60 (보스 본체)
역병핵 HP: Phase 1: 3 + Phase 2: 3(재생성 1~2회 = +3~6) + Phase 3: 6(재생성 포함 +6~9) + Phase 4: 6(유지)
역병핵에 의한 큐브 HP 증가 총량: 예상 +8~12
Holo Koi Decoy 추가 HP: 50% 발동률 x Holo Koi 수 = 예상 +4~6
Phase 4 Echo 추가 HP (Neon Surge + Foundation Shake): 예상 +3~5
---
총 예상 소모 HP: 60 + 18~23 (역병핵) + 4~6 (Decoy) + 3~5 (Echo) = 85~94
이론 최저 AP: 85~94
실제 필요 AP (빗나감 x1.3): 110~122
총 가용 AP (24턴 기준): ~80
벨트 효율 보정: 히어로 원소 분포 최적화 시 실효 AP ~100~110

여유도 = 100~110 / 110~122 = 0.82~1.0
-> 목표 범위 0.9~1.1의 하한에 근접. 역병핵 우선 처리 전략으로 실효 HP를 낮추면 여유도 0.9 이상 달성 가능
```

**조정 노트**: 역병핵을 방치하면 여유도 0.82 (실질 클리어 불가), 적극 관리하면 여유도 0.95 (Very Hard). 이것이 역병핵 메카닉의 밸런스 설계 의도다.

**★★★ 달성 가이드**: 20턴 제한은 Phase당 평균 5턴을 의미한다. Phase 1(HP 18)을 5턴에 처리하려면 턴당 3.6 HP 피해가 필요하며, 이는 Light 히어로의 상성 2x를 적극 활용해야 달성 가능. AP 사용률 55%+는 벤치 보관 히어로를 최소화하고, 벨트 순환을 정확히 읽어야 함을 의미한다.

### 8.4 실패 안전장치

- **역병핵 관리 힌트**: Phase 1에서 역병핵을 늦게 처리하면 주변 큐브 HP가 증가하는 것을 직접 체험하게 되어, Phase 2 이후의 전략을 자연스럽게 학습

**성가비(AP당 기대 스코어)**: 전 원소 균등. Light가 2x 피해로 AP당 가치가 높지만, Dark 큐브 비율 60%에 제한되므로 전체 AP당 기대값은 다른 원소와 균형 (Light: Dark 60% x 2x = 1.2 실효 / 타 원소: 혼합 25% x 1x + Dark 60% x 1x = 0.85 실효 -> Light 우위는 의도적 설계, 파티 편성 전략의 보상)
