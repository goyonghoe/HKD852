## 난이도 지표 (§4)

| 지표              | 공식                              | 값  | 평가                                      |
| ----------------- | --------------------------------- | --- | ----------------------------------------- |
| **총 큐브 HP**    | Σ(각 큐브 HP)                     |     |                                           |
| **총 가용 AP**    | Σ(각 히어로 AP)                   |     |                                           |
| **AP 효율**       | 총 AP / 총 큐브 HP                |     | > 1.0 필수                                |
| **원소 커버리지** | 히어로 원소 종류 / 큐브 원소 종류 |     | 1.0 = 완전 커버                           |
| **이론 최저 AP**  | 총 큐브 HP                        |     |                                           |
| **실제 필요 AP**  | 이론 최저 × 1.3~1.8               |     | 벨트 순환 고려                            |
| **여유도**        | 총 AP / 실제 필요 AP              |     | easy 1.5+ / normal 1.2~1.5 / hard 1.0~1.2 |
