## 1. 한줄 컨셉

> **"홍콩 뒷골목을 누비는 사이버펑크 용병. 자리를 비워도, 당신의 용병은 쉬지 않는다."**

세로형 오토슈터(v1)의 실패 원인이었던 **탑뷰 장르 ↔ 사이드뷰 에셋 미스매치**를 해소하고, 보유 리소스 100%가 자연스럽게 활용되는 **사이드뷰 Idle 오토배틀러**로 방향 전환.

- Idle RPG는 KR 상위 매출 47%를 차지하는 RPG 장르의 접근 가능한 진입점

## 3. 타겟 플레이어

- **1차**: 25-45세 KR 남성, MMORPG에 지쳤지만 RPG는 여전히 좋아하는 직장인
- **2차**: 글로벌 Legend of Mushroom/Capybara Go! 팬 (NA/JP)
- **세션 형태**: 하루 3-5회 × 각 3-5분 (출퇴근, 점심, 취침 전)
- **플레이 맥락**: 한 손 세로 모드 (지하철/엘리베이터 친화)

## 4. 코어 루프 (60초 세션)

```
  [복귀] 오프라인 골드·XP 챙기기 (10초)
     ↓
  [배치] 영웅 파티 확인 / 장비 교체 (선택)
     ↓
  [전투] 자동 레인 진행 (카메라 횡스크롤)
     ↓ 몬스터 처치 → 루트 자동 수집
  [진행] 스테이지 클리어 → 다음 레인
     ↓
  [성장] 레벨업 / 장비 드롭 / 스킬 포인트
     ↓
  [이탈] 오프라인 전환 (보상 누적 시작)
```

- **입력**: 스킬 버튼 3-4개 (터치) + 전투 속도 1x/2x/3x 토글
- **AFK 비율**: 70% 자동 진행 / 30% 액티브 (보스/던전)
- **핵심 감각**: 짧은 로그인에도 **수치가 눈에 띄게 오른다**

## 5. 메타 루프 (주간 진행)

| 시스템           | 기능                              | 자원        |
| ---------------- | --------------------------------- | ----------- |
| 메인 스토리 레인 | 스테이지 1-1 ~ 20-10 (챕터 단위)  | 골드·장비   |
| 일일 던전 (6종)  | 요일별 재료 던전 (무기·방어·스킬) | 재료        |
| 주간 보스 레이드 | 길드/솔로 레이드                  | 보스 코인   |
| 영웅 가챠        | 소프트 가챠 (하드 가챠 없음)      | 크리스탈    |
| 장비 +강화       | +0 ~ +20 확률 강화                | 골드·재료   |
| 펫/탈것          | 사이드킥 버프                     | 이벤트 보상 |

**진행 곡선**: 첫 7일 = 스테이지 1-1 ~ 7-10 체험 / 2주차 = 첫 벽(스테이지 10-x 보스) / 4주차 = 가챠 의존 시작

## 7. 전투 시스템

- **포지셔닝**: 사이드뷰 레인 (8-12 타일 깊이). 영웅 3-5명 좌측, 몬스터 우측 → 좌측으로 전진
- **자동 행동**: 사거리 내 최근접 타겟 공격. 스킬은 쿨다운 기반 자동 발동 (수동 토글 옵션)
- **데미지 공식 (초안)**:
  ```
  dmg = (ATK × skill_mult × level_scale) × (1 - DEF_reduction) × crit
  ```
- **전투 속도**: 1x(기본) → 2x(VIP2) → 3x(VIP5) → Offline(AFK 시)
- **스킬 슬롯**: 기본 스킬 1 + 선택 스킬 3 (영웅별 고정 풀)

## 13. 차별화 포인트

**"왜 이 게임이어야 하는가"** — 경쟁작 대비 한 가지 이상의 뚜렷한 차별화:

1. **홍콩 사이버펑크 세계관**: Legend of Mushroom(판타지), Capybara(동물) 대비 선명한 비주얼 정체성
2. **한 손 세로 UI**: 경쟁작 대부분 가로 모드 → 지하철/통근 유저 미충족 수요 공략
3. **Idle 속도 2배 기본**: 첫 1시간 완료 속도가 경쟁작 대비 1.5배 빠름 → 초반 이탈 감소
4. **한국어 1티어 품질**: 글로벌 게임의 번역체가 아닌, 처음부터 KR 작문
