# /market-research — 최신 시장 데이터 기반 리서치

## 목적

CEO의 전략/수익화/시장 진입 질문에 대해 **2025-2026년 최신 데이터**를 수집·검증하여 근거 있는 권고안을 제공합니다.

> **배경**: 과거 지식(2024년 기준)으로 2026년 시장을 제안하는 실수 방지 (실수 목록 #16)

## 자동 트리거 가이드

다음 상황에서 이 스킬을 **선행 실행**하십시오:

- CEO가 "넥스트 스텝", "수익화", "시장 진입", "뭘 팔면 좋을까", "어디서 돈 벌까" 류 질문 시
- 특정 시장/니치의 상업성을 평가할 때
- 전략적 방향 전환을 논의할 때
- 새로운 수익원 또는 사업 모델을 제안해야 할 때

**원칙**: 전략/수익 관련 답변을 내기 전에 반드시 최신 시장 데이터를 확인한다. 과거 지식 기반 추천 금지.

## 절차

### Step 1: 리서치 범위 정의

CEO 질문에서 다음을 추출합니다:

- **핵심 키워드**: 시장/제품/서비스 명칭
- **타겟 지역**: NA, EU, CN, KR, JP (CLAUDE.md 우선순위 참조)
- **평가 목적**: 진입 가능성 / 수익성 / 경쟁력 / 트렌드

인자가 없거나 모호하면 CEO에게 명확화를 요청합니다.

### Step 2: 멀티쿼리 웹 리서치

WebSearch를 **최소 5회** 실행합니다. 각 쿼리는 병렬 호출합니다.

| #   | 쿼리 패턴                                                     | 목적                        |
| --- | ------------------------------------------------------------- | --------------------------- |
| 1   | `[keyword] market size 2025 2026`                             | 시장 규모/포화도            |
| 2   | `[keyword] revenue case study 2025`                           | 실제 매출/RPM/전환율        |
| 3   | `[keyword] success story indie solo creator`                  | 성공 사례 (특히 1인/소규모) |
| 4   | `[keyword] failure saturated risk 2025`                       | 실패 사례/리스크            |
| 5   | `[keyword] 한국 시장 2025` 또는 `[keyword] korea market 2025` | 한국 시장 특수성            |

필요 시 추가 쿼리:

- `[keyword] pricing strategy`
- `[keyword] competitor landscape`
- `[keyword] [specific_region] regulation`

### Step 3: 데이터 검증

수집된 데이터에 대해:

1. **출처 신뢰도 평가**: 공식 보고서 > 업계 매체 > 블로그 > SNS
2. **날짜 확인**: **2025-2026년 데이터만 채택** — 2024년 이전 데이터는 "참고용"으로만 표기
3. **교차 검증**: 상충 데이터가 있으면 2개 이상 출처에서 확인된 수치만 HIGH 신뢰도 부여
4. **편향 필터**: 마케팅성 자료, 과대 주장 식별

신뢰도 기준:

- **HIGH**: 2개+ 독립 출처 확인, 2025-2026 데이터
- **MEDIUM**: 1개 출처이나 신뢰 매체, 또는 2024 후반 데이터
- **LOW**: 미확인, 단일 블로그/SNS, 또는 2024 이전

### Step 4: 경쟁 환경 분석

- 주요 플레이어 (Top 3-5) 식별
- 진입 장벽 (기술/자본/네트워크/규제)
- 차별화 가능 포인트
- 레드오션/블루오션 판단

### Step 5: 실현 가능성 평가

CEO의 현재 리소스 맥락을 반영합니다:

- **인력**: 1인 (AI 에이전트 보조)
- **시간**: 부업 수준 (주당 제한된 시간)
- **기술**: Claude Code + AI 도구 활용 가능
- **자본**: 최소 투자 선호
- **강점**: AI 활용 능력, 게임/콘텐츠 도메인 지식

평가 항목:

- CEO 리소스 대비 난이도: LOW / MID / HIGH
- 예상 초기 투자 (시간/비용)
- 예상 수익 구간
- Time-to-Revenue (첫 수익까지 기간)

### Step 6: 구조화 리포트 출력

아래 형식으로 출력합니다. 파일 저장이 필요하면 `outputs/market_research_[YYYYMMDD]_[topic].md`에 저장합니다.

```markdown
## Market Research Report

**주제**: [리서치 주제]
**날짜**: [YYYY-MM-DD]
**신뢰도**: [HIGH / MEDIUM / LOW] — 전체 리포트의 데이터 신뢰도

### 시장 현황

- 시장 규모: [수치 + 출처]
- 포화도: [블루오션 / 경쟁적 / 과포화]
- 성장 추세: [성장률 + 방향]

### 실측 데이터

| 지표          | 수치  | 출처     | 날짜 |
| ------------- | ----- | -------- | ---- |
| 시장 규모     | $XX B | [출처명] | 2025 |
| 평균 RPM/단가 | $XX   | [출처명] | 2025 |
| 전환율        | X.X%  | [출처명] | 2025 |

### 성공 사례

- **[사례명]**: [요약] — 출처: [URL]

### 실패/리스크 사례

- **[사례명]**: [요약] — 출처: [URL]

### 한국 시장 특수성

- [한국 시장만의 특이점, 규제, 문화적 차이]

### 경쟁 환경

| 플레이어 | 포지션      | 강점   | 약점   |
| -------- | ----------- | ------ | ------ |
| [이름]   | [시장 위치] | [강점] | [약점] |

### 실현 가능성 평가

- **CEO 리소스 대비 난이도**: [LOW / MID / HIGH]
- **예상 초기 투자**: [시간: X시간/주, 비용: $XX]
- **예상 수익 구간**: [$XX ~ $XX/월]
- **Time-to-Revenue**: [X주 ~ X개월]

### 권고안

1. **[최우선 권고]** — 근거: [데이터 기반 이유]
2. **[차순위 권고]** — 근거: ...
3. **[대안/피해야 할 것]** — 근거: ...

### 출처

- [출처1 제목](URL) — [날짜]
- [출처2 제목](URL) — [날짜]
```

## 주의사항

1. **절대 과거 지식만으로 답변하지 않는다** — WebSearch 없이 권고안을 내리지 않음
2. **"~할 수 있다"보다 "실제로 ~한 사례가 있다"를 우선** — 가능성이 아닌 실증 데이터
3. **장밋빛 전망 금지** — 리스크와 실패 사례를 반드시 포함
4. **출처 URL과 날짜를 반드시 명시** — 검증 불가능한 주장 배제
5. **한국 시장 특수성 누락 금지** — 글로벌 데이터만으로 한국 시장 판단하지 않음
