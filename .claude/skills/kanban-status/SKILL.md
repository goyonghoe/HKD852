# /kanban-status — 칸반 보드 현황 조회

## 목적
전체 칸반 보드의 태스크 현황을 CLI 테이블로 출력합니다.
프로젝트별 필터링을 지원하며, 모든 팀원이 읽기 전용으로 사용할 수 있습니다.

## 인자
- `--project <프로젝트>` (선택): 특정 프로젝트만 조회 (WanChai, Saju_Agent 등)
- `[필터]` (선택): `assignee:game-designer`, `priority:high`, `status:in_progress`, `sprint:sprint-003`, `division:game` 등
- 인자 없으면 전체 현황 요약

## 실행 절차

### 1. 데이터 로드
`PMO_Agent/kanban.json` 파일을 Read 도구로 읽습니다.

### 2. 필터 적용
인자가 있으면 해당 필드로 필터링합니다.

### 3. 출력 형식

#### 요약 헤더

## 우선순위 배지
- `critical`: 🔴🔴
- `high`: 🔴
- `mid`: 🟡
- `low`: 🟢

## 상태 매핑 (5컬럼)
- **대기**: `backlog`
- **진행 중**: `in_progress`
- **검토**: `done`, `qa_fail`, `redteam_reject`
- **QA 통과**: `qa_passed`
- **완료**: `final_done`
