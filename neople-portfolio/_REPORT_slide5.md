### 2. UX 원칙 가이드 — `ux-principles.html` (신규)

- **오버킬 7원칙**(각 원칙: D4/PoE2 근거 + 오버킬 적용 + PC/콘솔 분기 + 스크린샷 슬롯) → **PC↔콘솔 입력 적응 매트릭스** → **안티패턴 체크리스트**.
- 7원칙: ①깊이 보존·부수 복잡함만 제거 ②던파 성장루프=드랍교체 아닌 옵션커스텀 ③정보구조 공통·인터랙션만 입력별 ④탑뷰 주인공은 전장(HUD 가장자리) ⑤컨트롤러를 잔손질 형벌로 만들지 않기 ⑥복잡함은 층층이 ⑦접근성은 출시 초기 핵심축.
- 평결: "던파 코어루프를 룰 수준에서 이해 — 검색만 한 사람은 못 쓰는 수준" (만장일치 강점).
