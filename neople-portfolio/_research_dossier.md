# 오버킬 UX 문서 — 검증된 리서치 도시어 (2026-06-18)

> 디렉터 발언/사실은 모두 웹 검색으로 검증. 채용 담당자가 가짜 인용을 알아채므로 사실 기반만 사용.

## Project Overkill (네오플)

- 던전앤파이터 IP 기반 **3D 액션 RPG**. 장르가 벨트스크롤 → **탑뷰 핵앤슬래시**로 진화. 내부 레퍼런스 게임 = **Path of Exile**.
- **콘솔 플랫폼 출시 확정** (넥슨 2026년 5월 분기 실적발표). → PC + 콘솔 하이브리드 전제 성립.
- 원작 14년 전 시점 배경. 2025 하반기 출시 목표(방향성 변경으로 난항 보도).
- 출처: gamemeca, inven, namuwiki(프로젝트 오버킬), zdnet.

## Path of Exile 2 — Jonathan Rogers (Game Director)

- **핵심 철학**: "incidental complexity(부수적 복잡함)는 제거하되 depth(깊이)는 최대한 유지." 스킬젬 시스템을 훨씬 쉽게.
- 접근성 + 깊이 **동시 추구**(신규는 쉽게 진입, 하드코어는 깊이). 튜토리얼로 초반에 점진적 도입.
- **시각 명료성** 개선(특히 보스전): 중독 시 체력 오브가 초록색으로 변함.
- **콘솔 적응**: 스킬 오토타게팅(예: Glacial Cascade가 콘솔에선 얼어붙은 적에 자동 락온, PC는 위치 클릭).
- ⚠️ **약점(개선 필요)**: 컨트롤러/콘솔에서 **인벤토리·스택탭·거래 관리가 번거로움**. 컨트롤러용 UI와 마우스+키보드 UI가 **완전히 다름**, 콘솔에선 일부 요소가 축약/삭제됨. 입력 전환이 매끄럽지 않아 "스택탭·채팅·재화 쓸 땐 M&KB로 로그인하라"는 우회법 권장.
- 출처: rectifygaming, mmorpg.com(인터뷰 + 80h 컨트롤러 리뷰), theouterhaven, PoE 공식 포럼.

## Diablo IV — Joe Shely (Game Director) / Drew McCrory (Senior Lead UX & Accessibility Designer)

- **접근성을 day-one 핵심 기둥**으로(게임플레이와 동등한 비중): 리매핑, 자막 커스터마이즈, 색 대비 설정, **전리품 오디오 큐**.
- **아이템화 단순화(시즌4 "Loot Reborn", 2024.5)**: 초기엔 "화요일에 데미지" 류 상황적 어픽스가 **과복잡**하다는 비판 → 어픽스 풀 대폭 축소, **레어 2개·레전더리 3개**로 줄이고 각 어픽스를 더 강력하게. Greater Affix 인디케이터 아이콘, Codex 'equip' 검색 추가. → **디렉터가 과복잡을 인정하고 명료성 방향으로 개선**.
- **컨트롤러 UI 통합**: PC에서 M&KB/컨트롤러 모두 지원하려 UI를 통합. 액션바를 좌하단 코너로 이동 → 전투 시야 확보. 상태바 PC는 중앙/좌측, 콘솔은 코너. 주력 스킬 리바인드 가능. 카우치 협동에서 독립 메뉴.
- ⚠️ **약점(개선 필요)**: 컨트롤러 **인벤토리 관리에 버튼 입력이 과다**(D3 콘솔 대비 "슈퍼 마이크로매니지먼트"). Tempering 실패로 재료 낭비, Masterworking 랜덤·리셋 → 캐주얼 **번아웃/스트레스**.
- 출처: icy-veins(접근성 2주년), blizzardwatch(시즌4 아이템화/UI 업데이트 2020·2024), gamespot(Loot Reborn), rpgsite(컨트롤러 UI 분기 업데이트), D4 공식 포럼(컨트롤러 마이크로매니지먼트).

## 하이브리드(PC+콘솔) 교훈 — 두 게임 대조

- **통합 vs 분리**: D4는 한 UI를 양 입력에 통합(이해 쉬움). PoE2는 입력별로 **완전히 분리**해 콘솔에서 마찰/기능 누락. → 교훈: **공통 정보구조 + 입력별 인터랙션 적응**, 한쪽을 희생하지 말 것.
- **콘솔 인터랙션**: 오토타게팅(PoE2 장점), 액션바 위치로 시야 확보(D4 장점), 그러나 **인벤/거래의 버튼 과다는 둘 다 약점** → 휠/래디얼·정렬 자동화·일괄 처리 필요.
- **명료성 vs 깊이**: D4는 덜어내 즉각 판단, PoE2는 깊이를 화면에 드러냄. 던파 코어루프(누적 성장·수집)엔 **둘의 균형** — 깊이는 보존하되 진입 마찰은 제거.
- **번아웃 방지**: D4 Tempering/Masterworking·PoE2 거래 마찰 = 둘 다 "스트레스 메커니즘" → 오버킬은 반복하지 말 것.

## 적용 원칙(요지) — "장점 취하고 단점 반복 안 함"

1. 깊이는 보존, 부수적 복잡함만 제거 (PoE2 철학 차용)
2. 접근성·명료성을 day-one 기둥으로, 어픽스/정보는 강하고 적게 (D4 Loot Reborn 차용)
3. 공통 정보구조 + 입력별 인터랙션 적응 (D4 통합 장점 + PoE2 분리 실패 회피)
4. 콘솔 인벤/거래의 버튼 과다·번아웃 메커니즘 반복 금지 (둘의 공통 약점 회피)
5. 탑뷰 시야 우선 — 액션바·상태바 배치로 전투 가독성 확보 (D4 차용)
