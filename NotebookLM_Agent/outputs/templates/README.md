# 리서치 보고서 템플릿 시스템

주제 유형에 따라 최적 템플릿을 자동 선택합니다.

## 템플릿 유형

| ID | 유형 | 특징 | 적합한 주제 |
|----|------|------|------------|
| `analysis` | 분석형 | 비교 매트릭스 + 스코어카드 + 데이터 테이블 | 시장 분석, 벤치마킹, 트렌드 분석 |
| `playbook` | 플레이북형 | 타임라인 + 체크리스트 + 의사결정 트리 | 실행 가이드, 수익화 전략, How-to |
| `comparison` | 비교형 | 나란히 비교 + 레이더 차트 + 프로콘 | 도구/제품 비교, 시장 비교, 기술 선택 |
| `dashboard` | 대시보드형 | KPI 카드 + 진행률 바 + 상태 뱃지 | 현황 리포트, 성과 추적, 모니터링 |

## 자동 선택 로직

`template_selector.py`가 분석 내용의 키워드를 스캔하여 최적 템플릿을 반환합니다.

## 톤/색상 매핑

| 주제 도메인 | 프라이머리 색상 | 그라디언트 |
|------------|---------------|-----------|
| 금융/투자 | 네이비 #1e3a5f | 네이비 → 골드 |
| 기술/AI | 에메랄드 #10b981 | 에메랄드 → 블루 → 퍼플 |
| 비즈니스/수익 | 앰버 #f59e0b | 앰버 → 핑크 |
| 엔터/문화 | 핑크 #ec4899 | 핑크 → 퍼플 → 앰버 |
| 게임 | 퍼플 #a855f7 | 퍼플 → 시안 |
| 마케팅/성장 | 블루 #3b82f6 | 블루 → 에메랄드 |
